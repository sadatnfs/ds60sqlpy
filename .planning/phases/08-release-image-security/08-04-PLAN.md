|----------|-------------|
| Upstream toolchain images to worker images | Copied toolchains and refreshed digests enter learner images |
| Maven Central jars to the Spark image | Replacement jars enter the runtime classpath |
| Local agent to public GitHub main | Commits and workflow runs on the owner's repository |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-12 | Tampering | refreshed bases and copied toolchains | high | mitigate | Every reference pinned by digest and enforced by the universal pin test; digests resolved from the official registries with imagetools |
| T-08-13 | Tampering | replacement Spark jars | high | mitigate | Exact versions from Maven Central with sha256 verified in the Dockerfile; same artifact only, patch or minor bump |
| T-08-14 | Elevation of Privilege | pushes and dispatches to main | medium | mitigate | Only build-test markers or the dispatch workflow; no publish marker; explicit path staging so unrelated edits are not committed |
| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package-manager dependency; only version bumps of existing artifacts; any new name found is listed in the SUMMARY with its registry page |
