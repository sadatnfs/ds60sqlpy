# AFModel as a historical design case

Start with: tmb-016, r-049.

Outcome: Translate a historical modeling architecture into an original, inspectable panel example.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

The user's [AFModel repository](https://github.com/sadatnfs/AFModel) illustrates an important idea: a forecasting system can combine structural trends, explanatory variables, group effects and autoregressive residual behavior in a custom TMB objective. Its public source includes choices for differencing, fixed effects, group intercepts, random coefficients and autoregression. Understanding those mechanisms is more useful than copying a large historical implementation unchanged.

This course uses independently written synthetic models and neutral sensor-panel labels. It does not import historical datasets, environment paths, organization metadata or source routines. AFModel's published `AFModel/LICENSE.md` identifies MIT terms; TMB and the other cited projects have their own licenses. Scholarly and design attribution remain separate from code reuse.

### Worked case A: decompose a forecast

Write \(y_{gt}=m(t;\theta)+b_g+r_{gt}+\epsilon_{gt}\). The structural mean explains the common trend. The group effect represents a persistent offset. The residual state represents temporally evolving deviations. Observation noise represents remaining measurement variation. The companion constructs these components explicitly and prints their sum for two original synthetic panels.

This decomposition makes assumptions visible. A persistent group offset and an AR process with correlation near one can compete to explain the same low-frequency pattern. A large parameter set is not automatically a richer scientific explanation if the observed history cannot distinguish its components.

### Worked case B: forecasting residuals without leakage

At the final training time, an AR(1) residual forecast is \(\phi^h r_{gT}\). It depends on residuals computed from the fitted structural model using training data. Recomputing that model with future observations before assessing the forecast leaks information. The companion predicts three future residual means for each group using only its last training residual.

The owned compiled capstone currently uses a nonlinear trend plus independent group intercepts. The separate AR1 template studies latent residual dependence. Combining both structures into one larger model is an extension that requires new identifiability and integration checks; the course does not claim the current panel template silently includes every historical AFModel option.

### Diagnostics and answered discussion

**Why not automatically port all old flags?** Each flag expands the model space and can create incompatible combinations. Start with explicit statistical targets and qualified examples. **Does a lagged observed outcome equal a latent autoregressive residual?** No. A regression on lagged outcomes can have different measurement-error and initial-condition assumptions. **Can a model with many groups be split by group?** Only if the latent and parameter ownership contract permits it; shared fixed parameters still require one coherent objective.

Neal Marquez's [ar.matrix](https://github.com/nmmarquez/ar.matrix) offers another historical perspective on precision-based autoregressive simulation. Chapter 15 derives its relevant mathematical ideas independently. The next chapters modernize the Python-to-R boundary without copying the older PyMB implementation.

### Complete R companion

```r
time <- 0:5; trend <- 3 * exp(-.5 * time) + 1
residual_a <- c(.3, .2, -.1, .1, .05, .02)
residual_b <- c(-.2, -.1, .1, .2, .1, .04)
print(data.frame(time = time, trend = trend, panel_a = trend - .4 + residual_a, panel_b = trend + .4 + residual_b))
phi <- .6; horizon <- 1:3
print(data.frame(horizon = horizon, panel_a_residual = phi^horizon * tail(residual_a, 1), panel_b_residual = phi^horizon * tail(residual_b, 1)))
stopifnot(all(abs(phi^horizon * tail(residual_a, 1)) < abs(tail(residual_a, 1))))
```
