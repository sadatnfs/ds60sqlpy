# AR(1) states and sparse precision

Start with: tmb-014, statistics-025.

Outcome: Connect a time-series recurrence to covariance, precision and TMB density.

**Where this runs.** In the classroom, the base-R companion at the end of this chapter builds the tridiagonal AR(1) precision matrix and checks that it inverts the covariance. The compiled latent AR(1) model is `models/ar1.cpp` in the separately prepared [owned project](../projects/tmb-local/README.md), and `tests/acceptance.R` compares its Laplace objective with the exact stationary-covariance likelihood; a companion run is not a TMB compiler or rpy2 receipt, so its output is not evidence that a compiled model or the rpy2 bridge ran.

A stationary first-order autoregression can be written \(u_t=\phi u_{t-1}+\eta_t\), with \(|\phi|<1\), stationary standard deviation \(\tau\) and innovation variance \(\tau^2(1-\phi^2)\). The initial state has distribution \(u_1\sim N(0,\tau^2)\). These initial and innovation distributions together define the normalized joint density.

The covariance is \(\operatorname{Cov}(u_i,u_j)=\tau^2\phi^{|i-j|}\). Its inverse is tridiagonal: for two or more states the endpoint diagonals are \(1/[\tau^2(1-\phi^2)]\), interior diagonals are \((1+\phi^2)/[\tau^2(1-\phi^2)]\), and adjacent off-diagonals are \(-\phi/[\tau^2(1-\phi^2)]\). A single-state process has precision \(1/\tau^2\).

## Key terms

- **Stationary AR(1) process:** The recurrence \(u_t=\phi u_{t-1}+\eta_t\) with \(|\phi|<1\), whose marginal variance stays at \(\tau^2\) for every \(t\).
- **Innovation variance:** The variance \(\tau^2(1-\phi^2)\) of each new shock \(\eta_t\), chosen so the stationary variance remains \(\tau^2\).
- **Precision matrix:** The inverse covariance; for an AR(1) chain it is tridiagonal, so each state is directly linked only to its neighbors.
- **Initial state distribution:** The density of \(u_1\), here \(N(0,\tau^2)\); changing it changes the joint model, not just a numerical detail.

### Worked case A: covariance and precision agree

The companion builds both matrices for five states and verifies their product is identity. It also checks a negative correlation: a stationary AR(1) permits negative \(\phi\), causing alternating signed correlations. Our `ar1.cpp` uses `phi=tanh(phi_raw)` and `density::SCALE(density::AR1(phi), tau)(u)`, where `tau` is stationary scale rather than innovation scale.

Sparse precision reflects conditional independence: given neighboring states, distant states do not add direct conditional dependence. Sparse does not mean independent, and partitioning consecutive states into separate fits drops a boundary relationship.

### Worked case B: changing initial variance changes the model

A conditional likelihood that treats \(u_1\) as fixed omits its stationary density. That may be useful for a deliberately conditional analysis, but it differs from the stationary marginal model. The companion calculates the difference using a short observed latent sequence. The effect can be substantial when the sequence is short or correlation is near the stationarity boundary.

For observations \(y_t=\beta+u_t+\epsilon_t\), observation noise contributes \(\sigma^2I\) to the marginal covariance. The prepared acceptance compares TMB's integrated NLL to this dense covariance oracle. Noise and process variance can be weakly distinguished in short series, so inspect uncertainty and profiles before interpreting them separately.

### Diagnostics and answered discussion

**Can I just fit each time block independently in Spark?** Not without handling the boundary-state dependence or changing the target. **Does sparse factorization always use linear memory?** It depends on graph structure and fill-in after elimination; a simple chain is favorable, while general graphs can be much harder. **Is this copied from ar.matrix?** No. The course derives and implements its own tiny matrix oracle. Neal Marquez's [ar.matrix](https://github.com/nmmarquez/ar.matrix) is cited as a useful historical example of sparse autoregressive precision and simulation, with its own GPL licensing.

Continue by deciding whether complete panels are independent or share parameters and latent effects. That determines what can safely be parallelized.

### Worked case C: reading the companion's precision matrices

With \(\tau=0.7\) and \(\phi=0.6\), the common denominator is \(\tau^2(1-\phi^2)=0.49\times0.64=0.3136\). The companion's printed matrix should therefore have this pattern:

```text
      [,1]      [,2]      [,3]      [,4]      [,5]     (closed-form, phi = 0.6)
[1,]  3.188776 -1.913265  0         0         0
[2,] -1.913265  4.336735 -1.913265  0         0
[3,]  0        -1.913265  4.336735 -1.913265  0
[4,]  0         0        -1.913265  4.336735 -1.913265
[5,]  0         0         0        -1.913265  3.188776
```

The endpoint entry is \(1/0.3136\) and the interior one is \(1.36/0.3136\): interior states have two neighbors, so their conditional variance \(0.3136/1.36=0.2306\) is smaller than an endpoint's \(0.3136\). For \(\phi=-0.6\), only the off-diagonal sign flips to \(+1.913265\). The covariance, by contrast, is dense: its corner entry is \(0.49\times0.6^4=0.0635\), small but not zero. TMB's `density::AR1` evaluates the NLL through this tridiagonal structure, so a series of length \(n\) costs order \(n\) rather than the \(n^3\) of a dense Cholesky.

The second companion print compares two NLLs for \(u=(0.8,0.3,-0.1)\). The conditional version, which keeps only the two transitions, is 0.854898. Adding \(-\log\phi(0.8;0,0.7)\) for the stationary first state gives 2.070223. The 1.215 difference is a single term, but its size depends on \(u_1/\tau\), and in a fitted model it pulls \(\tau\) and \(\phi\) toward values that make the first state plausible.

### What the forecast block in `ar1.cpp` adds

The template reports \(\beta+\phi^{h+1}u_n\) as the step-\(h\) prediction and \(\tau^2(1-\phi^{2(h+1)})+\sigma^2\) as `innovation_variance`. With the acceptance values \(\phi=0.5\), \(\tau=0.7\) and \(\sigma=0.3\), the variance is \(0.49\times0.75+0.09=0.4575\) one step ahead, \(0.549375\) two steps ahead and \(0.579521\) five steps ahead, approaching \(\tau^2+\sigma^2=0.58\). This variance conditions on the last state, so it omits uncertainty in \(u_n\) itself. The `ADREPORT(prediction)` standard error carries that part, which is why a forecast interval needs both quantities added on the variance scale.

### Base-R companion (runs in the classroom)

```r
n <- 5; tau <- .7
for (phi in c(-.6, .6)) {
  covariance <- tau^2 * phi^abs(outer(1:n, 1:n, "-"))
  precision <- matrix(0, n, n)
  diag(precision) <- c(1, rep(1 + phi^2, n - 2), 1)
  precision[row(precision) == col(precision) + 1 | row(precision) == col(precision) - 1] <- -phi
  precision <- precision / (tau^2 * (1 - phi^2))
  stopifnot(max(abs(precision %*% covariance - diag(n))) < 1e-12)
  print(precision)
}
u <- c(.8, .3, -.1); phi <- .6
conditional <- -sum(dnorm(u[-1], phi * u[-length(u)], tau * sqrt(1 - phi^2), log = TRUE))
print(c(conditional_nll = conditional, stationary_nll = conditional - dnorm(u[1], 0, tau, log = TRUE)))
```
