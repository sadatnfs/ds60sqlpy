# c-017: Ownership APIs, borrowing and independent clones

## Level and prerequisites

Intermediate, approximately 120 minutes plus a later retrieval session. Direct prerequisites: `c-016`

## Learning objectives

Explain borrow, owned result, clone. Implement the six investigations with explicit checks, identify a plausible defect and defend a fresh boundary case before execution. Completing a reference is not evidence of independent mastery.

## Purpose and mental model

A reusable C component needs an ownership vocabulary. A borrowed pointer grants temporary access without transferring release responsibility. An owned result makes the caller responsible for destruction. A clone creates independent owned storage; a shallow struct copy usually does not. Document whether a function consumes its input on success, on failure, both or neither. Ambiguity produces leaks, double-free and use-after-free defects that can be difficult to diagnose after components are combined. The small text owner here has one destructor and an explicit clone operation. It never represents a shallow copy as a second independent owner.

## Vocabulary and concepts

- **Borrow:** Temporary access without taking release responsibility.
- **Owned result:** A value whose recipient must release its resources.
- **Clone:** An independent allocation containing equivalent data.

## Syntax anatomy and execution trace

The owner struct contains a char pointer and length. create allocates length plus one, copies bytes and writes a terminator. clone calls the same creation policy on a borrowed source. destroy releases and resets the owner. Use a const pointer for borrowed read access. Returning a struct by value can transfer ownership, but subsequent copies must obey the documented move-or-clone policy because C does not enforce it automatically.

## Worked example / walkthrough

### Worked example 1: Create an owned string

Create an owner for alpha.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

struct Text {
  char *data;
  size_t len;
};
bool text_create(struct Text *out, const char *source) {
  if (out == NULL || source == NULL || out->data != NULL)
    return false;
  size_t n = strlen(source);
  if (n == SIZE_MAX)
    return false;
  char *data = malloc(n + 1);
  if (data == NULL)
    return false;
  memcpy(data, source, n + 1);
  out->data = data;
  out->len = n;
  return true;
}
void text_destroy(struct Text *t) {
  free(t->data);
  t->data = NULL;
  t->len = 0;
}

int main(void) {
  /* Create an owned string */
  {
    struct Text t = {0};
    CHECK(text_create(&t, "alpha"));
    CHECK(t.len == 5 && strcmp(t.data, "alpha") == 0);
    text_destroy(&t);
  }
  puts("Worked example checks passed.");
  return 0;
}
```

**Observe:** Length is 5 and content is alpha.

The owner contains both storage and logical length. The terminator is additional storage, not part of len.

### Worked example 2: Clone independent storage

Clone cat and mutate the clone to bat.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

struct Text {
  char *data;
  size_t len;
};
bool text_create(struct Text *out, const char *source) {
  if (out == NULL || source == NULL || out->data != NULL)
    return false;
  size_t n = strlen(source);
  if (n == SIZE_MAX)
    return false;
  char *data = malloc(n + 1);
  if (data == NULL)
    return false;
  memcpy(data, source, n + 1);
  out->data = data;
  out->len = n;
  return true;
}
void text_destroy(struct Text *t) {
  free(t->data);
  t->data = NULL;
  t->len = 0;
}

int main(void) {
  /* Create an owned string */
  {
    struct Text t = {0};
    CHECK(text_create(&t, "alpha"));
    CHECK(t.len == 5 && strcmp(t.data, "alpha") == 0);
    text_destroy(&t);
  }

  /* Clone independent storage */
  {
    struct Text a = {0}, b = {0};
    CHECK(text_create(&a, "cat") && text_create(&b, a.data));
    b.data[0] = 'b';
    CHECK(strcmp(a.data, "cat") == 0 && strcmp(b.data, "bat") == 0);
    text_destroy(&a);
    text_destroy(&b);
  }
  puts("Worked example checks passed.");
  return 0;
}
```

**Observe:** The original remains cat.

Two independently allocated owners can be destroyed separately. A plain struct assignment would share the pointer and make that unsafe.

## Common pitfalls and diagnosis

Begin with the first relevant compiler warning or error. A declaration mismatch can cause many later diagnostics, so fix one cause at a time. If a check fails, compare actual and expected values and identify the earliest state transition that differs from the intended invariant. A program that compiles can still contain undefined behavior. A program that ran once without crashing can still access invalid memory.

For every pointer, identify its target object, bounds, alignment, lifetime and whether mutation is permitted. For every library call, inspect its return value before using output. For every owned resource, identify one release on each completed path. The worked examples and solutions explain the lesson-specific counterexamples; keep those distinctions rather than replacing a rejected input with a plausible default.
