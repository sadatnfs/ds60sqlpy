# mle-016: Accepted model pointers and rollback after failure

## Level and prerequisites

Advanced. Direct prerequisites: `mle-011`, `mle-014`, `mle-015`

**Outcome:** Activate and recover model state through explicit accepted versions.

## Question and mechanism

A candidate model should not become active merely because a file was written. Activation needs accepted artifact identity, interface compatibility and a reviewed decision. Keeping the current pointer separate from candidate files lets a failed candidate leave the accepted model unchanged.

The first case validates a candidate hash before replacing the pointer. A deliberately incorrect expected hash causes rejection while the old pointer bytes remain exact. The second activates a new version and deliberately returns to the prior version. These are local file-state mechanisms, not a distributed transaction across every serving replica.

Atomic visibility and durable recovery are different claims. os.replace gives a useful local replacement boundary, but power-loss durability, remote filesystems, multiple writers and deployment-wide consistency need additional design and qualification. The real Docker project restricts activation to an owned control CLI, validates model structure before publication and keeps the predictor's state mount read-only.

## Syntax and data contract

Write a candidate under a versioned name, validate its identity, write a complete pending pointer and replace the current pointer atomically. The pointer records the resolved version and hash. A failed check occurs before the active pointer changes. Preserve accepted versions and define cleanup separately from activation.

## Worked case 1: Reject a bad candidate before activation

The first case activates v1, records the exact pointer bytes and attempts a v2 activation with a wrong hash. The old pointer must remain unchanged. This tests a specific failure boundary rather than only the successful path.

**Expected evidence:** The failed candidate leaves the active v1 pointer byte-identical.

```python
import contextlib
import hashlib
import json
import tempfile
from pathlib import Path


def activate(root, version, model, expected_hash):
    candidate = root / (version + ".json")
    candidate.write_text(json.dumps(model, sort_keys=True))
    actual = hashlib.sha256(candidate.read_bytes()).hexdigest()
    if actual != expected_hash:
        raise ValueError("candidate hash mismatch")
    temporary = root / "current.pending"
    temporary.write_text(json.dumps({"version": version, "sha256": actual}))
    temporary.replace(root / "current.json")


def example_one():
    with tempfile.TemporaryDirectory() as d:
        root = Path(d)
        model = {"weight": 2.0}
        encoded = json.dumps(model, sort_keys=True).encode()
        expected = hashlib.sha256(encoded).hexdigest()
        activate(root, "v1", model, expected)
        before = (root / "current.json").read_bytes()
        with contextlib.suppress(ValueError):
            activate(root, "v2", {"weight": 99.0}, "0" * 64)
        assert (root / "current.json").read_bytes() == before
        return {"failed_candidate_kept_active_v1": True}


if __name__ == "__main__":
    print(example_one())
```


## Worked case 2: Perform a deliberate rollback

The second case activates v1, then v2, then v1 again. It checks the final version and absence of a pending pointer. A rollback is recorded as an explicit action, not hidden by deleting candidate evidence.

**Expected evidence:** The accepted version returns to v1 with no pending pointer file.

```python
import hashlib
import json
import tempfile
from pathlib import Path


def activate(root, version, model, expected_hash):
    candidate = root / (version + ".json")
    candidate.write_text(json.dumps(model, sort_keys=True))
    actual = hashlib.sha256(candidate.read_bytes()).hexdigest()
    if actual != expected_hash:
        raise ValueError("candidate hash mismatch")
    temporary = root / "current.pending"
    temporary.write_text(json.dumps({"version": version, "sha256": actual}))
    temporary.replace(root / "current.json")


def example_two():
    with tempfile.TemporaryDirectory() as d:
        root = Path(d)
        for version, weight in [("v1", 2.0), ("v2", 3.0), ("v1", 2.0)]:
            model = {"weight": weight}
            encoded = json.dumps(model, sort_keys=True).encode()
            activate(root, version, model, hashlib.sha256(encoded).hexdigest())
        assert json.loads((root / "current.json").read_text())["version"] == "v1"
        assert not (root / "current.pending").exists()
        return {"deliberate_pointer_rollback": True, "accepted_version": "v1"}


if __name__ == "__main__":
    print(example_two())
```

## Diagnose errors and misleading results

If an invalid candidate becomes active, inspect validation order. If a rollback changes predictions unexpectedly, inspect feature/preprocessing compatibility and artifact identity. If a response is uncertain, reconcile the current version before repeating or cleaning operations.
