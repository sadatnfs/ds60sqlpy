# llm-001: learner evidence worksheet

Read [the companion guide](../guides/llm-001.md) for definitions and the two
published walkthroughs. Work in saved notes or your own copy. Keep your first
prediction, the arithmetic/table you used, and your revised conclusion.
No code execution, remote model or installation is required.

## Exercises

1. **Classify six claims.** Classify these: a fixed mask blocks later keys; a table has 2/3 correct records; all future outputs are true; this fixture has no observed failures; no observed failures means zero risk; a supplied score matrix has one row per query.

2. **Compute two accuracies.** Use q1=A/correct, q2=A/correct, q3=B/incorrect and compute record-weighted versus equal-family accuracy.

3. **Challenge fluent correctness.** Use the 7+8 answer in the walkthrough. State which universal claim it contradicts and which broad negative claim it does not establish.

4. **Detect repeated evidence.** Duplicate q1 using the same ID and family. Decide whether the duplicate should count as another independent question.

5. **Refuse an empty accuracy.** Evaluate no questions and decide whether accuracy is zero, one, or undefined.

6. **Transfer to a new family balance.** Use three correct questions from family A and one incorrect question from family B. Compare record and family weighting, then write a bounded report.

## Before solution comparison

State one result you can defend and one claim the fixture cannot support.
Use the companion guide's Expected/Verify checks before opening solutions.
