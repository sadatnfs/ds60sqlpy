# AR(1) states and sparse precision

Start with: tmb-014, r-049.

Outcome: Connect a time-series recurrence to covariance, precision and TMB density.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A stationary first-order autoregression can be written \(u_t=\phi u_{t-1}+\eta_t\), with \(|\phi|<1\), stationary standard deviation \(\tau\) and innovation variance \(\tau^2(1-\phi^2)\). The initial state has distribution \(u_1\sim N(0,\tau^2)\). These initial and innovation distributions together define the normalized joint density.

The covariance is \(\operatorname{Cov}(u_i,u_j)=\tau^2\phi^{|i-j|}\). Its inverse is tridiagonal: for two or more states the endpoint diagonals are \(1/[\tau^2(1-\phi^2)]\), interior diagonals are \((1+\phi^2)/[\tau^2(1-\phi^2)]\), and adjacent off-diagonals are \(-\phi/[\tau^2(1-\phi^2)]\). A single-state process has precision \(1/\tau^2\).

### Worked case A: covariance and precision agree

The companion builds both matrices for five states and verifies their product is identity. It also checks a negative correlation: a stationary AR(1) permits negative \(\phi\), causing alternating signed correlations. Our `ar1.cpp` uses `phi=tanh(phi_raw)` and `density::SCALE(density::AR1(phi), tau)(u)`, where `tau` is stationary scale rather than innovation scale.

Sparse precision reflects conditional independence: given neighboring states, distant states do not add direct conditional dependence. Sparse does not mean independent, and partitioning consecutive states into separate fits drops a boundary relationship.

### Worked case B: changing initial variance changes the model

A conditional likelihood that treats \(u_1\) as fixed omits its stationary density. That may be useful for a deliberately conditional analysis, but it differs from the stationary marginal model. The companion calculates the difference using a short observed latent sequence. The effect can be substantial when the sequence is short or correlation is near the stationarity boundary.

For observations \(y_t=\beta+u_t+\epsilon_t\), observation noise contributes \(\sigma^2I\) to the marginal covariance. The prepared acceptance compares TMB's integrated NLL to this dense covariance oracle. Noise and process variance can be weakly distinguished in short series, so inspect uncertainty and profiles before interpreting them separately.

### Diagnostics and answered discussion

**Can I just fit each time block independently in Spark?** Not without handling the boundary-state dependence or changing the target. **Does sparse factorization always use linear memory?** It depends on graph structure and fill-in after elimination; a simple chain is favorable, while general graphs can be much harder. **Is this copied from ar.matrix?** No. The course derives and implements its own tiny matrix oracle. Neal Marquez's [ar.matrix](https://github.com/nmmarquez/ar.matrix) is cited as a useful historical example of sparse autoregressive precision and simulation, with its own GPL licensing.

### Complete R companion

```r
n <- 5; tau <- .7
for (phi in c(-.6, .6)) {
  covariance <- tau^2 * phi^abs(outer(1:n, 1:n, "-"))
  precision <- matrix(0, n, n)
  diag(precision) <- c(1, rep(1 + phi^2, n - 2), 1)
  precision[row(precision) == col(precision) + 1 | row(precision) == col(precision) - 1] <- -phi
  precision <- precision / (tau^2 * (1 - phi^2))
  stopifnot(max(abs(precision %*% covariance - diag(n))) < 1e-12)
  print(precision)
}
u <- c(.8, .3, -.1); phi <- .6
conditional <- -sum(dnorm(u[-1], phi * u[-length(u)], tau * sqrt(1 - phi^2), log = TRUE))
print(c(conditional_nll = conditional, stationary_nll = conditional - dnorm(u[1], 0, tau, log = TRUE)))
```
