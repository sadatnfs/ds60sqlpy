# Day 07 — Week 1 Project: From Questions to Queries (Companion Guide)

Goal
- Apply Days 01–06 to deliver a small analytical story: business questions, validated queries, and a short write-up.

Deliverables
- 3–5 questions (e.g., top categories, new-vs-returning customers, zero-sales products)
- Reusable SQL snippets with parameters (dates, segments)
- A brief narrative (what you learned, caveats, next steps)

Checklist
1) Define the audience and the decisions your report informs.
2) Validate each join and aggregation (sanity-check counts, totals).
3) Include a data quality section (missing values, outliers, NULL semantics).
4) Save queries with clear names; parameterize dates with psql variables if useful.

Stretch goals
- Build a view that encapsulates core joins for reuse.
- Provide both summary and detail queries with drill-through keys.

Rubric
- Correctness, clarity, performance (reasonable), documentation.
