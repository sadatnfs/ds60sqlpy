# viz-002: Aggregation, missingness and distribution views

## Level and prerequisites

Beginner. Direct prerequisite: `viz-001`. Review `statistics-006` for empirical distributions and measurement grain.

## Learning objective

Build a histogram and empirical cumulative distribution from the same cleaned observations, explaining missingness and bin normalization. Use the Python or JavaScript Plotly variant in the prepared classroom; all inputs are inline and offline.

## Define what each mark means

Durations are 1,1,2,2,3,4,6,8,10,12 minutes plus one missing value. Keep ten observed values and report the missing count. Replacing missing with zero would claim an immediate completion that was never observed. A histogram aggregates observations into intervals; an ECDF reports the fraction at or below each observed value without choosing bins.

## Worked case: unequal bin widths

Use edges 0,3,6,9,13. The first three bins are left-closed/right-open and the final bin includes its upper endpoint. Counts are 4,2,2,2. Widths are 3,3,3,4. For density height, divide count by both observed sample size and bin width. Heights are approximately .1333,.0667,.0667,.05 per minute.

\[
\sum_j \text{density}_j\,\text{width}_j=1.
\]

Equal count does not imply equal density when widths differ. Bar area represents probability here; raw counts on unequal-width bars would encode a different quantity. The reference calculates bins explicitly so the boundary policy is inspectable rather than delegated to automatic bin choices.

## Contrasting case: ties in an ECDF

There are two observations at one and two at two. The CDF jumps to .2 at one and .4 at two. Aggregate ties before drawing steps, and include a zero-probability point before the first observation. A horizontal-then-vertical line shape implements the chosen right-continuous display. Linear interpolation would imply probability increasing between values even though no observations occur there.

Both views summarize this sample; neither establishes the population distribution. The small table reports bin boundaries, counts and density. The caption states the denominator ten and the excluded missing observation.

## Six progressive exercises

1. **Trace boundaries.** Assign each duration to a bin. Expected evidence: 4,2,2,2 and total ten. Hint: decide where exact boundary values three and six belong.
2. **Compute density.** Normalize counts using sample size and width. Expected evidence: the sum of bar areas is one. Hint: density units are inverse minutes.
3. **Change bins.** Use edges 0,6,13. Expected evidence: counts 6,4 and unequal widths 6,7. Hint: recompute geometry and normalization together.
4. **Expose a bad missing-value policy.** Replace the missing value with zero and explain which population statement changed. Expected evidence: eleven claimed durations and a changed ECDF. Hint: do not call this a harmless display edit.
5. **Render the tied ECDF.** Show jumps .2 at one and .4 at two. Expected evidence: the curve reaches one at twelve and does not rise between observations. Hint: group equal values before cumulative summation.
6. **Transfer to rates.** Compare two groups of sizes ten and twenty using probability density rather than raw counts. Expected evidence: both density areas are one, with sample sizes stated. Hint: equal chart heights need not mean equal event totals.

## Common mistakes and next step

Check counts before colors. An off-by-one bin boundary can preserve the grand total while changing the shape. Never reuse a count axis label after switching to density. Add a readable table and caption because an interactive hover is not an accessible explanation of bin semantics.
