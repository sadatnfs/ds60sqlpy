## Outcome and mechanism

Deliver a self-contained analysis that validates inputs, joins metadata, summarizes groups and reports a bounded conclusion.

An analytical deliverable needs more than a final chart or scalar. A reviewer should be able to identify the input records, their grain, the admission rules, the grouping definition and the numerical meaning of each output. The capstone combines the earlier contracts into one small original pipeline rather than introducing an unrelated external dataset.

The synthetic input contains one measurement per record ID and a segment key. A validated dimension supplies segment labels. The pipeline rejects invalid keys or negative/nonfinite measurements according to its declared policy, then reports admitted counts and group sums/means. Keeping this ledger prevents an attractive average from concealing dropped records or a duplicated join.

A summary should retain enough state to reconcile. Group observed counts sum to the admitted count, and group sums sum to the admitted amount. The overall observation mean is reconstructed from those totals, not by averaging group means indiscriminately. Sort the final report by a stable group label so a repeated run can compare its structure directly.

The numerical result is descriptive for this synthetic admitted population. It does not establish a treatment effect, a representative survey or a predictive model. The next chapters develop exploratory analysis, uncertainty and modeling assumptions. A good handoff states those limits alongside the actual checked outputs, with source and environment metadata sufficient to reproduce the computation.

## Worked examples

### Example 1: Validate and enrich a small measurement table

```r
raw <- data.frame(id = c("R1", "R2", "R3", "R4"), segment = c("A", "B", "A", "B"), amount = c(10, 20, NA_real_, 40))
dimension <- data.frame(segment = c("A", "B"), label = c("Alpha", "Beta"))
stopifnot(!anyDuplicated(raw$id), !anyDuplicated(dimension$segment))
keep <- is.finite(raw$amount) & raw$amount >= 0
admitted <- raw[keep, , drop = FALSE]
index <- match(admitted$segment, dimension$segment)
stopifnot(!anyNA(index))
admitted$label <- dimension$label[index]
stopifnot(nrow(admitted) == 3L, sum(admitted$amount) == 70)
print(admitted)
```

**Expected observation:** Three admitted records, total 70.

The unknown measurement is excluded under a finite-nonnegative policy, while every admitted segment has exactly one dimension match.

### Example 2: Reconcile group and overall summaries

```r
data <- data.frame(label = c("Alpha", "Beta", "Beta"), amount = c(10, 20, 40))
groups <- split(data$amount, data$label)
count <- vapply(groups, length, integer(1))
total <- vapply(groups, sum, numeric(1))
report <- data.frame(label = as.character(names(groups)), count = unname(count), total = unname(total), mean = unname(total / count))
stopifnot(sum(report$count) == nrow(data), sum(report$total) == sum(data$amount))
stopifnot(isTRUE(all.equal(sum(report$total) / sum(report$count), 70 / 3)))
print(report)
```

**Expected observation:** Alpha count 1, total 10, mean 10; Beta count 2, total 60, mean 30.

Alpha has one admitted record and Beta has two. The final observation mean uses all three rather than equal weighting of the two group means.
