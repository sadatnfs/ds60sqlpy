# Airflow workshop maintenance

Use the root/course guidance and repository Add a learning path skill. This is an
owned optional local project, not an ordinary pad executor or production cluster.
Keep Airflow 3.3.2 and its Python 3.12 constraints/locks together. The upstream
image and explicit isolated-Core fallback have separate qualification evidence.

Use the explicit CronDataIntervalTimetable and validate actual full UTC-day
intervals. Daily shorthand produced zero-duration trigger windows during initial
qualification. Run IDs are not interval identifiers: inspect logical date,
run-after and interval fields. Never rewrite old Dag Run history to hide a change.
Retain the original diagnostic and qualify a changed fixture contract explicitly.

Asset consumers capture one immutable per-run source manifest before mapping.
Retries reuse that reference; both regions must use the same observed versions.
Reconcile saved summaries with their own versions, including older pre-correction
ones. XCom carries bounded references, not an unbounded dataset.

Keep the finite two-day fixture, intentional first failure, idempotent partition
write, scoped correction, one-slot pool and redacted SDK connection check. Existing
pool configuration is retained on resume. Readback never triggers or recreates work.
Do not install providers from task code or perform side effects while parsing DAGs.

Preserve source, metadata, logs and outputs as separate state categories. Follow
strict ownership/native-image checks, exact-container resume and confirmed scoped
deletion. Never mount an engine socket, use unrelated credentials, run global prune
or delete learner data as a repair. A local SimpleAuth/SQLite demonstration does
not establish PostgreSQL deployment or high availability.

For changes, run focused pure-data/policy tests and real native Docker gates for
scheduled intervals, retries, asset/map/pool, connection rejection, browser login,
source-bound readback, pool-edit retention, exact resume and replacement. Local
ARM64 acceptance is separate from native AMD64 CI and from upstream descriptors.
