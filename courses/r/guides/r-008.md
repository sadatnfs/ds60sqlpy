## Outcome and mechanism

Construct and subset matrices while distinguishing elementwise arithmetic from a matrix product.

A matrix is an atomic vector with a two-element dim attribute. Its entries share one storage type. By default matrix fills columns first, so matrix(1:6, nrow=2) has first column 1,2 and second column 3,4. The optional byrow argument changes how the supplied sequence is arranged, not the meaning of later row and column indices.

The expression a * b multiplies corresponding entries. The expression a %*% b computes a matrix product and requires compatible inner dimensions. Those operations answer different questions even when both are syntactically valid. In a design-matrix calculation, rows usually represent observations and columns represent features; a coefficient column then produces one prediction per observation.

Subsetting can drop a dimension. m[,1] often returns a vector, whereas m[,1, drop=FALSE] preserves a one-column matrix. A function that requires two-dimensional input should retain and test its shape rather than relying on the number of selected columns being greater than one. Empty or single-column cases often expose this boundary.

Basic linear algebra also requires numerical assumptions. A square matrix is not automatically invertible. Prefer solving a system with solve(A, b) when the goal is a solution rather than constructing an inverse by habit. Later statistical work will revisit conditioning, rank and stable decompositions; these examples use tiny nonsingular systems with an explicit residual check.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Matrix | An atomic vector with two dimensions. |
| Column-major order | The order in which R fills and stores ordinary matrix entries. |
| Elementwise multiplication | The * operator applied to corresponding entries. |
| Matrix product | The %*% operation combining rows and columns. |

## Read the syntax

matrix(data, nrow=...) declares shape, t transposes it, dim reports it and drop=FALSE retains it during extraction. For A of shape m by n and beta of shape n by one, A %*% beta has shape m by one.

## Worked examples

### Example 1: Rows, columns and a prediction

```r
design <- cbind(intercept = c(1, 1, 1), x = c(0, 1, 2))
beta <- c(2, 3)
prediction <- design %*% beta
stopifnot(identical(dim(prediction), c(3L, 1L)))
stopifnot(identical(as.numeric(prediction), c(2, 5, 8)))
print(prediction)
```

**Expected observation:** 2,5,8 in a 3 by 1 matrix.

Each row combines an intercept and one feature with the same coefficient vector. Matrix multiplication preserves one output per observation.

### Example 2: Solve and check a small system

```r
a <- matrix(c(2, 0, 0, 4), nrow = 2)
b <- c(6, 8)
solution <- solve(a, b)
stopifnot(isTRUE(all.equal(solution, c(3, 2))))
stopifnot(max(abs(a %*% solution - b)) < 1e-12)
stopifnot(is.matrix(a[, 1, drop = FALSE]), is.null(dim(a[, 1])))
print(solution)
```

**Expected observation:** Solution 3,2; residual below tolerance.

The residual checks the solved equation. The extraction comparison shows why a one-column matrix needs an explicit shape policy.
