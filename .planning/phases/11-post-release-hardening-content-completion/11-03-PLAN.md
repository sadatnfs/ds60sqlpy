# Plan 11-03: let the R worker build packages from source

## Objective

Learners can `install.packages()` a source package with C, C++ or Fortran code
in the R worker (HARD-04).

## Tasks

1. Tracer: keep `gcc g++ gfortran make` and the C library headers in
   `docker/workers/Dockerfile.r` (drop the purge), and keep the R `Makeconf`
   pointing at the installed compilers.
2. Add a qualification check that builds and loads a tiny package with C and
   Fortran sources (`R CMD INSTALL` into a temporary library) in CI, and a
   static test that the purge cannot return.
3. Account for the compiler and header packages in the CVE policy only through
   real fixes or justified pending-owner entries (with 11-04).

## Verification

- R worker build and qualification green in CI with the package-build check.
