# Prediction and uncertainty with sdreport

Start with: tmb-009, tmb-015.

Outcome: Report distinct intervals for a mean, a latent state and a future observation.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

The word prediction hides several different targets. A fitted mean for an observed group, a future state of that same group, a new observation and a new group's outcome have different uncertainty. State the target before calling any reporting function.

For the AR(1) observation model, conditional on the current latent state and fixed parameters,
\[
E[y_{T+h}\mid u_T]=\beta+\phi^h u_T,
\qquad \operatorname{Var}(y_{T+h}\mid u_T)=\tau^2(1-\phi^{2h})+\sigma^2.
\]
The variance includes future state innovations and new observation noise. It does not yet include uncertainty about the estimated current state or fixed parameters.

### Worked case A: same-group forecast horizon

The companion prints the conditional mean and future innovation variance at horizons one through six. The state influence decays toward the fixed intercept while the innovation variance approaches \(\tau^2+\sigma^2\). A negative correlation alternates the sign of the state contribution; uncertainty still involves the squared persistence.

Our AR1 model AD-reports the conditional mean and plain-reports the innovation variance. A `sdreport` standard error for the conditional mean addresses estimated-quantity uncertainty under its local approximation. Combining it with future innovation variance can produce an approximate predictive variance, but derived components and dependence assumptions must be justified. Do not label every `Std. Error` column a prediction interval.

### Worked case B: a new group

In a random-intercept model, the expected new-group effect is zero, while its variance is \(\tau^2\). A same-group fitted intercept can use information from existing measurements; a genuinely new group cannot. The companion compares a known-group conditional mean standard error with a simplified new-observation uncertainty that adds group and observation variance. It explicitly treats variance components as known for this illustration.

The general law of total variance is \(\operatorname{Var}(Y)=E[\operatorname{Var}(Y\mid\Theta)]+\operatorname{Var}(E[Y\mid\Theta])\). It explains why conditional-mean uncertainty alone is too narrow for future observations. Nonlinear transforms, weak identification and variance boundaries can make a Gaussian delta approximation poor; simulation or likelihood profiles can provide a more suitable summary.

### Diagnostics and answered discussion

**Does `sdreport` sample a posterior?** No. Its covariance calculations use local approximations to the likelihood and latent structure. **Can I forecast a group not represented in `u` using `group_pred`?** The current panel project intentionally rejects unknown group indices. New-group forecasting requires a separate target with new latent variation, not an out-of-bounds access. **Should I invert the full latent precision?** Only if the scientific output needs it and the size is manageable. Selected predictions are often sufficient.

See the [sdreport reference](https://cran.r-project.org/web/packages/TMB/TMB.pdf). Validate interval behavior through simulation and time-respecting held-out data rather than relying on a well-formatted table.

### Parameter uncertainty, state uncertainty and observation noise

For a conditional mode \(\hat u(\theta)\), a first-order covariance decomposition contains conditional curvature \(H_{uu}^{-1}\) plus the fixed-parameter sensitivity contribution \(J V_\theta J^T\), where \(J=d\hat u/d\theta\). Cross-covariances also matter when a prediction combines fixed and latent components. Computing a fitted intercept's standard error by adding separate variances and ignoring their covariance can be wrong.

`sdreport` implements its documented generalized delta approximation. `ignore.parm.uncertainty=TRUE` intentionally omits one uncertainty source and must be labeled. `getJointPrecision=TRUE` requests an additional joint precision representation; requesting it is not the same as safely materializing a dense covariance for every state. For a large forecast table, select the scientifically relevant contrasts and preserve their grouping and units.

### Complete R companion

```r
h <- 1:6; phi <- .7; tau <- .8; sigma <- .3; current_state <- 1.2; beta <- 2
print(data.frame(horizon = h, mean = beta + phi^h * current_state, innovation_variance = tau^2 * (1 - phi^(2 * h)) + sigma^2))
known_mean_se <- .1
new_observation_sd <- sqrt(known_mean_se^2 + tau^2 + sigma^2)
print(c(mean_se = known_mean_se, new_group_observation_sd = new_observation_sd))
stopifnot(new_observation_sd > known_mean_se, all(diff(tau^2 * (1 - phi^(2 * h)) + sigma^2) > 0))
```
