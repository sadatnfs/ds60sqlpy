## Outcome and mechanism

Assemble a tested analytical value object with unique record identity, explicit missingness, compatible aggregation and a documented package continuation.

A small analytical package should make its scientific data contract visible. This capstone represents a batch of scalar measurements: each row has one unique nonempty identifier, one numeric value and a shared unit. An observed NA is permitted as missing data; NaN and infinities are rejected. The constructor checks equal lengths and stores a value object. These rules prevent accidental recycling, duplicate records and silent changes of measurement scale before a summary is calculated.

The public operations are metric_batch, summary and combine_batches. The summary method reports row, observed and missing counts, an observed-value mean and the unit. An empty or entirely missing batch has no observed mean and returns NA_real_. The calculation selects observed entries before arithmetic, avoiding the mistaken assumption that multiplying NA by a zero indicator removes it. Missingness is a recorded property of the fixture, not evidence that excluding missing observations yields an unbiased population estimate.

Combining two batches concatenates their records after checking both values and matching units. The constructor then rejects duplicate identifiers across the combined data. This prevents a repeated record from receiving double weight through a convenient concatenation. It does not automatically reconcile conflicting observations, convert units or infer whether two different identifiers describe the same entity. Those policies require additional domain evidence.

A public method validates even a class-labeled object because S3 labels can be forged or fields modified. The helper reconstructs a checked value and the operations return ordinary lists suitable for inspection. No global accumulator is shared between calls. The reference verifies that failed combinations leave the original inputs unchanged and that a saved summary remains a value after later objects are constructed.

The tests are derived from the contract: known arithmetic, missingness denominators, all-missing and empty inputs, unequal lengths, duplicate IDs, nonfinite values, unit mismatches and forged objects. A final passing marker means these explicit checks passed for this program. It is not an exhaustive proof of correctness or scientific validity. Keep new regression cases when a real defect is discovered rather than asserting only that code runs.

## Read the syntax

metric_batch(ids,values,unit) creates the validated S3 object. summary.metric_batch participates in base summary dispatch. combine_batches checks equal units and delegates duplicate detection to the constructor. For observed indicators \(m_i\), the mean is \(\sum_{i:m_i=1}x_i/\sum_i m_i\) only when at least one value is observed. The code subsets before summing to preserve NA semantics.

## Worked examples

### Example 1: A summary carries its denominator and units

```r
metric_batch <- function(ids, values, unit) {
  if (!is.character(ids) || anyNA(ids) || any(!nzchar(ids)) || anyDuplicated(ids)) {
    stop("ids must be unique nonempty strings", call. = FALSE)
  }
  if (!is.numeric(values) || is.complex(values) || !is.null(dim(values)) ||
    any(is.nan(values)) || any(is.infinite(values))) {
    stop("values must be a numeric vector with only finite values or NA", call. = FALSE)
  }
  if (length(ids) != length(values)) stop("ids and values must have equal length", call. = FALSE)
  if (!is.character(unit) || length(unit) != 1L || is.na(unit) || !nzchar(unit)) {
    stop("unit must be one nonempty string", call. = FALSE)
  }
  structure(list(ids = ids, values = as.double(values), unit = unit), class = "metric_batch")
}
validate_batch <- function(x) {
  if (!inherits(x, "metric_batch")) stop("expected a metric_batch")
  metric_batch(x$ids, x$values, x$unit)
}
summary.metric_batch <- function(object, ...) {
  x <- validate_batch(object)
  observed <- !is.na(x$values)
  list(
    rows = length(x$ids), observed = sum(observed), missing = sum(!observed),
    mean = if (any(observed)) mean(x$values[observed]) else NA_real_, unit = x$unit
  )
}
combine_batches <- function(x, y) {
  x <- validate_batch(x)
  y <- validate_batch(y)
  if (!identical(x$unit, y$unit)) stop("incompatible batch units")
  metric_batch(c(x$ids, y$ids), c(x$values, y$values), x$unit)
}

a <- metric_batch(c("a", "b", "c"), c(2, NA_real_, 6), "ms")
s <- summary(a)
stopifnot(s$rows == 3L, s$observed == 2L, s$missing == 1L, s$mean == 4, s$unit == "ms")
b <- metric_batch("d", 8, "ms")
combined <- combine_batches(a, b)
stopifnot(summary(combined)$rows == 4L, summary(combined)$observed == 3L)
stopifnot(isTRUE(all.equal(summary(combined)$mean, 16 / 3)))
print(summary(combined))
```

**Expected observation:** Four rows, three observed, one missing; mean 16/3 ms.

The missing row remains in the row count but not in the observed mean denominator. The new record contributes eight milliseconds once. The result describes the admitted records without claiming that missingness is random.

```r
assert_error <- function(expr, pattern) {
  message <- tryCatch(
    {
      force(expr); NULL
    },
    error = conditionMessage
  )
  stopifnot(is.character(message), length(message) == 1L, grepl(pattern, message))
}

a <- metric_batch(c("a", "b"), c(2, 4), "ms")
before <- a
assert_error(combine_batches(a, metric_batch("b", 9, "ms")), "unique nonempty")
assert_error(combine_batches(a, metric_batch("c", 1, "s")), "incompatible batch units")
stopifnot(identical(a, before))
missing <- metric_batch(c("m", "n"), c(NA_real_, NA_real_), "ms")
stopifnot(summary(missing)$observed == 0L, is.na(summary(missing)$mean))
print(summary(missing))
```

**Expected observation:** Both invalid combinations rejected; all-missing mean NA and observed count 0.

The two failed combinations test different boundaries: duplicate identity and incompatible units. Neither modifies the input. The all-missing case returns missing output deliberately rather than inventing a zero average.

## Reference review

The capstone reference checks independent arithmetic as well as the representation invariant. The equal-length rule prevents recycling; uniqueness prevents a repeated identifier from contributing twice; unit compatibility prevents a silent scale change. Missing observations remain visible in the summary ledger.

The forged-object test establishes why class labels alone are insufficient. The unchanged-input assertions support the chosen value-object interface, while the proposed NAMESPACE lines identify the optional package boundary. No package has been installed or published by this script, and passing its checks does not make missingness ignorable or supply a causal design.
