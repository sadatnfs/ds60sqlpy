## Learning objectives

Build offline from reviewed inputs and name license/version obligations.

## Vocabulary and concepts

Reproducibility means another environment can reconstruct the same declared build inputs. Vendoring keeps an approved source dependency locally. A CMake target names include paths, features and link requirements so consumers inherit the right settings. A lock records exact dependency identities but still needs an actual offline build check.

## Syntax and mechanism

Use target_include_directories and target_compile_features on named targets instead of machine-specific global paths. An offline default must not call FetchContent to download missing sources. Delivery also includes licenses and platform/compiler receipts.
