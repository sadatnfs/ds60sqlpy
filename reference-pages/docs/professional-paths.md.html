Professional and specialization paths#

The historical Days 1–60 remain stable. Named modules add the relational foundations and professional practice that do not fit honestly into one more linear countdown. The generated catalog is the source of truth for exact prerequisites and artifact paths:

The classroom lists these routes with their prerequisites. Contributors can inspect the legacy catalog with their prepared POSIX/WSL interpreter:

uv run --no-sync python scripts/course.py catalog

Choose a lane from demonstrated prerequisites. You do not need every specialization to call the shared curriculum complete.

Add relational engineering after SQL fundamentals#

A new SQL learner begins with the three tiny-table starter labs, sql-start-01 through sql-start-03, then SQL Day 1: SELECT, WHERE, and ORDER BY. The named relational-engineering modules then deepen responsibilities at the point where their prerequisites make sense:

  1. Complete SQL Days 1–15.
  2. Take sql-found-01 - relational design, DDL, and constraints.
  3. Complete the transaction and locking sequence through SQL Day 39.
  4. Take sql-found-02 - versioned migrations and safe evolution.

Both named scripts use isolated disposable schemas; SQL Days 1–60 continue to query the seeded training schema.

Evidence before completion#

A module is complete when the learner can:

  1. reproduce the main behavior from a clean local state;
  2. pass the module's self-check or tests;
  3. explain one failure mode and one tradeoff without the solution open; and
  4. distinguish local/fake evidence from any optional live or platform-specific evidence.

Record classroom progress in the browser lesson workspace when that is where you studied. Its pads, notes and progress remain in the project's Docker learning volume.

The contributor CLI maintains separate progress in this checkout's ignored .learning/ directory. It does not update Docker-volume progress. If you intentionally studied through the prepared contributor workflow, use the exact stable lesson ID and record your own evidence from the repository root in Bash on Linux/macOS or Windows WSL 2:

uv run --no-sync python scripts/course.py progress complete python-pro-01 \
  --notes "Built and inspected a wheel from a clean target."

This records your chosen completion; it does not execute the exercise or certify mastery. Do not mark completion merely because a reference ran.

Beginner confidence before professional work#

New learners take the three SQL starter modules before the historical core: sql-start-01 (tables and grain), sql-start-02 (values, NULL and order), and sql-start-03 (constructing and debugging a query). Python's four named foundation practice modules appear after Days 1, 3, 8 and 10 in catalog order. They teach tracing, evidence-based debugging, trustworthy records, and an independent investigation without requiring an advanced library.
