# Reporting objects and uncertainty controls

Start with: tmb-027, tmb-009, tmb-018.

Outcome: Read report objects without losing shape, estimand or uncertainty assumptions.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

`sdreport` returns an object with methods for printing, summaries and restoration of parameter shapes. `print.sdreport` provides a compact display. `summary.sdreport` can select fixed, random or AD-reported quantities. The registered `as.list.sdreport` method reconstructs shaped lists, reducing the temptation to guess which unnamed vector element corresponds to a scientific quantity.

Call these through R's generic functions: `print(report)`, `summary(report, select="report")` and `as.list(report, what="Estimate", report=TRUE)`. The method name need not be a directly exported function to be available through dispatch. The API inventory records that distinction.

### Worked case A: preserve shape and covariance

The companion constructs a two-parameter estimate and its covariance, derives a contrast and calculates its standard error with the full covariance. Reordering displayed rows does not permit reordering a covariance matrix independently. For a real TMB report, select by inspected names and keep the original mapping to the template.

`getReportCovariance=FALSE` avoids requesting a dense covariance among every AD-reported quantity. It does not mean standard errors are exact or free. `skip.delta.method=TRUE` deliberately skips delta calculations; absence of a standard error must not be converted into zero uncertainty.

### Worked case B: nonlinear transformation bias

If \(Z\sim N(m,v)\), then \(E[e^Z]=e^{m+v/2}\), while exponentiating the mean gives \(e^m\). The companion compares the two. This is a simple example of transformation bias, not proof that every arbitrary prediction should receive the same correction. `sdreport(bias.correct=TRUE)` applies its documented correction machinery and has resource controls such as split groups. Choose it for a specified estimand and assess approximation quality.

`ignore.parm.uncertainty=TRUE` intentionally conditions on estimated fixed parameters for some calculations. Such a result can be useful for isolating one component of uncertainty, but must be labeled. The default fitted-parameter covariance and a posterior covariance are not interchangeable claims.

### Answered discussion

**Why not request p-values for every output?** A p-value needs a meaningful null and valid regular approximation. Derived scales at boundaries and weakly identified latent components often violate simple assumptions. **Can the printed table be treated as the full result?** Printing omits object structure and provenance. Save typed values, diagnostics and the exact report configuration. **Are formatting methods separate fitting algorithms?** No. They expose an existing result and should not be counted as independent model validation.

See [sdreport and its S3 methods](https://cran.r-project.org/web/packages/TMB/TMB.pdf). The chapter companion is a transparent numerical illustration, while the prepared API probe exercises the actual report methods when available.
