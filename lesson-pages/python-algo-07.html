Vocabulary and concepts#

  • Mergeable summary: State that can combine disjoint input chunks for one declared calculation without retaining or replaying their observations. A moment merge needs each chunk's count, center and squared-deviation sum.
  • Stable cutoff: A selection rule that preserves the declared order among equally ranked records. Here earlier arrivals win equal-score top-k ties, regardless of the payload's alphabetical order.
  • Order statistic: A value defined by sorted position rather than input position, such as the median. Producing answers in one pass does not imply that an exact order statistic uses bounded retained memory.
  • Reservoir sample: A bounded set of input positions selected while the full stream length is unknown. Equal values at different positions remain different eligible observations, and the retained objects are references.
Stream, summary, merge and order statistic#

A stream here is an iterable that may be consumable only once. An iterator can yield a value and then forget it. Calling list(values) materializes the entire stream and changes the memory contract even if the next calculation is fast. Tests should therefore use one-pass sources rather than only reusable lists.

A summary state retains information sufficient for a particular calculation. A count and mean cannot reconstruct every observation. A mergeable summary can combine states from disjoint chunks without replaying their original data. An order statistic depends on sorted position, such as the median. Exact general medians require much more retained information than a mean and variance summary.

A reservoir holds a bounded sample while the total input length remains unknown. Sampling is by input position: equal values at different positions are separate possible observations. Returning duplicate values does not mean a position was selected twice. These distinctions affect both correctness tests and the interpretation of output.

Welford state and stable updates#

The state is a tuple (n,μ,M2)(n,\mu,M_2)(n,μ,M2​), where nnn is the count, μ\muμ the mean, and M2M_2M2​ the sum of squared deviations from that mean. For a new value xxx, let δ=x−μ\delta=x-\muδ=x−μ. Update using

The old and new means have different roles. Reusing the old mean in the final factor produces the wrong recurrence. This approach avoids computing variance as a difference between two large raw sums, which can lose small variation when all values have a large common offset.

The calculation still uses finite floating-point arithmetic. It can round, and sufficiently large intermediate differences can overflow even when each input is finite. The contract rejects a nonfinite or negative computed state rather than quietly claiming a usable variance. Constant many numeric fields also does not mean a fixed bit count: a Python integer count can grow in representation size.

Empty input has the identity state (0, 0.0, 0.0). Sample variance uses M2/(n−1)M_2/(n-1)M2​/(n−1) only for n≥2n\ge2n≥2. Returning None for fewer observations distinguishes undefined sample variance from an observed zero variance. The denominator alone does not establish independent observations or an unbiased statistical model.

Worked example: chunk size affects both mean and spread#

Predict whether the combined mean is 15 or closer to 20. This complete rational calculation avoids using the exercise implementation as its own oracle.

from fractions import Fraction

left = [10, 10]
right = [20, 20, 20, 20]
na, nb = len(left), len(right)
ma, mb = Fraction(sum(left), na), Fraction(sum(right), nb)
combined_mean = ma + (mb - ma) * Fraction(nb, na + nb)
between = (mb - ma) ** 2 * Fraction(na * nb, na + nb)
assert combined_mean == Fraction(50, 3)
assert between == Fraction(400, 3)
assert sum((Fraction(value) - combined_mean) ** 2 for value in left + right) == between
print("Count-weighted mean:", combined_mean, "between-group squared deviation:", between)

The right chunk has twice as many observations, so the combined mean is 50/350/350/3, not the simple average of chunk means. Both chunks individually have zero within-chunk spread, yet the combined sample varies because their centers differ. A merge that only adds their two zero M2 values loses all of that between-group variation.

Stable top-k is a record policy#

The earlier heap lesson retained numeric values. This unit retains (integer_score, string_payload) records and specifies which equal-score records survive the cutoff: earlier arrivals win. The payload is not a secondary alphabetical key, and duplicates remain separate occurrences.

A bounded min-heap should expose the worst retained record at its root. Lower scores are worse; for equal scores, later arrivals are worse. A key (score, -position, payload) expresses this because positions are unique. The payload never breaks a tie between distinct records with the same position. Replace the root only when the incoming record is better.

At most kkk records are retained during scanning, and sorting only those survivors costs O(klog⁡k)O(k\log k)O(klogk). The scan costs O(nlog⁡k)O(n\log k)O(nlogk) for positive bounded k, with the usual constant-size interpretation when k is one. The output itself also holds up to k records. A zero limit still consumes and validates the source so malformed records do not disappear behind a special case.

Exact prefix medians need growing state#

Maintain the lower half in a max-heap represented by negated integers and the upper half in an ordinary min-heap. Python 3.12 has the required min-heap functions, so no newer max-heap API is needed. Keep the lower heap the same size as the upper heap or larger by one, with every lower value no greater than every upper value.

For an odd prefix, the median is the largest lower value. For an even prefix, it is the average of the largest lower and smallest upper values. Returning Fraction preserves an exact half-integer even far beyond float64 precision. Using floating conversion would silently alter the exactness contract.

The function is a generator, so it yields answers as input arrives and does not retain every output. Its heaps nevertheless retain every input value: after t observations, they contain t entries. This is a one-pass exact algorithm with linear retained state, not a bounded quantile sketch. Approximate quantile algorithms trade accuracy for memory under separate contracts; they are outside these six exercises.

Worked example: prove a small reservoir distribution exactly#

A seeded histogram can look plausible by chance. Instead, this complete program enumerates every random choice path for a four-item stream and a two-slot reservoir.

from collections import Counter
from itertools import product

# Exhaust all Algorithm R choices for four distinct items and two slots.
counts = Counter()
for third_slot, fourth_slot in product(range(3), range(4)):
    reservoir = ["a", "b"]
    if third_slot < 2:
        reservoir[third_slot] = "c"
    if fourth_slot < 2:
        reservoir[fourth_slot] = "d"
    counts[tuple(sorted(reservoir))] += 1
assert len(counts) == 6 and set(counts.values()) == {2}
print("Each of six pairs appears on two of twelve equally probable draw paths:", dict(counts))

There are three equally likely choices at the third item and four at the fourth, giving twelve equally likely paths. Each of the six unordered pairs appears twice. This checks uniform subsets in the tiny fixture without a tolerance or a flaky statistical threshold.

Now change the replacement rule to always replace slot zero whenever a new item is admitted. Some pairs become impossible or overrepresented. The admission probability alone is insufficient: the replacement slot must also be selected correctly. The exhaustive example isolates that failure much more clearly than printing one sample.

Reservoir inclusion reasoning and state ownership#

Algorithm R fills the first k slots, then draws uniformly from range(t) for the t-th observed item. If the drawn index is below k, it replaces that reservoir slot. For t>kt>kt>k, the new item's inclusion probability is k/tk/tk/t. An old item already included with probability k/(t−1)k/(t-1)k/(t−1) survives with probability 1−1/t1-1/t1−1/t, giving

This proves equal inclusion probabilities by induction. Uniform subsets follow from the full Algorithm R argument and are independently exercised by the small exhaustive check. A particular seeded output is not itself that proof.

Pass an explicit random.Random instance. Its getstate and setstate methods support replay in a compatible runtime with the same call sequence. The function advances that instance when replacement draws are needed. It makes no cross-version bitwise promise. For k zero, it consumes the stream without draws; for a stream shorter than k, all values are returned in encounter order.

Reservoir values are retained by reference. Sampling a mutable dictionary does not deep-copy it, so later mutation of that dictionary can change the sampled object's contents. The algorithm promises a sample of positions, not an immutable data snapshot. Keep that ownership boundary visible when sampling evolving records.

Use Welford updates with constant many numeric state fields and do not retain observations. Empty input returns (0, 0.0, 0.0). Accept finite Python int/float values excluding bool, convert to float, and reject invalid values or nonfinite/negative computed state with ValueError.

Expected: [2, 4, 6] returns (3, 4.0, 8.0). A constant stream has M2 zero. Inputs around a large offset should be checked against an independent centered calculation, not raw sum-of-squares subtraction.

def moments(values: Iterable[float]) -> Moments:
    count, mean, m2 = 0, 0.0, 0.0
    for raw in values:
        value = _finite_number(raw)
        count += 1
        delta = value - mean
        mean += delta / count
        m2 += delta * (value - mean)
        if not math.isfinite(mean) or not math.isfinite(m2) or m2 < 0:
            raise ValueError("Moment update exceeds the finite nonnegative-state contract")
    return count, mean, m2

Update the count, then use the old-mean delta for the mean adjustment and the new-mean delta for the M2 adjustment. This avoids directly subtracting two large nearly equal sums of squares. It still uses floating arithmetic, so input conversion and accumulation are approximate. Constant many fields does not mean a fixed bit budget for an arbitrarily large Python integer count.

Exercise 2: Combine unequal chunks without averaging means blindly#

Contract: merge_moments. Accept two valid (count, mean, M2) tuples and return their merged summary without observations. Counts are nonnegative Python integers excluding bool; means and M2 must be finite, M2 nonnegative, empty states exactly (0, 0, 0), and singleton M2 zero. Empty state is an identity. Use the weighted mean and between-group correction; reject invalid or nonfinite results with ValueError.

Expected: Merging moments([2]) with moments([4, 6]) matches moments([2, 4, 6]) within tolerance. Averaging chunk means without their counts would give 3.5 instead of 4.

def merge_moments(left: Moments, right: Moments) -> Moments:
    na, ma, m2a = _state(left)
    nb, mb, m2b = _state(right)
    if na == 0:
        return nb, mb, m2b
    if nb == 0:
        return na, ma, m2a
    count = na + nb
    delta = mb - ma
    mean = ma + delta * (nb / count)
    m2 = m2a + m2b + delta * delta * (na * (nb / count))
    if not math.isfinite(mean) or not math.isfinite(m2):
        raise ValueError("Merged moments exceed finite floating range")
    return count, mean, m2

The correction accounts for different chunk centers. Adding M2 values alone omits the variation between those centers. Mathematical merging is associative, but floating evaluation is not bitwise associative, so compare different partitionings with justified tolerance. A state validator can check the declared structural constraints without proving that a summary truly came from the claimed original data.

Exercise 3: Distinguish undefined from zero variance#

Contract: sample_variance. Validate the moment-state contract used by merge_moments. Return M2/(count - 1) for count at least two, otherwise None. Preserve the tuple and do not reinterpret an empty or singleton sample as zero variance. Reject invalid states with ValueError. This is an arithmetic sample-variance calculation, not automatic evidence of an unbiased model estimate.

Expected: The summary of [2, 4, 6] gives 4.0. Empty and singleton summaries give None; [7, 7] gives 0.0. A singleton state with positive M2 is invalid.

def sample_variance(state: Moments) -> float | None:
    count, _, m2 = _state(state)
    return None if count < 2 else m2 / (count - 1)

The denominator count minus one belongs to sample variance. Population variance of a fully observed population would use count instead. Returning None keeps an undefined estimate distinct from observed zero spread. Statistical unbiasedness requires assumptions such as independent identically distributed observations with finite variance; choosing this denominator alone does not establish them.

Exercise 4: Retain scored records with an explicit tie policy#

Contract: stable_top_k. Consume a one-pass iterable of (Python integer score, string payload) records, excluding bool scores, and retain at most k heap records. k must be a nonnegative Python integer excluding bool. Return up to k records ordered by descending score, with earlier input records first on equal scores. Preserve duplicates and payloads, never sort or retain the full input, and validate records even when k is zero. Invalid input raises ValueError.

Expected: [(5, "first"), (7, "best"), (5, "second"), (5, "third")] with k=3 returns [(7, "best"), (5, "first"), (5, "second")]. Equal scores do not sort by payload.

def stable_top_k(records: Iterable[tuple[int, str]], k: int) -> list[tuple[int, str]]:
    k = _size(k)
    heap: list[tuple[int, int, str]] = []
    for position, record in enumerate(records):
        if not isinstance(record, (tuple, list)) or len(record) != 2:
            raise ValueError("Expected an integer score and string payload")
        score, label = record
        if isinstance(score, bool) or not isinstance(score, int) or not isinstance(label, str):
            raise ValueError("Expected an integer score and string payload")
        if k == 0:
            continue
        candidate = (score, -position, label)
        if len(heap) < k:
            heapq.heappush(heap, candidate)
        elif candidate > heap[0]:
            heapq.heapreplace(heap, candidate)
    return [(score, label) for score, _, label in sorted(heap, reverse=True)]

The heap root must be the worst retained candidate: lowest score, and latest arrival on a tie. A tuple of score and negative position supplies that ordering, while the unique position keeps payload comparisons irrelevant. Replacing only when a new candidate is better preserves earlier ties. Auxiliary retained record count is O(k), extending the earlier value-only heap exercise to stable record identity.

Exercise 5: Maintain exact order statistics with two heaps#

Contract: prefix_medians. Return a lazy iterator yielding the exact Fraction median after each Python integer input, excluding bool. Use a negated lower min-heap as a max-heap and a normal upper min-heap, keeping lower equal in size to upper or larger by one. Preserve duplicates and use no floating conversion. Empty input yields nothing; invalid items raise ValueError when consumed. Retained heap entries grow with the prefix length.

Expected: For [5, 1, 9, 3], yield fractions [5, 3, 5, 4]. For [2100, 2100 + 1], the second median is exactly Fraction(2**101 + 1, 2).

def prefix_medians(values: Iterable[int]) -> Iterator[Fraction]:
    lower: list[int] = []
    upper: list[int] = []
    for value in values:
        if isinstance(value, bool) or not isinstance(value, int):
            raise ValueError("Exact medians require integer values")
        if not lower or value <= -lower[0]:
            heapq.heappush(lower, -value)
        else:
            heapq.heappush(upper, value)
        if len(lower) > len(upper) + 1:
            heapq.heappush(upper, -heapq.heappop(lower))
        elif len(upper) > len(lower):
            heapq.heappush(lower, -heapq.heappop(upper))
        if len(lower) > len(upper):
            yield Fraction(-lower[0])
        else:
            yield Fraction(-lower[0] + upper[0], 2)

The lower heap root gives the largest lower-half value and the upper root gives the smallest upper-half value. Rebalancing sizes ensures the middle order statistics are exposed. Fractions preserve half-integer answers even far beyond float precision. A generator avoids storing every output, but these two heaps still retain every input value: exact general prefix medians are not a constant-memory summary.

Exercise 6: Sample positions without knowing stream length#

Contract: reservoir_sample. Consume an arbitrary one-pass iterable with Algorithm R, retaining at most k objects and using the supplied exact random.Random instance. Require nonnegative Python integer k excluding bool; invalid k or generator raises ValueError before consumption. For the t-th item after filling k slots, draw uniformly from range(t) and replace that slot only when it is below k. Return reservoir slot order. k=0 consumes the stream without draws; streams shorter than k return all items in encounter order.

Expected: For n >= k, return k sampled positions without replacement; repeated values may appear when positions differ. Saving and restoring rng.getstate() reproduces a run in the same runtime and call sequence. Input objects are retained by reference, not deep-copied.

def reservoir_sample(values: Iterable[T], k: int, rng: random.Random) -> list[T]:
    k = _size(k)
    if type(rng) is not random.Random:
        raise ValueError("Expected an explicit random.Random generator")
    result: list[T] = []
    for position, value in enumerate(values):
        if position < k:
            result.append(value)
        elif k:
            slot = rng.randrange(position + 1)
            if slot < k:
                result[slot] = value
    return result

At time t, a new item enters with probability k/t. An old retained item survives with probability 1 - 1/t, because exactly one of the t possible draws replaces its slot. Multiplying its previous inclusion probability k/(t-1) by this survival probability gives k/t. A fixed seed demonstrates replay, while exhaustive small draw paths can independently verify uniform subsets without a flaky frequency threshold.

import heapq
import math
import random
from collections.abc import Callable, Iterable, Iterator
from fractions import Fraction
from typing import TypeVar

T = TypeVar("T")
Moments = tuple[int, float, float]


def _finite_number(value: float) -> float:
    if isinstance(value, bool) or not isinstance(value, (int, float)):
        raise ValueError("Expected a finite real number, excluding bool")
    try:
        result = float(value)
    except OverflowError as error:
        raise ValueError("Value exceeds floating range") from error
    if not math.isfinite(result):
        raise ValueError("Expected a finite number")
    return result


def _state(state: Moments) -> Moments:
    if not isinstance(state, tuple) or len(state) != 3:
        raise ValueError("Expected a (count, mean, M2) tuple")
    count, mean, m2 = state
    if isinstance(count, bool) or not isinstance(count, int) or count < 0:
        raise ValueError("Count must be a nonnegative integer")
    mean, m2 = _finite_number(mean), _finite_number(m2)
    if m2 < 0 or (count == 0 and (mean != 0 or m2 != 0)) or (count == 1 and m2 != 0):
        raise ValueError("Invalid moment state")
    return count, mean, m2


def _size(value: int) -> int:
    if isinstance(value, bool) or not isinstance(value, int) or value < 0:
        raise ValueError("Expected a nonnegative integer size")
    return value


def moments(values: Iterable[float]) -> Moments:
    count, mean, m2 = 0, 0.0, 0.0
    for raw in values:
        value = _finite_number(raw)
        count += 1

        mean += delta / count
        m2 += delta * (value - mean)
        if not math.isfinite(mean) or not math.isfinite(m2) or m2 < 0:
            raise ValueError("Moment update exceeds the finite nonnegative-state contract")
    return count, mean, m2

    try:
        call()

def main() -> None:
    state = moments(iter([2.0, 4.0, 6.0]))
    assert state == (3, 4.0, 8.0) and moments([]) == (0, 0.0, 0.0)
    merged = merge_moments(moments([2.0]), moments([4.0, 6.0]))
    assert merged == state and merge_moments(state, moments([])) == state
    assert sample_variance(state) == 4.0 and sample_variance(moments([9])) is None
    expect_value_error(lambda: moments([math.inf]))

    records = [(5, "first"), (7, "best"), (5, "second"), (5, "third")]

        Fraction(3),

    rng.setstate(checkpoint)
    assert reservoir_sample(range(30), 4, rng) == sample
    assert len(sample) == 4 and len(set(sample)) == 4
    assert reservoir_sample([1, 2], 5, random.Random(0)) == [1, 2]
    assert reservoir_sample(range(20), 0, random.Random(0)) == []
