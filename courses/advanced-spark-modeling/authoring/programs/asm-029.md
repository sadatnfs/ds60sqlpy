# Worked reference: Lightning topology review

This is an editable reading/project reference. It has no ordinary pad Run action.

Write the actual process tree before interpreting results. If an outer launcher already creates two ranks, a second uncontrolled two-process launch inside each rank can produce four processes and duplicate data. The project must use one compatible topology owner.

Record global/local rank, world size, Trainer strategy, device count, sampler behavior and step count. Compare the custom likelihood step with its serial reference. A logged rank mean needs weighting if ranks see unequal counts. A checkpoint containing only weights is not evidence of exact optimizer resume.

After separately preparing the project described in its README, run from the repository root:

```bash
courses/advanced-spark-modeling/projects/spark-torch/workshop run lightning-ddp
```

Inspect the actual source-bound receipt. This command reference does not assert that preparation or execution has already occurred on your machine.
