# nlminb and optimization evidence

Start with: tmb-006, r-043.

Outcome: Assess a fit using objective, gradient, status and multiple starting points.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

An optimizer answers a computational question: did its search procedure satisfy its stopping rules? Scientific estimation adds further questions: is the solution an identifiable minimum, does it depend on the initial point, and does the fitted model explain the observations reasonably? Keep those claims separate.

`nlminb(start, objective, gradient)` accepts an initial parameter vector and callable functions. Its result includes `par`, `objective`, `convergence`, `message`, iteration count and evaluations. The project's `fit_objective` records the maximum absolute gradient and a narrow diagnostic flag. That flag is not a guarantee of global optimality or valid uncertainty.

### Worked case A: normal mean from different starts

Fit the normalized normal model from a low mean with a narrow scale and from a high mean with a broad scale. The closed-form answer is known, so compare final coordinates as well as objective values. The companion does this in base R with an analytic gradient. Observe that different paths can take different numbers of evaluations while arriving at the same solution.

Use a relative parameter or objective tolerance consistent with data scale. A gradient of 0.001 may be small or large depending on units and curvature. Reparameterizing predictors can make convergence more stable without changing the underlying scientific model, provided predictions are transformed consistently.

### Worked case B: weakly determined nonlinear decay

The nonlinear model has mean \(a e^{-bt}+c\). If observations cover only early times, \(e^{-bt}\approx1-bt\), so data mainly identify \(a+c\) and \(ab\). Very different values of \(a,b,c\) can therefore give similar fits. The companion compares two such curves on a short interval and on a longer forecast horizon. An optimizer may find a good short-term fit but a poorly determined long-range forecast.

A useful retry changes a diagnosed cause: rescale predictors, choose a physically plausible start, or inspect a likelihood profile. Repeating the same optimization blindly does not add information. Save failed fits with status, message and parameter values; do not silently drop them from simulation summaries.

### Diagnostics and answered discussion

**Is convergence code zero sufficient?** No. Check finite objective and gradient, compare initial and final values, inspect curvature, and evaluate predictive residuals. **Should I simply increase iteration limits?** Only after determining whether the algorithm is progressing toward an identifiable solution. More iterations cannot fix an unbounded likelihood. **Can I average two fitted parameter vectors?** Usually not. Averages can leave constrained parameter spaces or lie in a low-likelihood region; compare fits at their actual objectives.

For latent models, an outer optimizer's success can coexist with a failed inner optimization. Chapter 14 inspects that extra layer explicitly. The [R `nlminb` documentation](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/nlminb.html) explains its stopping and control parameters; retain the package/version context with any numerical receipt.

### Complete R companion

```r
y <- c(1, 2, 4, 7)
fn <- function(p) -sum(dnorm(y, p[1], exp(p[2]), log = TRUE))
gr <- function(p) c(sum(p[1] - y) / exp(2 * p[2]), length(y) - sum((y - p[1])^2) / exp(2 * p[2]))
fits <- lapply(list(c(-2, 0), c(8, 2)), function(start) nlminb(start, fn, gr))
for (fit in fits) print(c(fit$par, value = fit$objective, gradient = max(abs(gr(fit$par)))))
stopifnot(max(abs(fits[[1]]$par - fits[[2]]$par)) < 1e-4)
curve <- function(t, a, b, c) a * exp(-b * t) + c
print(data.frame(time = c(0, .1, 8), first = curve(c(0, .1, 8), 3, .6, 1), second = curve(c(0, .1, 8), 6, .3, -2)))
```
