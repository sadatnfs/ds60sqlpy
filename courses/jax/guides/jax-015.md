# jax-015: Train a small neural network with visible parameters

## Mechanism and purpose

A multilayer perceptron combines affine maps with nonlinear functions. The nonlinearity matters: composing only affine maps still produces an affine map. Here a hidden tanh layer receives one feature, produces four hidden coordinates, then an output projection returns one prediction. Every weight and bias is visible in a pytree.

Initialization is part of the experiment. We split a key for the two weight matrices and use small random values, with zero biases. Reusing a key would tie random construction unintentionally. Repeating initialization with the same complete policy supports replay in the pinned environment, but does not make different random seeds irrelevant to a scientific comparison.

The training step computes a scalar mean loss, differentiates it with respect to the parameter tree and returns updated parameters. A short Python loop repeatedly calls the compiled step. Data stays literal and small; no model download or opaque trainer is required. The reported final loss is computed after the final update.

The target rule in this fixture is tanh(2x). Training points and held-out interpolation points are listed separately. Their numerical relationship is deliberately simple, making the experiment auditable. A reduced training loss shows that the optimization path addressed the authored objective. A held-out error adds a separate observation on the listed points, but those few values do not establish broad population reliability.

Failure diagnosis should proceed from input shape to forward values, loss reduction, gradient tree, update state and fresh evaluation. Increasing model width or training steps before checking those contracts can hide a basic defect. Later capstones ask for a defensible comparison, not just a longer loop that happens to print a smaller number.

## Key terms

- **MLP:** A multilayer perceptron that alternates affine maps with nonlinear functions, here one tanh hidden layer of four units.
- **Initialization policy:** The complete rule for creating starting parameters, including key splits, value scale and zero biases.
- **Training step:** One compiled function that computes the mean loss, differentiates it and returns updated parameters.
- **Held-out evaluation:** Measuring error on listed inputs never used for updates, which is separate evidence from a reduced training loss.

## Derivation and shape contract

For row inputs \(X\in\mathbb R^{N\times1}\), compute \(H=\tanh(XW_1+b_1)\) with \(W_1\in\mathbb R^{1\times4}\), then \(\widehat Y=HW_2+b_2\) with \(W_2\in\mathbb R^{4\times1}\). The model contains 4+4+4+1=13 parameters. Its mean loss reduces N scalar prediction events. The gradient tree must have the same structure and leaf shapes as those 13 parameters.

## Worked investigations

### Worked example 1: Trace the architecture

Initialize the model and inspect parameter count and output shape.

The final singleton is an output-feature axis. It must match the target shape exactly before calculating the loss.

**Expected:** 13 parameters; predictions shape (5,1), all finite.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def initialize(key):
    first, second = jax.random.split(key)
    return {
        "w1": 0.3 * jax.random.normal(first, (1, 4), dtype=jnp.float64),
        "b1": jnp.zeros(4),
        "w2": 0.3 * jax.random.normal(second, (4, 1), dtype=jnp.float64),
        "b2": jnp.zeros(1),
    }


def forward(parameters, inputs):
    hidden = jnp.tanh(inputs @ parameters["w1"] + parameters["b1"])
    return hidden @ parameters["w2"] + parameters["b2"]


train_x = jnp.array([[-1.0], [-0.5], [0.0], [0.5], [1.0]])
train_y = jnp.tanh(2 * train_x)


def main():
    # Case 1: Trace the architecture
    parameters = initialize(jax.random.key(31))
    assert sum(x.size for x in jax.tree.leaves(parameters)) == 13
    predictions = forward(parameters, train_x)
    assert predictions.shape == train_y.shape == (5, 1)
    assert bool(jnp.isfinite(predictions).all())

    print("jax-015: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: A bounded optimization observation

Train for exactly 120 updates from the fixed initialization and recompute the loss.

The assertion concerns this deterministic optimization fixture. Held-out evaluation and scientific interpretation remain separate observations.

**Expected:** Finite final training loss smaller than its initial value.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def initialize(key):
    first, second = jax.random.split(key)
    return {
        "w1": 0.3 * jax.random.normal(first, (1, 4), dtype=jnp.float64),
        "b1": jnp.zeros(4),
        "w2": 0.3 * jax.random.normal(second, (4, 1), dtype=jnp.float64),
        "b2": jnp.zeros(1),
    }


def forward(parameters, inputs):
    hidden = jnp.tanh(inputs @ parameters["w1"] + parameters["b1"])
    return hidden @ parameters["w2"] + parameters["b2"]


def objective(parameters, inputs, labels):
    return jnp.mean((forward(parameters, inputs) - labels) ** 2)


def step(parameters, inputs, labels):
    gradients = jax.grad(objective)(parameters, inputs, labels)
    return jax.tree.map(lambda p, g: p - 0.05 * g, parameters, gradients)


compiled_step = jax.jit(step)
train_x = jnp.array([[-1.0], [-0.5], [0.0], [0.5], [1.0]])
train_y = jnp.tanh(2 * train_x)


def train():
    parameters = initialize(jax.random.key(31))
    for _ in range(120):
        parameters = compiled_step(parameters, train_x, train_y)
    return parameters


def main():
    # Case 1: A bounded optimization observation
    initial = initialize(jax.random.key(31))
    trained = train()
    before = objective(initial, train_x, train_y)
    after = objective(trained, train_x, train_y)
    assert bool(jnp.isfinite(after))
    assert float(after) < float(before)

    print("jax-015: 1 asserted case passed")


if __name__ == "__main__":
    main()
```
