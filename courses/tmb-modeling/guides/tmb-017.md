# Shared effects versus separable blocks

Start with: tmb-016, asm-011.

Outcome: Prove when group-level Laplace contributions can be added and when they cannot.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

Suppose the joint objective decomposes as \(f(\theta,u)=\sum_g f_g(\theta,u_g)\), where latent vectors \(u_g\) have disjoint ownership and no cross-group terms. Conditional on the shared fixed parameters, the latent integral factorizes. Each group can compute its own marginal contribution, and a driver can sum values and gradients evaluated at the same \(\theta\).

The latent Hessian is then block diagonal. Its determinant is the product of block determinants, so the log determinant is their sum. This algebra is the reason independent-group Laplace evaluation can be distributed. It is not a generic consequence of storing data in partitions.

### Worked case A: block-diagonal integration

The companion builds two positive-definite precision blocks and compares the full log determinant with the sum of the block log determinants. Both agree. Each group's normalized latent prior must appear exactly once. Any prior or penalty on the shared fixed parameters must also be added once globally, unless the mathematical model explicitly assigns separate terms.

If groups have different dimensions, include the correct \(-q_g\log(2\pi)/2\) term in each contribution. The project keeps normalized densities so such constants do not disappear unnoticed. Unequal group sizes change information and should not be replaced by equal averaging.

### Worked case B: one cross-group edge

Add a covariance or precision connection between two latent groups. The full determinant now differs from the product of the separate determinants. Dropping the edge and summing independent fits describes a different model. The companion demonstrates this with a two-dimensional precision matrix whose off-diagonal entry changes the determinant from four to \(4-0.8^2\).

There are advanced methods for coupled systems, including distributed linear algebra, structured message passing and approximations that communicate boundary information. Implementing them requires a new algorithm and its own numerical acceptance. Merely launching TMB separately inside `mapPartitions` does not reproduce a coupled Laplace approximation.

### Diagnostics and answered discussion

**May fixed parameters be shared while latent groups remain independent?** Yes. Conditional factorization at each common fixed vector is sufficient. The driver still runs one shared optimization. **Can a shared random intercept be copied into every group?** That creates separate latent variables unless their joint integration is preserved. Copying a name is not sharing a variable mathematically. **How should an integration package react to an unsupported coupling?** Reject the requested decomposition explicitly before computing a misleading answer.

The advanced Spark project tests both accepted additive cases and a coupled-model rejection. Its small local numerical evidence should be described as correctness for the tested decomposition, not as a universal distributed TMB engine or proof of speedup on a large cluster.

### Complete R companion

```r
A <- matrix(c(2, .2, .2, 1), 2, 2); B <- matrix(c(3, .4, .4, 2), 2, 2)
full <- matrix(0, 4, 4); full[1:2, 1:2] <- A; full[3:4, 3:4] <- B
logdet <- function(M) as.numeric(determinant(M, logarithm = TRUE)$modulus)
print(c(full = logdet(full), blocks = logdet(A) + logdet(B)))
stopifnot(abs(logdet(full) - logdet(A) - logdet(B)) < 1e-12)
coupled <- matrix(c(2, .8, .8, 2), 2, 2)
print(c(coupled = logdet(coupled), incorrect_independent = 2 * log(2)))
stopifnot(abs(logdet(coupled) - 2 * log(2)) > .1)
```
