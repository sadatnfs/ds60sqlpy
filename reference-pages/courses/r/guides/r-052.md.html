Outcome and mechanism#

Build a compact uncertainty display whose panels, interval target and axis choices support a valid comparison.

A statistical graphic should identify the quantity represented by each mark. A raw observation, a fitted mean and an uncertainty interval are different objects. Placing them in adjacent panels can help a reader see both the underlying measurements and the summary, provided their scales and labels remain explicit.

An interval must name its target and construction. A mean confidence interval is not a prediction interval for a future observation, and a standard-error bar is not automatically a 95 percent interval. The tiny group example computes Student t intervals from the actual within-group sample standard deviations and counts, retaining the assumptions rather than drawing arbitrary error bars.

Comparable panels need deliberate scales. Shared limits support direct visual comparisons of magnitudes. Free scales can reveal within-panel patterns but make equal-looking distances mean different numerical changes. Neither policy is universally correct; choose it according to the comparison and explain it in the caption.

A logarithmic scale gives equal distance to equal ratios, while a linear scale gives equal distance to equal differences. Zero and negative values require special treatment on a logarithmic scale. A truncated baseline can be appropriate for some position-based plots but is especially misleading for bars whose lengths encode magnitude from zero.

Base graphics par settings affect subsequent drawing. Save and restore settings within a plotting helper so a multi-panel layout does not unexpectedly alter a caller's later graph. This is separate from graphics-device ownership: restoring a layout does not close or publish a figure. The reference creates one two-panel page and leaves browser readability as a separate visual acceptance check.

Vocabulary#

Term Meaning
Interval target The quantity an interval procedure is intended to cover, such as a mean or future response.
Shared scale The same numerical mapping used across panels for a stated comparison.
Logarithmic scale A position scale where equal distances correspond to equal ratios.
Layout state Graphics parameters such as mfrow and margins that influence subsequent drawing.

Read the syntax#

Compute each group's n, mean and sd/sqrt(n), then use qt with its degrees of freedom for the declared mean interval. Set par(mfrow=c(1,2)) inside a function with on.exit(par(old)). Plot raw values in one panel and means with segments/arrows in the other. Set common y limits when direct magnitude comparison is intended.

Worked examples#

Example 1: Show observations and interval summaries#

groups <- list(A = c(1, 2, 3, 4), B = c(2, 3, 6, 7))
summary <- do.call(rbind, lapply(names(groups), function(g) {
  x <- groups[[g]]; se <- sd(x) / sqrt(length(x)); half <- qt(0.975, length(x) - 1) * se
  data.frame(group = g, n = length(x), mean = mean(x), lower = mean(x) - half, upper = mean(x) + half)
}))
draw <- function() {
  old <- par(mfrow = c(1, 2), mar = c(4, 4, 3, 1))
  on.exit(par(old), add = TRUE)
  limits <- range(c(unlist(groups), summary$lower, summary$upper))
  plot(rep(1:2, each = 4), unlist(groups), xaxt = "n", ylim = limits, xlab = "Group", ylab = "Observed value", pch = 16, main = "Raw observations")
  axis(1, at = 1:2, labels = names(groups))
  plot(1:2, summary$mean, xaxt = "n", ylim = limits, xlab = "Group", ylab = "Mean and t interval", pch = 16, main = "95% mean intervals")
  axis(1, at = 1:2, labels = summary$group)
  arrows(1:2, summary$lower, 1:2, summary$upper, angle = 90, code = 3, length = 0.06)
}
stopifnot(identical(summary$n, c(4L, 4L)), identical(summary$mean, c(2.5, 4.5)))
draw()

Expected observation: One two-panel graphic; group means 2.5/4.5 and explicitly constructed t intervals.

The first panel retains the observations, while the second identifies a model-dependent interval for each mean. Shared y limits keep the magnitude comparison consistent.

Example 2: Equal ratios and equal differences#

values <- c(1, 10, 100)
stopifnot(identical(diff(values), c(9, 90)))
stopifnot(max(abs(diff(log10(values)) - c(1, 1))) < 1e-12)
plot(values, rep(1, 3), log = "x", yaxt = "n", xlab = "Positive quantity (log scale)", ylab = "", pch = 16, main = "Equal ratios have equal horizontal spacing")
text(values, rep(1, 3), labels = values, pos = 3)

Expected observation: Linear differences 9/90; log10 differences 1/1.

The log scale changes the mapping from values to positions. The arithmetic checks establish equal log-space increments; visual label placement still needs inspection at the delivered size.
