# Count and censored likelihood terms

Start with: tmb-003, clp-009.

Outcome: Write normalized terms that reflect what was actually observed.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A likelihood is a probability of the observed information, not a universal residual formula. Counts, censored durations and continuous measurements have different supports and observation processes. Begin by writing the experiment before choosing a numerical loss.

For counts with exposure \(e_i>0\), use \(Y_i\sim\operatorname{Poisson}(e_i\exp(\alpha+\beta x_i))\). Exposure may be hours observed or population-time. Its logarithm is an offset with coefficient fixed to one, not an arbitrary extra estimated covariate. The Poisson assumption equates conditional mean and variance; overdispersion can motivate a negative-binomial model rather than hiding the discrepancy in a standard error.

### Worked case A: exposure changes the expected count

Two records have exposures one and two, predictor values zero and one, and counts zero and three. With baseline rate two and rate ratio 1.5, their expected counts are two and six. A zero count contributes finite probability. Replacing it with a missing value or dividing counts by exposure and fitting an unweighted Gaussian model changes the experiment. The companion computes exact `dpois` contributions and prints the result.

For event times, let \(d_i=1\) indicate an observed event and \(d_i=0\) right censoring at time \(t_i\). With hazard \(h\) and cumulative hazard \(H\), a record contributes \(H(t_i)-d_i\log h(t_i)\) to NLL. If entry is delayed until \(a_i<t_i\), conditioning on survival to entry subtracts \(H(a_i)\).

### Worked case B: one event and one censored record

A Weibull model has \(H(t)=(t/\lambda)^k\) and \(\log h(t)=\log k-\log\lambda+(k-1)(\log t-\log\lambda)\). For \(k=1\), it reduces to an exponential distribution. The companion uses an event at two and a censored record at four entering at one, with scale two. The total NLL is \(2.5+\log 2\). Treating the censored duration as an event would add a log-hazard term that was never observed.

The C++ model branches on fixed entry data to set \(H(0)=0\) directly. This avoids differentiating a generic zero-to-variable-power expression, whose intermediate logarithm can be undefined even when the mathematical limit is well defined.

### Diagnostics and answered discussion

**Does this handle interval censoring?** No. An interval observation needs a probability such as \(S(L)-S(R)\), evaluated stably on a log scale. **Is censoring assumed harmless?** The likelihood assumes an appropriate independent censoring mechanism conditional on modeled variables. Informative censoring needs a fuller observation model. **Can exposure be zero?** Our model rejects it. A zero-exposure/zero-count record carries a special structural interpretation and should not be silently logged.

The project tests exact two-record values and finite-difference gradients. That establishes arithmetic on stated examples, not the adequacy of Poisson or Weibull assumptions for a new dataset.

### Complete R companion

```r
expected <- c(1, 2) * exp(log(2) + log(1.5) * c(0, 1))
print(data.frame(count = c(0, 3), expected = expected, nll = -dpois(c(0, 3), expected, log = TRUE)))
t <- c(2, 4); entry <- c(0, 1); event <- c(1, 0); scale <- 2; shape <- 1
H <- function(x) (x / scale)^shape
logh <- log(shape / scale) + (shape - 1) * log(t / scale)
nll <- sum(H(t) - H(entry) - event * logh)
print(c(censored_nll = nll, wrong_all_events = sum(H(t) - H(entry) - logh)))
stopifnot(abs(nll - (2.5 + log(2))) < 1e-12)
```
