A prepared custom quadratic likelihood#

This model is the original extension in native/models/custom_models.hpp. It demonstrates how a prepared custom C++ objective participates in the same Python and Scala DataFrame APIs as the built-in models.

Likelihood and parameterization#

The callback squares the supplied x inside the native objective and prediction hook. Curvature is unconstrained, so both upward and downward parabolas are possible. The model validates the numerical domain of x separately during fitting and prediction.

The actual fixture#

The shared gallery fixture contains 128 observations. Its native fit fields are x, y. Row identity is row_id. The fixed-seed generator writes 12 significant digits of canonical precision. These are public synthetic observations, not a production dataset.

Fit the DataFrame#

Run from the package directory with a prepared classic Spark session named spark. The common frame helper constructs a bounded SQL VALUES DataFrame; it does not introduce a PythonRDD or Python UDF into the executor plan.

import json
import sys
from pathlib import Path
from ds60_spark_tmbad import ModelSpec, PreparedRuntime, SparkTMBad

sys.path.insert(0, str(Path("python/examples").resolve()))
from gallery.run_gallery import frame

recipe = json.loads(Path("python/examples/gallery/fixtures.json").read_text())["cases"][
    "quadratic_gaussian"
]
runtime = PreparedRuntime.from_manifest("/opt/spark-tmbad/artifact.json")
api = SparkTMBad(runtime)
training = frame(spark, recipe["training_rows"], list(recipe["training_rows"][0]), ordered=False)
spec = ModelSpec(
    "quadratic_gaussian",
    {"x": "x", "y": "y"},
    id_columns=["row_id"],
    group_columns=[],
    order_columns=[],
)
fitted = api.fit_shared(
    training.repartition(2),
    spec,
    options={**recipe["fit_options"], "initial_parameters": [0.5, 0.3, -0.510825623766]},
)
print(fitted.model["parameter_names"])
print(fitted.model["parameters"])
print(fitted.model["fit"])

The shared fit uses one population parameter vector across all input partitions. Inspect converged, the raw/projected scores, active bounds and the stop reason. The API withholds predictions from an unconverged fit by default; do not use a diagnostic override to make an example appear successful.

Response-free prediction#

history = training.limit(0)
requested = frame(
    spark, [{"row_id": 1000, "x": -0.5}, {"row_id": 1001, "x": 1.0}], ["row_id", "x"], ordered=False
)
predicted = fitted.predict(
    requested, options={"target": "response", "columns": {"x": "x"}, "output_prefix": "prediction_"}
)
predicted.orderBy("row_id").show()

The requested rows contain no future y. A history-dependent target receives its historical response in a separate DataFrame. Native field names and Spark column names are mapped explicitly instead of inferred from their spelling.

Forecast the declared target#

future = frame(
    spark, [{"row_id": 1000, "x": -0.5}, {"row_id": 1001, "x": 1.0}], ["row_id", "x"], ordered=False
)
forecasts = fitted.forecast(
    history,
    future,
    options={
        "target": "response",
        "history_columns": {"x": "x", "y": "y"},
        "future_columns": {"x": "x"},
        "output_prefix": "forecast_",
    },
)
forecasts.orderBy("row_id").show()

The future target evaluates the prepared quadratic mean at the supplied x. It does not extrapolate a time process, and it does not estimate uncertainty about the curve's coefficients. See the custom-authoring guide for the actual weighted objective callback.

A fixed-parameter calculation#

At intercept=1, curvature=0.5 and sigma=0.25, x=-2 and x=2 both have mean 3 and variance 0.0625. At x=0 the mean is 1. This symmetry is a useful independent target check.

This calculation explains the target at stated parameters. It is distinct from the actual estimated values recorded by a gallery execution.

Common mistakes#

  • Supplying x squared as native field x, which would square it a second time.
  • Changing the C++ objective without rebuilding the worker and source-bound manifest.
  • Treating a prepared custom model as permission to compile arbitrary source inside a Spark task.

See the gallery, preparation, and custom-model contracts for the full execution and scope boundaries. A local run is not a cluster-scale or global-optimum guarantee.
