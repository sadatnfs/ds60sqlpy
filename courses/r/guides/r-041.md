## Outcome and mechanism

Produce a descriptive summary whose observation counts, missing-value policy and distributional limits are explicit.

An exploratory summary starts with the unit represented by each row. A value may describe one measurement, one person or one aggregated group. Those units determine what a count or mean means. Before choosing a plot or model, record the eligible rows and the distinction between an observed zero and an absent measurement.

R represents missing numeric values with NA. Arithmetic often propagates that missingness, making an unexamined mean return NA. Setting na.rm=TRUE changes the calculation to use observed values. It does not establish that those observed values represent the missing population. Report the observed and missing counts alongside the summary, especially when availability differs between groups.

A mean compresses a distribution and is sensitive to extreme values. A median answers a different descriptive question about the middle ordered observation. Neither is universally preferable. Comparing them with quantiles and the actual small sample can expose skew or an outlier that a single scalar hides. The authored long-tail fixture below makes this sensitivity visible without claiming to diagnose a real data-quality error.

Grouped summaries introduce another denominator choice. A group with one observed value should not automatically receive the same weight as a group with two when reconstructing the overall observation mean. Retaining counts and sums makes that aggregation auditable. An empty group and a group whose rows are all missing also have different data-collection meanings, even if neither has an observed mean.

Choose an explicit all-missing policy. This lesson reports NA_real_ for the mean and median when no observed values exist, preserving the absence of information. Returning zero would create a numerical observation that was never measured. The policy is a semantic decision at the analysis boundary, not merely a way to suppress a warning.

These summaries describe the admitted records. They do not prove a causal effect, a representative sampling design or a mechanism for missing values. A subsequent inferential analysis needs those assumptions stated separately. Keep original records and identifiers so a reviewer can reconstruct which values entered each statistic.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Observation unit | The entity or event represented by one admitted row. |
| Missing value | An absent measurement, distinct from a measured numerical zero. |
| Observed-value mean | A mean whose denominator counts only values retained by the declared missingness policy. |
| Robust descriptive summary | A statistic such as the median whose response to extreme observations differs from the mean. |

## Read the syntax

Use is.na to create a missingness mask and sum it to retain counts. Select observed values before calculating summaries. For values x_i with observed indicators m_i, the observed mean is \(\sum_i m_i x_i/\sum_i m_i\) when the denominator is positive. The implementation selects valid entries first rather than multiplying NA by zero. split keeps the group labels available; a safe summary function makes the all-missing case explicit.

## Worked examples

### Example 1: A denominator ledger

```r
x <- c(1, NA_real_, 4, 6, NA_real_)
observed <- !is.na(x)
summary <- c(rows = length(x), observed = sum(observed), missing = sum(!observed), mean = mean(x[observed]))
stopifnot(summary[["rows"]] == 5, summary[["observed"]] == 3, summary[["missing"]] == 2)
stopifnot(isTRUE(all.equal(summary[["mean"]], 11 / 3)))
print(summary)
```

**Expected observation:** Rows 5, observed 3, missing 2, observed mean 11/3.

The complete-case calculation retains three observed measurements and excludes two missing records from the mean denominator. Their exclusion is reported rather than interpreted as proof that missingness is harmless.

### Example 2: A long tail changes the mean

```r
x <- c(1, 2, 2, 3, 100)
stopifnot(isTRUE(all.equal(mean(x), 21.6)), median(x) == 2)
without_extreme <- x[-5]
stopifnot(mean(without_extreme) == 2, median(without_extreme) == 2)
print(c(mean = mean(x), median = median(x)))
```

**Expected observation:** Mean 21.6 and median 2; the four smaller values have mean and median 2.

Removing the extreme value changes the mean greatly while the median stays two. This is an arithmetic sensitivity comparison, not an instruction to delete large real observations without investigation.

## Reference review

The reference preserves the observed set explicitly. Selecting x[valid] avoids performing arithmetic on missing entries and makes the denominator count inspectable. The zero in the first fixture is a valid measurement, so removing it would create another selection error.

The grouped calculation retains enough information to reconstruct the observation-weighted mean. Averages of group averages change the weighting unless group counts are equal or equal group weighting is the intended question. The all-missing branch returns missing output deliberately; it does not turn absent evidence into a zero estimate.

The tail comparison uses the same five authored values for both summaries. Its conclusion is about their arithmetic sensitivity. Decisions about measurement error, eligibility or population inference require evidence not present in this small fixture.
