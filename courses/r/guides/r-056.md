## Outcome and mechanism

Construct diagnostic graphics from fitted quantities and explain which model concerns they can investigate without treating a plot as proof.

A diagnostic graphic asks a specific question about a fitted model or its assumptions. Residuals versus fitted values can reveal systematic mean patterns or changing spread. A normal Q-Q plot compares ordered residuals with a reference distribution's quantiles. Neither graphic automatically decides whether an analysis is scientifically valid.

Build diagnostics from explicit fitted quantities. Retain observation identity so a surprising point can be traced back to its source. The same residual can arise from a measurement issue, a missing predictor, a nonlinear relationship or an unusual but legitimate observation. A visual pattern suggests further investigation rather than authorizing deletion by appearance alone.

The first fixture has a known linear trend and small authored errors chosen to be orthogonal to the design. This gives exact coefficient and residual checks before plotting. The diagnostic layers are then tied to the same numerical residuals, avoiding a chart that accidentally uses stale or differently ordered data.

A second fixture creates spread that grows with the predictor. Its residual magnitudes increase systematically even though the conditional mean is correctly represented. This distinguishes a variance-model concern from a wrong mean slope. It also explains why a low overall error can hide important subgroup or range-specific behavior.

Q-Q departures have several possible explanations, and fitted residuals are not an independent random sample of unobserved errors. Sample size, leverage, model fitting and dependence affect interpretation. Use diagnostics with substantive knowledge, sensitivity analyses and an appropriate validation design. A visually straight segment or nonsignificant test is not a universal assumption certificate.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Residual diagnostic | An examination of observed-minus-fitted values for a specified model concern. |
| Q-Q plot | A comparison of ordered sample values with theoretical or empirical reference quantiles. |
| Heteroskedasticity | Variation in conditional error spread across predictor values or groups. |
| Diagnostic hypothesis | A proposed explanation of a pattern that requires further evidence rather than automatic acceptance. |

## Worked examples

### Example 1: Tie diagnostic marks to fitted residuals

```r
d <- data.frame(id = 1:8, x = 0:7)
d$y <- 1 + 2 * d$x + c(-0.3, 0.2, 0.1, -0.2, 0.4, -0.1, 0.2, -0.3)
fit <- lm(y ~ x, data = d)
diagnostic <- data.frame(id = d$id, fitted = fitted(fit), residual = residuals(fit))
p <- ggplot2::ggplot(diagnostic, ggplot2::aes(fitted, residual)) +
  ggplot2::geom_point() +
  ggplot2::geom_hline(yintercept = 0, linetype = "dashed") +
  ggplot2::labs(x = "Fitted response", y = "Residual", title = "Residuals from the declared linear fit")
stopifnot(max(abs(unname(coef(fit)) - c(1, 2))) < 1e-10)
stopifnot(max(abs(ggplot2::ggplot_build(p)$data[[1]]$y - diagnostic$residual)) < 1e-12)
print(p)
```

**Expected observation:** Coefficients1/2 and eight correctly paired residual marks.

The numerical oracle validates the fit and the actual residual values passed to the layer. The plot then supports inspection of patterns rather than replacing those calculations.

### Example 2: Separate mean fit from changing spread

```r
d <- data.frame(x = rep(1:4, each = 2))
d$y <- 2 * d$x + rep(c(-1, 1), 4) * d$x
fit <- lm(y ~ x, data = d)
diagnostic <- data.frame(fitted = fitted(fit), residual = residuals(fit))
stopifnot(abs(coef(fit)[["x"]] - 2) < 1e-10)
stopifnot(abs(cor(abs(diagnostic$residual), diagnostic$fitted) - 1) < 1e-10)
p <- ggplot2::ggplot(diagnostic, ggplot2::aes(fitted, residual)) +
  ggplot2::geom_point() +
  ggplot2::geom_hline(yintercept = 0) +
  ggplot2::labs(x = "Fitted response", y = "Residual", title = "Authored spread increases with the predictor")
print(p)
```

**Expected observation:** Slope 2 with residual magnitude increasing exactly with fitted value.

Each predictor value has symmetric errors, preserving the mean line, while their magnitudes grow. This controlled construction isolates a spread concern without claiming a real dataset follows this mechanism.
