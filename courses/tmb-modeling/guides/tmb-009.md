# REPORT versus ADREPORT

Start with: tmb-008, bayes-015.

Outcome: Choose plain diagnostics or derivative-aware uncertainty for each output.

**Where this runs.** In the classroom, the base-R companion at the end of this chapter computes delta-method variances for transformed parameters. The templates in the separately prepared [owned project](../projects/tmb-local/README.md) declare both kinds of output, for example `REPORT(residual)` and `ADREPORT(sigma)` in `models/normal_mean.cpp`; `tests/acceptance.R` reads `obj$report()` and calls `TMB::sdreport`; a companion run is not a TMB compiler or rpy2 receipt, so its output is not evidence that a compiled model or the rpy2 bridge ran.

A fitted parameter vector is rarely the final scientific answer. You may want fitted values, a positive scale, an incidence ratio, a forecast or a contrast. TMB distinguishes ordinary report values from quantities for which derivatives are recorded.

`REPORT(value)` makes a value available through the object's report function. Use it for residual vectors and diagnostics when standard errors are not required. `ADREPORT(value)` records a differentiable derived quantity so `sdreport` can propagate uncertainty. An AD report is not a new likelihood term, not an observation and not evidence that a prediction has been externally validated.

## Key terms

- **REPORT:** A template macro that makes a value available through the object's report function for diagnostics, without derivative-based standard errors.
- **ADREPORT:** A template macro that records a differentiable derived quantity so `sdreport` can propagate parameter uncertainty to it.
- **Delta method:** The first-order approximation \(\operatorname{Var}(g)\approx JVJ^T\), where \(J\) is the Jacobian of the derived quantity \(g\) and \(V\) is the parameter covariance.
- **Derived quantity:** A function of fitted parameters, such as \(\sigma=e^s\) from a log-scale coordinate \(s\) or a rate ratio, reported on its natural scientific scale.

### Worked case A: scale on its natural units

Our normal template declares log sigma but uses `ADREPORT(sigma)`. If the covariance of log sigma is \(v_s\), its first-order variance on the original scale is \(\sigma^2v_s\). The companion verifies this derivative numerically. In the prepared project:

```r
fit <- fit_objective(obj)
plain <- obj$report(fit$par)
uncertainty <- TMB::sdreport(obj, par.fixed = fit$par)
summary(uncertainty, "report")
```

Pass `par.fixed=fit$par` explicitly. R's stored last-evaluated parameter state can differ from the final estimate after a diagnostic calculation. Evaluate reports at the intended estimate and retain parameter names rather than selecting arbitrary row numbers in an uninspected summary.

### Worked case B: a ratio with covariance

For \(g(\alpha,\beta)=e^{\beta-\alpha}\), the Jacobian is \((-g,g)\). Its variance approximation is \(g^2(V_{\alpha\alpha}+V_{\beta\beta}-2V_{\alpha\beta})\). Ignoring the covariance can seriously change uncertainty. The companion uses a small positive-definite covariance matrix and compares the full delta method to the independence assumption.

This ratio example also explains why plain `REPORT` and `ADREPORT` are not interchangeable. Both can return the same point estimate. Only the derivative-aware quantity supplies the Jacobian needed for the standard delta calculation. Conversely, AD-reporting a million fitted values can create unnecessary work and memory pressure when the scientific report only needs a few contrasts.

### Diagnostics and answered discussion

**Does the standard error of a fitted mean describe a future observation?** No. A new observation includes process or observation noise in addition to parameter uncertainty. **Should all residuals be AD-reported?** Usually not. They are often diagnostics, and their joint covariance can be large. **Can I report a threshold indicator with a delta standard error?** A discontinuous function is poorly served by a local derivative. Use a suitable simulation-based probability or a smooth scientific estimand, and explain what is approximated.

For random effects, `sdreport` combines conditional latent uncertainty and sensitivity to fixed parameters under its approximation. This is more than evaluating a derivative while holding every latent state fixed. Consult the [sdreport reference](https://cran.r-project.org/web/packages/TMB/TMB.pdf), and use chapter 18 to choose the correct predictive target.

### Worked case C: what `sdreport` should print for the normal template

Fit `normal_mean.cpp` to \(y=(1,2,4,7)\). The estimate of log sigma is \(\hat s=0.829114\), so \(\hat\sigma=\sqrt{5.25}=2.291288\). Chapter 8 showed that the Hessian in \((\mu,s)\) is \(\operatorname{diag}(0.7619,8)\), so the log-scale variance is \(1/8\). The derivative of \(\sigma=e^s\) is \(e^s\) itself, and the AD-reported standard error should therefore be \(2.291288\times\sqrt{1/8}=0.810093\). The call and the expected shape are:

```r
rep <- TMB::sdreport(obj, par.fixed = fit$par)
summary(rep, "report")
```

```text
       Estimate   Std. Error     (hand-derived from the closed-form Hessian)
sigma  2.291288   0.810093
```

Reading this table: the estimate is the square root of the ML variance 5.25, not `sd(y) = 2.645751`, because the template's density divides by \(n\) through the likelihood rather than by \(n-1\). The standard error is a first-order statement. With four observations, the implied interval \(2.29\pm1.96\times0.81\) dips to 0.70 on the low side, while back-transforming the log-scale interval gives \((1.15,4.58)\). TMB reports the former; deciding which interval to publish is the analyst's job. Because `residual` is only a `REPORT`, the same `summary(rep, "report")` call will not list it; it is reached through `obj$report(fit$par)$residual`, a plain vector \((-2.5,-1.5,0.5,3.5)\) with no standard errors.

### Covariance sign and the ratio example

The companion's covariance has a positive off-diagonal 0.015. Its ratio is \(e^{0.5}=1.648721\), the full delta standard error is \(1.648721\sqrt{0.04+0.09-0.03}=0.521371\), and the independence version is \(1.648721\sqrt{0.13}=0.594455\). Positive correlation between \(\alpha\) and \(\beta\) narrows the ratio's uncertainty because errors in the two coefficients partly cancel in \(\beta-\alpha\). Flip the sign to \(-0.015\) and the variance term becomes \(0.16\), so the standard error rises to \(1.648721\times0.4=0.659488\), larger than the independence value. In a compiled model, `ADREPORT(exp(beta - alpha))` gets this covariance automatically from the joint Hessian; hand-assembling the ratio from two marginal standard errors silently assumes the off-diagonal is zero.

A practical rule for this chapter: AD-report the few scalar quantities that appear in the results table, keep residual vectors and fitted curves in `REPORT`, and if a long vector must be AD-reported, call `sdreport` with `getReportCovariance = FALSE` as the project's acceptance test does, so TMB returns standard errors without storing the full dense covariance of every reported element.

### Base-R companion (runs in the classroom)

```r
s <- log(2); var_s <- .04
h <- 1e-6
jac <- (exp(s + h) - exp(s - h)) / (2 * h)
print(c(delta_variance = exp(2 * s) * var_s, numerical = jac^2 * var_s))
alpha <- .2; beta <- .7; ratio <- exp(beta - alpha)
V <- matrix(c(.04, .015, .015, .09), 2, 2)
J <- c(-ratio, ratio)
print(c(ratio = ratio, full_se = sqrt(drop(t(J) %*% V %*% J)), independence_se = ratio * sqrt(sum(diag(V)))))
stopifnot(abs(jac - exp(s)) < 1e-8, all(eigen(V, symmetric = TRUE)$values > 0))
```
