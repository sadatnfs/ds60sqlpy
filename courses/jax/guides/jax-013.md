# jax-013: Stable categorical losses and active-target masks

## Starting point and outcome

Intermediate. Direct prerequisites: `jax-012`

Compute a stable masked categorical objective and verify its value and direct logit gradients.


## Mechanism and purpose

A categorical model emits one score for each candidate. These logits are not probabilities. Softmax normalizes them, while log-softmax computes their normalized logarithms in a stable form. A target index selects the event whose assigned log probability is scored. The loss therefore depends on candidate identity, not just a sorted list of scores.

A mask selects which target events contribute to the objective. Its denominator must count the same events as its numerator. Padding adds storage positions without adding observations. Dividing by padded width makes the reported mean and every gradient depend on padding density. A lower number produced that way is not better prediction.

Ignoring a label does not erase its input representation from a complete model. An attention mask controls information access; a loss mask controls direct supervision. This unit supplies literal logits, so it isolates the loss and direct logit derivatives without claiming to test a whole decoder's attention or embedding paths.

Input validation is deliberately separate from the transformed numerical function. Host-side checks confirm shape, at least one active target and legal active class indices. The pure loss then replaces ignored sentinel indices with a safe gather index before selecting log probabilities. A masked invalid index should not be used in a gather and only discarded afterward.

Uniform logits make an exact baseline: every class has equal probability. That is useful for checking the active count, but it can hide target permutations because every target has the same loss. Also retain a nonuniform example whose correct class identity matters. The combination of value, active count and per-row gradients supplies stronger evidence than a single mean.

## Derivation and shape contract

With C classes and active indicators \(m_i\), define \(L=-\frac{\sum_i m_i\log p_i(y_i)}{\sum_i m_i}\). For N active targets, the derivative of an active logit is \((p_{ij}-\mathbf1_{\{j=y_i\}})/N\). At uniform three-class probabilities and three active targets, true-class coordinates have derivative \(-2/9\), other coordinates \(1/9\), and ignored rows zero. An all-ignored batch has no defined empirical mean.

### Worked example 1: Uniform active-target accounting

Validate the fixture with `admit`, then compute its mean loss.

The ignored row contributes neither negative log probability nor denominator count.

**Expected:** log(3), with three active targets.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import math
import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def admit(logits, targets, active):
    labels, mask = np.asarray(targets), np.asarray(active)
    if logits.ndim != 2 or labels.shape != (logits.shape[0],) or mask.shape != labels.shape:
        raise ValueError("one target and mask per logit row")
    if mask.dtype != np.bool_ or not mask.any():
        raise ValueError("at least one active Boolean target")
    if np.any(labels[mask] < 0) or np.any(labels[mask] >= logits.shape[1]):
        raise ValueError("active target outside classes")


def token_mean(logits, targets, active):
    safe = jnp.where(active, targets, 0)
    selected = jnp.take_along_axis(jax.nn.log_softmax(logits), safe[:, None], axis=1)[:, 0]
    return -jnp.where(active, selected, 0.0).sum() / active.sum()


logits = jnp.zeros((4, 3))
targets = jnp.array([0, 1, 2, -100])
active = jnp.array([True, True, True, False])


def main():
    # Case 1: Uniform active-target accounting
    admit(logits, targets, active)
    assert int(active.sum()) == 3
    close(token_mean(logits, targets, active), math.log(3.0))

    print("jax-013: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: Inspect direct gradients

Differentiate the loss with respect to every logit.

This exposes supervision identity even when uniform logits give equal losses for every target.

**Expected:** Diagonal true-class entries -2/9, other active entries 1/9, ignored row all zero.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def token_mean(logits, targets, active):
    safe = jnp.where(active, targets, 0)
    selected = jnp.take_along_axis(jax.nn.log_softmax(logits), safe[:, None], axis=1)[:, 0]
    return -jnp.where(active, selected, 0.0).sum() / active.sum()


logits = jnp.zeros((4, 3))
targets = jnp.array([0, 1, 2, -100])
active = jnp.array([True, True, True, False])


def main():
    # Case 1: Inspect direct gradients
    g = jax.grad(token_mean)(logits, targets, active)
    expected = np.full((4, 3), 1 / 9)
    expected[np.arange(3), np.arange(3)] = -2 / 9
    expected[3] = 0.0
    close(g, expected)

    print("jax-013: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

## Diagnosis and boundaries

A suspiciously small loss can come from a wrong denominator, wrong class axis or masking after an invalid operation. Inspect active target identities and direct gradients. The host-side validation function is intentionally not a transformed numerical kernel.
