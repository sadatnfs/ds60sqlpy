# mle-011: Model artifacts, registry versions and trusted loading

## Level and prerequisites

Intermediate. Direct prerequisites: `mle-004`, `mle-010`

**Outcome:** Publish and resolve a model artifact with an explicit trusted interface.

## Question and mechanism

A model artifact is a bundle of fitted state and its interface contract. The feature order, units, preprocessing, dependencies and validation evidence matter alongside the estimator. A consumer should verify compatibility and artifact identity before loading or using it.

The first case serializes a model created by this same program, verifies its exact bytes, reloads it and compares predictions. It then logs the artifact through MLflow, creates a real registered-model version and links a candidate alias to that version. This establishes actual local registry behavior, not a production promotion policy.

Serialized Python objects can execute code when loaded. The example loads only its own newly written trusted artifact. A hash checks integrity relative to a trusted expected value; it does not make an attacker-provided model and attacker-provided hash safe. The longer-lived service project uses a bounded JSON model representation to avoid arbitrary object deserialization at that serving boundary.

## Syntax and data contract

joblib writes and reads the program's own trusted fitted pipeline. A manifest retains feature order and SHA256. MLflow create_model_version links the artifact to its run, while set_registered_model_alias and get_model_version_by_alias exercise actual version resolution. A candidate alias is a label, not automatic acceptance or deployment.

## Worked case 1: Verify a trusted artifact and registry link

The first program checks bytes before reloading its own model, compares prediction parity and registers the artifact with MLflow. It verifies that the alias resolves to the expected version and run.

**Expected evidence:** Reloaded predictions match, and the actual registry version retains its linked run.

```python
import hashlib
import os
import tempfile
from pathlib import Path

import numpy as np
import pandas as pd


def configure_local_tools():
    os.environ.update(
        FEAST_USAGE="False",
        DO_NOT_TRACK="true",
        MLFLOW_ENABLE_TELEMETRY="false",
        MLFLOW_DISABLE_AGENT_HINT="1",
        DBT_SEND_ANONYMOUS_USAGE_STATS="false",
    )


def dataset():
    rng = np.random.default_rng(17)
    n = 120
    usage = rng.uniform(1, 100, n)
    tickets = rng.poisson(2, n)
    region = np.where(np.arange(n) % 2 == 0, "north", "south")
    logit = 0.9 * tickets - 0.035 * usage + (region == "north") * 0.3
    probability = 1 / (1 + np.exp(-logit))
    label = (rng.random(n) < probability).astype(int)
    cutoff = np.arange(n) + 100
    return pd.DataFrame(
        {
            "id": np.arange(n),
            "customer_id": np.arange(n) % 12,
            "cutoff": cutoff,
            "available_at": cutoff - 2,
            "label_available_at": cutoff + 4,
            "usage": usage,
            "tickets": tickets,
            "region": region,
            "label": label,
        }
    )


def fit_pipeline(frame):
    from sklearn.compose import ColumnTransformer
    from sklearn.impute import SimpleImputer
    from sklearn.linear_model import LogisticRegression
    from sklearn.pipeline import Pipeline
    from sklearn.preprocessing import OneHotEncoder, StandardScaler

    numeric = Pipeline([("impute", SimpleImputer(strategy="median")), ("scale", StandardScaler())])
    transform = ColumnTransformer(
        [
            ("numeric", numeric, ["usage", "tickets"]),
            ("region", OneHotEncoder(handle_unknown="ignore", sparse_output=False), ["region"]),
        ]
    )
    model = Pipeline(
        [("features", transform), ("classifier", LogisticRegression(max_iter=200, random_state=17))]
    )
    model.fit(frame[["usage", "tickets", "region"]], frame["label"])
    return model


def tracker(directory):
    configure_local_tools()
    from mlflow.tracking import MlflowClient

    root = Path(directory)
    root.mkdir(parents=True, exist_ok=True)
    client = MlflowClient(
        tracking_uri="sqlite:///" + str(root / "tracking.db"),
        registry_uri="sqlite:///" + str(root / "tracking.db"),
    )
    experiment = client.create_experiment(
        "local-quality-investigation", artifact_location=(root / "artifacts").as_uri()
    )
    return client, experiment


def example_one():
    frame = dataset()
    train = frame[frame.label_available_at <= 180]
    model = fit_pipeline(train)
    import joblib

    with tempfile.TemporaryDirectory() as d:
        path = Path(d) / "trusted-model.joblib"
        joblib.dump(model, path)
        expected = hashlib.sha256(path.read_bytes()).hexdigest()
        contract = {
            "features": ["usage", "tickets", "region"],
            "schema_version": 1,
            "artifact_sha256": expected,
        }
        assert hashlib.sha256(path.read_bytes()).hexdigest() == contract["artifact_sha256"]
        restored = joblib.load(path)
        sample = frame.iloc[[90]][contract["features"]]
        assert np.allclose(restored.predict_proba(sample), model.predict_proba(sample))
        client, experiment = tracker(Path(d) / "tracking")
        run = client.create_run(experiment)
        client.log_artifact(run.info.run_id, str(path), "model")
        client.create_registered_model("customer-model")
        version = client.create_model_version(
            "customer-model",
            source=f"runs:/{run.info.run_id}/model/{path.name}",
            run_id=run.info.run_id,
        )
        client.set_registered_model_alias("customer-model", "candidate", version.version)
        registered = client.get_model_version_by_alias("customer-model", "candidate")
        assert registered.version == version.version and registered.run_id == run.info.run_id
        client.set_terminated(run.info.run_id)
        return {
            "own_trusted_artifact_round_trip": True,
            "contract": contract,
            "registry_version": registered.version,
            "registry_linked_run": True,
        }


if __name__ == "__main__":
    print(example_one())
```


## Worked case 2: Detect integrity and semantic changes

The second case changes an artifact payload and a unit definition separately. The same feature names do not make hours and minutes compatible. Both exact-byte identity and semantic contract versioning are therefore needed.

**Expected evidence:** Tampered bytes fail their expected hash and the changed unit contract has a different identity.

```python
import hashlib
import json


def digest(data):
    return hashlib.sha256(
        json.dumps(data, sort_keys=True, separators=(",", ":"), allow_nan=False).encode()
    ).hexdigest()


def example_two():
    contract = {"features": ["usage", "tickets", "region"], "unit": "hours", "version": 1}
    incompatible = {**contract, "unit": "minutes", "version": 2}
    assert digest(contract) != digest(incompatible)
    payload = b"accepted model"
    expected = hashlib.sha256(payload).hexdigest()
    changed = payload + b"changed"
    assert hashlib.sha256(changed).hexdigest() != expected
    return {
        "same_names_do_not_prove_semantic_compatibility": True,
        "tamper_detected_before_deserialization": True,
    }


if __name__ == "__main__":
    print(example_two())
```

## Diagnose errors and misleading results

A model can deserialize successfully and still expect the wrong inputs. An alias can resolve correctly and still point to an unaccepted candidate. Inspect artifact identity, feature meaning and acceptance evidence separately, and reject untrusted executable serialization.
