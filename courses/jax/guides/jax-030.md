## Mechanism and purpose

A component is ready for reuse only when another reader can identify its accepted inputs, output meaning and failure policy. This capstone combines a masked regression objective with a closed-form ridge solve. It deliberately separates host-side input validation from the pure numerical functions, making the transformation boundary visible.

Each row represents an observation with a feature vector and one target. The mask selects participating observations. A ridge penalty applies to every supplied coefficient under this declared convention, including any intercept column. Other conventions can exclude an intercept; that would be a different objective and must be named rather than silently substituted.

The reference solves the normal equations for a tiny well-conditioned fixture. It is not a recommendation to form normal equations for every large or ill-conditioned regression problem. Their conditioning can be worse than the original design matrix. The scientific purpose here is a compact independently checkable objective with a known optimum and a gradient that should vanish there.

Acceptance has several layers. Shape and finite-value checks validate the data. An exact coefficient fixture checks the intended equation. A masked outlier and row permutation check the population and identity policy. The gradient at the solved optimum checks consistency between the objective and solution. JIT parity checks supported transformation behavior. None of those tests alone would establish a valid causal interpretation or population model.

## Key terms

- **Input-validation contract:** Host-side checks of shapes, finite values and a nonempty mask that run before the pure numerical functions.
- **Masked objective:** A loss averaged only over rows whose mask is one, so a masked outlier does not count as an observation.
- **Ridge penalty:** The term lambda times the squared coefficient norm, applied here to every coefficient including any intercept column.
- **Normal equations:** The linear system obtained by setting the ridge objective gradient to zero, solved here for a small well-conditioned fixture.
- **Layered acceptance:** Separate checks of data validity, an exact coefficient fixture, mask and permutation policy and a vanishing optimum gradient.

## Derivation and shape contract

Define \(L(w)=\sum_i m_i(x_i^{\mathsf T}w-y_i)^2/\sum_i m_i+\lambda\lVert w\rVert_2^2\). Setting its gradient to zero gives \((X^{\mathsf T}MX/N+\lambda I)w=X^{\mathsf T}My/N\), where M is diagonal with mask entries and \(N=\sum_i m_i\). For rows (1,0),(1,1),(1,2), targets 1,3,5 and lambda zero, the unique fixture solution is (1,2).

## Worked investigations

### Worked example 1: An independently known solution

Validate the unpenalized fixture with `admit`, solve it, then evaluate its gradient.

The coefficients are known from the target rule. A vanishing gradient additionally checks consistency between the coded objective and solved equation.

**Expected:** Weights [1,2], zero loss and zero gradient within tolerance.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import math
import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def admit(design, targets, mask, penalty):
    if design.ndim != 2 or targets.shape != (design.shape[0],) or mask.shape != targets.shape:
        raise ValueError("row contracts differ")
    if np.asarray(mask).dtype != np.bool_ or not np.asarray(mask).any():
        raise ValueError("nonempty Boolean observation mask required")
    if not math.isfinite(penalty) or penalty < 0:
        raise ValueError("nonnegative finite penalty required")
    if not np.isfinite(np.asarray(design)).all() or not np.isfinite(np.asarray(targets)).all():
        raise ValueError("finite literal data required")


def objective(weight, design, targets, mask, penalty):
    squared = (design @ weight - targets) ** 2
    return jnp.where(mask, squared, 0.0).sum() / mask.sum() + penalty * jnp.vdot(weight, weight)


def solve(design, targets, mask, penalty):
    count = mask.sum()
    weighted = mask[:, None] * design
    matrix = design.T @ weighted / count + penalty * jnp.eye(design.shape[1])
    rhs = design.T @ jnp.where(mask, targets, 0.0) / count
    return jnp.linalg.solve(matrix, rhs)


design = jnp.array([[1.0, 0.0], [1.0, 1.0], [1.0, 2.0]])
targets = jnp.array([1.0, 3.0, 5.0])
mask = jnp.ones(3, dtype=bool)


def main():
    # Case 1: An independently known solution
    admit(design, targets, mask, 0.0)
    weight = solve(design, targets, mask, 0.0)
    close(weight, [1.0, 2.0])
    close(objective(weight, design, targets, mask, 0.0), 0.0)
    close(jax.grad(objective)(weight, design, targets, mask, 0.0), [0.0, 0.0])

    print("jax-030: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: An ignored outlier is not an observation

Append a finite extreme row and target with mask false.

Both numerator and denominator preserve the three-observation population.
