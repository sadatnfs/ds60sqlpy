## Outcome and mechanism

Produce a small analytical report that connects the scientific question, model comparison, numerical evidence and limits.

An analysis is more than a fitted object. A reviewer needs to know the question, the observations used, the model choices, the evaluation design and the numerical evidence supporting each conclusion. A reproducible report preserves those relationships rather than displaying only a favorable score.

This unit compares an affine model with a quadratic feature model on a synthetic response rule. The training and held-out inputs are declared before fitting. The quadratic rule is known, providing an independent coefficient and prediction oracle. The comparison is useful precisely because its mechanics can be reconstructed without an external dataset or service.

Both candidates must be evaluated on the same held-out observation identities. Reordering predictions without preserving their IDs can change the errors while every vector length still looks correct. Retain IDs, targets and predictions together, validate uniqueness and align by identity before aggregating.

A lower held-out error on four authored points supports a bounded statement about that fixture. It does not establish that a quadratic model is generally preferable, that real data follow the same rule, or that a larger study's sampling uncertainty is negligible. Model-selection decisions should be separated from a final assessment if the comparison is extended.

A report artifact should preserve counts, metric definitions, candidate identities, package/runtime information and the relevant limitations. Temporary JSON round trips demonstrate a local serialization contract. They do not imply that arbitrary worker-created files are automatically exported or durable across classroom Runs. Keep the report's durable source and observed receipt in the supported channels, and use a separately prepared workflow for persistent external artifacts.

## Read the syntax

Fit both lm formulas on the training data only. Build a held-out table containing id, actual and each candidate prediction. Calculate squared-error means from aligned records. Use jsonlite with an owned tempfile for a bounded report round trip, and record R/package versions as metadata rather than claiming environment portability from a single run.

## Worked examples

### Example 1: Compare an explicit baseline

```r
train <- data.frame(x = c(-2, -1, 0, 1, 2))
train$y <- 1 + 2 * train$x - 0.5 * train$x^2
heldout <- data.frame(id = paste0("q", 1:4), x = c(-1.5, -0.5, 0.5, 1.5))
heldout$actual <- 1 + 2 * heldout$x - 0.5 * heldout$x^2
affine <- lm(y ~ x, data = train)
quadratic <- lm(y ~ x + I(x^2), data = train)
heldout$affine <- predict(affine, heldout)
heldout$quadratic <- predict(quadratic, heldout)
mse <- c(affine = mean((heldout$actual - heldout$affine)^2), quadratic = mean((heldout$actual - heldout$quadratic)^2))
stopifnot(abs(mse[["affine"]] - 0.390625) < 1e-10, mse[["quadratic"]] < 1e-20)
print(heldout)
print(mse)
```

**Expected observation:** Affine MSE 0.390625; quadratic error near zero on four authored held-out points.

The exact target rule supplies an independent oracle. Both candidates use the same four held-out rows, so the numerical comparison does not mix different evaluation populations.

### Example 2: Preserve report structure

```r
report <- list(question = "Compare two fixed synthetic regression candidates", counts = list(training = 5L, heldout = 4L), metric = "mean squared error per held-out observation", limitations = c("synthetic target", "four held-out observations"))
round_trip <- function(value) {
  path <- tempfile(fileext = ".json")
  on.exit(unlink(path), add = TRUE)
  jsonlite::write_json(value, path, auto_unbox = TRUE, pretty = TRUE)
  jsonlite::read_json(path, simplifyVector = TRUE)
}
restored <- round_trip(report)
stopifnot(restored$counts$heldout == 4, identical(restored$metric, report$metric))
print(restored)
```

**Expected observation:** Metric and held-out count preserved through a local JSON round trip.

Serialization retains a named report contract. The tempfile is owned and removed by the example, so this does not claim persistent artifact publication.
