# One-step-ahead predictive residuals

Start with: tmb-031, tmb-015.

Outcome: Construct diagnostics that respect observation ordering and conditioning.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

An ordinary fitted residual uses a model estimated with all available observations. A one-step-ahead residual instead evaluates the next observation using an appropriate conditional distribution given earlier observations. That distinction matters for latent time series and sequential model criticism.

For a continuous conditional CDF \(F_t\), the probability integral transform \(U_t=F_t(Y_t\mid Y_{1:t-1})\) is uniform under the correctly specified model, and \(Z_t=\Phi^{-1}(U_t)\) is standard normal. Parameters estimated from the same finite data can alter the ideal reference behavior, so simulation-based calibration remains useful.

### Worked case A: known Gaussian forecasts

The companion transforms a few observations using specified forecast means and standard deviations. It verifies that the resulting standardized residual equals the normal-CDF transform. The means are supplied as prior forecasts, not fitted retrospectively using each target observation.

`oneStepPredict` supports several Gaussian and generic methods and requires model-specific observation and indicator conventions. Its `observation.name`, `data.term.indicator`, `subset`, `conditional`, `reverse` and method settings must match the actual template. The current nine-model project does not claim full OSA support merely because the function is exported.

### Worked case B: discrete randomized residuals

A Poisson CDF jumps at integer values, so directly applying its CDF does not produce a continuous uniform variable. A randomized transform samples within the observed probability mass interval: \(F(y)-V p(y)\), with \(V\sim U(0,1)\). The companion implements this on seeded count observations and records the seed.

A different randomized residual seed changes individual residuals without changing the fitted model. Diagnose distributions and patterns, not the visual appeal of one chosen seed. Do not search seeds until a normality plot looks better.

### Answered discussion

**Can observations be reordered freely?** The joint factorization may remain valid, but conditional questions and diagnostic patterns change. Time-series order should follow the scientific forecasting task. **Does `parallel=TRUE` make all methods efficient?** It changes execution and needs its own resource and equivalence check. **Is OSA a forecast benchmark?** It is a model diagnostic. A held-out forecast evaluation still needs a defined training/validation separation and horizon.

Read [oneStepPredict's complete arguments and beta-status note](https://cran.r-project.org/web/packages/TMB/TMB.pdf) before preparing a template-specific native example.

### Complete R companion

```r
y <- c(-.2, .5, 1.4);forecast_mean <- c(0, .2, 1);forecast_sd <- c(1, .5, .8)
z <- qnorm(pnorm(y, forecast_mean, forecast_sd))
print(z);stopifnot(max(abs(z - (y - forecast_mean) / forecast_sd)) < 1e-12)
set.seed(3232);counts <- c(0, 1, 3, 5);lambda <- 2
u <- ppois(counts, lambda) - runif(length(counts)) * dpois(counts, lambda)
print(data.frame(counts = counts, randomized_quantile = u, residual = qnorm(u)))
stopifnot(all(u > 0 & u < 1))
```
