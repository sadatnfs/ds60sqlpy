its explicitly selected Compose project and its labeled PostgreSQL volume.

replacement, HTTP acceptance, browser delivery and saved readback are separate
claims. Keep fixed actions, loopback ports, exact Host/Origin checks, per-framework
sessions, owner-scoped SQL/ORM, CSRF enforcement and bounded message/body limits.

framework dependencies; this Dockerfile adds original source and collected
Django static assets. The local OpenAPI explorer is an original limited viewer,
not Swagger/ReDoc. Preserve offline behavior and use textContent for schema and
response data. Do not introduce external fonts, analytics or validators.

database contents and receipts outside source payloads. A successful TestClient
lesson is not evidence for this real server workshop.
