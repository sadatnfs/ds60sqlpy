## Outcome and mechanism

Fit and evaluate a small time-series model while preserving temporal information boundaries and forecast targets.

Time order is part of the data contract. A forecast made at one origin may use only information available by that origin. Randomly shuffling observations can therefore answer a different question from future prediction and can introduce information from later periods into an earlier fit.

ARIMA models describe dependence through autoregressive terms, differencing and moving-average innovation terms. The order triple p,d,q names those components; it is not a universal recipe chosen merely because a series looks noisy. Differencing changes the modeled quantity, while intercept and mean conventions depend on whether the series is differenced.

A fixed-parameter AR(1) fixture is useful for checking forecast mechanics. With zero mean and coefficient one half, an h-step forecast is one half to the h power times the latest value. Holding the coefficient fixed separates this arithmetic from estimation uncertainty and model selection. It does not claim that one half is an appropriate parameter for an unseen real series.

Forecast standard errors describe the fitted model's predictive uncertainty under its assumptions. Their nominal intervals do not automatically account for all model-selection, parameter or structural-change uncertainty. Residual diagnostics can identify remaining patterns, but a lack of obvious structure in a short series is limited evidence.

Rolling-origin evaluation records each training window, origin, horizon, prediction and later outcome. A naive last-value baseline is often a useful comparison because its information boundary is transparent. Keep horizons and denominators consistent when aggregating errors, and do not tune a model repeatedly on the final backtest period while presenting that period as untouched evaluation.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Forecast origin | The last time whose information is available when a forecast is issued. |
| Innovation | A new unpredictable disturbance under the stated time-series model. |
| Differencing | Transforming a series into changes, which alters the quantity modeled. |
| Backtest | Evaluation of forecasts against later observed outcomes using declared historical information boundaries. |

## Read the syntax

Use ts to retain an observation frequency and arima with explicit order, mean and fitting options. predict(fit,n.ahead=...) returns forecast means and standard errors. For a fixed coefficient, set fixed and its transformation policy deliberately. A rolling-origin loop must slice training data before each target time and retain its forecast horizon.

## Worked examples

### Example 1: A fixed AR(1) oracle

```r
y <- ts(c(2, 1.2, 0.8, 0.1, -0.2, 0.3, 0.1, 0.4))
fit <- arima(y, order = c(1, 0, 0), include.mean = FALSE, fixed = 0.5, transform.pars = FALSE, method = "ML")
forecast <- predict(fit, n.ahead = 3)
stopifnot(max(abs(as.numeric(forecast$pred) - 0.4 * 0.5^(1:3))) < 1e-10)
stopifnot(all(is.finite(forecast$se)), all(forecast$se >= 0))
print(forecast)
```

**Expected observation:** Forecasts 0.2,0.1,0.05 with finite nonnegative SEs.

The coefficient and mean are fixed explicitly, so the forecast means have a hand-calculated oracle. The fitted innovation scale and its forecast SE are separate model-dependent quantities.

### Example 2: A rolling-origin naive baseline

```r
y <- 1:8
origins <- 4:7
records <- do.call(rbind, lapply(origins, function(origin) {
  training <- y[seq_len(origin)]
  prediction <- tail(training, 1)
  data.frame(origin = origin, target_time = origin + 1, prediction = prediction, actual = y[origin + 1])
}))
records$error <- records$actual - records$prediction
stopifnot(all(records$origin < records$target_time), all(records$error == 1), mean(records$error^2) == 1)
print(records)
```

**Expected observation:** Four one-step forecasts, all errors1, MSE 1.

Every prediction uses only its prefix. The exact trend fixture gives error one for the last-value baseline, making the information boundary and error calculation visible.

## Reference review

The fixed-coefficient model isolates forecast arithmetic from parameter estimation. The rolling-origin reference separately verifies that each forecast uses a historical prefix and is scored at the declared next time. This prevents a correct error formula from hiding an invalid information boundary.

The differencing check retains both the new length and changed target. Forecast uncertainty is reported as a property of the fitted model, with its assumptions and omitted uncertainty sources named. No production forecasting claim follows from these synthetic controls.
