# clp-012: Correlated panel residuals

Tutorial mode. Stage: intermediate. Direct prerequisites: `clp-006`, `r-049`.

## Keep dependent observations together

Repeated measurements within a subject can remain correlated after subtracting their mean curve. Treating them as independent changes the likelihood and often overstates how much independent information the sample contains. A convenient introductory model uses a stationary AR(1) covariance for each complete panel:

\[
\Sigma_{jk}=\sigma^2\rho^{|j-k|},\qquad \sigma>0,\quad |\rho|<1.
\]

Here \(\sigma\) is the marginal residual standard deviation, not the innovation standard deviation. For a stationary AR(1) recursion, innovation variance is \(\sigma^2(1-\rho^2)\). Confusing those definitions changes every covariance entry. The integer distance assumes equally spaced observations; irregular time gaps require a model that encodes their actual distance.

If panels are independent conditional on shared parameters, the total NLL sums complete-panel contributions. For residual vector \(r_g\) of length \(T\),

\[
\mathcal L_g=\frac12\{T\log(2\pi)+\log|\Sigma|+r_g^\top\Sigma^{-1}r_g\}.
\]

Rows within a panel do not separately factor under this marginal representation. They can sometimes be expressed through sequential conditional densities, but those conditionals must preserve the model's history and boundary treatment.

## Numerical linear algebra

Factor \(\Sigma=LL^\top\) with a lower-triangular Cholesky factor. Solve \(Lz=r_g\), giving quadratic form \(z^\top z\), and compute \(\log|\Sigma|=2\sum_j\log L_{jj}\). Avoid explicitly constructing \(\Sigma^{-1}\) merely to evaluate a quadratic form. Cholesky also provides a useful domain check because an invalid covariance fails positive-definiteness requirements.

Dense Cholesky is appropriate for the tiny teaching panels. It has cubic cost in panel length and quadratic storage. A production implementation for long structured time series would exploit the structure, such as innovation recursions or sparse methods, while preserving the same probability law.

## Worked case 1: two complete independent panels

Use residuals \((0.4,0.2,-0.1)\) and \((-0.3,0.1,0.2)\), with marginal scale 0.5 and correlation 0.6. Their common covariance has diagonal 0.25, adjacent covariance 0.15 and lag-two covariance 0.09. The program computes the summed Cholesky NLL and compares it with two evaluations of Torch's `MultivariateNormal`.

The total is about 1.424674. This value has a concrete interpretation only with its observation units, scale and covariance attached. The code reports two independent panels, not six independent records. It does not estimate covariance parameters from these two panels, and it does not claim that such a small sample would support reliable uncertainty estimation.

## Worked case 2: flattening changes the model

Concatenate the two residual vectors and incorrectly apply one length-six AR(1) covariance. The model now correlates the last measurement of the first subject with the first measurement of the second. Its NLL is about 1.201530, a different value for a different probability model. The lower value does not indicate a better implementation; the supposed subjects were made dependent by a coding shortcut.

Set \(\rho=0\) instead. The within-panel covariance becomes diagonal and the joint NLL agrees with the independent Normal calculation, approximately 2.054748. This limiting case is an independent structural check on the covariance formula and log-determinant calculation. A correct nonzero-correlation implementation should recover this simpler boundary of the model family.

## Debugging and scientific limits

Verify sorting within each panel, panel identifiers, repeated timestamps and gaps. A grouping operation that drops identifiers before sorting can create false adjacency. Do not combine two different subjects to fill a fixed-size tensor batch without retaining a mask and covariance block boundary. Missing observations require selecting the appropriate covariance submatrix or deriving a valid conditional model; replacing missing residuals by zero creates artificial information.

Near \(|\rho|=1\), the covariance becomes ill-conditioned. A transform can keep the parameter inside its domain but cannot guarantee numerical stability. If a diagonal jitter is added, disclose its magnitude and sensitivity because it changes the covariance. Independent-panel sandwich or bootstrap uncertainty needs enough independent panels; a large number of correlated rows is not a substitute.

## Answered review questions

**Can Spark parallelize this likelihood?** Complete independent panels can be assigned to workers, each returning panel loss and gradient contributions. Splitting a panel across workers requires an explicit valid decomposition, not arbitrary row summation.

**Why retain the log determinant?** It penalizes changes in covariance volume and depends on estimated scale and correlation. Keeping only the quadratic form allows covariance inflation to distort fitting.

**Does this execute a cluster?** No. It verifies the local complete-panel formula with actual Torch linear algebra. Distributed scheduling, retries and aggregation are separate engineering and validation tasks.

```python
"""Complete float64 CPU likelihood investigation with original synthetic data."""

from __future__ import annotations

import json
import math

import torch

DTYPE = torch.float64
torch.set_num_threads(1)


def tensor(values):
    return torch.as_tensor(values, dtype=DTYPE)


def ar1_covariance(length, sigma, rho):
    sigma, rho = tensor(sigma), tensor(rho)
    if (
        length < 1
        or sigma.ndim != 0
        or rho.ndim != 0
        or not bool(torch.isfinite(sigma) & torch.isfinite(rho))
        or float(sigma) <= 0
        or abs(float(rho)) >= 1
    ):
        raise ValueError("Require positive scale and an interior stationary correlation")
    index = torch.arange(length)
    distance = (index[:, None] - index[None, :]).abs()
    return sigma.square() * rho.pow(distance)


def panel_nll(residuals, sigma, rho):
    if residuals.ndim != 2 or residuals.numel() == 0 or not bool(torch.isfinite(residuals).all()):
        raise ValueError("Use a finite nonempty matrix of independent complete panels")
    groups, length = residuals.shape
    covariance = ar1_covariance(length, sigma, rho)
    factor = torch.linalg.cholesky(covariance)
    whitened = torch.linalg.solve_triangular(factor, residuals.T, upper=False)
    return (
        groups * (length * math.log(2 * math.pi) / 2 + torch.log(torch.diag(factor)).sum())
        + whitened.square().sum() / 2
    )


def run_cases():
    residuals = tensor([[0.4, 0.2, -0.1], [-0.3, 0.1, 0.2]])
    sigma, rho = 0.5, 0.6
    correct = panel_nll(residuals, sigma, rho)
    distribution = torch.distributions.MultivariateNormal(
        torch.zeros(3, dtype=DTYPE), covariance_matrix=ar1_covariance(3, sigma, rho)
    )
    independent_oracle = -distribution.log_prob(residuals).sum()
    diagonal = panel_nll(residuals, sigma, 0.0)
    iid = -torch.distributions.Normal(tensor(0), tensor(sigma)).log_prob(residuals).sum()
    wrong = panel_nll(residuals.reshape(1, -1), sigma, rho)
    assert torch.allclose(correct, independent_oracle, atol=1e-12, rtol=0)
    assert torch.allclose(diagonal, iid, atol=1e-12, rtol=0)
    assert abs(float(correct - wrong)) > 1e-4
    return {
        "two_independent_panel_nll": float(correct),
        "wrong_cross_boundary_nll": float(wrong),
        "rho_zero_nll": float(diagonal),
        "panel_covariance": ar1_covariance(3, sigma, rho).tolist(),
        "independent_units": 2,
    }


if __name__ == "__main__":
    print(json.dumps(run_cases(), sort_keys=True, allow_nan=False))
```
