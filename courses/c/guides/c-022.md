# c-022: Stacks, queues and ring-buffer invariants

## Level and prerequisites

Intermediate, approximately 120 minutes plus a later retrieval session. Direct prerequisites: `c-021`

## Learning objectives

Implement the six investigations, from the "preserve FIFO order" case to the "transfer stack contrast" case, with explicit checks, identify a plausible defect and defend a fresh boundary case before execution. Completing a reference is not evidence of independent mastery.

## Purpose and mental model

A stack removes the most recently inserted value; a queue removes the earliest. The same array storage can support different behavioral contracts. A bounded ring buffer reuses positions by wrapping indices modulo capacity. Keep occupancy separate from index values so full and empty are not confused when head equals tail. Every enqueue must prove spare capacity before writing, and every dequeue must prove nonempty state before reading. Fixed capacity makes resource use predictable and overflow behavior explicit. A concurrent queue requires additional synchronization; the sequential ring here is not automatically safe to share across threads.

## Vocabulary and concepts

- **FIFO:** First in, first out removal order.
- **LIFO:** Last in, first out removal order.
- **Ring buffer:** Fixed storage reused through wrapped indices.

## Syntax anatomy and execution trace

The queue stores head and count. The next insertion index is (head+count)%capacity, and removal advances head modulo capacity. count ranges from zero through capacity. Returning bool plus an output pointer preserves the distinction between an empty queue and a legitimate zero-valued item. Rejected operations leave both structure and output unchanged.

## Worked example / walkthrough

### Worked example 1: Preserve FIFO order

Enqueue 2 then 5 and dequeue twice.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

enum { QUEUE_CAPACITY = 4 };
struct Queue {
  int data[QUEUE_CAPACITY];
  size_t head, count;
};
bool enqueue(struct Queue *q, int value) {
  if (q->count == QUEUE_CAPACITY)
    return false;
  size_t index = (q->head + q->count) % QUEUE_CAPACITY;
  q->data[index] = value;
  q->count++;
  return true;
}
bool dequeue(struct Queue *q, int *out) {
  if (q->count == 0 || out == NULL)
    return false;
  *out = q->data[q->head];
  q->head = (q->head + 1) % QUEUE_CAPACITY;
  q->count--;
  return true;
}

int main(void) {
  /* Preserve FIFO order */
  {
    struct Queue q = {0};
    int out = 0;
    CHECK(enqueue(&q, 2) && enqueue(&q, 5));
    CHECK(dequeue(&q, &out) && out == 2);
    CHECK(dequeue(&q, &out) && out == 5);
  }
  puts("Worked example checks passed.");
  return 0;
}
```

**Observe:** The values arrive as 2 then 5.

The queue contract differs from a stack, which would return 5 first.

### Worked example 2: Reject an empty read

Dequeue from a new queue with output 9.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

enum { QUEUE_CAPACITY = 4 };
struct Queue {
  int data[QUEUE_CAPACITY];
  size_t head, count;
};
bool enqueue(struct Queue *q, int value) {
  if (q->count == QUEUE_CAPACITY)
    return false;
  size_t index = (q->head + q->count) % QUEUE_CAPACITY;
  q->data[index] = value;
  q->count++;
  return true;
}
bool dequeue(struct Queue *q, int *out) {
  if (q->count == 0 || out == NULL)
    return false;
  *out = q->data[q->head];
  q->head = (q->head + 1) % QUEUE_CAPACITY;
  q->count--;
  return true;
}

int main(void) {
  /* Preserve FIFO order */
  {
    struct Queue q = {0};
    int out = 0;
    CHECK(enqueue(&q, 2) && enqueue(&q, 5));
    CHECK(dequeue(&q, &out) && out == 2);
    CHECK(dequeue(&q, &out) && out == 5);
  }

  /* Reject an empty read */
  {
    struct Queue q = {0};
    int out = 9;
    CHECK(!dequeue(&q, &out) && out == 9 && q.count == 0);
  }
  puts("Worked example checks passed.");
  return 0;
}
```

**Observe:** The operation fails and output stays 9.

No element is read before the occupancy check. Zero cannot be used as an empty sentinel because zero may be a real item.

### Exercise 3: Reject a full write

Fill four slots and attempt a fifth insertion.

**Expected:** The fifth fails and occupancy stays four.

**Verify:** Keep a CHECK equivalent to `!enqueue(&q, 99) && q.count == 4`. Control edit: changing `for (int i = 0; i < 4; i++)` to `for (int i = 1; i < 4; i++)` must fail it; then restore it.

**Progressive hints:** First trace `q` from initialization. Then recall: A bounded container must state whether full means reject, overwrite or block.

### Exercise 4: Wrap reused storage

Fill, remove two values, then add two more.

**Expected:** Remaining order is 2, 3, 4, 5.

**Verify:** Keep a CHECK equivalent to `dequeue(&q, &out) && out == i`. Control edit: changing `for (int i = 2; i < 6; i++) {` to `for (int i = 2; i <= 6; i++) {` must fail it; then restore it.

**Progressive hints:** First trace each value in `dequeue(&q, &out) && out == i` from initialization. Then recall: Wrapped physical positions still implement one logical FIFO sequence.

### Exercise 5: Retain a real zero

Enqueue zero and then read it.

**Expected:** The read succeeds with output zero.

**Verify:** Keep a CHECK equivalent to `enqueue(&q, 0) && dequeue(&q, &out) && out == 0`. Control edit: `CHECK(enqueue(&q, 1) && dequeue(&q, &out) && out == 0);` must fail; then restore it.

**Progressive hints:** First trace `q` and `out` from initialization. Then recall: Status and payload are separate channels, so an ordinary zero does not look like failure.

### Exercise 6: Transfer stack contrast

Push 2 and 5 into a bounded stack and pop once.

**Expected:** The popped value is 5.

**Verify:** Keep a CHECK equivalent to `out == 5 && length == 1`. Control edit: changing `size_t length = 0;` to `size_t length = 1;` must fail it; then restore it.

**Progressive hints:** First trace `out` and `length` from initialization. Then recall: The pop index is the last occupied position. `CHECK(length > 0)` proves the stack is nonempty before the decrement, so `stack[--length]` never wraps the unsigned `length` to `SIZE_MAX` and reads outside `stack`; a general pop must make the same test and report failure instead.

## Common pitfalls and diagnosis

Computing the ring index as `head + count` without `% capacity` runs past the array. Comparing `head == tail` alone cannot tell an empty buffer from a full one; keep an explicit count.
