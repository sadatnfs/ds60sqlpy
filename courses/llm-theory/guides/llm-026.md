# llm-026: What a representation probe establishes

## Level and prerequisites

Intermediate; approximately 105 minutes. Direct prerequisites: `llm-025`. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

## Learning objectives

Distinguish accessible information from a causal explanation of a model decision. The central investigation is concrete: Probe frozen tiny-model representations on a synthetic local label with a shuffled-label control and a held-out document split. The finish condition is Report the control result and split unit. Even a successful probe is not described as proof that the model used that feature causally. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

## Purpose and mental model

<!-- textbook-advanced-start -->

### Ask what information a representation makes accessible

An internal representation is a vector produced by some stage of a model. It can contain information useful for many tasks, including information that the model's own output layer never uses. A probe is a separate predictor that reads this vector and attempts to recover a chosen label. The central question is therefore about accessibility under a specified readout, not automatically about a causal explanation of the original model's behavior.

Write h_i in \(\mathbb{R}^d\) for the frozen representation of example i and y_i for its label. A linear binary probe forms \(z_{i}={w}^{T}\) h_i+b and probability \(p_{i}=\sigma(z_{i})\), where \(\sigma(z)=\frac{1}{1+\exp(-z)}\). The probe's trainable parameters are w and b. The representation-generating model has its own parameters theta, which remain fixed during this investigation. Keeping these two parameter sets separate makes the meaning of "frozen" precise.

#### Build a positive control whose answer can be derived

The supplied vectors are[-2,0],[-1,1],[1,0],[2,1], with labels[0,0,1,1]. The first coordinate was deliberately chosen to encode the label's sign. A threshold at zero therefore classifies all four correctly. This is a positive control for the mechanics of reading a representation: we know where the signal was placed and can verify that the readout finds it. It is not evidence that an independently trained language model discovered a linguistic property.

A transparent logistic-regression calculation shows how a learned probe could move toward this signal. Initialize \(w=[0,0]\) and \(b=0\). Every prediction is then .5. For mean binary cross entropy, the gradient is \(\frac{\partial L}{\partial w}=\frac1N\sum_i(p_i-y_i)h_i\) and \(\frac{\partial L}{\partial b}=\frac1N\sum_i(p_i-y_i)\). On the four vectors, residuals are[.5,.5,-.5,-.5]. Their weighted first-coordinate sum is-3, their second-coordinate sum is 0, and their scalar sum is 0. Dividing by \(N=4\) gives gradient[-.75,0] and bias gradient 0.

With learning rate 1, a gradient-descent step produces \(w=[0.75,0]\). It now assigns negative logits to the first two rows and positive logits to the last two. This derivation explains why a separate probe can learn the supplied signal while the feature tensor stays unchanged. The current reference demonstrates a fixed sign predictor and an independent trainable-weight gradient path; it does not run this full logistic-training experiment or measure a pretrained encoder. The expanded calculation is a paper-and-pencil interpretation of the mechanism.

#### Keep three kinds of evidence apart

Consider a downstream model whose decision is based only on the second coordinate h_2. The full representation still makes the label perfectly decodable through h_1, but that downstream computation ignores h_1. A successful probe of h_1 therefore does not establish that the original decision used it. Conversely, a weak probe that fails to recover a label does not establish that no information is present: the signal may require a nonlinear readout, a different token aggregation or more data.

It helps to separate three claims. A representation contains recoverable information if a specified probe predicts a label on an appropriate evaluation set. A probe is simple or efficient under a declared capacity and training budget if the readout class and fitting procedure justify that description. A feature is causally used for an original behavior only if an appropriate intervention or other causal design connects changes in that feature to the behavior. Each claim needs a different experiment.

An intervention is not automatically definitive either. Replacing an activation coordinate with an extreme value may move the vector far outside the distribution produced by the model. A changed output can then reflect disruption rather than the ordinary functional role of that coordinate. Compare controlled interventions, meaningful baselines and multiple settings, and name the outcome being measured. The tiny lesson is an introduction to these distinctions, not an implementation of a complete causal interpretability method.

#### Probe capacity changes the interpretation

A linear probe with d input features has d weights plus a bias for binary classification. A larger multilayer probe can represent more complicated decision boundaries and may also memorize source identity. If one probe achieves a higher score, the difference could arise from better access to the intended feature, greater capacity to solve the task itself, different optimization or a more favorable split. Architecture alone does not identify the explanation.

A control task asks whether the same probe can succeed on a label assignment that should not reveal the target linguistic relationship. For example, a stable random label assigned to each word type can expose a probe's ability to memorize identity. Such a control should be fitted and evaluated with the same capacity and budget as the main probe if the comparison is intended to assess memorization. The lesson's shuffled-label exercise instead compares a fixed sign predictor with one permuted label vector. It shows an association breaking in that small table, but it is not a retrained control-task study.

The primary [probe-control study](https://arxiv.org/abs/1909.03368) motivates making the readout's learning ability visible. The course fixture uses authored vectors so every label relationship can be inspected locally. Its \(\frac{2}{4}\) shuffled score is not a universal chance threshold for arbitrary label imbalance, multiclass tasks or different permutation schemes. Define the null comparison before interpreting its numeric value.

#### A split must separate the intended unit of transfer

The two held-out vectors[-3,1] and[3,0] are correctly classified by the frozen sign rule. Report that as \(\frac{2}{2}\) on the supplied positive control. There are only two observations, and the label construction remains exactly the same sign rule. The result verifies transfer to these two constructed points; it cannot establish broad semantic generalization.

Now suppose training and evaluation contain different sentences copied from the same document template. Even if the rows differ, a probe may exploit shared formatting or document identity. A split by row is then weaker than a split by source family. If the intended question is transfer to unseen documents, all related examples from one document family should remain on one side. If the intended question is transfer across languages or domains, the split must reflect that harder boundary. A held-out label alone does not specify what was held out.

Preprocessing and representation selection also belong inside the experimental boundary. Choosing the best layer, pooling rule, regularization strength or threshold after repeatedly examining final evaluation results uses that set for selection. A clean final assessment requires a prior development split or another explicit selection procedure. Freezing the base encoder does not freeze all these other decisions.

#### Follow gradients to verify the frozen-state contract

A representation tensor can be detached from the encoder graph while a new probe weight still requires gradients. The probe loss then updates w without changing theta. Merely naming a variable `frozen_features` does not enforce this. Inspect which parameters require gradients, which parameters belong to the optimizer, and whether the representation is recomputed under a training mode that changes buffers or stochastic behavior.

There are several different failure signatures. A probe gradient of None can mean that a tensor was disconnected or never used. A zero gradient tensor can mean the current derivative is zero. A nonzero encoder gradient violates a strict frozen-encoder experiment even if the optimizer later ignores it. An encoder buffer changing under training mode can alter representations without any parameter gradient. For a real study, save and compare the relevant model state rather than checking a single tensor flag.

The representation's axes matter too. A token-level task, a pooled sentence task and a document-level task use different examples and denominators. Averaging token vectors can erase order information; selecting the final token can make sequence length and causal context important. State the extraction rule, layer, tokenization and model version so another reader can reproduce the representation being probed.

#### Read a result without turning it into an explanation it did not earn

A defensible conclusion might say: "A fixed linear sign rule recovered the authored binary label on four construction rows and two new rows; the shuffled comparison scored \(\frac{2}{4}\); no original-model causal-use claim was tested." A real encoder study would replace those construction details with actual model and dataset identities, probe fitting results and independent evaluation units. The language of the conclusion should follow the experiment, not the attractiveness of a perfect score.

## Vocabulary and concepts

**Probe:** A supervised readout trained or evaluated on a representation.

**Frozen representation:** Features held fixed while the readout is investigated.

**Causal use:** A feature influencing a decision under an appropriate intervention.

## Syntax anatomy and reasoning sequence

Create frozen torch tensors and fit or derive a small linear probe separately from the encoder. Never backpropagate the probe objective into the frozen representation. Compare predicted labels on held-out identities, not the same rows used to choose the threshold. Shuffling labels changes the association while retaining the feature distribution. Record counts and split units beside both scores.

## Decodable information is not necessarily used information

The synthetic representations are [-2, 0], [-1, 1], [1, 0], [2, 1], with labels determined by the sign of the first coordinate. A fixed threshold on that coordinate decodes every training label and the two supplied held-out labels. Consider a downstream model that instead reads only the second coordinate. The label remains decodable from the full representation even though that downstream computation ignores the informative coordinate. This is a concrete counterexample to equating decodability with causal use.

The fixture's threshold predictor is hand specified, and its separate trainable linear weight demonstrates a gradient path without updating the frozen representation tensor. It is not a full pretrained-model probe experiment. The shuffled-label comparison checks this fixed predictor against a permuted label vector; it is not the same as retraining a probe on shuffled labels under an equal optimization budget. Those distinctions keep the demonstration's conclusion aligned with the work actually performed.

## Design a real probe comparison

A probe study would identify a representation layer and token aggregation rule, freeze the base model, fit a declared-capacity predictor using training records and evaluate on held-out families. Probe capacity matters: a powerful predictor may memorize labels or solve a task from incidental structure rather than reveal a simple, accessible feature. Compare with meaningful baselines and controls under the same split and budget, not only with chance accuracy on the training set.

Known family overlap can make a held-out score optimistic even when the representations themselves are frozen. Two rows from one source family are not automatically independent examples of transfer. The two-point holdout here is a teaching fixture, not a precise estimate of deployment reliability. Report its count, label construction and limitations rather than attaching a broad semantic claim to perfect accuracy.

A causal-use claim needs an intervention or other design connecting the represented information to the model's behavior. Removing or changing a feature, activation or component can be informative, but such an intervention must be interpreted carefully because it may shift the representation outside its ordinary distribution. A probe result, an intervention result and an explanation of model behavior are related evidence, not interchangeable labels.


## Worked example / walkthrough

### Example A: Construct transparent representations

The label is deliberately encoded in a coordinate. This supplies a clear positive control for the probing procedure.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F

features=torch.tensor([[-2.,0.],[-1.,1.],[1.,0.],[2.,1.]]); labels=torch.tensor([0,0,1,1]); prediction=(features[:,0]>0).long()
assert torch.equal(prediction,labels)
```

**Expected:** first-coordinate sign predicts all four labels.

### Example B: Use a held-out fixture

The threshold is fixed before opening these two rows. The result has only two held-out units and should be reported with that count.

```python
import numpy as np
```

**Expected:** two correct held-out predictions.

## Common pitfalls and diagnosis

Ask whether the result shows information present in a representation, a predictor trained to recover it, or the original model using it. These are distinct claims. Inspect probe capacity, split families and the exact shuffled-label control that ran. Perfect accuracy on two synthetic holdout rows is not broad semantic or causal evidence.
