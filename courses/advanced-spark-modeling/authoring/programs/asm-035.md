# Worked reference: Coupled Hessian counterexample

This is an editable reading/project reference. It has no ordinary pad Run action.

For H=[[2,1],[1,2]], det(H)=3. Treating the diagonal blocks as independent gives 2*2=4. The omitted curvature contribution is half log(4/3), approximately 0.1438410362. At off-diagonal zero, both determinants are four.

A spatial edge crossing a Spark partition boundary contributes coupling. Dropping it changes the prior and marginal likelihood. Valid alternatives include complete independent connected components or a solver that retains the cross-block structure. This calculation is a proof counterexample, not a distributed coupled-Laplace implementation.
