# viz-006: Compare models on common observations and scales

## Level and prerequisites

Intermediate. Direct prerequisites: `viz-003`, `viz-005`, `statistics-022`.

## Preserve the pairing

Two models predict the same eight held-out outcomes 1 through 8. Model A errors are .2,-.2,.5,-.5,.1,-.1,1,-1. Model B errors are .4,-.4,.6,-.6,.2,-.2,1.5,-1.5. A paired comparison follows each user's two losses instead of comparing unrelated aggregate distributions.

The first panel plots observed versus predicted values for both models on the same axes, with an identity line. Circles and squares distinguish models independently of color. The second panel shows each user's squared loss under A minus squared loss under B. This decomposition reveals where the average gain originates.

## Worked case: connect geometry and loss

A point above the identity line is an overprediction. Distance from that line in the outcome direction is its residual, but squared-loss difference compares two squared residuals. For user u6, A's error one gives loss one and B's error 1.5 gives loss 2.25, so the paired difference is -1.25.

All eight differences are negative and their mean is -.3775 squared units. The reference checks this number independently of the drawing. The plot supports a statement about these eight held-out records. It does not establish a population confidence interval, fairness across unseen groups or robustness to future distribution shift.

## Contrasting case: changing the scale changes appearance

If model A uses a prediction axis from zero to ten while model B uses zero to twenty, the same residual looks smaller in B's panel. Shared limits are necessary when visual distance is intended to be comparable. Equal physical aspect can further help identity plots; captions should explain what comparisons the layout supports.

For distributions on different units, forcing shared numeric limits may instead be meaningless. Choose common scales when the scientific quantities are common, not as a universal style rule. Small multiples should preserve axis semantics and indicate any intentional exceptions.

## Six progressive exercises

1. **Calculate one paired loss.** Work u6's difference. Expected evidence: -1.25 squared units. Hint: subtract losses, not raw predictions.
2. **Build two panels.** Put observed/predicted points beside paired losses. Expected evidence: common point axes [0,10], identity reference and clearly labeled loss units.
3. **Change one failure.** Increase B's final error magnitude from 1.5 to two. Expected evidence: the last paired difference becomes -3 and the average becomes more favorable to A. Hint: keep the observation identity fixed.
4. **Repair a misleading comparison.** Give one model a wider axis, then restore comparability. Expected evidence: explain the apparent change despite unchanged numeric data.
5. **Aggregate by meaningful groups.** Split u0-u3 and u4-u7 and report each mean paired loss. Expected evidence: group counts and a weighted recombination equal to the overall mean. Hint: equal group sizes happen here; do not assume they always do.
6. **Transfer to repeated visits.** Describe a customer-level resampling scheme when each user contributes several losses. Expected evidence: all visits from one customer stay together. Hint: chart rows are not automatically independent units.

## Review

Subplots do not create independent evidence. Keep preprocessing, tuning and final evaluation boundaries outside the visualization code explicit. A beautiful paired-loss display can still describe a leaked evaluation set. Provide a table containing actual, both predictions and paired difference so calculations remain inspectable without interaction.
