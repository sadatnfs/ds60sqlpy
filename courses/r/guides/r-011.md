## Outcome and mechanism

Implement bounded loops with explicit scalar conditions, empty-input behavior and predictable output shape.

An if expression chooses one branch based on a single TRUE or FALSE value. A missing or multi-element condition is not a valid replacement for one known decision. When the input is a vector, decide whether the question concerns any value, every value or each value separately before selecting a control structure.

A for loop iterates over a supplied sequence. The common pattern seq_along(x) creates valid positions for x, including an empty sequence when x is empty. By contrast, 1:length(x) becomes 1:0 for an empty vector, which unexpectedly contains two positions. Empty-input tests expose this bug before a loop starts selecting nonexistent data.

Preallocate an output when its size is known. numeric(length(x)) creates a vector ready for assignment at each position. Repeatedly extending an output can cause avoidable allocations and obscures the intended shape. The main purpose here is a clear invariant: after iteration i, the first i outputs satisfy the transformation contract.

A while loop needs a condition that eventually changes or an explicit bound. It is appropriate for convergence or state-dependent work when a fixed sequence is not available. Keep an iteration limit and distinguish reaching a tolerance from merely exhausting that limit. The classroom also applies runtime limits, but an external timeout is not a substitute for a correct stopping rule.

## Read the syntax

Use braces for a branch or loop containing multiple expressions. A loop variable takes each supplied value in turn. next skips the remaining current iteration and break ends the loop; neither returns from an enclosing function automatically.

## Worked examples

### Example 1: Preallocate and handle an empty vector

```r
x <- c(2, 4, 6)
out <- numeric(length(x))
for (i in seq_along(x)) {
  out[[i]] <- x[[i]]^2
}
stopifnot(identical(out, c(4, 16, 36)))
empty <- numeric(0)
stopifnot(length(seq_along(empty)) == 0L, identical(1:length(empty), c(1L, 0L)))
print(out)
```

**Expected observation:** 4,16,36.

The output length is established before iteration. seq_along also gives the intended zero iterations for empty input.

### Example 2: A bounded state-dependent loop

```r
remaining <- 20
steps <- 0L
while (remaining > 3 && steps < 10L) {
  remaining <- remaining / 2
  steps <- steps + 1L
}
stopifnot(steps == 3L, remaining == 2.5)
print(c(steps = steps, remaining = remaining))
```

**Expected observation:** Three steps; remaining 2.5.

Each iteration reduces the state and increments a bound. The final condition is checked separately from the iteration count.
