        How the classroom works
        
          
        
            Every lesson page has the same parts in the same places. This page names each part, says
            what to click, and shows how to start, switch and finish a lesson. You do not need any
            coding experience to follow it.

        The lesson page at a glance
        
              
        
                The lesson text is on the left and your code is on the right. Press a numbered box
                to read about that part. Drag the thin divider between the two sides to give either
                one more room.
              
        
              
              
          
                
        1. 
                  
          Header and search
          
                  
          
                    Always at the top. DS60 Classroom and
                    All subjects return to the course catalog.
                    Search lessons and subjects finds any lesson by topic, title or
                    ID. How it works opens this page.
                  
          
                
          2. 
                
        2. 
                  
          Lesson list
          
                  
          
                    Every lesson in the current subject, in order. Click a lesson to open it.
                    Switch subject at the top changes to another course,
                    Find in this path filters the list, and
                    Hide lesson list gives the lesson more room.
                  
          
                
          3. 
                
        3. 
                  
          Lesson title, Previous and Next
          
                  
          
                    The title says what you will be able to do by the end. Links under it name
                    earlier lessons this one builds on. ← Previous and
                    Next → move through the course in order. The
                    Lesson, Code and Result
                    buttons below jump to those parts of the page.
                  
          
                
          4. 
                
        4. 
                  
          Runtime notice
          
                  
          
                    Says whether this lesson's language is ready to run on your computer. If it is
                    not, open Prepare this lesson's runtime for the exact command
                    to paste into a terminal, then open Run settings below the
                    editor and press Check runtime.
                  
          
                
          5. 
                
        5. 
                  
          Lesson text
          
                  
          
                    The explanation and worked examples. Use Contents to jump to a
                    section and Focus on reading to widen the text. Worked
                    solutions wait behind Reveal separate solutions at the end, so
                    you can try first.
                  
          
                
          6. 
                
        6. 
                  
          Exercises
          
                  
          
                    Practice problems for this lesson, one at a time. The numbered buttons and
                    arrows move between them. Each one offers Show a hint,
                    Show the solution and Mark as solved.
                    Hide folds the panel away when you want more room for code.
                  
          
                
          7. 
                
        7. 
                  
          Code editor
          
                  
          
                    Where you type. It starts with the lesson's example code, and your changes save
                    automatically. Above it, Predict before you run is a place to
                    write what you expect to happen. A− and
                    A+ change the text size.
                  
          
                
          8. 
                
        8. 
                  
          Run bar
          
                  
          
                    Run code runs everything in the editor.
                    Step through runs it one step at a time so you can watch what
                    happens. Cancel job stops a long run, and
                    Save work keeps your code and notes.
                    Run settings holds the Time limit and
                    Check runtime.
                  
          
                
          9. 
                
        9. 
                  
          Result
          
                  
          
                    What your program printed, tables, charts and any error message. When there is
                    an error, Inspect source line jumps to the line that caused it.
                    Saved runs lists earlier results for this lesson.
                  
          
                
          10. 
                
        10. 
                  
          Your notes
          
                  
          
                    Explain the evidence is where you write what the result showed
                    and why. Notes are saved with your work for this lesson.

        Start the classroom
        
              
        
                Open a Bash terminal in the project folder. On Windows, use WSL. Before your first
                start, run ./classroom doctor to check that your Docker-compatible
                engine is using Linux containers and that Docker Compose 2.28.0 or newer is
                available. The check does not start services. If it passes, run
                ./classroom to build only missing images, start the services, and print
                the classroom address to open in your browser. This local build does not publish
                images.
              
        
              
        
                
        First time on this computer
        
                
        ./classroom doctor then ./classroom
        
                
        Smaller download (Python, SQL and a few more)
        
                
        ./classroom --starter
        
                
        Use the published images instead of building
        
                
        ./classroom --all --from-hub sadatnfs --tag 2.1.0
        
                
        See whether it is running and where
        
                
        ./classroom status
        
                
        Stop for today (keeps all your work)
        
                
        ./classroom stop
        
                
        Come back later without downloading anything
        
                
        ./classroom resume
        
              
        
            
        

            
        
              
        Open or switch lessons
        
              
        
                Every lesson is open from the start. You can begin in the middle of a course; the
                page prepares whatever that lesson needs.
              
        
              
          
                
        1. 
                  Search. Press Ctrl K (Cmd K on a Mac) or
                  / anywhere outside the code editor, type a topic, title or lesson ID
                  such as sql-07, and press Enter.
                
          2. 
                
        2. 
                  Browse. Choose All subjects, pick a course, then
                  pick a lesson from the list on the left.
                
          3. 
                
        3. 
                  Switch. Inside a lesson, use Switch subject at
                  the top of the lesson list, or ← Previous and
                  Next → under the title.
                
          4. 
                
        4. 
                  Return. Resume on the catalog page and
                  Continue in search reopen the last lesson you used. You can also
                  bookmark the address of any lesson.
                
          5. 
              
        
              
        
                Code and notes are saved separately for each lesson, so switching never loses work.
              
        
            
        

            
        
              
        Work through a lesson
        
              
          
                
        1. 
                  Read the lesson text on the left, including its worked examples.
                
          2. 
                
        2. 
                  Predict. Write what you expect the code to do in
                  Predict before you run. A wrong guess is useful; it shows what to
                  look at.
                
          3. 
                
        3. 
                  Run. Press Run code or Ctrl Enter.
                  The result appears under the editor.
                
          4. 
                
        4. 
                  Change one thing and run again. Small changes teach the most.
                
          5. 
                
        5. 
                  Explain the result in Explain the evidence.
                
          6. 
              
        
            
        

            
        
              
        Exercises and solutions
        
              
          
                
        1. Pick an exercise with its number. Read the task and write your answer in the
                  editor.
          2. 
                
        2. Stuck? Show a hint reveals one hint at a time.
          3. 
                
        3. 
                  Show the solution asks you to try once first, then opens the
                  worked answer.
                
          4. 
              
        
              
        With the solution open you can:
        
              
        
                
        Run the solution
        
                
        Runs the worked answer and shows its result. Your own code is not changed.
        
                
        Step through the solution
        
                
        Walks through the worked answer one step at a time (Python and SQL). Your own
                  code stays in the editor unchanged.
        
                
        Compare with my code
        
                
        Shows your code and the solution side by side, with differences marked.
        
                
        Use in my editor
        
                
        Copies the solution into your editor. Undo brings your own code
                  back.
        
                
        Mark as solved
        
                
        Records that you finished this exercise. It is a note for you, not a grade.
        
              
        
            
        

            
        
              
        Step through code
        
              
        
                Step through runs your code slowly, one step at a time, so you can
                see what the computer does instead of only the final answer. It works in Python and
                SQL lessons.
              
        
              
        
                
        Python
        
                
        
                  The line about to run is highlighted. Beside it you see every variable and its
                  value, with values that just changed marked, plus anything printed so far.
                
        
                
        SQL
        
                
        
                  One SELECT query is shown in the order the database actually works:
                  any WITH part first, then FROM and JOIN,
                  WHERE, GROUP BY, HAVING,
                  SELECT, ORDER BY and LIMIT. Each step runs
                  read-only and shows the rows it produces. If the editor holds several queries,
                  click inside the one you want first.
                
        
                
        When SQL cannot be stepped
        
                
        
                  Statements that change data or tables, queries that lock rows with
                  FOR UPDATE, and queries whose clauses are out of order or incomplete
                  are not stepped. You see a short message instead, and nothing runs against the
                  database. Use Run code for those.
                
        
              
        
              
        
                Move with Next step and Back, the slider, or the
                arrow keys. Stepping never saves your code or records a run, so it is safe to
                experiment.
              
        
            
        

            
        
              
        SQL lessons and the course database
        
              
        
                SQL lessons use a practice database with course tables. The
                Course database panel at the top of the code side shows its state.
              
        
              
        
                
        Starting in the middle of the course
        
                
        
                  Just press Run code. The course tables load automatically the
                  first time. You can also press Load course tables first.
                
        
                
        Build the schema
        
                
        Some later lessons use their own tables. This button creates them for you.
        
                
        Reset training data
        
                
        
                  Puts the practice tables back to their original rows if an exercise changed or
                  deleted data. Your saved code and notes are not affected.
                
        
                
        Check again
        
                
        Refreshes the panel after you start or restart the classroom.

        When something goes wrong
        
              
        
                
        The notice says the runtime is not ready
        
                
        
                  Open Prepare this lesson's runtime, run the command it shows in a
                  terminal, then press Check runtime under
                  Run settings.
                
        
                
        A run seems stuck
        
                
        
                  Press Cancel job. For slow programs, open
                  Run settings, choose a longer Time limit and run
                  again.
                
        
                
        My code shows an error
        
                
        
                  Read the last line of the error first; it names the problem. Press
                  Inspect source line to jump to it, or
                  Step through
                  to watch where things go wrong.
                
        
                
        SQL says a table does not exist
        
                
        
                  Press Load course tables or the schema button in the
                  Course database panel. If rows are missing, use
                  Reset training data.
                
        
                
        The page reloaded during a run
        
                
        Press Reconnect saved job to pick the run back up.
