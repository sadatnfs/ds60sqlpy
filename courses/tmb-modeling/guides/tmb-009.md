# REPORT versus ADREPORT

Start with: tmb-008, bayes-015.

Outcome: Choose plain diagnostics or derivative-aware uncertainty for each output.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A fitted parameter vector is rarely the final scientific answer. You may want fitted values, a positive scale, an incidence ratio, a forecast or a contrast. TMB distinguishes ordinary report values from quantities for which derivatives are recorded.

`REPORT(value)` makes a value available through the object's report function. Use it for residual vectors and diagnostics when standard errors are not required. `ADREPORT(value)` records a differentiable derived quantity so `sdreport` can propagate uncertainty. An AD report is not a new likelihood term, not an observation and not evidence that a prediction has been externally validated.

### Worked case A: scale on its natural units

Our normal template declares log sigma but uses `ADREPORT(sigma)`. If the covariance of log sigma is \(v_s\), its first-order variance on the original scale is \(\sigma^2v_s\). The companion verifies this derivative numerically. In the prepared project:

```r
fit <- fit_objective(obj)
plain <- obj$report(fit$par)
uncertainty <- TMB::sdreport(obj, par.fixed = fit$par)
summary(uncertainty, "report")
```

Pass `par.fixed=fit$par` explicitly. R's stored last-evaluated parameter state can differ from the final estimate after a diagnostic calculation. Evaluate reports at the intended estimate and retain parameter names rather than selecting arbitrary row numbers in an uninspected summary.

### Worked case B: a ratio with covariance

For \(g(\alpha,\beta)=e^{\beta-\alpha}\), the Jacobian is \((-g,g)\). Its variance approximation is \(g^2(V_{\alpha\alpha}+V_{\beta\beta}-2V_{\alpha\beta})\). Ignoring the covariance can seriously change uncertainty. The companion uses a small positive-definite covariance matrix and compares the full delta method to the independence assumption.

This ratio example also explains why plain `REPORT` and `ADREPORT` are not interchangeable. Both can return the same point estimate. Only the derivative-aware quantity supplies the Jacobian needed for the standard delta calculation. Conversely, AD-reporting a million fitted values can create unnecessary work and memory pressure when the scientific report only needs a few contrasts.

### Diagnostics and answered discussion

**Does the standard error of a fitted mean describe a future observation?** No. A new observation includes process or observation noise in addition to parameter uncertainty. **Should all residuals be AD-reported?** Usually not. They are often diagnostics, and their joint covariance can be large. **Can I report a threshold indicator with a delta standard error?** A discontinuous function is poorly served by a local derivative. Use a suitable simulation-based probability or a smooth scientific estimand, and explain what is approximated.

For random effects, `sdreport` combines conditional latent uncertainty and sensitivity to fixed parameters under its approximation. This is more than evaluating a derivative while holding every latent state fixed. Consult the [sdreport reference](https://cran.r-project.org/web/packages/TMB/TMB.pdf), and use chapter 18 to choose the correct predictive target.

### Complete R companion

```r
s <- log(2); var_s <- .04
h <- 1e-6
jac <- (exp(s + h) - exp(s - h)) / (2 * h)
print(c(delta_variance = exp(2 * s) * var_s, numerical = jac^2 * var_s))
alpha <- .2; beta <- .7; ratio <- exp(beta - alpha)
V <- matrix(c(.04, .015, .015, .09), 2, 2)
J <- c(-ratio, ratio)
print(c(ratio = ratio, full_se = sqrt(drop(t(J) %*% V %*% J)), independence_se = ratio * sqrt(sum(diag(V)))))
stopifnot(abs(jac - exp(s)) < 1e-8, all(eigen(V, symmetric = TRUE)$values > 0))
```
