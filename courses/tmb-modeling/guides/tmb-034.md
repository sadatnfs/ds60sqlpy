# Alternative integration and sequential reduction

Start with: tmb-033.

Outcome: Compare integration strategies without confusing a documented helper with a supported public export.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

Laplace approximation is not the only possible way to integrate latent variables. Low-dimensional numerical quadrature can provide a useful oracle, and structured sequential reductions can exploit particular dependency patterns. The `integrate` argument of `MakeADFun` selects specialized integration paths whose requirements must be matched to the model.

`SR(x, discrete=FALSE)` is an exported helper for a sequential-reduction integration grid. Here `x` supplies interval breaks: the actual descriptor for breaks -3 through 3 has six midpoint locations and six unit widths. The continuous mode represents integration with respect to Lebesgue measure; the discrete mode uses counting measure. Constructing this descriptor is not the same as fitting an integrated model. The manual also documents `GK(...)`, a Gauss-Kronrod helper, but the pinned TMB 1.9.25 NAMESPACE does not export `GK`. That distinction matters: documentation presence does not guarantee that `TMB::GK` is a supported public call. This course records it as a documented non-exported helper and does not create a stable runtime promise around namespace-internal access.

### Worked case A: quadrature checks a small latent integral

The companion compares one-dimensional numerical integration of a non-quadratic density with its local Gaussian Laplace approximation. Increasing the tail penalty changes the true integral while leaving the local quadratic curvature unchanged. This creates a transparent test case for approximation quality.

A grid's domain and spacing determine accuracy. Too narrow a domain drops tail mass; too coarse a grid misses curvature. Numerical quadrature can also be expensive as dimension increases. A tensor grid with \(k\) points per axis has \(k^q\) combinations in \(q\) dimensions, making naive high-dimensional integration impractical.

### Worked case B: discrete integration is summation

For a finite latent state with known prior probabilities, marginalization is a weighted sum of conditional likelihoods. The companion computes a two-state mixture directly. Treating the state as a continuous parameter and applying a Gaussian Laplace approximation would change the problem. `discrete=TRUE` in a relevant grid helper expresses a distinct integration measure; it is not a universal switch for every latent categorical model.

### Answered discussion

**Should every large model use sequential reduction?** Only if its structure and the method's tested contract support it. **Can I claim exact inference because quadrature is deterministic?** Numerical truncation and integration error remain. **Why mention an unexported helper?** To prevent learners from mistaking an internal or incompletely exposed API for a promised stable interface. The inventory lists both callable public surface and explicitly separate documented helpers.

Use the [MakeADFun, SR and GK manual entries](https://cran.r-project.org/web/packages/TMB/TMB.pdf), pinned source and independent tiny examples before preparing an advanced integration variant.
