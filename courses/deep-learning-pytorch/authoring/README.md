# PyTorch course authoring sources

The original topic specifications and renderer generate all36 bundles while preserving the reviewed track IDs,prerequisites and paired TensorFlow IDs. Run `python courses/deep-learning-pytorch/authoring/build.py` from the repository root. Every topic supplies a mechanism explanation,syntax anatomy,three worked examples,six distinct exercise checks,a framework comparison and answered interview reasoning.

Shared helper code appears once in the worked sequence;later blocks reuse earlier fixture state as the guide explains. Separate reference scripts contain all six checked exercises. The renderer does not download packages/models/data,qualify a runtime,change shared generators or touch learner state. Edit the topic specifications when changing generated text. Optional one-time prose-editing scratch tools are not part of this durable authoring source.
