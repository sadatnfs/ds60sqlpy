# Hessian, curvature and weak identification

Start with: tmb-007, r-042.

Outcome: Explain when inverse curvature can and cannot support standard errors.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

The Hessian \(H\) contains second derivatives of the negative log likelihood. Near a regular interior optimum, a quadratic approximation is \(f(\theta)\approx f(\hat\theta)+\frac12(\theta-\hat\theta)^TH(\theta-\hat\theta)\). Under suitable sampling assumptions, the inverse observed information \(H^{-1}\) approximates covariance. This is a local asymptotic statement, not a universal uncertainty formula.

For Gaussian regression with known variance \(\sigma^2\), the coefficient information is \(X^TX/\sigma^2\). If columns of \(X\) are linearly dependent, there are parameter directions that do not change the mean and hence do not change the likelihood. The Hessian is singular. More optimizer iterations cannot create information in those directions.

### Worked case A: ordinary and almost duplicate predictors

The companion compares a centered predictor to a second predictor that is almost its duplicate. The smallest eigenvalue of the information matrix approaches zero while the condition number grows. Individual coefficients become unstable even when fitted means remain precise over the observed design. Centering can improve intercept-slope conditioning, but it does not remove actual duplicate information.

A Hessian with one negative eigenvalue at a proposed solution indicates a saddle, numerical error or an invalid approximation. A positive determinant alone does not prove positive definiteness: a two-dimensional matrix with both eigenvalues negative has a positive determinant. Use a Cholesky factorization or inspect eigenvalues for small teaching problems.

### Worked case B: transforming uncertainty

Suppose the estimated log scale is \(\hat s\) with variance \(v_s\). The delta method gives \(\operatorname{Var}(e^{\hat s})\approx e^{2\hat s}v_s\). A symmetric interval on log scale, transformed back by exponentiation, remains positive and is generally asymmetric on the original scale. The companion compares these reports. They are approximations, not identical intervals.

For large random-effect models, the latent precision matrix can be sparse. Explicitly inverting it into a dense matrix can consume far more memory than fitting the model. Request only the quantities needed for a scientific report. `sdreport` can avoid the full report covariance with `getReportCovariance=FALSE`; that does not eliminate every potentially expensive covariance calculation.

### Diagnostics and answered discussion

**Does `pdHess=TRUE` prove the model fits?** No. It concerns local curvature, not residual structure, selection bias or the correctness of the likelihood. **What if a variance is estimated near zero?** Regular Wald intervals can fail at boundaries. Use scientifically appropriate profiles, simulation or alternative inference and explain the boundary. **Can I use a robust sandwich covariance?** Sometimes, under a justified estimating-equation and dependence structure. It is not automatically what `sdreport` returns.

Read the [sdreport implementation and documentation](https://github.com/kaskr/adcomp/blob/master/TMB/R/sdreport.R). Later chapters distinguish fixed-effect information, conditional latent uncertainty and uncertainty of future observations.

```r
x <- seq(-1, 1, length.out = 20)
X <- cbind(1, x)
near <- cbind(1, x, x + 1e-5 * cos(seq_along(x)))
print(list(
  ordinary = eigen(crossprod(X), symmetric = TRUE)$values,
  nearly_collinear = eigen(crossprod(near), symmetric = TRUE)$values
))
stopifnot(kappa(crossprod(near)) > 1e8)
s <- log(2); se_s <- .2
print(list(delta_sd = exp(s) * se_s, transformed_interval = exp(s + c(-1, 1) * 1.96 * se_s)))
stopifnot(all(exp(s + c(-1, 1) * 1.96 * se_s) > 0))
```
