## Learning objectives

Ship an installable library with robust parsing and an independent consumer.

## Vocabulary and concepts

A reusable record library separates stable data contracts from user-interface code. Packaging declares headers and link targets. Compatibility tests protect callers from accidental changes. The capstone combines strict parsing, named errors, ownership and exact integer output with an auditable fixture ledger.

## Syntax and mechanism

Keep parse_record independent of files and terminals. A library caller supplies a string_view and receives an owned result or named rejection. A host project is required to exercise a library target and consumer link; the browser demonstrates the same value-level core in one file.
