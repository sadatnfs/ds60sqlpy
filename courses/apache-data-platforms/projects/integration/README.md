## Actual bounded batch dossier

Copy this directory into work/apache-integration and prepare the ordinary native
data-platforms-python image. From the copied directory:

```bash
bash run.sh batch batch-1
```

The launcher validates a local native Linux image before creating output and never
requests emulation, a pull or a build. The script uses actual PyIceberg/Arrow/DataFusion. It refuses an existing output
directory, creates two committed snapshots, compares exact rows and independent
regional totals, verifies the old materialized relation stays fixed, reopens
the catalog and rejects a wrong logical catalog. It saves a source/library/schema/
snapshot/result receipt. It does not claim direct Spark or DataFusion-Iceberg
connector acceptance. Filesystem paths in the local catalog belong to the stated
container mount; moving its files needs an explicit relocation/restore design.

For a second experiment, choose another absent batch directory. Do not overwrite
an accepted receipt. No package download or network service is involved at run
time. The source is a standalone owned project, not a multi-file browser editor.
