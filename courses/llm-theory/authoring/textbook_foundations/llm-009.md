## Contextual information is a weighted computation

An embedding gives a token occurrence an initial vector, but understanding its role often requires other tokens. Attention is one way to construct a context-dependent vector. For a selected position, it compares a query with candidate keys, converts those comparisons into weights and uses the weights to mix candidate value vectors. The query and key determine where information is taken from; the values determine what numerical information is combined. These are roles in a computation, not literal questions, dictionary keys or human explanations.

It helps to separate the three steps before reading the compact matrix expression. First form one score for each query/key pair. Next normalize each query's allowed scores into a probability row. Finally multiply that row by the value matrix, obtaining one weighted average of value vectors. With T query positions and T key positions, the weight matrix has T squared entries. If each value has D_v features, the output has T rows and D_v columns. The weights range over positions, not vocabulary tokens. An attention probability of 0.7 therefore means a mixing coefficient for a particular value row, not a 70 percent probability that a word or claim is correct.

The equal-score fixture deliberately removes complicated content matching. Every query and key is zero, so all allowed scores are zero. The causal mask makes the first query see one value, the second see two and the third see three. With values [2,0], [0,2] and [6,6], the first output must be [2,0]. The second is their first-two average, [1,1]. The third is the three-way average, [8/3,8/3]. We can predict these outputs without any exponentials because equal legal scores imply equal weights.

Now change only the third value to [100,200]. The first two outputs should be identical to their previous values, because the changed row is in their future. The final output changes to [34,202/3]. This test translates the abstract word "causal" into an observable condition. An unmasked computation instead makes every output that global average, immediately exposing future information in the first row. The test is stronger than inspecting whether the mask has a triangular shape: it checks the result of the whole operation.

The equal-score case is easy to understand but deliberately incomplete. A function that ignores queries and keys could pass it, so the following derivation also uses unequal dot products. This is a general testing principle: one controlled fixture isolates a particular mechanism, while a second fixture must challenge assumptions that the first one makes invisible. Exact weighted outputs, row sums, forbidden zeros and independent prefix recomputation test different properties.

Attention is useful when the relevance of an earlier representation depends on the current representation. It still needs projected features, positional information, residual paths and training to become part of a useful model. The [Transformer architecture](https://arxiv.org/abs/1706.03762) combines these pieces; this chapter isolates one small head so that its information flow can be understood without hiding inside a framework call.
