Language-model mechanisms and evidence#

Study in the unified classroom: run ./classroom from the repository root, then choose Language-model mechanisms and evidence on /classroom. Python, SQL and all other subjects share this home and workspace. Each subject has its own theme; prerequisites guide your choices and you set the pace. The one-command setup prepares the Docker runtimes and preserves saved work. Native terminal/editor commands below are optional alternatives.

All 48 chapters are authored, from probability and tokenization through actual tiny-model training, inference, evaluation and modern Transformer mechanisms. The route has 27 Core/NumPy lessons, 16 PyTorch CPU lessons and 5 reading lessons. The index below is generated from the reviewed plan and complete authored manifest.

Start in the Docker classroom#

Use the Docker classroom setup, open Journeys, and choose the LLM theory journey. Select a chapter, read its guide, save your own learner pad and use Run for an executable lesson. The selected worker supplies the declared Python packages. Host Python, PyTorch and TensorFlow installations are not prerequisites for this route.

Reading chapters use written calculations and reasoning cases. Their read marker is a study record, not an executed test or proof of mastery. For code chapters, record predictions, attempt the six tasks, use progressive hints, then compare the separate executable and explained solutions after an attempt. Preserve learner work under the classroom's saved pad or ignored .learning/expansion/ directories.

The default lessons use tiny literal offline fixtures and bounded CPU computations. No default chapter downloads model weights or calls a paid model API. Actual reference and worked-example qualification is recorded in the ML content status, expert chapter status and depth-review record. Runtime evidence is separate from a claim that a small model is a reliable subject expert.

Follow a complete Transformer calculation#

Inside a Transformer walks through an inspectable NumPy decoder forward pass, tensor shapes, causal-prefix checks, a finite-difference derivative and an explicitly head-only update. Use it alongside chapters 009-011 and 016, then continue to 043-048 for architecture families, positional methods, RMSNorm/SwiGLU, head sharing and exact blockwise attention, sparse experts and speculative decoding.

For a subject assistant, retrieval or fine-tuning project, continue into Applied LLM systems. That route develops corpus provenance, chunking, lexical/hybrid retrieval, access boundaries, grounded citations, abstention, evaluation, actual tiny-model adaptation and an explicitly optional pretrained recipe. NLP foundations supplies additional text and classical retrieval methods. The dedicated PyTorch and TensorFlow journeys cover their frameworks broadly.
