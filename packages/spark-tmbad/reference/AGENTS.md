# Optional R reference ownership and evidence

This directory is an independent optional reference project. The primary
Spark/TMBad package must remain usable without R, RTMB or glmmTMB. Use the actual
pinned upstream glmmTMB library here; do not describe its features as a native
port or copy AGPL implementation into original MIT source. Preserve LICENSE,
NOTICE.md, upstream source/archive identities and all dependency notices.

Runtime receives trusted registry identifiers and data-only options. Adding a
model means original source, explicit data/parameter admission, fresh preparation
and qualification. Never compile or download during a fit or deserialize
executable R/C++ text from a saved result. Prepared directories and old evidence
are immutable. Failed fits and incomplete simulations remain visible.

Keep marginal ML, coefficient MAP, random-effect Laplace, exact conjugate
posterior inference and posterior sampling distinct. Exact lasso requires its
nonsmooth solver and KKT checks. Forecasts state conditioning, response-free
future inputs and which uncertainty layers are included. A fitted variance or
successful optimizer alone does not establish calibration.

Use the parent package's public preparation/runtime boundaries. Source checks,
compilation, serial R fits, actual Spark execution and different native
architectures require separate receipts. No new external publication is implied
by changing this directory. Coordinate every heavy install, build or model run
with root, use native ARM64 locally, and never contact Docker Hub from the
restricted local host. Preserve learner volumes and unrelated resources.

Use parallel agents where possible with disjoint ownership. Do not use em dashes.
