Purpose and mental model#

A total negative log likelihood grows with the number of targets being scored. Cross entropy in this lesson is the mean target negative log likelihood under an explicitly declared empirical weighting. Perplexity is the exponential of that mean in natural-log units. It is a re-expression of the same token-level score, not an independent language-quality measurement.

For target probabilities [0.5,0.25], total NLL is 3log(2), the two-target mean is 1.5log(2), and perplexity is 2 raised to 1.5. Appending ignored padding must not improve the score by increasing its denominator. A report must name the number of active targets rather than merely the length of a padded tensor.

Tokenization changes the target units. One tokenizer can score a word as one token while another scores three characters. Their per-token perplexities can therefore move in a different direction from probability assigned to the same complete string. Later model comparisons must freeze tokenization and scoring policy or use another explicitly compatible measure. This lesson makes those traps inspectable with arithmetic instead of a leaderboard.

Vocabulary and concepts#

Cross entropy here: the empirical average negative log probability of the supplied target tokens under a declared weighting.

Perplexity: exp(mean negative log likelihood) when natural logarithms are used.

Active target: a target included in both the loss sum and denominator after an explicit mask.

Token weighting: equal contribution per active target position, not necessarily per document.

Comparable score: a measure whose target representation, inclusion rule and evaluation unit are compatible across the systems being compared.

Syntax or reasoning anatomy#

Add the negative logs for active targets, divide by their count, then exponentiate if perplexity is useful. Mask by selection before counting. A zero-probability active target has infinite loss under the declared distribution; an ignored target contributes neither a loss nor a denominator term. An all-ignored row has no defined empirical mean and should fail explicitly.

The helper exposes total_nll, active_targets, mean_nll and perplexity as separate fields. This makes a denominator error observable without inspecting printed prose. Equal-document weighting first computes each document mean and then averages documents, so a long document no longer contributes proportionally more targets. Choose the aggregation unit before comparing outcomes, and retain that choice with saved predictions.

Worked example / walkthrough#

Example A: Two target probabilities#

Use the same conditional probabilities for both the loss and perplexity calculation.

import math

probabilities = [0.5, 0.25]
total = -sum(math.log(p) for p in probabilities)
mean = total / 2
perplexity = math.exp(mean)
assert math.isclose(mean, 1.5 * math.log(2), rel_tol=0, abs_tol=1e-12)
assert math.isclose(perplexity, 2**1.5, rel_tol=0, abs_tol=1e-12)
print(total, mean, perplexity)

Expected: The three values are related but not interchangeable. Perplexity counts uncertainty in this particular token unit, not factual accuracy.

Example B: Ignored padding cannot improve a mean#

Append an ignored position and compare its correct denominator with a broken zero-loss average.

active_losses = [-math.log(0.5), -math.log(0.25)]
correct = sum(active_losses) / 2
wrong = sum(active_losses) / 3
assert math.isclose(correct, 1.5 * math.log(2), rel_tol=0, abs_tol=1e-12)
assert wrong < correct
print(correct, wrong)

Expected: The wrong mean looks better solely because a padding slot was counted as another observation. No model prediction improved.

Progressive hints#

  • Hint 1: Write the sum, active count and mean as three separate quantities.
  • Hint 2: Select active positions before counting them; zeroing an ignored loss is not enough.
  • Hint 3: For tokenizer comparisons, distinguish a complete-string probability from a per-token average.

Common pitfalls#

If padding lowers a reported mean loss, inspect the active-target count before changing weights or a learning rate. If perplexity is infinite, determine whether an active probability was zero or exponentiation exceeded the available numeric range. Keep a finite log score even when its exponential cannot be represented.

If a tokenizer changes, start a new experiment and label its target units. A lower per-token perplexity across incompatible vocabularies is not a direct quality ranking. A loss score also does not count correct answers or supported citations. Use an answer-level metric when that is the intended claim, with its own held-out question and family policy.
