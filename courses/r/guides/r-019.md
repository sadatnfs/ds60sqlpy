## Outcome and mechanism

Round-trip small local data through appropriate formats while verifying types, missingness and cleanup.

A file format has a data contract. CSV is a text table and does not inherently preserve R classes, factor levels or every missing-value distinction. A reader can infer types, but inference may interpret an identifier as a number or a literal label as a missing marker. Supply relevant column classes and missing-value rules for a stable interface.

JSON represents objects, arrays, nulls and primitives. The prepared jsonlite package can convert between R objects and JSON, but simplification and scalar unboxing affect shape. A one-element vector and a scalar may need different JSON representations in an external API. State those choices rather than relying on whichever example happens to contain multiple values.

RDS stores one R object with its structure and attributes. It is useful for local R-specific artifacts, while CSV and JSON are generally more interoperable. A binary round trip does not establish that a serialized object is safe or compatible with every future version. Load only trusted artifacts and avoid pretending that a local serialization format is a public schema specification.

The classroom run directory is temporary. Files created by a script are useful inside that run, but arbitrary outputs do not automatically become permanent learner documents. Saved source, notes and captured figures use the classroom's separate persistence contract. These examples use temporary paths, verify the round trip and clean up; they do not require host directories or external network access.

## Read the syntax

tempfile creates a unique path, write.csv(..., row.names=FALSE) avoids an accidental index column, read.csv(..., colClasses=...) states types, and unlink removes owned temporary files. jsonlite::toJSON/fromJSON use explicit namespaced calls. saveRDS/readRDS retain one R object.

## Worked examples

### Example 1: A typed CSV round trip

```r
path <- tempfile(fileext = ".csv")
original <- data.frame(id = c("001", "002"), amount = c(2, NA_real_))
write.csv(original, path, row.names = FALSE, na = "")
restored <- read.csv(path, colClasses = c("character", "numeric"), na.strings = "")
stopifnot(identical(original, restored))
unlink(path)
print(restored)
```

**Expected observation:** IDs 001,002; second amountNA.

The ID remains character, and the empty missing marker is a deliberate part of this synthetic CSV contract.

### Example 2: JSON for interchange, RDS for R structure

```r
record <- list(id = "A", values = c(2, 4))
encoded <- jsonlite::toJSON(record, auto_unbox = TRUE)
restored <- jsonlite::fromJSON(encoded)
stopifnot(restored$id == "A", identical(as.numeric(restored$values), c(2, 4)))
path <- tempfile(fileext = ".rds")
value <- factor(c("A", "B"), levels = c("A", "B", "C"))
saveRDS(value, path)
stopifnot(identical(readRDS(path), value))
unlink(path)
print(encoded)
```

**Expected observation:** JSONrecord and exact factor round trip.

The JSON contract contains a scalar ID and an array of values. The RDS round trip additionally retains factor levels, including the unused level.
