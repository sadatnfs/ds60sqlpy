# Compile, load and isolate an owned library

Start with: tmb-004, cpp-001.

Outcome: Explain exactly which source and native library a model evaluation uses.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A C++ source file is portable text. Its compiled shared library is not. The binary depends on CPU architecture, operating system, compiler conventions, R's ABI, TMB headers and linked libraries such as Matrix. A Linux ARM64 `.so` is not a macOS library, and it is not an AMD64 library. Docker standardizes the Linux environment but does not make incompatible machine instructions portable.

The project prepares R 4.6.1, TMB 1.9.25 and a matching Matrix/RcppEigen stack. `R/compile.R` copies allowlisted original source files into an owned build directory and compiles serially with `-O1 -g0`, `framework="CppAD"`, bounds checking and safe unloading. Preparation is separate from evaluation. `R/api.R` only loads an already prepared model library.

### Worked case A: source to loaded code

```bash
Rscript --vanilla R/compile.R "$PWD" /tmp/tmb-owned-build
TMB_BUILD_DIR=/tmp/tmb-owned-build Rscript --vanilla tests/acceptance.R
```

These are commands inside the separately prepared project, not commands for an ordinary R pad. `--vanilla` suppresses user startup files that might change repositories or compiler settings. `TMB_BUILD_DIR` selects one trusted directory. The project checks the loaded library's resolved path, so a same-named DLL already loaded from somewhere else causes an explicit error.

A compiler's success proves only that source could be translated and linked. A fresh process must then load the library, construct an objective and evaluate its value and gradient. Our acceptance layer performs those steps with independent oracles. The base-R companion illustrates source fingerprint changes; it does not pretend to invoke a compiler.

### Worked case B: stale binary after an edit

Suppose the source changes from a normal to a Poisson likelihood but the old `.so` remains. An optimizer can still return a clean result from the old normal code. Compare source fingerprints, rebuild explicitly and use a fresh R process. Never overwrite a library while another process is actively using it. Keep model binaries and receipts together, and do not serialize TMB objects between machines.

For deliberate compiler-error acceptance, work in a disposable copied build directory, introduce a syntax error there, and require a nonzero compilation status. Preserve the good source and library. The test is useful because wrappers sometimes swallow compiler status and attempt to load a stale binary. The project compiler checks each return status before continuing.

### Diagnostics and answered discussion

**Why use a fresh process instead of repeated `dyn.unload`?** R objects can retain native pointers. A fresh process gives a clear lifetime boundary and avoids accidentally using freed objects. **Is a matching filename sufficient?** No. Match source, build metadata and native architecture. **Can `TMBad` replace `CppAD` without any qualification?** It is a supported framework choice, but changes derivative machinery and compile behavior. Rebuild and rerun numerical checks. Some `intern=TRUE` paths specifically require TMBad.

The [compile and FreeADFun documentation](https://cran.r-project.org/web/packages/TMB/TMB.pdf) explains these boundaries. Retain third-party license notices with prepared dependencies; do not infer redistribution terms from the license of this course's original model files.

### Complete R companion

```r
text1 <- "normal likelihood version 1"
text2 <- "normal likelihood version 2"
paths <- c(tempfile(), tempfile())
writeLines(text1, paths[1]); writeLines(text2, paths[2])
fingerprints <- tools::md5sum(paths)
print(fingerprints)
stopifnot(unname(fingerprints[1]) != unname(fingerprints[2]))
print(list(
  R = as.character(getRversion()), platform = R.version$platform,
  note = "Source identity demonstration only; no DLL compiled"
))
unlink(paths)
```
