# Likelihood profiles versus slices

Start with: tmb-028, tmb-008.

Outcome: Explain nuisance reoptimization and derive a profile-likelihood interval.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A one-dimensional likelihood profile fixes a target parameter and reoptimizes nuisance parameters at each target value. A slice holds nuisance parameters fixed. They are generally different curves. Since profiling can improve the nuisance fit, its minimized NLL is no greater than the corresponding fixed-nuisance slice at the same target.

`tmbprofile(obj, name=...)` profiles a named coordinate; `lincomb` supports a specified linear contrast. Controls such as `h`, `ytol`, `ystep`, `parm.range`, `adaptive` and `slice` govern the search. These options should be chosen for the intended domain and diagnostic resolution, not used to conceal a difficult likelihood surface.

### Worked case A: a correlated quadratic

For \(f(a,b)=\frac12[a^2+2\rho ab+b^2]\), the nuisance optimum at fixed \(a\) is \(b=-\rho a\). The profile is \(\frac12(1-\rho^2)a^2\); the slice at \(b=0\) is \(a^2/2\). The companion plots the numerical values in a table. Strong correlation makes the slice look more informative than the actual profile.

A likelihood-ratio interval uses a rise of approximately \(\chi^2_{1,1-\alpha}/2\) in NLL under regular asymptotic assumptions. `confint` for a `tmbprofile` object extracts crossings from the computed profile, while `plot.tmbprofile` visualizes its shape. Sparse sampling can miss a crossing or make interpolation coarse.

### Worked case B: asymmetry on a transformed scale

A symmetric interval for log scale becomes asymmetric after exponentiation. Profile the coordinate you actually understand and transform interval endpoints consistently. The companion compares these endpoints with a symmetric original-scale delta interval. Neither is automatically valid at a variance boundary or under weak identification.

### Answered discussion

**Is profiling the same as integrating?** No. A profile retains the best nuisance value at each target; an integral accounts for probability volume. **Can I trust a profile that terminates before reaching the cutoff?** Report a one-sided or unresolved interval rather than inventing the missing endpoint. **Should a profile be centered at an unchecked optimizer result?** First verify the optimum, parameter names, gradient and feasible domain. Otherwise the profile can be anchored to the wrong solution.

Consult [tmbprofile, plot.tmbprofile and confint.tmbprofile](https://cran.r-project.org/web/packages/TMB/TMB.pdf). A native profile probe on the original normal model is a small API test, not proof that profiles for a complex multimodal model will be reliable.

### Complete R companion

```r
a <- seq(-2, 2, length.out = 5);rho <- .8
print(data.frame(a = a, nuisance = -rho * a, profile = .5 * (1 - rho^2) * a^2, slice = .5 * a^2))
stopifnot(all(.5 * (1 - rho^2) * a^2 <= .5 * a^2))
s <- log(2);se <- .3
print(list(log_scale_endpoints = s + c(-1, 1) * 1.96 * se, natural_scale_endpoints = exp(s + c(-1, 1) * 1.96 * se)))
natural_center <- exp(s)
transformed <- exp(s + c(-1, 1) * 1.96 * se)
delta <- natural_center + c(-1, 1) * 1.96 * natural_center * se
print(data.frame(
  method = c("transformed log-scale interval", "symmetric original-scale delta interval"),
  lower = c(transformed[1], delta[1]), upper = c(transformed[2], delta[2])
))
stopifnot(
  max(abs(transformed - delta)) > .1,
  abs((delta[1] + delta[2]) / 2 - natural_center) < 1e-12
)
```
