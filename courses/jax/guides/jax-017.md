# jax-017: Continuation requires parameters, history and keys

## Starting point and outcome

Intermediate. Direct prerequisites: `jax-016`

Define and verify a bounded continuation contract that preserves every state component used by the next update.


## Mechanism and purpose

A checkpoint should be specified by the continuation it promises. An inference snapshot may need parameters and preprocessing. A training continuation can also require optimizer moments, step count, random keys, scheduler state and data position. Matching today's prediction is weaker than reproducing the next update.

This lesson uses a scalar momentum update with a small random perturbation of its gradient. Its state is weight, velocity, typed random key and update count. We advance the state before saving, so history and key progression are nontrivial. A weights-only snapshot would omit two mechanisms that influence the next step.

Serialization is a boundary between numerical objects and durable representation. NumPy arrays in an npz file store the scalar values and key data without requiring object pickles. The key algorithm is explicitly fixed for this fixture, so reconstruction does not silently reinterpret raw key words under a different algorithm. A real artifact also needs versions, shapes, dtype, model construction and the relevant data contract.

The ordinary classroom worker owns a temporary directory that is removed after each Run. Saving a small file within one Run demonstrates a local save/read transition; it does not create a durable learner checkpoint available to a later Run. Source, notes and saved run output have their own supported persistence channels. A production checkpoint workflow needs an explicitly prepared artifact location and lifecycle.

Compare an uninterrupted next state with one computed after reconstruction. Then deliberately omit velocity while keeping the same key, so the negative control isolates optimizer history rather than changing several causes at once. This evidence establishes the stated scalar continuation, not a distributed data loader, cross-version bitwise portability or a large-model storage system.

## Derivation and shape contract

The transition draws noise \(\xi_t\) from its current key, forms \(g_t=2(w_t-2)+0.01\xi_t\), updates \(v_{t+1}=0.9v_t+g_t\) and \(w_{t+1}=w_t-0.1v_{t+1}\), and returns the next key and count. Reconstructing only w generally changes the next result because v and the next draw also appear in these equations. Equal keys isolate the missing-velocity comparison.

## Worked investigations

### Worked example 1: Reconstruct the next transition

Save the two-step state to an owned temporary file, load it and compare the next update with uninterrupted continuation.

The check inspects all state used by the actual transition, not only current predictions or one serialized array.

**Expected:** Matching next weight, velocity, key data and step count three.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp

import tempfile
from pathlib import Path

# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def next_state(state):
    weight, velocity, key, count = state
    next_key, draw_key = jax.random.split(key)
    noise = jax.random.normal(draw_key, (), dtype=jnp.float64)
    gradient = 2.0 * (weight - 2.0) + 0.01 * noise
    velocity = 0.9 * velocity + gradient
    return weight - 0.1 * velocity, velocity, next_key, count + 1


def prepared_state():
    state = (
        jnp.float64(0.0),
        jnp.float64(0.0),
        jax.random.key(52, impl="threefry2x32"),
        jnp.int64(0),
    )
    return next_state(next_state(state))


def save_state(path, state):
    w, v, key, count = state
    np.savez(
        path,
        weight=np.asarray(w),
        velocity=np.asarray(v),
        key=np.asarray(jax.random.key_data(key)),
        count=np.asarray(count),
    )


def load_state(path):
    with np.load(path, allow_pickle=False) as saved:
        return (
            jnp.asarray(saved["weight"]),
            jnp.asarray(saved["velocity"]),
            jax.random.wrap_key_data(jnp.asarray(saved["key"]), impl="threefry2x32"),
            jnp.asarray(saved["count"]),
        )


def compare(left, right):
    close(left[0], right[0])
    close(left[1], right[1])
    assert np.array_equal(
        np.asarray(jax.random.key_data(left[2])), np.asarray(jax.random.key_data(right[2]))
    )
    assert int(left[3]) == int(right[3])


def main():
    # Case 1: Reconstruct the next transition
    state = prepared_state()
    with tempfile.TemporaryDirectory() as directory:
        path = Path(directory) / "state.npz"
        save_state(path, state)
        restored = load_state(path)
        compare(next_state(state), next_state(restored))
        assert int(next_state(restored)[3]) == 3

    print("jax-017: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: Omit history deliberately

Keep the saved weight and key but reset velocity to zero before the next step.

Using the same key holds the next random perturbation fixed, so the difference identifies missing momentum history.

**Expected:** A different next weight.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def next_state(state):
    weight, velocity, key, count = state
    next_key, draw_key = jax.random.split(key)
    noise = jax.random.normal(draw_key, (), dtype=jnp.float64)
    gradient = 2.0 * (weight - 2.0) + 0.01 * noise
    velocity = 0.9 * velocity + gradient
    return weight - 0.1 * velocity, velocity, next_key, count + 1


def prepared_state():
    state = (
        jnp.float64(0.0),
        jnp.float64(0.0),
        jax.random.key(52, impl="threefry2x32"),
        jnp.int64(0),
    )
    return next_state(next_state(state))


def main():
    # Case 1: Omit history deliberately
    state = prepared_state()
    wrong = (state[0], jnp.float64(0.0), state[2], state[3])
    assert not np.isclose(float(next_state(state)[0]), float(next_state(wrong)[0]))

    print("jax-017: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

## Diagnosis and boundaries

If continuation differs, compare the next key, current optimizer history, dtype, update count and configuration before increasing tolerance. The current example reconstructs numerical state within one process; a fresh-process and persistent-storage acceptance test is an additional workflow, not implied by this file round trip.
