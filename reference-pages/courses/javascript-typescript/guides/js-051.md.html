js-051: Histograms, bin boundaries and distribution shape#

Level and prerequisites#

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: js-050. This is the D3.js specialization within the JavaScript path. Use the original language and browser lessons whenever syntax or DOM behavior is unfamiliar.

Learning objectives#

Build the explicit-boundary count histogram. Compare two groups with different sample sizes. Produce a chart whose data transformation, visual encoding and interaction can be explained and checked independently.

Purpose, vocabulary and mental model#

A histogram groups quantitative observations into intervals and displays their counts or density. The bins are numerical intervals, not arbitrary categories. Their boundaries affect the apparent distribution, especially with small samples. A meaningful histogram states the sample, units, domain and binning policy.

A bin usually includes its lower boundary and excludes its upper boundary, except the final bin includes its upper endpoint. This convention prevents double-counting values exactly on a threshold. Values outside the declared domain require a policy and should not disappear without explanation.

Count and density are different vertical quantities. With unequal bin widths, equal counts do not imply equal density. A density histogram uses height proportional to count divided by sample size and bin width, so area represents probability mass. The reference uses equal-width bins and counts to keep the first reasoning explicit.

Syntax anatomy and mechanism#

d3.bin().domain([0, 10]).thresholds([2, 4, 6, 8]) creates intervals with known edges. Each returned bin is an array of observations with x0 and x1 properties. The count is its length. A rectangle’s width follows x(x1)-x(x0), and its height follows the count scale.

Test boundary values explicitly. The sample [0, 2, 2, 4, 9, 10] produces counts [1, 2, 1, 0, 2] for the chosen bins. The total count must equal the number of included finite observations. This simple conservation check catches many accidental exclusions.

Worked example / walkthrough#

Worked example 1: Inspect a threshold boundary#

The value 2 belongs to the interval starting at 2.

const bins=d3.bin().domain([0,10]).thresholds([2,4,6,8])([0,2,2,4,9,10]);
console.log(bins.map(b=>b.length));

Expected observation: 1, 2, 1, 0, 2.

Worked example 2: Compute one density height#

This is an analytical quantity, not a plotting coordinate.

const count=2, sampleSize=6, width=2;
console.log(count/(sampleSize*width));

Expected observation: 1/6 per unit; the bin area is 1/3.

Debugging and common mistakes#

Keep three checkpoints separate: the records after parsing, the domain and geometry after transformation, and the visible marks after rendering. A chart can look plausible while silently dropping records or assigning the wrong scale. Inspect counts, IDs, finite coordinates and meaningful expected values before adjusting colors. A missing mark may come from invalid input, a missing selection, an undefined scale result or clipping outside the viewBox.

The controlled failure for this lesson is: Diagnose a missing maximum value. Its distinguishing evidence is The final boundary convention or declared domain is wrong. Preserve that failing case when repairing your program. Do not remove an assertion or broaden a scale merely to hide a wrong input. Explain whether a changed value should affect the data, an encoding, a layout or only presentation.

Accessibility and interpretation#

Give the visualization a descriptive title and a short textual summary of the main result. Keep a table or list when exact values matter. Do not encode a critical category only through color; use labels, shapes or position as appropriate. Interactive controls need keyboard operation and clear focus, and motion should respect the user's reduced-motion preference. Automated DOM checks support, but do not replace, a real keyboard and assistive-technology review.

A data scientist must also defend the statistical meaning. State the population, units, aggregation, missing-value policy and uncertainty where relevant. Synthetic points illustrate a mechanism and do not establish a real-world finding. A beautiful visualization should make a valid claim easier to inspect, not make a weak claim appear certain.
