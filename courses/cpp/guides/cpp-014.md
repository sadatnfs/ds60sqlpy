## Learning objectives

Deliver a deterministic small CLI from source and explain its failure behavior.

## Vocabulary and concepts

An auditable CLI is a command-line program whose inputs, accepted values, rejected records and output can be reconciled. Parsing and business validation are separate steps. Integer cents avoid decimal rounding ambiguity. The ledger keeps every input accounted for instead of silently discarding bad text.

## Syntax and mechanism

Parse each complete field with from_chars, require the entire string to be consumed, then add only valid nonnegative values. Maintain accepted and rejected counts independently from the sum. Returning nonzero is appropriate for a fatal file failure; per-row rejection can be a documented partial-report policy.
