## Purpose and mental model

A residual compares a prediction with its paired target. A loss turns residuals into an objective the training procedure will try to reduce. The reduction policy decides whether you add contributions or average them, and which records count in the denominator. This bookkeeping is part of the mathematical objective, not an afterthought in the reporting layer.

Use residuals [1,-1,2]. Squaring produces [1,1,4], whose sum is 6 and mean is 2. Duplicating all three records doubles the sum while leaving the mean unchanged. If you instead mask out one record, a correct mean must divide by the number of accepted records rather than the original array length.

Different losses emphasize different mistakes. Squaring penalizes a large residual more strongly than an absolute-value score. A model can therefore rank better on mean absolute error while ranking worse on mean squared error. Decide the task's objective before selecting a favorite result. This lesson uses fixed arrays, not an optimizer, so every distinction can be checked without a framework or a training-quality claim.

## Vocabulary and concepts

**Residual:** prediction minus target for one paired observation, retaining the sign of the error.

**Squared loss:** the square of a residual, measured in squared target units.

**Reduction:** the policy combining individual contributions into a sum or mean.

**Mask:** a declared inclusion rule selecting which observations participate in both numerator and denominator.

**Metric:** a reported measure used to assess a model; it need not be the exact objective used to fit it.

## Syntax or reasoning anatomy

In np.square(residuals), every observation contributes its own nonnegative value. np.sum adds those values. np.mean divides their sum by the number of included entries. Applying a mask by indexing first makes the selected denominator visible. Setting excluded contributions to zero and then taking a mean over the original array instead introduces extra denominator terms.

The reference helper accepts only a finite nonempty residual vector and a supported reduction name. An optional boolean mask must have the same shape and select at least one record. The helper returns a scalar, but that scalar still carries its record count and squared units conceptually. A root-mean-squared value returns to the target's units; taking a square root does not restore information about which observations were included.

## Worked example / walkthrough

### Example A: Two reductions of one fixture

Calculate the squares first, then compare the scalar reductions.

```python
import numpy as np

r = np.array([1.0, -1.0, 2.0])
squared = np.square(r)
assert squared.sum() == 6.0
assert squared.mean() == 2.0
print(squared, squared.sum(), squared.mean())
```

**Expected:** The signs disappear after squaring, but the observation count remains three. Sum and mean answer different scale questions.

### Example B: Zeroing a masked entry changes the wrong denominator

Select the first two observations only, and contrast it with zeroing the last square before averaging.

```python
include = np.array([True, True, False])
correct = np.square(r[include]).mean()
wrong = np.where(include, np.square(r), 0.0).mean()
assert correct == 1.0
np.testing.assert_allclose(wrong, 2 / 3, rtol=0, atol=1e-12)
print(correct, wrong)
```

**Expected:** Both numerators equal 2. The accepted set has two records, so its mean is 1, whereas the broken calculation divides by three.

## Common pitfalls

If duplicating a dataset changes an average loss, inspect whether the implementation is really reporting a sum or has changed a mask. If padding improves a score despite adding no useful observations, check whether padded zeros increased the denominator. If two models change ranking under another metric, explain the changed penalty rather than declaring one calculation wrong.

A scalar value without units, count and reduction is incomplete evidence. Reject a fully excluded mask instead of reporting a zero objective. Source groups may deserve equal weight for a stated use, but that is a deliberate different metric from weighting every observation equally. Record the weighting decision before evaluating which model benefits.
