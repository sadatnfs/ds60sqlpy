# Language and API boundaries

The prepared actual Python route:

```bash
bash run.sh clients
bash run.sh evidence
```

The optional native Rust project lives under `rust-client/`. Its README documents
the selected crate version, dependency preparation and current qualification
status. It is not an ordinary Rust classroom pad, and source presence is not a
successful compile or distributed-runtime receipt.

Read the Python SQL and DataFrame implementations beside the Rust source. Keep
local compilation, remote submission and exact result readback as separate gates.
Do not substitute a local result when a scheduler request fails.
