# Worked reference: Compiled artifact identity

This is an editable reading/project reference. It has no ordinary pad Run action.

The compatibility record includes C++ source hash, target OS/architecture, compiler and flags, R version, TMB version, dependency image identity and resulting library identity. Identical source does not imply identical ABI.

A missing library is a preparation failure. An AMD64 library in an ARM64 process is a target mismatch. A stale library from another source hash is an artifact mismatch. None should fall back to a different implementation while retaining a TMB-passed label. Compile once in an isolated preparation step, then construct native objective state per worker process.

After separately preparing the project described in its README, run from the repository root:

```bash
courses/advanced-spark-modeling/projects/spark-tmb/workshop run failure-contracts
```

Inspect the actual source-bound receipt. This command reference does not assert that preparation or execution has already occurred on your machine.
