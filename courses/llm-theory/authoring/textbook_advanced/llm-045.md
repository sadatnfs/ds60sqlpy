## Normalize feature geometry without losing track of the residual path

Position mechanisms change how vectors express location. Normalization changes how their scale and common offsets affect subsequent computation. In a transformer, these choices influence both the forward representation and the gradients that travel through many layers. The names LayerNorm and RMSNorm are not interchangeable labels for "make values small"; their formulas preserve and remove different directions.

Let x be one token's d-dimensional feature vector. A tokenwise LayerNorm computes mean \(\mu=\frac1d\sum_ix_i\), centered values \(c=x-\mu\cdot 1\), variance \(v=\frac1d\sum_ic_i^2\), and normalized values \(\frac{c}{\sqrt{v+\epsilon}}\), followed by any learned gain and bias. RMSNorm uses \(\frac{x}{\sqrt{\frac1d\sum_ix_i^2+\epsilon}}\), typically with learned gain, without subtracting the mean. The reduction axis is the feature axis of one token under this construction.

### Calculate the two transformations on a new vector

For \(x=[1,2,3]\), LayerNorm has mean 2, centered values[-1,0,1] and variance \(\frac{2}{3}\). Ignoring only the tiny epsilon for this hand calculation, the normalized result is approximately[-1.224745,0,1.224745]. RMSNorm has mean square \(\frac{14}{3}\) and root mean square about 2.160247, giving approximately[.462910,.925820,1.388730]. The latter has nonzero mean because centering was never part of its definition.

Adding 5 to every feature leaves LayerNorm's centered vector unchanged. RMSNorm generally changes because both the raw numerator and root mean square change. Multiplying by a positive constant produces another useful comparison: with epsilon zero and nonzero input, both normalizers remove that positive scale under their respective formulas. With positive epsilon, exact scale invariance no longer holds at every magnitude. Small epsilon is a numerical design parameter, not permission to ignore its effect near zero.

Learned gain and bias can alter the final mean and scale. A unit-gain, zero-bias normalized vector may have zero feature mean under LayerNorm, while an arbitrary learned gain can change that property. State which stage of the formula is being discussed instead of generalizing a property of the standardized intermediate to every final output.

### Derive the Jacobian by separating numerator and denominator

For RMSNorm, write \(r=\sqrt{\frac{x^{\mathsf T}x}{d}+\epsilon}\). The derivative of \(\frac{x_{i}}{r}\) with respect to x_j contains a direct numerator term \(\frac{\delta_{ij}}{r}\) and a denominator term \(-\frac{x_ix_j}{dr^3}\). This yields \(J=\frac{I}{r}-\frac{xx^{\mathsf T}}{dr^3}\). A learned elementwise gain multiplies the corresponding output rows of this Jacobian.

The geometry becomes clear by testing directions. If u is perpendicular to x, then \(Ju=\frac{u}{r}\). Along x itself, \(Jx=\frac{\epsilon\cdot x}{{r}^{3}}\). When epsilon is zero, a radial scale change has no first-order effect. Near the zero vector, r is approximately \(\sqrt{\epsilon}\), so the Jacobian can have magnitude about \(\frac{1}{\sqrt{\epsilon}}\). Epsilon makes division defined but does not guarantee small sensitivities.

LayerNorm adds a centering projection. Let \(P=I-\frac1d\mathbf1\mathbf1^{\mathsf T}\), so c=Px and \(r=\sqrt{\frac{c^{\mathsf T}c}{d}+\epsilon}\). Its unit-gain Jacobian is \(\frac{P}{r}-\frac{cc^{\mathsf T}}{dr^3}\). Because \(P\cdot 1=0\) and \({c}^{T}\cdot 1=0\), the all-ones shift direction is annihilated. This explains the reference's post-normalization Jacobian test directly from the formula, rather than treating the result as an opaque autograd observation.

### Place normalization relative to the skip connection

A residual block adds a transformed branch to a direct path. In pre-norm form, \(y=x+F(N(x))\); in post-norm form, \(y=N(x+F(x))\). Applying the chain rule gives \(I+J_FJ_N\) for pre-norm and \(J_N(I+J_F)\) for post-norm. The location of J_N changes which routes a gradient can follow.

Set F to zero as a controlled case. Pre-norm returns x exactly and has identity Jacobian. Post-norm returns N(x) and still has the normalizer's Jacobian. This isolates placement from the complexity of a learned attention or feed-forward branch. It is a powerful local test because the expected difference can be derived without a long training run.

A direct identity path can help explain optimization behavior, but it is not a complete theorem about training success. Depth, initialization, residual scaling, final normalization, optimizer and data all interact. Moving normalization across an addition changes the function and should be treated as an architectural change, not a harmless code refactor with guaranteed checkpoint equivalence.

### A gated feed-forward block has two interacting projections

A plain feed-forward block can be written \(\phi(XW_1)W_2\). A SwiGLU-style block instead forms \(G=XW_{g}\) and \(U=XW_{u}\), multiplies SiLU(G) elementwise by U, then projects through W_d. \(\operatorname{SiLU}(g)=g\operatorname{sigmoid}(g)\). The word "gate" describes a multiplicative role; SiLU is not constrained to[0,1] and is not a probability.

For example, \(g=-1\) gives SiLU(g)≈-.268941. With \(u=2\), the scalar product is about-.537883, so the gate can change sign rather than merely attenuate a positive value. At \(g=0\), SiLU is zero but its derivative is \(\frac{1}{2}\). This is why the reference's output can be zero while the gate receives a nonzero gradient.

Let H=SiLU(G) elementwise_mul U and let \(R=\frac{\partial L}{\partial Y}\). The gradient reaching H is R \({W_{d}}^{T}\). Multiplying this by SiLU(G) gives the up-branch derivative; multiplying by U and SiLU'(G) gives the gate-branch derivative. A zero up-branch gradient at a zero gate is therefore a local consequence of the product, not necessarily a disconnected parameter. Inspect both activations and both gradient paths before diagnosing an optimizer failure.

### Compare architectures at a stated resource budget

For input/output width d and hidden width h, a bias-free plain two-matrix FFN has 2dh weights. The gated version has 3dh because it uses gate, up and down matrices. Retaining the same hidden width increases that part of the parameter count by 50 percent. A quality comparison that ignores this change cannot attribute the difference solely to the activation mechanism.

To match this weight count, choose gated hidden width two-thirds of the plain hidden width when the dimensions and implementation permit it. The fixture's \(d=4\), plain \(h=6\) and gated \(h=4\) each give 48 weight entries. This matches one resource measure. It does not automatically equalize activation memory, operation scheduling, kernel efficiency or task quality.

Biases, rounded hardware-friendly widths and additional projections can change the exact count. Write the matrix dimensions and bias policy before using a shorthand ratio. The small model makes this accounting easy; the same habit prevents confusion when comparing larger checkpoints with different feed-forward conventions.

### Diagnose numerical differences before drawing training conclusions

When two implementations disagree, compare the reduction axis, mean subtraction, variance formula, epsilon placement, gain/bias values and dtype. A common-shift case distinguishes centering behavior; a zero vector probes epsilon handling; a nonconstant vector exposes an incorrect variance reduction. Testing only an all-ones vector can hide important differences or collapse the centered variance to zero.

During causal modeling, normalizing independently over features preserves the token information boundary. Accidentally normalizing over token positions can introduce dependence on future positions. A normalization bug can therefore look like an attention-mask bug at the final output. Follow the dependency graph and compare intermediate states to identify the first divergence.
