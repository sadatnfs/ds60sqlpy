tf-019: Convolution as a local, shared computation#

Level and prerequisites#

Intermediate; approximately 120 minutes. Direct prerequisites: tf-018. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

Learning objectives#

Trace a convolution kernel, channels and receptive field on a tiny array. The central investigation is concrete: Apply kernel [[1,0],[0,-1]] to the fixed 3x3 image containing 1 through 9 with VALID padding and no bias. The finish condition is The 2x2 output is all -4. TensorFlow uses cross-correlation convention; rotating the kernel would change this example to +4. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

Purpose and mental model#

Convolutional layers reuse a small kernel at many positions. Each output sees a local patch, so the kernel has fewer parameters than an unconstrained map from every input pixel to every output pixel. TensorFlow applies cross-correlation: it slides the kernel without rotating it. A mathematical convolution would reverse spatial axes. Channels and batches add axes but do not change the basic local dot product. VALID padding includes only patches entirely inside the image; SAME padding inserts boundary values under a defined convention. The output shape depends on input size, kernel size, stride and padding, not on the apparent visual size of a plotted image.

Vocabulary and concepts#

Kernel: Shared weights applied to each local patch.

Stride: Distance between adjacent kernel positions.

Receptive field: Input positions that can influence an output.

Syntax anatomy and reasoning sequence#

tf.nn.conv2d expects image shape(batch,height,width,channels) and filter shape(height,width,input_channels,output_channels). A3x3 single-channel image and2x2 kernel with stride1 and VALID padding produce shape(1,2,2,1). The first result is1-5=-4. Rotating the kernel changes that sign. Keep the batch/channel singleton axes visible when checking shapes.

Trace spatial sharing without losing the indexing convention#

TensorFlow's convolution operation uses the common neural-network cross-correlation convention: the supplied kernel is applied without the spatial flip used in the mathematical definition of convolution. Flipping the difference kernel therefore changes the sign of this fixture's result. Write one window and its coefficient products before reasoning from a picture.

For valid padding, a spatial dimension with input length H, kernel length K, stride S and unit dilation has output length ⌊H−KS⌋+1\left\lfloor \frac{H-K}{S}\right\rfloor+1. Dilation changes the effective kernel size to 1+(K-1)D. Padding changes which locations are available. A shape calculation should specify those choices instead of assuming the output matches the input dimensions.

A kernel tensor shaped (kh, kw, Cin, Cout) contains kh×kw×Cin×Cout weights. The lesson's 2×2, one-input-channel, two-output-channel construction has eight. An explicit bias would add one parameter per output channel. Increasing image height adds output positions and computation, but it does not create a separate set of weights for every location.

Locality limits influence. A corner input pixel belongs to fewer valid windows than an interior pixel, so changing one pixel need not change every output. A zero-sum kernel is invariant to adding the same constant to every value of a fully covered window. That argument needs care at zero-padded boundaries, where padding values may not receive the same constant shift.

Worked example / walkthrough#

Example A: Compute local differences#

Every patch has a bottom-right value four greater than its top-left value. The equal outputs are an arithmetic property of this ramp image, not a generic property of convolution.

import numpy as np
import tensorflow as tf

image=tf.reshape(tf.range(1,10,dtype=tf.float32),(1,3,3,1)); kernel=tf.reshape(tf.constant([1.,0.,0.,-1.]),(2,2,1,1))
out=tf.nn.conv2d(image,kernel,strides=1,padding='VALID')
np.testing.assert_array_equal(out.numpy().reshape(2,2),np.full((2,2),-4))

Expected: all four outputs-4.

Example B: Rotate the kernel#

Kernel orientation distinguishes cross-correlation from mathematical convolution. A symmetric kernel would hide this difference, which is why the asymmetric diagonal kernel is useful.

import numpy as np
import tensorflow as tf

image=tf.reshape(tf.range(1,10,dtype=tf.float32),(1,3,3,1)); kernel=tf.reshape(tf.constant([1.,0.,0.,-1.]),(2,2,1,1))
out=tf.nn.conv2d(image,kernel,strides=1,padding='VALID')
np.testing.assert_array_equal(out.numpy().reshape(2,2),np.full((2,2),-4))
rot=tf.reverse(kernel,axis=[0,1]); changed=tf.nn.conv2d(image,rot,strides=1,padding='VALID')
np.testing.assert_array_equal(changed.numpy().reshape(2,2),np.full((2,2),4))

Expected: all outputs+4.

Common pitfalls and diagnosis#

A sign reversal suggests a kernel-orientation mismatch. A wrong output shape suggests padding, stride, dilation or channel-order assumptions. Count weights from kernel dimensions and biases from the layer definition. For an unexpected global effect from one pixel, inspect the exact windows containing that pixel before assuming weight sharing means global mixing.
