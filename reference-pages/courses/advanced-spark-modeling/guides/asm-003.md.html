asm-003: Independent group fits and one shared model#

Tutorial mode. Stage: beginner. Direct prerequisites: asm-002, spark-016.

Starting point and result#

“Fit a model on Spark” can describe two very different operations. You might want one independent model per product, with separate parameter vectors. Or you might want one shared parameter vector fit to all products. This chapter makes the distinction observable before any complicated optimization enters the picture.

The example fits Gaussian means for a two-record group and a six-record group. It computes separate group MLEs, the pooled global MLE, and an unweighted average of group MLEs. All three are sensible numbers, but they answer different questions. You will also change the group sizes to see when two of the formulas happen to coincide.

Worked case 1: unequal groups#

Group A has values 1,31,31,3, so its independent estimate is 222. Group B has six values with sum 606060, so its estimate is 101010. The pooled estimate is (4+60)/(2+6)=8(4+60)/(2+6)=8(4+60)/(2+6)=8. An unweighted average of the two group estimates is 666.

Spark computes a grouped count, sum and mean. The reference then combines only the count and sum fields to obtain the pooled MLE. It checks the estimate against the direct serial mean and evaluates the global squared error at both 666 and 888. The pooled optimum has the smaller common-mean objective, as the derivative predicts.

This does not say the value 666 is “bad” in every context. If the question is the average of the two products' typical outcomes with equal product importance, it can be the intended descriptive quantity. The model and target, not the distributed API, determine the correct weighting.

Worked case 2: change the amount of data, not the formula#

Replicate every B observation twice. The separate A and B means remain 222 and 101010, but the pooled common-mean fit moves toward B because the shared-mean model now contains more B observations. The unweighted average of the separate means stays at 666. This changed-data experiment distinguishes the two objectives without any numerical optimizer.

Now compare equal-size groups A=(1,3)A=(1,3)A=(1,3) and B=(9,11)B=(9,11)B=(9,11). Both the count-weighted combination and the unweighted group average produce 666. That agreement is a special case caused by equal ngn_gng​, not a proof that averaging fitted parameters is valid generally.

For a nonlinear model, even count weighting of group-specific fitted coefficients usually does not recover the global optimum. The optimization map is nonlinear in the data, different groups can have different feature designs, and a shared parameter enters every term jointly. Carry loss and gradient summaries at the same trial parameter if the goal is one shared model.

Failure diagnosis#

A grouped fit with tiny groups may produce an undefined variance or unidentifiable coefficients. Report group count, design rank and convergence diagnostics with every fit. Do not quietly replace a failed group by zeros and then summarize those zeros as estimates.

If results change when the number of executor partitions changes but group membership does not, inspect whether a function fits one model per physical partition rather than one per scientific group. A repartition can mix or split groups. Only explicit complete-group ownership or sufficient-statistic aggregation provides the intended contract.

Group labels are keys, not ordering guarantees. The program sorts the small output before checking it. Production code should write a keyed result table and join it back by validated keys rather than trusting collection order.

Interview discussion#

Can I average coefficients from models fit on each partition? Usually no. For the simple shared Gaussian mean, count and sum are sufficient and count-weighted means happen to work. A generic model does not inherit that property. Derive the global score equation or use a justified distributed optimization method.

What does an independent per-customer fit require? Each customer's complete relevant data, enough observations and a clearly defined parameter set. Customers can run independently only if the objective has no shared parameters or coupled latent effects.

Why not collect each group to Python? You may do so for a bounded small group, but a large or skewed group can exhaust one worker's memory. This particular Gaussian model only needs count and sum; built-in distributed aggregates are a better representation of its mathematics.

from __future__ import annotations

import json
import math


def session(name):
    from pyspark.sql import SparkSession

    spark = (
        SparkSession.builder.master("local[2]")
        .appName(name)
        .config("spark.ui.enabled", "false")
        .config("spark.driver.host", "127.0.0.1")
        .config("spark.driver.bindAddress", "127.0.0.1")
        .config("spark.sql.shuffle.partitions", "2")
        .config("spark.sql.adaptive.enabled", "false")
        .config("spark.sql.ansi.enabled", "true")
        .config("spark.sql.session.timeZone", "UTC")
        .getOrCreate()
    )
    if spark.version != "4.0.1":
        spark.stop()
        raise RuntimeError("This worked reference is qualified for Spark 4.0.1")
    spark.sparkContext.setLogLevel("ERROR")
    return spark


def run(spark):
    from pyspark.sql import functions as F

    a = [1.0, 3.0]
    b = [8.0, 10.0, 10.0, 12.0, 9.0, 11.0]
    rows = [("A", x) for x in a] + [("B", x) for x in b]
    frame = spark.createDataFrame(rows, "group string, y double").repartition(3)
    groups = (
        frame.groupBy("group")
        .agg(F.count("*").alias("n"), F.sum("y").alias("total"), F.avg("y").alias("mean"))
        .orderBy("group")
        .collect()
    )
    assert [(r.group, r.n, r.total, r.mean) for r in groups] == [
        ("A", 2, 4.0, 2.0),
        ("B", 6, 60.0, 10.0),
    ]
    pooled = math.fsum(r.total for r in groups) / sum(r.n for r in groups)
    average_models = math.fsum(r.mean for r in groups) / len(groups)
    assert pooled == 8.0 and average_models == 6.0
    assert sum((y - pooled) ** 2 for _, y in rows) < sum((y - average_models) ** 2 for _, y in rows)
    duplicated_b = (sum(a) + 2 * sum(b)) / (len(a) + 2 * len(b))
    equal_sized = (sum(a) + sum([9.0, 11.0])) / 4
    assert math.isclose(duplicated_b, 124 / 14) and equal_sized == 6.0
    print(
        json.dumps(
            {
                "independent_means": {r.group: r.mean for r in groups},
                "shared_mean_mle": pooled,
                "unweighted_model_mean": average_models,
                "shared_mean_after_B_replication": duplicated_b,
                "equal_group_sizes_coincide": equal_sized,
            }
        )
    )


if __name__ == "__main__":
    spark = session("asm-003")
    try:
        run(spark)
    finally:
        spark.stop()
