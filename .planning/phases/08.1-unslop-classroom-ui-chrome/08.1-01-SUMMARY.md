# Plan 08.1-01 summary: unslop classroom chrome

The classroom chrome went through the unslop process (look, audit,
classify, direction, nine passes, checklist). It was classified as light
slop and handled in polish mode: remove only, with no feature, behavior,
element ID, data attribute, ARIA, section order or lesson content changes.
The full findings table is in `08.1-AUDIT.md`.

## Changes by pass

1. Spacing: no changes; the spacing scale was already consistent.
2. Color: removed the accent-colored hero word, the gradient wash on the
   live browser controls, the radial dot grid on the preview stage and the
   3px area-colored part rules (now 1px `var(--rule)`). The lesson folio
   numeral moved from accent to muted.
3. Icons: the theme toggle half disc no longer uses a gradient (border plus
   inset shadow). The favicon is a plain sans "d." No emoji icons existed;
   a guard now keeps it that way.
4. Copy: the hero heading lost its trailing period and emphasis. No hype or
   exclamation copy was found in chrome.
5. Type: weights collapsed from nine values (450 to 760) to 400, 500 and 600
   (400 x6, 500 x35, 600 x34); headings and `strong` take 600 from one base
   rule. All negative letter-spacing is removed. The italic Georgia brand mark
   is now the UI family at 600. The italic diff skip line is upright.
6. Layout: unchanged; the folio numeral is smaller (3rem to 2.5rem).
7. Details: radii 6/4/10px, light shadows tightened to a hairline plus a
   faint lift, ease set to `cubic-bezier(0.22, 1, 0.36, 1)`.
8. Visuals: the shimmer skeleton is now a static block; the `.map-lesson`
   stripes stay as a functional wireframe (commented).
9. Motion: removed the skeleton loop, shortened `.manual-parts li` to 0.3s,
   turned `ink-in` into a short border-color change. Only the three
   functional busy pulses loop, and reduced motion stops them.

The credit comment `Chrome polish follows unslop by @heydamir (CC BY 4.0).`
sits at the top of the `:root` token block in `classroom.css`.

  pass.
