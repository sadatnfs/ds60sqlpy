## Curvature and sampling variation answer different questions

The inverse observed information is a familiar large-sample variance approximation for a regular correctly specified likelihood. Under misspecification or dependent observations, the variability of the score may no longer equal its expected curvature. A sandwich estimator separates those two ingredients instead of assuming they coincide.

Let \(q_i(\theta)\) be a contribution to the minimized objective and \(u_i=\nabla q_i(\widehat\theta)\). Using sums throughout,

\[
H=\sum_i\nabla^2q_i(\widehat\theta),\quad
B=\sum_i u_i u_i^\top,\quad
\widehat V=H^{-1}BH^{-1}.
\]

For independent clusters \(g\), replace row scores in the meat with cluster scores \(U_g=\sum_{i\in g}u_i\), so \(B_{\mathrm{cluster}}=\sum_gU_gU_g^\top\). These are uncorrected forms. Finite-sample corrections, degrees of freedom and asymptotic assumptions must be declared separately. A large number of rows within a few clusters does not provide a large number of independent clusters.

## Worked case 1: four clusters with duplicated measurements

The fixture consists of four independent conceptual clusters with paired observations \((0,0),(2,2),(4,4),(6,6)\). Fit a common mean using a working Gaussian variance one. The estimated mean is three and the sum-loss curvature is \(H=8\). A working-model inverse-information variance is therefore \(1/8=0.125\).

The squared row scores sum to 40, yielding an iid sandwich variance \(40/64=0.625\). Within each cluster the two residuals have the same sign, so cluster score squares sum to 80, yielding uncorrected cluster variance \(80/64=1.25\). The differences are intentional: one calculation assumes the working variance is correct, one uses empirical row variation, and one preserves the within-cluster dependence unit.

This four-cluster example is designed to make the arithmetic transparent. It is much too small to claim reliable asymptotic cluster-robust coverage. A precise computed variance can still have an unreliable inferential approximation. The code names the estimator `cluster_sandwich_variance_uncorrected` to avoid hiding that qualification.

## Worked case 2: enumerate a cluster bootstrap

Resample four whole clusters with replacement from the empirical set of four. There are \(4^4=256\) ordered bootstrap samples, so this tiny case can enumerate all possibilities without random Monte Carlo error. The variance of the resulting bootstrap means is exactly 1.25, agreeing with the uncorrected cluster sandwich for this equal-size mean fixture.

The bootstrap percentile endpoints are one and five for the specified empirical distribution and quantile convention. Enumeration removes simulation noise; it does not make those endpoints an exact population confidence interval. The empirical bootstrap distribution is based on only four observed clusters, and percentile coverage is a statistical property requiring assumptions and evaluation beyond calculating the endpoints.

Resampling individual rows would treat the duplicated within-cluster observations as independently exchangeable and target a different sampling scheme. For unequal cluster sizes, whether to average observations or clusters determines the estimand and the bootstrap calculation. Preserve the estimator's weighting rule within every resample.

## Weak information is a separate failure

The program attempts to invert a singular information matrix and requires an explicit failure. A sandwich cannot rescue a parameter that the objective does not identify. The bread must represent an appropriately identified, regular estimator before its inverse can be interpreted. Near-boundary parameters, mixture label ambiguities and flat nonlinear profiles from earlier chapters require special care.

A bootstrap fit must also record failed optimizations. Silently discarding failures can bias the retained bootstrap distribution toward easy or favorable datasets. Report the resampling unit, number of attempted and retained fits, initialization policy, convergence diagnostics and interval method. For time series, block or model-based resampling may be appropriate; a row bootstrap usually destroys temporal dependence.

## Answered review questions

**Is a robust variance estimator robust to every modeling problem?** No. It may accommodate particular variance or dependence misspecification under suitable asymptotics. It does not remove selection bias, repair a wrong estimand or identify an unobserved causal effect.

**Why can the inverse Hessian be numerically valid but scientifically wrong?** It describes local objective curvature. Its equality with sampling precision requires assumptions about the score distribution and independent units that can fail.

**What should a report say about this example?** It demonstrates three distinct variance formulas and an exact empirical cluster-bootstrap calculation on a tiny synthetic fixture. It does not establish interval coverage, broad bootstrap validity or production readiness for a particular scientific dataset.
