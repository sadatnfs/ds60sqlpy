## Learning objectives

Form a hypothesis from a stack, breakpoint or profile before editing code.

## Vocabulary and concepts

A debugger pauses a process so its call stack and local values can be inspected. A profile measures where work was spent. A hypothesis predicts an observation that can be checked. Debugging starts with the smallest reproducible discrepancy, while performance measurement needs a correctness check and a fixed workload.

## Syntax and mechanism

Build with -g for source-level symbols. A breakpoint stops at a selected line; stepping enters or advances statements. Timing tiny expressions is dominated by overhead, so use a bounded repeated workload and report units plus compiler/build mode rather than a universal speed claim.
