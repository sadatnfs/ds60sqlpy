## Outcome and mechanism

Inspect the numeric design implied by a formula before interpreting coefficients or fitting a model.

An R formula describes terms rather than directly performing ordinary arithmetic. The formula y ~ x + group requests a response and additive predictor terms. An intercept is included by default in many modeling functions. The expression x * group expands into main effects and an interaction, while x:group requests the interaction term alone. Read the formula language before interpreting its symbols as raw numerical operators.

model.matrix turns predictor terms into numeric columns. An unordered factor commonly creates contrast columns relative to a baseline; an interaction multiplies or combines the relevant encoded columns. Inspect column names and a few rows so the coefficient meanings are concrete. A displayed category name is not itself a numeric column until an encoding rule is chosen.

The design can be rank deficient. Including both x and twice_x alongside an intercept does not create two independently identifiable effects because the columns carry the same information. qr(X)$rank diagnoses a numerical rank for the declared tolerance. A regression function may drop or mark coefficients, but that behavior is not a scientific resolution of the redundant specification.

A full-rank tiny design still does not establish a valid statistical model. Response distribution, error dependence, selection and out-of-sample behavior need separate analysis. This chapter prepares the representation needed for later lm and glm lessons; it does not turn a solved matrix into evidence of causality or generalization.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Formula | A symbolic specification of a modeled relationship. |
| Design matrix | Numeric columns produced from a model formula and data. |
| Interaction | A term allowing one predictor effect to depend on another. |
| Rank deficiency | A design whose columns do not provide independent information for every coefficient. |

## Read the syntax

model.matrix(~ x + group, data) builds predictors, including an intercept under this formula. Use ~ x * group for main effects plus interaction and inspect colnames. qr(X)$rank should be compared with ncol(X), with a documented tolerance for numerical decisions.

## Worked examples

### Example 1: Inspect an interaction design

```r
data <- data.frame(x = c(0, 1, 0, 1), group = factor(c("A", "A", "B", "B"), levels = c("A", "B")))
design <- model.matrix(~ x * group, data = data)
stopifnot(identical(colnames(design), c("(Intercept)", "x", "groupB", "x:groupB")))
stopifnot(qr(design)$rank == 4L)
print(design)
```

**Expected observation:** Four identifiable columns for these four distinct rows.

The interaction is zero for A and follows x for B, allowing a different slope in the two groups under this encoding.

### Example 2: A redundant predictor cannot identify a separate effect

```r
data <- data.frame(x = 0:3)
data$twice_x <- 2 * data$x
design <- model.matrix(~ x + twice_x, data = data)
stopifnot(ncol(design) == 3L, qr(design)$rank == 2L)
print(c(columns = ncol(design), rank = qr(design)$rank))
```

**Expected observation:** Three columns, rank two.

twice_x is exactly determined by x. More column names do not create more independent information.
