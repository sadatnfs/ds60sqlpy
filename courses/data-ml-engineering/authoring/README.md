# Book authoring contract

The maintained fragments are foundations/chapters.json, ml-lifecycle/chapters.json
and serving/chapters.json. Each is a JSON list. Foundations owns dme-001 through
dme-032 and dme-041 through dme-056. Root owns dme-033 through dme-040 in the
ml-lifecycle fragment. Serving owns dme-057 through dme-072. A record has exactly
these fields:

```json
{
  "id": "dme-001",
  "title": "From a record to an engineering decision",
  "level": "beginner",
  "minutes": 90,
  "prerequisites": [],
  "runtime_profile": "python-core",
  "language": "python",
  "concepts": ["row grain", "contract"],
  "outcome": "State a testable contract for a small data product.",
  "guide_source": "courses/data-ml-engineering/authoring/foundations/chapters/dme-001.md",
  "source_path": "courses/data-ml-engineering/authoring/foundations/examples/dme-001.py",
  "related_paths": [{"label": "Polars workshop", "path": "courses/polars/README.md"}]
}
```

Markdown contains the full chapter H1, exactly two headings beginning
`## Worked case 1:` and `## Worked case 2:`, original theory, application and
changed-condition diagnosis, answered interview discussion and primary sources.
Insert exactly one `<!-- worked-program -->` marker where the complete program
should appear. The program has complete example_one(), example_two() and main()
functions. The publisher inserts exact source bytes into the fenced program.
Do not paste a second independently maintained copy of that complete code.

Local Markdown links must resolve from the maintained Markdown source directory.
The publisher relocates them to the generated guide directory. Prefer
related_paths for cross-course/project links so every source location stays valid.
Web references remain ordinary Markdown links. Write TeX with explicit delimiters.

`python courses/data-ml-engineering/authoring/build.py --source-check` validates
completed source records without registration. The normal command publishes only
when all 72 records and artifacts are present; --check checks exact generated
bytes. It emits tutorial-mode metadata and complete-source admissions, with no
forced practice or solution gate. Shared readers are generated by root afterward.

Prepared profiles currently allowed are python-core, data-engineering,
spark-local-python and llm-torch-cpu. New dependencies or execution surfaces need
root coordination. Owned project source is separate from the bounded pad; never
start a persistent service or install packages in a chapter program.

A fragment may additionally own output-contracts.json with the shared
{schema_version: 1, units: [...]} format. Use the actual chapter ID and declared
output kinds/count/descriptions/accessibility requirements. The aggregate validates
these entries against the shared output contract and publishes one combined
figure-contracts.json only with the complete book. Ordinary outputs remain limited
to two plots/tables/reports per run under the existing size limits.
