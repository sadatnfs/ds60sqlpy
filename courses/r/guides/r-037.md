## Outcome and mechanism

Use a small simulation to investigate a probability while separating simulation error from model uncertainty.

Simulation begins with a model, not a random-number call. State the outcome space, probabilities and independence assumptions. Drawing four independent fair coin flips is a specific mechanism; drawing four correlated user events is a different one. A simulation can be internally correct and still answer the wrong real-world question if its generative assumptions do not fit.

A Monte Carlo probability estimate is the fraction of simulated repetitions satisfying an event. More repetitions generally reduce numerical sampling variation, but they do not repair a misspecified model. For independent Bernoulli event indicators with probability p, the estimator's standard error is approximately \(\sqrt{p(1-p)/B}\), where B is the number of repetitions. The estimated p can provide a practical approximation when its limitations are understood.

Set a seed for reproducibility, then report the number of repetitions and the generator context. Do not keep trying seeds until a preferred result appears. A deterministic reference should test a broad justified approximation bound or compare with an exact small-case calculation, rather than asserting one arbitrary simulated decimal as a scientific truth.

Simulation output also has a unit. A repetition may represent a trial, a user, a whole experiment or a time series. Accidentally treating every internal draw as an independent replication changes the uncertainty calculation. Keep repetitions and within-repetition observations separate in array dimensions and summaries. Later bootstrap and resampling chapters build on this distinction.

## Read the syntax

Use rbinom(B, size, prob) for B binomial outcomes under the stated independent-trial model. Compute event indicators, their mean and a Monte Carlo error estimate. The mathematical standard error is \(\sqrt{p(1-p)/B}\) for independent indicators.

## Worked examples

### Example 1: Compare a simulated event with an exact probability

```r
set.seed(41)
repetitions <- 20000L
heads <- rbinom(repetitions, size = 4, prob = 0.5)
estimate <- mean(heads >= 3)
exact <- 5 / 16
mcse <- sqrt(estimate * (1 - estimate) / repetitions)
stopifnot(abs(estimate - exact) < 0.02, mcse < 0.005)
print(c(estimate = estimate, exact = exact, mcse = mcse))
```

**Expected observation:** Estimate near 0.3125 with finite simulation error.

There are four ways to obtain exactly three heads and one way to obtain four, among sixteen equally likely sequences. The simulation approximates that model probability.

### Example 2: Repetition size and estimator precision

```r
p <- 0.3
small <- sqrt(p * (1 - p) / 100)
large <- sqrt(p * (1 - p) / 400)
stopifnot(isTRUE(all.equal(large, small / 2)))
print(c(repetitions100 = small, repetitions400 = large))
```

**Expected observation:** Approximately 0.0458 and 0.0229.

Quadrupling independent repetitions halves this standard error. It does not imply that a biased real-world model becomes correct.
