# viz-008: Export a reviewable figure with accessible evidence

## Level and prerequisites

Advanced. Direct prerequisites: `viz-006`, `viz-007`. The core workflow stays offline and does not require a static-image export service or additional browser installation.

## Preserve the claim with the figure

At a declared observation cutoff, twelve jobs have statuses completed eight, pending three and failed one. Pending is not a failure and not a completed observation. A chart that merges pending with failed makes a different operational claim. State the cutoff, units and status definition in a caption.

The reference uses bar heights, printed values and patterns as well as color. A semantic table gives exact values, and the caption explains the denominator. Color alone is insufficient for users with color-vision differences, printing or assistive technology.

## Worked case: specification round-trip

A Plotly figure is a data/layout specification. Python serializes it to JSON, reconstructs a figure from that JSON, and checks that counts and table rows are preserved. It prints the serialized size and a SHA-256 identity for that specification. A hash identifies bytes; it does not establish scientific validity or capture every browser rendering detail.

The JavaScript variant provides a native button that exposes readable JSON in a labeled textarea. The user can inspect and copy it. The handler checks that reconstructed counts still sum to twelve. It performs no network request, automatic file download or model publication.

## Contrasting case: screenshot versus specification

A screenshot preserves appearance at one viewport but loses interactive behavior and often the underlying data. JSON preserves a specification, but rendering can vary with library version, fonts and browser. A source-bound classroom observation records another evidence layer. Keep these artifacts distinct instead of labeling any one of them a complete reproduction of all others.

For publication-quality images, use an explicitly prepared export route and inspect the result. This core lesson does not silently install Kaleido or claim a screenshot exists because JSON serialization succeeded. The supplied figure remains bounded below 200 KiB, uses inline values, and needs no external image or map tiles.

## Review accessibility as behavior

Read the caption and table without hovering. Use keyboard navigation for native controls. Check labels at increased zoom and a narrow panel. Inspect contrast, clipping and noncolor distinctions. A table node or ARIA attribute is useful structure, but it does not prove that a screen reader announces the intended information in the actual browser.

Python figures attach a plain description and primitive-cell table under `layout.meta`; the classroom's figure panel can render them as accessible text and HTML. These are data fields, not arbitrary HTML or executable callbacks. The JavaScript reference builds its own caption, table headers and cells with safe text insertion.

## Six progressive exercises

1. **Audit the denominator.** Reconcile all statuses. Expected evidence: total twelve, with pending retained as its own state.
2. **Add redundant encodings.** Preserve category meaning without color. Expected evidence: readable labels/patterns and a table.
3. **Round-trip JSON.** Serialize and reconstruct the figure. Expected evidence: counts 8,3,1 and the same table rows.
4. **Detect an edited claim.** Change failed from one to two without updating the caption. Expected evidence: a deliberate inconsistency is caught before export. Hint: check derived totals from data rather than hardcoded prose.
5. **Review a narrow view.** Inspect at roughly 400px width and increased text zoom. Expected evidence: no hidden essential labels, usable controls and accessible exact values.
6. **Transfer to a scientific report.** Prepare an effect figure with units, estimator, interval interpretation, source version and limitations. Expected evidence: another reader can reconstruct the stated calculation without inferring it from colors.

## Final interpretation

An interactive figure should make evidence easier to inspect. It does not strengthen identification, repair missing measurements or create uncertainty guarantees. Keep the chart's numerical claims aligned with the underlying scientific analysis and record the execution and accessibility checks actually performed.
