# Normalizing a latent process

Start with: tmb-032, tmb-013.

Outcome: Explain why process normalization depends on parameters and affects estimation.

**Where this runs.** In the classroom, the base-R companion at the end of this chapter checks a Gaussian normalizing constant by quadrature and the null space of an intrinsic precision. No file in the separately prepared [owned project](../projects/tmb-local/README.md) calls `TMB::normalize`, so this chapter's TMB usage is explanatory; the [API reference](../API-REFERENCE.md) gives the pinned signature; a companion run is not a TMB compiler or rpy2 receipt, so its output is not evidence that a compiled model or the rpy2 bridge ran.

A latent quadratic penalty is not automatically a normalized density. If \(u\) has precision \(Q(\theta)\), its Gaussian NLL is \(\frac12u^TQu-\frac12\log|Q|+\frac q2\log(2\pi)\). Omitting the determinant changes the objective whenever the precision depends on estimated parameters.

`normalize(obj, flag, value=0)` provides automatic process normalization for a suitable template. The template must have a data flag that disables observation terms, leaving only the unnormalized process contribution. This is a specific interface requirement, not a function that can infer arbitrary missing likelihood terms from source code.

## Key terms

- **Process density:** The probability density of the latent process alone, such as a Gaussian with precision \(Q(\theta)\), separate from observation terms.
- **Partition function:** The normalizing integral of an unnormalized density; when it depends on parameters, dropping it changes the estimates.
- **normalize:** The TMB function `normalize(obj, flag, value=0)` that adds automatic process normalization when a data flag can switch off every observation term.
- **Improper process:** A latent density, such as an unanchored random walk, whose singular precision makes the integral diverge so no normalizer exists.

### Worked case A: the missing determinant

The companion evaluates a one-dimensional quadratic process at two scales. Its unnormalized integral depends on scale. Adding the correct normalizer makes the integral one. The difference shows why a parameter-dependent “constant” cannot be dropped merely because it does not involve the latent state.

The process flag must disable every observation contribution while preserving the intended process density. If it also disables part of the prior precision or leaves an observation term active, normalization addresses the wrong function. Test the flag explicitly on a tiny known model before using it for a difficult process.

### Worked case B: an improper process

A random-walk difference penalty without an anchored level can be invariant to adding the same constant to every state. Its precision is singular and the integral over the unconstrained level diverges. The companion demonstrates a zero eigenvalue. No numerical normalizer can turn an improper unrestricted density into a proper one without adding a constraint, boundary distribution or other scientific assumption.

Our existing random-intercept and AR1 templates include their analytic normalizers and do not need this helper. The new API lesson explains when `normalize` would be appropriate rather than wrapping an already normalized model and accidentally changing the target.

### Answered discussion

**Is normalization just subtracting the minimum?** No. A density's integral, not its peak, must equal one. **Does a Laplace normalization become exact for every process?** No. Exactness requires an appropriate special case or independent proof. **Can a singular intrinsic model be used at all?** Yes with explicit constraints or a formulation that accounts for its improper components, but that is a different model contract.

Consult [normalize in the TMB manual](https://cran.r-project.org/web/packages/TMB/TMB.pdf) and validate a new flag-enabled template before advertising its compiled capability.

### Worked case C: the two raw integrals and the singular precision

The unnormalized kernel \(e^{-u^2/(2\tau^2)}\) integrates to \(\sqrt{2\pi}\,\tau\). The companion's loop should therefore print:

```text
tau   raw_integral   normalized    (closed-form values, rounded)
0.5   1.253314       1
2.0   5.013257       1
```

The raw integral changes by a factor of 4 when \(\tau\) moves from 0.5 to 2, so its negative log changes by \(\log 4=1.386294\). Suppose an objective kept only \(u^2/(2\tau^2)\) and dropped \(\log\tau\). Estimating \(\tau\) would then favor large values without limit, because every increase in \(\tau\) shrinks the penalty while nothing charges for spreading the prior. The missing \(\log\tau\) term is exactly what charges for that spread. For a latent vector of length \(q\) with precision \(\tau^{-2}I\), the missing term is \(q\log\tau\), so the distortion grows with the number of latent states rather than averaging out.

The second block builds the first-difference matrix for three states and forms \(Q=D^\top D\):

```text
Q = [  1  -1   0 ]      eigenvalues: 0, 1, 3   (hand-derived)
    [ -1   2  -1 ]
    [  0  -1   1 ]
```

Every row sums to zero, which the companion asserts through \(Q\mathbf 1=0\). The zero eigenvalue belongs to the direction \((1,1,1)\): shifting all three states by the same constant leaves the penalty unchanged. The determinant \(|Q|\) is 0, so \(-\tfrac12\log|Q|\) is infinite and no finite normalizer exists. The nonzero eigenvalues 1 and 3 correspond to the contrasts the walk actually constrains, and their product 3 is the generalized determinant used when an intrinsic model is handled on the constrained subspace.

### Testing a normalization flag on this example

A flag-enabled version of a random-walk template would compute the observation terms only when a data flag is 1. Calling `normalize(obj, flag = "flag")` asks TMB to integrate the process-only objective and subtract its log integral. On the three-state walk above, that integral diverges, so a correct implementation should fail or return a non-finite value rather than a plausible number. Anchoring the first state with a proper prior, for example \(u_1\sim N(0,1)\), adds 1 to the top-left entry and makes \(|Q|=1\), a case a learner can check by hand before trusting the helper. The anchored precision has eigenvalues that are all positive, and the flag test then has a finite target.

### Base-R companion (runs in the classroom)

```r
for (tau in c(.5, 2)) {
  raw_integral <- integrate(function(u) exp(-u^2 / (2 * tau^2)), -Inf, Inf)$value
  normalized <- raw_integral / (sqrt(2 * pi) * tau)
  print(c(tau = tau, raw_integral = raw_integral, normalized = normalized));stopifnot(abs(normalized - 1) < 1e-8)
}
D <- matrix(c(-1, 1, 0, 0, -1, 1), 2, 3, byrow = TRUE)
Q <- crossprod(D)
print(eigen(Q, symmetric = TRUE)$values);stopifnot(max(abs(Q %*% rep(1, 3))) < 1e-12)
```
