# Worked reference: Epoch and restart accounting

This is an editable reading/project reference. It has no ordinary pad Run action.

An epoch defined as one complete pass over IDs 0..4 must have union `{0,1,2,3,4}`, assignment count five and no duplicates. A resampling epoch has a different contract and must retain its sampling rule and seed.

For a restart comparison, retain weights, optimizer moments, scheduler state, RNG states, epoch and sampler position. Compare an uninterrupted run with a resumed run under the same world size. If only loss agrees approximately, report numerical agreement rather than exact trajectory equivalence. The sharding case checks coverage; it is not automatically a full restart test.

```bash
courses/advanced-spark-modeling/projects/spark-torch/workshop run sharding-audit
```
