# Worked reference: Normal posterior versus MLE

This is an editable reading/project reference. It has no ordinary pad Run action.

Take observations `[1,3]`, known observation variance 1, prior mean 0 and prior variance 1. The MLE is 2. Posterior precision is 2+1=3, posterior variance is 1/3 and posterior mean is `(1+3+0)/3=4/3`.

The posterior mean differs from the MLE because the prior contributes information. A PyMC reference should target the posterior, while a normal likelihood optimizer targets the MLE. A TMB Laplace integral over Gaussian latent variables has a third declared role. Compare like targets before interpreting numerical disagreement as a bug.
