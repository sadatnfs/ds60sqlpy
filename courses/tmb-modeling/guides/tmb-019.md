# Simulate, recover and criticize

Start with: tmb-018, r-037.

Outcome: Use reproducible simulations to evaluate an estimator and its uncertainty claims.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

Simulation asks whether a fitting procedure behaves as intended when the data-generating mechanism is known. Fix parameters, generate observations, fit each simulated dataset, and record estimates, uncertainty and failures. It is a repeated experiment, not just a single dataset that happens to return a familiar number.

For \(B\) successful and failed planned replicates, report bias, root mean squared error and interval coverage with denominators defined in advance. Dropping non-converged fits can make a weak method look excellent. Save the reason for each failure and show both attempted and usable counts.

### Worked case A: known-variance normal means

The companion runs 200 bounded, seeded replicates with thirty observations each, using known standard deviation. It constructs normal intervals for the mean and prints empirical coverage. Even a correct 95% procedure will not produce exactly 95% coverage in a finite simulation. The approximate Monte Carlo standard error is \(\sqrt{p(1-p)/B}\); at \(p=.95,B=200\), it is about 0.015.

TMB's `SIMULATE` block in `normal_mean.cpp` provides a model-consistent generator. `checkConsistency` can compare simulated scores with theoretical centrality and examine Laplace approximation bias. Its interpretation is more nuanced than treating one p-value as a universal pass: a sufficiently large simulation can detect small approximation errors.

### Worked case B: dependence omitted from the fit

The companion generates each dataset with a common random shift plus independent observation noise. An interval that assumes thirty fully independent errors underestimates uncertainty because the common shift does not average away with sample size. The coverage deterioration illustrates model misspecification, even though the mean estimator remains unbiased across repeated experiments.

A simulation design should vary difficult conditions: small group count, nearly zero random-effect variance, high autocorrelation, short time history and uneven group sizes. Begin with a tiny exact oracle, then add complexity one assumption at a time. Do not enlarge simulation volume before diagnosing a broken estimator.

### Diagnostics and answered discussion

**Does parameter recovery prove the model is true?** No. It shows behavior under a chosen generator. Real-data model criticism checks residual structure, held-out predictions and domain assumptions. **Why record the seed?** It makes a failure reproducible; the software version and random-number generator behavior matter too. **Can I claim coverage from one synthetic fit?** No. One interval either contains the known value or not, and cannot estimate long-run coverage reliably.

The [TMB checkConsistency documentation](https://cran.r-project.org/web/packages/TMB/TMB.pdf) explains joint and marginal score checks. Our course keeps small deterministic arithmetic tests separate from stochastic simulation evidence so neither is mistaken for the other.

### Complete R companion

```r
set.seed(1919)
B <- 200L; n <- 30L; truth <- 2; sigma <- 1
estimate <- replicate(B, mean(rnorm(n, truth, sigma)))
covered <- abs(estimate - truth) <= qnorm(.975) * sigma / sqrt(n)
print(c(bias = mean(estimate) - truth, coverage = mean(covered), mcse = sqrt(.95 * .05 / B)))
dependent <- replicate(B, mean(truth + rnorm(1, 0, .6) + rnorm(n, 0, sigma)))
wrong_coverage <- mean(abs(dependent - truth) <= qnorm(.975) * sigma / sqrt(n))
print(c(coverage_assuming_independence = wrong_coverage, attempted = B))
stopifnot(all(is.finite(estimate)), wrong_coverage < .8)
```
