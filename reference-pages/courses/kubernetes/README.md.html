Kubernetes: beginner to advanced#

Study in the unified classroom: run ./classroom from the repository root, then choose Kubernetes: beginner to advanced on /classroom. Python, SQL and all other subjects share this home and workspace. Deep networking and operations#

The extension traces Pod, node and Service addresses through CNI, DNS, EndpointSlices, kernel/eBPF Service routing, NodePort, load balancers, Ingress, Gateway API, TLS, source-IP handling, headless discovery, NetworkPolicy, dual-stack, topology, draining and incident response. The maintained networking fixtures include manifests, a synthetic topology and an offline consistency checker. They do not install controllers or add new admitted browser operations. Windows host observations use Bash in WSL 2 and an explicit owned receipt.

How to work#

Read the guide, predict the stated case, write or edit your learner artifact, inspect one progressive hint at a time, then compare the separate solution after an attempt. A successful process or a manual read marker is not proof of understanding. Preserve actual learner edits in the app-owned workspace; the checked-in source is a starter.

The portable authoring inputs regenerate the 38 added lesson bodies while preserving the four original pilots. Public synthetic signature material is immutable. No lesson downloads tools, starts a cluster or selects an ambient context when opened.
