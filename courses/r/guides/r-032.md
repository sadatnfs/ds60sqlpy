## Outcome and mechanism

Aggregate groups while preserving missingness counts and enough state to reconstruct the intended overall mean.

A grouped summary changes the row grain. An observation table becomes one row per group, so each output field needs a clear aggregation rule. Counts, sums and means do not have identical missingness behavior. A reliable summary records both the number of input rows and the number of observed measurements used by a numerical statistic.

A mean alone loses information needed for later regrouping. If one group contains one observation and another contains three, averaging their means gives each group equal weight rather than each observation equal weight. Retaining observed count and sum permits reconstruction of the observation-weighted mean. Equal group weighting can be legitimate, but it answers a different question and should be named accordingly.

split and lapply provide a transparent base-R approach for small grouped computations. A factor key can retain a declared universe, including empty groups. A summary function should define the result for empty or all-missing groups before a table-building step combines outputs. Missing group labels also need a policy because some grouping functions omit them by default.

Aggregation order matters when the operation is not additive. A distinct count cannot generally be reconstructed by summing group distinct counts when the same entity appears in multiple groups. Similarly, a median is not reconstructed by averaging group medians. Keep the state required by the exact statistic or return to the underlying observations; do not assume every summary is composable like a sum.

## Read the syntax

Use split(data, key, drop=FALSE) for explicit factor-group retention, lapply for a structured summary and vapply when each group must return one known scalar. Reconstruct an overall observed mean as total observed sum divided by total observed count.

## Worked examples

### Example 1: Unequal group counts change the overall mean

```r
groups <- list(A = c(10), B = c(20, 30, 40))
counts <- vapply(groups, length, integer(1))
sums <- vapply(groups, sum, numeric(1))
means <- sums / counts
overall <- sum(sums) / sum(counts)
stopifnot(overall == 25, mean(means) == 20)
print(c(observation_mean = overall, equal_group_mean = mean(means)))
```

**Expected observation:** 25 versus 20.

The observation mean counts four measurements equally. The equal-group mean gives A and B equal influence despite their unequal sizes.

### Example 2: Retain an empty group and missing counts

```r
data <- data.frame(group = factor(c("A", "A", "B"), levels = c("A", "B", "C")), value = c(2, NA_real_, 6))
summary <- lapply(split(data$value, data$group, drop = FALSE), function(x) {
  observed <- x[!is.na(x)]
  c(rows = length(x), observed = length(observed), sum = sum(observed), mean = if (length(observed)) mean(observed) else NA_real_)
})
stopifnot(summary$A[["rows"]] == 2, summary$A[["observed"]] == 1)
stopifnot(summary$C[["rows"]] == 0, is.na(summary$C[["mean"]]))
print(summary)
```

**Expected observation:** Arows 2/observed 1; Crows 0/meanNA.

The declared C category remains visible with zero rows and no observed mean. A missing measurement within A is separately counted.
