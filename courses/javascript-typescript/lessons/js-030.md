# js-030: Forms, browser storage and application state

Use the browser fixture and record predictions before inspecting solutions.

## Exercises

1. **Validate one local form submission.** Save the snippet as HTML and submit name Ada and quantity 2, then try an invalid quantity.
   **Expected:** valid output Ada: 2; invalid input produces no accepted state.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.

2. **Handle storage success and failure explicitly.** Run this standalone snippet on a loopback HTTP origin and activate Save.
   **Expected:** either Saved or a visible Storage unavailable message, never an invented success.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.

3. **Load only a recognized stored schema.** Reject malformed JSON or a stored version other than 1 before rendering.
   **Expected:** invalid saved state is diagnosed and does not become accepted application state.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.

4. **Distinguish current state from persisted state.** Change a form value after saving without submitting again, then reload the page.
   **Expected:** the last saved value returns; the unsaved edit is not falsely described as persisted.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.

5. **Observe a change from another tab.** Open the same loopback URL in two tabs, save in one, and observe the other.
   **Expected:** the other tab reports an external change; the writing tab does not receive its own storage event.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.

6. **Reset only this lesson's key.** Remove the owned draft and verify an unrelated storage key remains.
   **Expected:** owned key absent; unrelated key unchanged.
   **Verify:** Record the observed value, exception or browser state and compare it with that expectation.
