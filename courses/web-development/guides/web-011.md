# web-011: The box model, sizing and overflow

## Level and prerequisites

Beginner; allow about 90 minutes, with extra time for independent practice. Direct prerequisites: `web-010`

## Learning objectives

Build a readable card that contains a long identifier. Explain which dimensions margin does and does not affect. Use content box, padding and border accurately when you explain a normal case and a failure case.

## Purpose, vocabulary and mental model

Every rendered box has content, optional padding, a border and an outside margin. With the default content-box sizing, a declared width describes the content, so padding and borders add to the outer width. With border-box sizing, the declared width includes the content, padding and borders. Margins remain outside either calculation. This distinction explains many layouts that unexpectedly exceed a parent.

Overflow occurs when content needs more room than the available box. Hiding overflow can conceal essential information; scrolling or wrapping may preserve it. Long unbroken strings and images are frequent sources of overflow. A fixed height can clip translated text, enlarged fonts or error messages, so prefer content-driven height unless the interaction truly requires a bounded region.

### Key terms

- **Content box:** The innermost area of a box that holds its text or children; by default `width` sizes only this area.
- **Padding:** The space between the content and the border, which shows the element's background.
- **Margin:** The transparent space outside the border that separates a box from its neighbors; adjacent vertical margins can collapse.
- **Box-sizing:** The property whose `border-box` value makes `width` include padding and border, which makes sizing predictable.
- **Overflow:** Content that does not fit its box, and the property that decides whether it is shown, clipped or scrollable.

## Syntax anatomy and mechanism

For a 200px content-box with 20px left and right padding and 2px borders, outer width is 244px. For a 200px border-box, the content width becomes 156px. Set a consistent box-sizing rule on all elements and pseudo-elements. Use max-inline-size to constrain readable width without assuming the writing direction.

## Worked example / walkthrough

### Worked example 1: Content-box arithmetic

The declared content width excludes padding and border.

```css
.card {
  width: 200px;
  padding: 20px;
  border: 2px solid;
}
```

**Expected observation:** The border box is 244px wide.

### Worked example 2: A predictable border box

The declared width now contains the interior spacing.

```css
.card {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid;
}
```

**Expected observation:** The border box is 200px wide.

## Contrast case: a fixed height that clips a validation message

The card below was sized for one line of text. Add the second line and compare the two overflow settings.

```css
.message {
  box-sizing: border-box;
  height: 3rem;
  padding: 0.5rem;
  overflow: hidden;
}
/* repair */
.message {
  height: auto;
  min-block-size: 3rem;
}
```

With `height: 3rem` and `overflow: hidden`, the box keeps its 3rem border box, and after 1rem of vertical padding only 2rem remain for text, so a second line of the message is cut off with no scrollbar and no warning. The repair keeps the minimum look of the original but lets the block grow, so a longer error such as Enter a whole number from 5 to 120 stays fully visible. Increase the root font size to see the difference grow: the fixed version loses more text, while the repaired version simply gets taller.

## Debugging and common mistakes

Do not use overflow:hidden to hide a layout bug without checking lost content. Vertical margins can collapse in ordinary block layout, while flex and grid layout have different rules. Inspect box measurements directly.

When a card is wider than you set, open the box model diagram and add content, padding and border; under content-box sizing the width you wrote covers only the content. When text disappears at the edge, look for overflow hidden or a fixed height before shrinking anything.
