## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Tampering | `uv.lock`, bootstrap locks, worker locks | high | mitigate | Hash-locked installs with `--require-hashes`; hashes from pypi.org metadata; no proxy URL recorded |
| T-08-10 | Denial of Service | postgres pin vs learner volume | high | mitigate | Same Debian major (collation stability); launcher repair path checked; lifecycle harness when present |

| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | Only version upgrades of packages already in the locks (existing, established projects: pillow, uv, pip, urllib3 and so on); no new package names; any new transitive name found during re-lock is listed in the SUMMARY with its PyPI project page |
