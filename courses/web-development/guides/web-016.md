# web-016: Grid: tracks, gaps and two-dimensional alignment

## Level and prerequisites

Intermediate; allow about 110 minutes, with extra time for independent practice. Direct prerequisites: `web-015`

## Learning objectives

Build an adaptive topic grid that survives a narrow container. Explain auto-fit versus auto-fill at a high level. Explain the mechanism, a normal case and a failure case in your own words, then retain source and observations separately.

## Purpose, vocabulary and mental model

Grid arranges items along rows and columns. A track is the space between two adjacent grid lines. Fractional fr units share remaining space after fixed sizes and gaps have been considered. They are not a fixed percentage of the full container. An item's minimum content contribution can still affect track size, which explains why a long unbroken value may widen an apparently equal grid.

Grid is useful when rows and columns must align across a collection. An auto-fit repeat with minmax can create as many columns as fit a preferred minimum, then distribute remaining room. The minimum must still fit a narrow viewport. A layout should adapt to its content, not depend on one device model or a fixed card count.

## Syntax anatomy and mechanism

Use `grid-template-columns:repeat(auto-fit,minmax(min(100%,14rem),1fr))` for a resilient card collection. The inner min permits a track to fit a container narrower than the preferred minimum. `gap` adds separation without changing source order. Named grid areas are useful for a page shell, but the source order must remain understandable when the layout collapses.

## Worked example / walkthrough

### Worked example 1: Two equal tracks

The remaining width is shared after the gap.

```css
.grid { display: grid; grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 1rem; }
```

**Expected observation:** Two tracks share the available width without an automatic min-content floor.

### Worked example 2: Adaptive cards

The preferred minimum is bounded by the available width.

```css
.cards { display: grid; grid-template-columns: repeat(auto-fit, minmax(min(100%, 14rem), 1fr)); gap: 1rem; }
```

**Expected observation:** The column count adapts to available space.

## Debugging and common mistakes

Do not use visual grid placement to conceal an incoherent document order. Avoid a minimum track width larger than the smallest intended container. Fr units are space-sharing rules, not magic overflow prevention.

Keep the source that produced the failure, the relevant input or viewport, and the actual observation. Repair one cause and repeat the original case before adding a new one. A browser can recover malformed HTML, silently ignore a CSS declaration or display a plausible layout with the wrong reading order. PHP can produce correct-looking text while missing an invalid-input branch. A successful parse or an initial reference marker therefore answers a narrower question than the full lesson objective.
