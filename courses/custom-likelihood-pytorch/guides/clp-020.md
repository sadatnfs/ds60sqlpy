# clp-020: Reproducible nonlinear panel dossier

Tutorial mode. Stage: advanced. Direct prerequisites: `clp-012`, `clp-018`, `clp-019`.

## Assemble a reproducible modeling dossier

A scientific model is more than a final coefficient vector. A reproducible dossier records the observation unit, probability law, parameter coordinates, fitting algorithm, derivative checks, prediction target, numerical evidence and limits. This capstone combines the earlier components into a deliberately small nonlinear panel analysis that can run offline in the prepared CPU classroom.

There are three independent synthetic panels, each observed at times zero through five. Their shared mean is

\[
m(t)=a e^{-bt}+c,
\]

with positive amplitude and decay rate represented by log coordinates. Within each panel, residual covariance is \(\Sigma_{jk}=\sigma^2\rho^{|j-k|}\). The demonstration supplies \(\sigma=0.25\) and \(\rho=0.5\); it estimates only the three mean parameters. The NLL sums complete-panel Gaussian contributions evaluated with Cholesky solves and includes log determinants and normalization constants.

## Worked case 1: fit, audit and predict with panel dependence

The generating mean parameters are \((a,b,c)=(2.5,0.55,0.6)\). To make a deterministic oracle, one panel adds residual vector \((0.12,-0.08,0.06,0.04,-0.10,0.09)\), another subtracts the same vector, and the third adds zero. Their average residual is exactly zero at every time, so the shared true mean is the optimum under either supplied covariance used in this chapter.

That symmetry is intentional. It permits a direct parameter-recovery assertion, but it is not a realistic stochastic sample and cannot establish consistency or interval coverage. L-BFGS starts from a different curve, the final gradient is checked, and the Hessian is required to be positive definite before its local inverse is used. The program reports closure evaluations and source-visible numeric diagnostics.

For an existing panel with final residual \(r_T\), stationary AR(1) prediction at horizon \(h\) has conditional residual mean \(\rho^h r_T\) and innovation uncertainty \(\sigma^2(1-\rho^{2h})\), when parameters and the observed final residual are treated as known. Thus each panel gets a different conditional forecast despite sharing the same population mean curve. The code evaluates horizons one and two, corresponding to future times six and seven.

## Worked case 2: impose false independence

Refit the same records with \(\rho=0\). The deliberately symmetric fixture still recovers the same shared mean parameters, so a comparison that only checks coefficient equality would miss the model difference. Its conditional forecast has no residual carryover, whereas the correlated model retains information from each panel's most recent residual.

The held-out fixture is constructed as the correlated conditional mean plus fixed small noise values. The program computes conditional forecast RMSE and the independence forecast RMSE, approximately 0.03136 and 0.04850 in the prepared runtime. This controlled case shows the mechanism by which conditional information can matter. It is not an unbiased performance contest: the held-out construction explicitly favors the correlated data-generating assumption. A real evaluation would need a preregistered holdout scheme and representative stochastic data.

## What the uncertainty columns do and do not contain

The code uses the inverse observed Hessian for the shared mean coordinates and differentiates future population means in those same coordinates. It reports a delta-method mean standard error. A second plug-in quantity adds \(\sigma^2(1-\rho^{2h})\) to that mean variance before taking a square root.

That second quantity is deliberately approximate. It does not propagate uncertainty in the supplied covariance parameters, and it omits the covariance between estimated mean parameters and the estimated final residual used for conditional prediction. It also omits cross-horizon covariance. A complete prediction interval could use a joint derivative calculation or a parametric bootstrap that refits the entire declared model and reproduces the conditioning scheme. The output therefore calls this value `plug_in_observation_sd`, not a validated coverage interval.

## From local correctness to distributed execution

The independent likelihood units are complete panels. A Spark implementation may evaluate different panels at a fixed shared parameter vector and sum their objective and gradient contributions. It must not independently optimize each panel and average its optimum, because that generally differs from fitting one shared parameter vector. It must preserve observation membership, parameter version, reduction mass and failure handling across repeated evaluations.

This capstone executes one CPU process and three tiny panels. It does not demonstrate cluster throughput, CUDA execution, DDP collectives or a production forecasting system. Those require separate execution evidence. The source is intentionally self-contained so that an integration package can compare its distributed result with this exact local oracle without relying on downloaded data or hidden preprocessing.

## Answered review questions

**Why retain a synthetic case with symmetric residuals?** It isolates numerical implementation from statistical sampling uncertainty and supplies a precise recovery target. Its artificial structure is a limitation that must be stated, then complemented by richer stochastic studies before substantive use.

**What would make the dossier stronger for a real dataset?** Validate sampling and missingness, compare scientifically plausible mean and covariance models, audit derivatives at multiple parameter values, inspect profile likelihoods, evaluate time-respecting held-out predictions and assess uncertainty coverage under realistic simulation scenarios.

**What should be preserved when handing the model to an engineer?** The complete objective and unit definitions, source and dependency identities, test data, expected outputs with tolerances, fitting and prediction contracts, resource limits, known failure cases and explicit boundaries of what has actually been executed.

## Complete reproducible program

Run this complete source in the separately prepared `llm-torch-cpu` pad. It uses float64 CPU tensors and tiny original offline fixtures. Each execution starts fresh. Save edited source and notes with classroom controls. There is no exam or hidden solution, and execution is not scientific model acceptance. Runtime: `llm-torch-cpu`.

```python
"""Complete float64 CPU likelihood investigation with original synthetic data."""

from __future__ import annotations

import json
import math

import torch

DTYPE = torch.float64
torch.set_num_threads(1)


def tensor(values):
    return torch.as_tensor(values, dtype=DTYPE)


def mean_curve(raw, time):
    return raw[0].exp() * torch.exp(-raw[1].exp() * time) + raw[2]


def covariance(length, sigma, rho):
    if length < 1 or not math.isfinite(sigma) or sigma <= 0 or not -1 < rho < 1:
        raise ValueError("Require a positive finite scale and stationary correlation")
    index = torch.arange(length)
    return sigma**2 * tensor(rho).pow((index[:, None] - index[None, :]).abs())


def panel_nll(raw, time, y, scale=0.25, rho=0.5):
    if raw.shape != (3,) or time.ndim != 1 or y.ndim != 2 or y.shape[1] != len(time):
        raise ValueError("Use three parameters and complete panels aligned to observation times")
    if y.numel() == 0 or not all(bool(torch.isfinite(value).all()) for value in (raw, time, y)):
        raise ValueError("Use finite parameters, times and nonempty panel data")
    factor = torch.linalg.cholesky(covariance(len(time), scale, rho))
    residual = y - mean_curve(raw, time)
    whitened = torch.linalg.solve_triangular(factor, residual.T, upper=False)
    return (
        y.shape[0] * (len(time) * math.log(2 * math.pi) / 2 + torch.log(torch.diag(factor)).sum())
        + whitened.square().sum() / 2
    )


def fit_panel(time, y, rho):
    raw = tensor([math.log(1.8), math.log(0.3), 0.3]).requires_grad_()
    optimizer = torch.optim.LBFGS(
        [raw],
        max_iter=160,
        tolerance_grad=1e-10,
        tolerance_change=1e-14,
        line_search_fn="strong_wolfe",
    )
    calls = 0

    def closure():
        nonlocal calls
        calls += 1
        optimizer.zero_grad()
        loss = panel_nll(raw, time, y, rho=rho)
        loss.backward()
        return loss

    optimizer.step(closure)

    def objective(value):
        return panel_nll(value, time, y, rho=rho)

    gradient = torch.autograd.grad(objective(raw), raw)[0]
    hessian = torch.autograd.functional.hessian(objective, raw)
    eigen = torch.linalg.eigvalsh(hessian)
    if float(eigen[0]) <= 0:
        raise ValueError("Nonpositive observed information cannot support this delta-method report")
    return (
        raw.detach(),
        torch.linalg.inv(hessian),
        float(gradient.abs().max()),
        calls,
        float(eigen[0]),
    )


def run_cases():
    time = torch.arange(6, dtype=DTYPE)
    truth = tensor([math.log(2.5), math.log(0.55), 0.6])
    residual = tensor([0.12, -0.08, 0.06, 0.04, -0.10, 0.09])
    y = mean_curve(truth, time) + torch.stack([residual, -residual, torch.zeros_like(residual)])
    estimate, parameter_covariance, gradient, calls, minimum_information = fit_panel(time, y, 0.5)
    iid, _, _, _, _ = fit_panel(time, y, 0.0)
    assert torch.allclose(estimate, truth, atol=5e-5, rtol=0) and gradient < 5e-4
    assert torch.allclose(iid, truth, atol=5e-5, rtol=0)
    horizon = tensor([1, 2])
    future_time = time[-1] + horizon
    mean = mean_curve(estimate, future_time)
    last_residual = y[:, -1] - mean_curve(estimate, time)[-1]
    conditional = mean + last_residual[:, None] * tensor(0.5).pow(horizon)
    future_noise = tensor([[0.05, -0.03], [-0.02, 0.04], [0.01, -0.02]])
    heldout = (
        mean_curve(truth, future_time)
        + tensor([0.09, -0.09, 0])[:, None] * tensor(0.5).pow(horizon)
        + future_noise
    )
    jacobian = torch.autograd.functional.jacobian(lambda p: mean_curve(p, future_time), estimate)
    mean_variance = torch.einsum("ij,jk,ik->i", jacobian, parameter_covariance, jacobian)
    plug_in_observation_variance = mean_variance + 0.25**2 * (1 - tensor(0.5).pow(2 * horizon))
    assert bool(torch.isfinite(conditional).all()) and bool(
        (plug_in_observation_variance > 0).all()
    )
    return {
        "parameters": [float(estimate[0].exp()), float(estimate[1].exp()), float(estimate[2])],
        "train_nll": float(panel_nll(estimate, time, y)),
        "gradient_max_abs": gradient,
        "objective_evaluations": calls,
        "minimum_information_eigenvalue": minimum_information,
        "future_times": future_time.tolist(),
        "conditional_group_forecasts": conditional.tolist(),
        "mean_forecast_se": mean_variance.sqrt().tolist(),
        "plug_in_observation_sd": plug_in_observation_variance.sqrt().tolist(),
        "conditional_rmse": float(torch.mean((conditional - heldout).square()).sqrt()),
        "wrong_independence_rmse": float(torch.mean((mean[None, :] - heldout).square()).sqrt()),
        "scope": (
            "three deliberately symmetric synthetic panels; "
            "supplied covariance; CPU numerical demonstration"
        ),
    }


if __name__ == "__main__":
    print(json.dumps(run_cases(), sort_keys=True, allow_nan=False))
```
