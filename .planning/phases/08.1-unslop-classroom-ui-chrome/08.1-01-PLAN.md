# Plan 08.1-01: unslop audit and chrome refinement

## Objective

Run the classroom chrome through the unslop skill (heydamir/unslop, CC BY 4.0,
cloned at `~/.cache/ds60sqlpy/unslop/repo/skills/unslop/`) and remove the
visual slop it finds, without changing features, lesson content, section order
or behavior (UX-03, ROADMAP Phase 08.1).

In scope: `src/ds60sqlpy/assets/classroom.html`, `classroom.css`,
`classroom.js`, `classroom-shell.js`, `classroom-guide.js`, and the small
sandbox and preview pages, plus the UI checks and tests that pin their markup.

Out of scope: lesson plans, lesson prose, examples, practice, solutions,
walkthrough step text, generated lesson readers, `courses/**`, `curriculum/**`
and vendored libraries. Copy changes are limited to chrome labels, buttons,
status and empty states.

## Direction (stated, not waited on; the user asked for autonomous work)

- Product: a local desktop classroom where a new coder reads a lesson, runs
  code against a real runtime and steps through a solution.
- Character: a quiet lab notebook with a teacher's margin notes; calm, exact,
  legible for long sessions.
- World: printed textbooks, lab notebooks, terminal output and editor gutters.
- Moments: opening a lesson, the first run, a failing run, stepping a
  walkthrough, finding the guide.
- Signature: one restrained accent for "the thing you can act on now", with
  tabular, monospace-aligned status and result counts.

## Tasks

1. Snapshot the current chrome at 1440x900 in both themes (home, lesson
   workspace, guide, tour, palette, walkthrough, a run result, an error) with
   the containerized Playwright runner. Keep the before shots under
   `work/p081/before/`.
2. Audit against `references/signs.md`; write every sign found with its file,
   selector or line, and classification (heavy, light, none) into
   `08.1-AUDIT.md`.
3. Apply the nine passes in order: spacing (4px scale), color (one tinted
   neutral ramp, three text roles, one accent, no gradients or glows), icons
   (no emoji as icons; one line icon treatment), copy (no exclamation marks,
   no hype, no trailing periods on labels), type (weights 400 to 500, sentence
   case, no uppercase tracked labels, tabular numbers), layout (keep sections
   and order), details (nested radius, keycaps, quiet counts), visuals (remove
   decorative filler), motion (no looping pulses, no `transition: all`, one
   easing curve, honor reduced motion).
4. Keep contrast at WCAG AA in both themes and keep every focus cue visible.
5. Update `scripts/check_classroom_ui.mjs` and UI tests only where they pin
   removed slop; add checks that guard the new rules (no gradients, no
   `transition: all`, no looping decorative animation, no emoji icons).
6. Re-snapshot (at most three render rounds) into `work/p081/after/`; record
   before and after pairs in `08.1-01-SUMMARY.md` with the checklist result and
   the credit line "unslop by @heydamir (CC BY 4.0)".
