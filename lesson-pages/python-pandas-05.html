Learning objectives#

Build a unique compound index, preserve its levels during selection, and explain label alignment before calculating differences. Turn observed records into a matrix while preserving the distinction between an unknown observation and an unobserved coordinate. Restore exactly the original observed relation. Finally, recognize export-name collisions and expose missing-side membership in a table comparison. Verify identity, values, nullable dtype and order independently.

Vocabulary and concepts#

  • Compound key: A tuple of fields that identifies an observation together. Neither site nor metric must be unique alone; (site, metric) must be unique under this lesson's one-measurement-per-coordinate contract. If the instrument can produce repeated readings, add a genuine reading identity or a time/version coordinate instead of silently averaging duplicates.
  • MultiIndex: pandas' index representation for named coordinate levels. A Series remains one-dimensional, even when its labels contain two coordinates. The index associates each value with its site and metric; it is not a separate measurement matrix or a guarantee about how the physical data are partitioned.
  • Alignment: Matching values by labels before arithmetic or combination. Matching two rows because they currently occupy position zero is a different operation. Removing labels with to_numpy() can be appropriate for a numerical algorithm, but then the caller owns the correspondence between positions.
  • Presence: Whether a record exists at a coordinate. An existing measurement whose value is unknown differs from a coordinate with no record. pd.NA alone cannot represent both meanings without another field or a documented policy.
  • Reshape: Moving coordinate levels between rows and columns. unstack turns a named row-index level into columns; stack performs the corresponding direction change. Neither command can recover information already discarded by aggregation, filtering or an ambiguous column-name encoding.

If sites form a set SSS and metrics form a set MMM, the observed relation R\mathcal{R}R may contain only some coordinates in S×MS\times MS×M. A rectangular display includes combinations outside R\mathcal{R}R. Keep an independent Boolean presence grid to distinguish those manufactured display cells from actual observations whose measurements are unknown.

Syntax anatomy#

set_index(["site", "metric"], verify_integrity=True) moves the two key columns into named index levels and refuses duplicate compound labels. sort_index() establishes an explicit coordinate order for display and tests. It does not create missing observations or resolve duplicate identities.

xs(label, level="site", drop_level=False) selects a cross-section while retaining the selected level. Without drop_level=False, downstream code may receive a one-level index when it expected the original two-level schema. An absent site needs an explicit empty-result policy rather than an accidental exception or a fabricated measurement.

unstack("metric") creates columns from observed metric labels. New rectangular cells can be missing even when the original data had no unknown measurements. In pandas 2.3, stack(future_stack=True) selects the newer stacking behavior; do not also pass dropna or sort. Select observed coordinates with the independent presence mask, then establish the desired final order yourself.

Worked example / walkthrough#

Worked example 1: Reordered coordinates change positional subtraction#
import pandas as pd

keys = pd.MultiIndex.from_tuples(
    [("north", "flow"), ("south", "flow")], names=["site", "metric"]
)
left = pd.Series([10, 30], index=keys)
right = pd.Series([20, 5], index=keys[::-1])
by_label = left - right
by_position = left.to_numpy() - right.to_numpy()
assert by_label.tolist() == [5, 10]
assert by_position.tolist() == [-10, 25]
print("Label differences:", by_label.tolist())
print("Position differences:", by_position.tolist())

The north value ten is compared with north value five. South's thirty is compared with south's twenty. The right-hand labels are reversed, so their physical positions do not describe the same pairing. Both answers are valid computations under different contracts; only the first answers this labelled measurement question. A result with the right length and plausible magnitudes does not prove the pairing was correct. Inspect at least one coordinate by hand.

Worked example 2: Unknown values and absent coordinates look alike#
raw = pd.DataFrame(
    {"site": ["north", "north", "south"], "metric": ["flow", "temp", "flow"]}
)
raw["value"] = pd.array([0, pd.NA, 7], dtype="Float64")
observed = raw.set_index(["site", "metric"], verify_integrity=True)["value"]
wide = observed.unstack("metric")
presence = pd.Series(True, index=observed.index).unstack("metric", fill_value=False)
assert pd.isna(wide.loc["north", "temp"])
assert pd.isna(wide.loc["south", "temp"])
assert bool(presence.loc["north", "temp"])
assert not bool(presence.loc["south", "temp"])
print("Observed coordinates:", int(presence.to_numpy().sum()))

The display has four cells but only three observed coordinates. North's temperature record exists and has an unknown value. South has no temperature record. Dropping every missing value while stacking would erase the north observation as well. Filling every missing cell with zero would invent a known temperature for both sites. Preserve the pair of value and presence grids.

Now append another north/flow record. A pivot without an aggregation rule must reject the duplicate coordinate. pivot_table can aggregate it, but choosing an aggregation changes the question and can destroy the original observations. Inspect the repeated keys and their provenance before deciding whether to add another identity level, reject the feed, or deliberately summarize it.

Common pitfalls#

If subtraction changes after sorting one input, inspect whether labels were discarded before the operation. If a selected site's index loses its name or number of levels, inspect drop_level and compare the complete index schema. If a reshaped result has too few records, compare observed-key membership before and after stacking, including records whose values are unknown. Do not only compare sums: dropping an unknown observation can leave every numeric total unchanged.

If an export has duplicate column names, inspect the original tuple labels. Joining their parts with a separator is ambiguous when a part contains that separator. For example, (a__b, c) and (a, b__c) both become a__b__c under that encoding. JSON array encoding preserves the two strings, including Unicode and quote characters; preserving complete pandas metadata is a separate task.

The functions here return new objects. Do not repair a caller's original index or fill its missing values as a side effect. Keep a deep input copy during testing and compare it after execution. Avoid relying on a warning disappearing as proof of correctness: inspect the output relation and the stated contract.

Exercise 1: Establish compound observation identity#

Inputs: A DataFrame with exactly site, metric, value columns. Keys are nonempty strings; value has nullable Float64 dtype, finite known measurements and optional pd.NA. Repeated compound keys are invalid.

Expected: Return a new Series named value, indexed by unique (site,metric) levels with those names, sorted by site then metric. Preserve every actual coordinate, zero and unknown value. Reject malformed keys, duplicate coordinates, wrong dtype or infinity with ValueError.

Verify: Compare the ordered tuple keys and nullable values with a manually constructed relation. Assert duplicate-key rejection and exact equality of a deep input copy afterward.

The reference first checks that the incoming table has exactly site, metric and value columns in that order. It requires nullable Float64 measurements instead of trying to infer whether strings or arbitrary objects are numerical. This is a deliberately narrow boundary for the exercise. A broader application can have a separate parsing function, but parsing and identity checks should not happen accidentally as a side effect of reshaping.

result = frame.set_index(["site", "metric"], verify_integrity=True)["value"].copy()

verify_integrity refuses repeated coordinate pairs. A second identical row is still a second observation under the input relation, so the implementation does not silently deduplicate it. The validator also rejects missing/empty key parts and infinite known measurements. Unknown pd.NA measurements remain allowed. Sorting the resulting index makes the final presentation explicit; it does not choose which duplicate should win.

The independent fixture starts in south/north/north order but ends at (north,flow), (north,temp), (south,flow). Zero is preserved as a known flow, and north temperature remains unknown. The test compares the original DataFrame with a deep copy, proving that the function did not mutate its caller.

Exercise 2: Retain the schema during a cross-section#

Inputs: A valid compound-key Float64 Series as above and one nonempty string site label. Input coordinate order may vary.

Expected: Return a new sorted Series for the chosen site while retaining both index levels and the value name/dtype. An absent site returns an empty Series with the same two-level schema.

Verify: Inspect both index names and all selected keys, including an observed unknown measurement. Assert an absent selection has zero rows and does not manufacture a zero value.

selected = values.xs(site, level="site", drop_level=False).copy().sort_index()

A cross-section chooses one value of a named coordinate level. The selection retains both level names, so another function expecting (site,metric) can consume it. The explicit drop_level=False is part of the output schema, not a cosmetic choice. Looking up north must retain its two observed measurements, including the unknown temperature, without inventing a south temperature.

An absent site returns a zero-length copy with the original two-level schema. This policy is chosen in the contract. Returning a fabricated zero reading would mean something different; letting an unhandled key error decide the policy would make absence difficult to distinguish from a malformed call. The output is sorted even if the supplied valid Series was not sorted originally.

Exercise 3: Preserve presence separately from value#

Inputs: A valid unique compound-key Series whose actual records can include an unknown measurement. Only the observed labels define grid axes.

Expected: Return matching (value_grid,presence_grid) DataFrames with site rows and metric columns in sorted order. Values use Float64; presence uses bool. An observed unknown is missing/True; an unobserved combination is missing/False.

Verify: Assert the number of True cells equals the original record count. Check north/temp unknown/True and south/temp unknown/False separately, rather than comparing only numeric totals.

grid = ordered.unstack("metric")
present = pd.Series(True, index=ordered.index, dtype=bool).unstack(
    "metric", fill_value=False
)

The reference begins with a validated unique coordinate relation. Unstacking measurement values makes a rectangle; unstacking a True value for every actual coordinate records which cells came from observations. Only manufactured cells receive False. Both grids have matching named axes, and measurement columns retain nullable Float64 dtype.

For north temperature, value is missing and presence is True. For south temperature, value is missing and presence is False. The number of True cells is therefore three, matching the original three records, while the matrix has four cells. Counting only nonmissing measurements would report two and erase the unknown observation. Filling the value grid with zeros would invent data.

Exercise 4: Restore the observed relation without dropping unknowns#

Inputs: Matching value and presence grids with unique named site/metric axes, Float64 measurement columns and bool membership columns. A False membership cell cannot contain a known value.

Expected: Return exactly the observed relation as a sorted Float64 Series named value, retaining unknown observations. Reject mismatched axes, invalid labels/dtypes, infinite observations and known values at absent coordinates with ValueError.

Verify: Use assert_series_equal against the independent original relation, including names, dtype and unknown positions. Change an absent cell to eight and require rejection before any value can be silently discarded.

stacked = grid.stack(future_stack=True)
observed = present.stack(future_stack=True)
result = stacked.loc[observed].astype("Float64").rename("value").sort_index()

The two stacked objects share coordinate labels. The Boolean presence Series selects actual observations, while the stacked values keep unknown measurements. The result is named value and sorted by both levels, matching the original canonical relation. dropna() would select known measurements instead, which is the wrong membership rule. Under this selected pandas stack implementation, do not additionally pass dropna or sort parameters.

Validation occurs before selection. Axes must match exactly, be uniquely named, and have valid string labels. Presence must contain ordinary Boolean columns, with no unknown membership values. Value columns must use the declared nullable numeric dtype. An absent coordinate containing a known value is contradictory; the reference rejects it instead of silently throwing the value away. The final Series validator also rejects infinite observed measurements. Compare complete Series identity, dtype, name, unknown positions and values in the roundtrip.

Exercise 5: Encode column coordinates without collisions#

Inputs: A unique two-level MultiIndex of string coordinate pairs. Components may contain separators, quotes, empty strings or Unicode; complete index metadata is outside this encoding contract.

Expected: Return a pandas Index named encoded_coordinate containing compact JSON array encodings in the original pair order. Preserve both component strings exactly and reject malformed/duplicate coordinate indices with ValueError.

Verify: Decode every label with json.loads and compare the resulting tuple sequence with the original pairs. Assert (ab,c) and (a,bc) remain distinct and Unicode/quote characters survive.

label = json.dumps(list(key), ensure_ascii=False, separators=(",", ":"))

The input is a unique two-level column index whose coordinate parts are strings. JSON array encoding preserves component boundaries and escapes quote characters without depending on a separator absent from every possible input. The pairs (a__b,c) and (a,b__c) therefore yield different labels. A Unicode component also survives decoding unchanged.

The inverse check uses the independent JSON parser and compares the decoded tuples with the original tuple sequence. Uniqueness alone would not prove the values were preserved: replacing every pair with a new numeric label would also be unique. The contract deliberately covers coordinate pairs, not every MultiIndex property. Store names, category domains and unused levels separately if an export requires those properties to survive too. Keep the multi-level representation whenever the consumer supports it and a flat encoding is unnecessary.

Exercise 6: Align comparisons and expose missing sides#

Inputs: Two valid unique compound-key Float64 Series. Their order and key sets may differ and either side may contain unknown measurements.

Expected: Return the sorted outer key union with columns left_present,right_present,left_value,right_value,difference. Membership is bool; numerical columns retain nullable Float64. Difference is left minus right and remains unknown when a side/value is unavailable.

Verify: Compare each output row with a hand-built tuple-key dictionary. Shuffle both inputs and assert unchanged output, inspecting right-only east/flow separately from observed-unknown north/temp.

b = right.reindex(keys)

The union defines one output coordinate per key present on either side. Each input is reindexed to those coordinates before subtraction. Membership flags come from each original index, independently of whether its measurement is known. The final frame exposes left_present, right_present, left_value, right_value and difference, with the two-level compound index retained.

In the reference fixture, east/flow appears only on the right, so its difference is unknown and left presence is False. North/temp exists only on the left but has an unknown measurement; left presence is True even though the displayed value is missing. The shared north/flow difference is minus two, while shared south/flow is minus six. Compare these values with a hand-built dictionary keyed by tuples, then shuffle both input orders and require the same sorted output. Filling missing sides with zero would answer a different comparison and conceal the distinction between absence, zero and an existing unknown measurement.

All six implementations operate on copies or newly created objects. Keep counterexamples small enough to inspect every coordinate; a large aggregate agreement can conceal both an identity error and an erased unknown record.

"""python-pandas-05: complete MultiIndex and reshape references.

These small trusted fixtures teach explicit identity and missingness policies.
Run the learner examples before comparing the six implementations.
"""

from __future__ import annotations

import json
import math

import pandas as pd  # type: ignore[import-untyped]


def _checked_series(values: pd.Series) -> None:
    if (
        not isinstance(values, pd.Series)
        or not isinstance(values.index, pd.MultiIndex)
        or values.index.nlevels != 2
        or list(values.index.names) != ["site", "metric"]
        or not values.index.is_unique
        or str(values.dtype) != "Float64"
        or any(not isinstance(part, str) or not part for key in values.index for part in key)
        or not values.dropna().map(math.isfinite).all()
    ):
        raise ValueError("Expected unique (site, metric) keys and finite-or-missing Float64 values")


# Exercise 1: Establish unique compound identity.
def keyed_measurements(frame: pd.DataFrame) -> pd.Series:
    """Return a sorted, named compound-key Series without aggregating observations."""
    if (
        not isinstance(frame, pd.DataFrame)
        or list(frame.columns) != ["site", "metric", "value"]
        or str(frame["value"].dtype) != "Float64"
    ):
        raise ValueError("Expected site, metric, value columns with nullable Float64 value")
    result = frame.set_index(["site", "metric"], verify_integrity=True)["value"].copy()
    _checked_series(result)
    return result.sort_index()


# Exercise 2: Select without dropping a coordinate level.
def select_site(values: pd.Series, site: str) -> pd.Series:
    """Select a site while retaining both named index levels, including empty results."""
    _checked_series(values)
    if not isinstance(site, str) or not site:
        raise ValueError("Expected a nonempty site label")
    if site not in values.index.get_level_values("site"):
        return values.iloc[:0].copy()
    return values.xs(site, level="site", drop_level=False).copy().sort_index()


# Exercise 3: Preserve observed membership when reshaping.
def observation_grid(values: pd.Series) -> tuple[pd.DataFrame, pd.DataFrame]:
    """Preserve an independent presence grid so an unknown observation is not lost."""
    _checked_series(values)
    ordered = values.sort_index()
    grid = ordered.unstack("metric")
    present = pd.Series(True, index=ordered.index, dtype=bool).unstack("metric", fill_value=False)
    return grid.copy(), present.copy()


# Exercise 4: Reconstruct actual records, including unknown values.
def restore_observations(grid: pd.DataFrame, present: pd.DataFrame) -> pd.Series:
    """Restore observed coordinates, retaining actual unknown values under future_stack."""
    if (
        not isinstance(grid, pd.DataFrame)
        or not isinstance(present, pd.DataFrame)
        or not grid.index.equals(present.index)
        or not grid.columns.equals(present.columns)
        or not grid.index.is_unique
        or not grid.columns.is_unique
        or grid.index.name != "site"
        or grid.columns.name != "metric"
        or any(not isinstance(label, str) or not label for label in grid.index)
        or any(not isinstance(label, str) or not label for label in grid.columns)
        or any(str(dtype) != "bool" for dtype in present.dtypes)
        or any(str(dtype) != "Float64" for dtype in grid.dtypes)
    ):
        raise ValueError("Expected matching unique site/metric axes and Boolean presence")
    if grid.where(~present).notna().any().any():
        raise ValueError("An absent coordinate cannot contain a measured value")
    # future_stack retains unknown values. The independent mask selects actual
    # observations; dropping all NA values would also delete observed unknowns.
    stacked = grid.stack(future_stack=True)
    observed = present.stack(future_stack=True)
    result = stacked.loc[observed].astype("Float64").rename("value").sort_index()
    _checked_series(result)
    return result


# Exercise 5: Export coordinate labels without delimiter collisions.
def encode_column_labels(columns: pd.MultiIndex) -> pd.Index:
    """Encode unique two-string coordinates without delimiter collisions.

    The JSON arrays preserve each pair, not arbitrary MultiIndex metadata such
    as names or unused levels. Keep that metadata separately if it is required.
    """
    if (
        not isinstance(columns, pd.MultiIndex)
        or columns.nlevels != 2
        or not columns.is_unique
        or any(not isinstance(part, str) for key in columns for part in key)
    ):
        raise ValueError("Expected unique two-string column coordinates")
    return pd.Index(
        [json.dumps(list(key), ensure_ascii=False, separators=(",", ":")) for key in columns],
        name="encoded_coordinate",
    )


# Exercise 6: Compare by coordinate and expose side membership.
def aligned_difference(left: pd.Series, right: pd.Series) -> pd.DataFrame:
    """Compare by labels while exposing side presence independently of known values."""
    _checked_series(left)
    _checked_series(right)
    keys = left.index.union(right.index, sort=True)
    a = left.reindex(keys)
    b = right.reindex(keys)
    return pd.DataFrame(
        {
            "left_present": keys.isin(left.index),
            "right_present": keys.isin(right.index),
            "left_value": a,
            "right_value": b,
            "difference": a - b,
        },
        index=keys,
    )


def verify_examples() -> None:
    fixture = pd.DataFrame(
        {"site": ["south", "north", "north"], "metric": ["flow", "temp", "flow"]}
    )
    fixture["value"] = pd.array([4, pd.NA, 0], dtype="Float64")
    original = fixture.copy(deep=True)
    keyed = keyed_measurements(fixture)
    assert list(keyed.index) == [("north", "flow"), ("north", "temp"), ("south", "flow")]
    assert keyed.loc[("north", "flow")] == 0 and pd.isna(keyed.loc[("north", "temp")])
    pd.testing.assert_frame_equal(fixture, original)
    assert select_site(keyed, "north").index.nlevels == 2
    assert select_site(keyed, "absent").empty
    grid, present = observation_grid(keyed)
    assert bool(present.loc["north", "temp"]) and not bool(present.loc["south", "temp"])
    assert pd.isna(grid.loc["north", "temp"]) and pd.isna(grid.loc["south", "temp"])
    pd.testing.assert_series_equal(restore_observations(grid, present), keyed)
    pairs = pd.MultiIndex.from_tuples([("a__b", "c"), ("a", "b__c"), ('"', "λ")])
    encoded = encode_column_labels(pairs)
    assert encoded.is_unique
    assert [tuple(json.loads(label)) for label in encoded] == list(pairs)
    other = pd.Series(
        pd.array([10, 2, 9], dtype="Float64"),
        index=pd.MultiIndex.from_tuples(
            [("south", "flow"), ("north", "flow"), ("east", "flow")],
            names=["site", "metric"],
        ),
        name="value",
    )
    result = aligned_difference(keyed, other)
    assert list(result.index) == [
        ("east", "flow"),
        ("north", "flow"),
        ("north", "temp"),
        ("south", "flow"),
    ]
    assert result.loc[("north", "flow"), "difference"] == -2
    assert result.loc[("south", "flow"), "difference"] == -6
    assert not bool(result.loc[("east", "flow"), "left_present"])
    assert bool(result.loc[("north", "temp"), "left_present"])
    duplicate = pd.concat([fixture, fixture.iloc[[0]]], ignore_index=True)
    try:
        keyed_measurements(duplicate)
    except ValueError:
        pass
    else:
        raise AssertionError("Duplicate compound identity must be rejected")
    invalid = grid.copy()
    invalid.loc["south", "temp"] = 8
    try:
        restore_observations(invalid, present)
    except ValueError:
        pass
    else:
        raise AssertionError("An absent measured cell must not be silently discarded")
    print("python-pandas-05: all six reference contracts and boundary checks passed")


if __name__ == "__main__":
    verify_examples()
