# js-046: Scales: domains, ranges, inversion and honest baselines

## Level and prerequisites

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: `js-045`.

## Learning objectives

Choose and configure linear and band scales, invert positions and keep an honest zero baseline. The central exercise is: Build a scale-based bar chart.

## Purpose, vocabulary and mental model

A scale maps values from a data domain to a visual range. A linear scale preserves proportional differences: equal changes in input produce equal changes in output. The domain is expressed in data units, while the range can be pixels or SVG coordinates. Mixing those spaces is a common source of invisible or misleading marks.

A vertical quantitative scale often has range `[bottom, top]` because SVG y increases downward. This reversal makes larger values appear higher. A band scale maps categories to discrete bands and provides a bandwidth for bars. The category order is an explicit design decision.

Bars encode magnitude by length, so a zero baseline is usually essential. A line chart can sometimes use a narrower vertical domain if the axis clearly communicates it and the analytical purpose warrants it. Log scales require positive values in an ordinary positive domain; zero cannot be inserted casually. Explain the scale choice as part of the claim.

### Key terms

- **Domain:** The input extent of a scale in data units, such as `[0, 10]` counts.
- **Range:** The output extent of a scale in visual units, such as `[40, 600]` SVG coordinates. A vertical range is often written `[bottom, top]` because SVG y grows downward.
- **Linear scale:** A callable `d3.scaleLinear` mapping in which equal input differences produce equal output differences. Its `.invert` method maps a coordinate back to a data value.
- **Band scale:** A `d3.scaleBand` mapping from discrete categories to evenly spaced bands whose `bandwidth()` gives bar thickness. A category outside its domain returns undefined.
- **Zero baseline:** Starting a bar chart's quantitative domain at zero so each bar's length stays proportional to its value.

## Syntax anatomy and mechanism

A linear scale is callable: `x(5)` returns a coordinate. Its `.invert(pixel)` maps a coordinate back to data, useful for interactions. `.clamp(true)` bounds output to the range but can hide out-of-domain values if used without a clear policy. `.nice()` adjusts domain endpoints for readable ticks; it does not modify the raw data.

For the example, domain `[0, 10]` and range `[40, 600]` maps 0 to 40, 5 to 320 and 10 to 600. The zero-origin formula is simple enough to check by hand before relying on the library.

## Worked example / walkthrough

### Worked example 1: Calculate and invert

The midpoint maps to the visual midpoint.

```javascript
const x = d3.scaleLinear().domain([0, 10]).range([40, 600]);
console.log(x(5), x.invert(320));
```

**Expected observation:** 320 and 5.

### Worked example 2: Lay out categories

A band scale allocates positions and width together; a linear scale gives each bar its height from a zero baseline.

```javascript
// js-046 worked example 2: a complete program for the classroom preview.
const host = document.querySelector("#chart");
const output = document.querySelector("#output");
host.replaceChildren();
const check = (condition, message) => {
  if (!condition) throw new Error(message);
};
const svg = d3
  .select(host)
  .append("svg")
  .attr("viewBox", "0 0 640 360")
  .attr("role", "img")
  .attr("aria-label", "Scales: domains, ranges, inversion and honest baselines")
  .style("width", "100%")
  .style("max-width", "640px");
const x = d3.scaleBand().domain(["A", "B", "C"]).range([40, 600]).padding(0.2);
const values = new Map([
  ["A", 3],
  ["B", 7],
  ["C", 5],
]);
const y = d3.scaleLinear().domain([0, 8]).range([320, 40]);
svg
  .selectAll("rect")
  .data(x.domain())
  .join("rect")
  .attr("x", (d) => x(d))
  .attr("width", x.bandwidth())
  .attr("y", (d) => y(values.get(d)))
  .attr("height", (d) => y(0) - y(values.get(d)))
  .attr("fill", "#2563eb");
check(x("A") < x("B") && x.bandwidth() > 0, "Bands are ordered and have positive width");
check(x("D") === undefined, "An unknown category has no band");
output.textContent = "js-046 worked example 2 complete";
```

**Expected observation:** Three bars share one band width in domain order; x("D") is undefined, so an unknown category gets no position.

## Six progressive exercises

### Exercise 1: Predict midpoint and endpoint positions.

**Expected evidence:** 0 maps to 40, 5 to 320 and 10 to 600.

**Progressive hint:** The scale maps data space into visual space.

### Exercise 2: Reverse a vertical range.

**Expected evidence:** Higher values move upward in SVG coordinates.

**Progressive hint:** The data order stays the same while the coordinate direction reverses.

### Exercise 3: Build a scale-based bar chart.

**Expected evidence:** Bar geometry derives from a zero baseline and a named domain.

**Progressive hint:** Use y(0)-y(value) for positive bar height rather than treating a coordinate as a magnitude.

### Exercise 4: Diagnose using y(value) as bar height.

**Expected evidence:** Position and length were confused.

**Progressive hint:** A vertical coordinate measures from the SVG origin.

### Exercise 5: Handle an unknown band category.

**Expected evidence:** Reject or explicitly extend the domain rather than emit undefined geometry.

**Progressive hint:** An undefined mapping should not silently remove a category.

### Exercise 6: Defend a scale choice for signed residuals.

**Expected evidence:** A diverging domain with visible zero and explicit units.

**Progressive hint:** Scale design should expose the analytical reference point.

## Debugging and common mistakes

Print the scale's output at the domain ends and midpoint before drawing: with domain [0, 10] and range [40, 600], expect 40, 320 and 600. A bar drawn with `height = y(value)` confuses position with length. Linear scales extrapolate unless clamped, so 12 maps to 712, and a band scale returns `undefined` for an unknown category. ([checkpoints](../STUDY-GUIDE.md#d3-debugging-checkpoints))

Exercise 4 is the controlled failure: Diagnose using y(value) as bar height. Distinguishing evidence: Position and length were confused.

## Accessibility and interpretation

State the scale in words beside the chart, for example "bars start at zero; one unit is 56 SVG units". When categories differ only by band position, label each band directly so a reader using magnification or a screen reader is not left matching positions to a distant legend. ([accessibility review](../STUDY-GUIDE.md#d3-accessibility-review))

A bar's length claims a magnitude measured from zero, so a truncated linear domain exaggerates differences. Signed residuals need a diverging domain centered on zero with that zero line drawn. Name the unit of the domain and decide whether out-of-domain values are clamped, rejected or allowed to extend past the range. ([statistical meaning](../STUDY-GUIDE.md#d3-statistical-meaning))
