Vocabulary and mental model#

  • Chunk: A bounded batch of rows read or processed at one time; it is an implementation boundary rather than a statistical group.
  • Reduction state: The information retained from a batch that can be combined with other batches to compute a global result.
  • Sufficient aggregation state: A state such as sum and count that retains what a specified aggregate needs, without claiming statistical sufficiency for every model.
  • Carry state: Information preserved across chunk boundaries, such as the previous window values or identities already observed.

Reading in chunks reduces peak input memory only if the computation avoids collecting every chunk again. A result may still require state proportional to the number of groups, distinct identities or output rows. State the memory behavior honestly: bounded batch size does not automatically make the whole algorithm constant-memory.

A global mean requires the sum and count of known observations. Averaging chunk means gives equal weight to chunks, which is wrong when they have different lengths or different missing counts. For chunks[1,3] and [100], the chunk means are 2 and 100, whose average is 51. The correct global mean is 104/3. Chunk boundaries must not change the result.

Missing values affect the denominator. A chunk with three rows but one known amount contributes one to a known-value mean count, while its record count is three. Preserve both counts when reporting data quality. For integer-cent totals, use Python integer accumulation and explicitly enforce the output representation's range instead of permitting silent fixed-width overflow.

Deduplication is a global operation when an event can appear in different chunks. A set or dictionary of observed identities grows with the number of unique events. That may be acceptable for a small pipeline, but it is not bounded by chunk size. A repeated identical event can be ignored under a declared policy; a repeated ID with conflicting content should stop the calculation rather than choose whichever arrived first silently.

Temporal windows also cross boundaries. Resetting a rolling mean for each chunk discards the previous batch's last values and changes the feature at every read boundary. A deque of the last window-size observations preserves the necessary history. In production, separate deques may be needed for each entity and time-based eviction needs actual timestamps, not only row counts.

Typed CSV chunks provide a concrete input boundary. Parse IDs and integer amounts with nullable integer dtypes and customer labels as strings. Validate exact columns, key presence and parse failures per chunk. The examples use in-memory text, so no file or network download is needed. The same reduction principles apply to a prepared local file reader, provided its schema and error policy are preserved.

Worked examples and syntax anatomy#

Example 1#
chunks = [pd.Series([1.0, 3.0]), pd.Series([100.0])]
means = [chunk.mean() for chunk in chunks]
correct = sum(chunk.sum() for chunk in chunks) / sum(chunk.count() for chunk in chunks)
assert np.mean(means) == 51 and np.isclose(correct, 104 / 3)
print("Wrong mean of means:", np.mean(means), "global mean:", correct)

The second chunk contains only one observation, so giving it the same influence as the two-row chunk changes the population weighting. Sum/count states retain enough information for the global mean regardless of how the input is partitioned.

Example 2#
text = "event_id,customer_id,amount_cents\n1,a,10\n2,b,\n3,a,20\n"
chunks = list(
    pd.read_csv(
        StringIO(text),
        chunksize=2,
        dtype={"event_id": "Int64", "customer_id": "string", "amount_cents": "Int64"},
    )
)
assert [len(chunk) for chunk in chunks] == [2, 1]
assert chunks[0].amount_cents.isna().sum() == 1
print("Typed chunk lengths:", [len(chunk) for chunk in chunks])

The empty amount is preserved as a missing nullable integer rather than coerced to zero. The final chunk is shorter, which is normal and is exactly why averaging per-chunk means is unsafe. Materializing chunks here is only for inspecting the tiny demonstration, not a scalable reading pattern.

Common mistakes and diagnosis#

If changing chunksize changes a mean, inspect whether chunk means were averaged instead of sum/count states. If duplicates survive only across batches, move identity state outside the per-chunk loop. If rolling results restart at every boundary, preserve the final window context. If memory still grows, count distinct groups, identity keys and collected output rows; bounded input batches do not bound those structures. If a later CSV chunk fails parsing, do not label previously emitted partial aggregates complete. Stage or checkpoint results with an explicit completion boundary in a real pipeline.

Exercise 1: Retain the correct mean denominator#

For a numeric Series containing finite values or missing entries, return accurate known-value sum and known-value count. Reject nonnumeric dtype or infinity with ValueError. An empty or all-missing numeric Series returns (0.0,0).

Expected: [1, NA,3] returns (4.0,2), not count 3. Empty Float64 and [NA] Float64 return (0.0,0); infinity fails.

def mean_state(values: pd.Series) -> tuple[float, int]:
    if not pd.api.types.is_numeric_dtype(values.dtype):
        raise ValueError("Expected numeric measurements")
    known = values.dropna().to_numpy(dtype=float)
    if not np.isfinite(known).all():
        raise ValueError("Known measurements must be finite")
    return math.fsum(float(value) for value in known), len(known)

The state records the number of observed values, not the number of rows in the batch. That distinction survives aggregation and prevents missing records from diluting a mean. math.fsum reduces avoidable cancellation error in the known-value sum. An empty state is an identity for later combination; it does not assert that the population mean is zero.

assert mean_state(pd.Series([1, pd.NA, 3], dtype="Float64")) == (4.0, 2)
assert mean_state(pd.Series([], dtype="Float64")) == (0.0, 0)
assert mean_state(pd.Series([pd.NA], dtype="Float64")) == (0.0, 0)
expect_value_error(lambda: mean_state(pd.Series([np.inf])))
Exercise 2: Combine uneven chunks correctly#

Combine sum/count states into one mean, returning None if total count is zero. Require finite sums and nonnegative integer counts; a zero-count state must have zero sum. Reject invalid states with ValueError.

Expected: States(4,2),(100,1) yield 104/3. Adding(0,0) has no effect. Empty states return None; (5,0), negative count or Boolean count is rejected.

def merge_means(states: list[tuple[float, int]]) -> float | None:
    for total, count in states:
        if (
            not math.isfinite(total)
            or isinstance(count, bool)
            or not isinstance(count, (int, np.integer))
            or count < 0
            or (count == 0 and total != 0)
        ):
            raise ValueError("Expected valid sum/count states")
    count = sum(count for _, count in states)
    return math.fsum(total for total, _ in states) / count if count else None

Summing numerators and denominators respects observation weighting across arbitrary partitions. A mean-of-means would require extra weights and is equivalent only when known counts match or are explicitly used. Returning None for no observed values preserves the distinction between an undefined mean and a measured zero. Invalid state checks catch upstream bookkeeping errors before they become plausible aggregate numbers.

mean = merge_means([(4.0, 2), (100.0, 1)])
assert mean is not None and math.isclose(mean, 104 / 3)
with_empty = merge_means([(0.0, 0), (4.0, 2), (100.0, 1)])
assert with_empty is not None and math.isclose(with_empty, 104 / 3)
assert merge_means([]) is None
expect_value_error(lambda: merge_means([(5.0, 0)]))
expect_value_error(lambda: merge_means([(1.0, True)]))
Exercise 3: Reduce typed amounts across batches#

Consume an iterable of chunks with nonmissing string customer_id and nullable/integer amount_cents. Reject missing or nonstring customers, noninteger amount dtype or totals outside signed int64 range. Return customer_id, row_count, known_count, total_cents sorted by customer, preserving missing totals when a customer has no known amounts.

Expected: Across chunks a:10, b:NA then a:20, b:NA, return a counts 2,2, total 30 and b counts 2,0, totalNA. Input chunk boundaries do not change the result.

def customer_totals(chunks: Iterable[pd.DataFrame]) -> pd.DataFrame:
    state: dict[str, tuple[int, int, int]] = {}
    for chunk in chunks:
        if (
            not {"customer_id", "amount_cents"}.issubset(chunk.columns)
            or chunk["customer_id"].isna().any()
            or not chunk["customer_id"].map(lambda value: isinstance(value, str)).all()
            or not pd.api.types.is_integer_dtype(chunk["amount_cents"].dtype)
        ):
            raise ValueError("Expected known string customer IDs and integer-cent measurements")
        for customer, amount in chunk[["customer_id", "amount_cents"]].itertuples(
            index=False, name=None
        ):
            rows, known, total = state.get(customer, (0, 0, 0))
            if not pd.isna(amount):
                known += 1
                total += int(amount)
            state[customer] = (rows + 1, known, total)
    output_rows = []
    for customer, (count, known, total) in sorted(state.items()):
        if not -(2**63) <= total < 2**63:
            raise ValueError("Customer total exceeds the declared Int64 representation")
        output_rows.append((customer, count, known, total if known else pd.NA))
    result = pd.DataFrame(
        output_rows, columns=["customer_id", "row_count", "known_count", "total_cents"]
    )
    result["total_cents"] = pd.array(result["total_cents"], dtype="Int64")
    return result

The dictionary retains one small state per customer, so memory scales with distinct customers rather than all event rows. Python integer totals avoid intermediate fixed-width wraparound, and the final range check makes the output Int64 boundary explicit. Row count and known count preserve missingness evidence. Repartitioning the same records into one chunk must yield the identical typed result, directly testing that a storage boundary did not change the metric.

a = pd.DataFrame({"customer_id": ["a", "b"], "amount_cents": pd.Series([10, pd.NA], dtype="Int64")})
b = pd.DataFrame({"customer_id": ["a", "b"], "amount_cents": pd.Series([20, pd.NA], dtype="Int64")})
r = customer_totals(iter([a, b]))
assert (
    r.customer_id.tolist() == ["a", "b"]
    and r.row_count.tolist() == [2, 2]
    and r.known_count.tolist() == [2, 0]
)
assert r.loc[0, "total_cents"] == 30 and pd.isna(r.loc[1, "total_cents"])
pd.testing.assert_frame_equal(r, customer_totals([pd.concat([a, b])]))
mixed_ids = pd.DataFrame(
    {"customer_id": ["a", 1], "amount_cents": pd.Series([1, 2], dtype="Int64")}
)
expect_value_error(lambda: customer_totals([mixed_ids]))
Exercise 4: Detect conflicts across chunk boundaries#

Consume chunks with nonmissing integer event_id and amount_cents that is integer or missing. Keep the first occurrence of identical event records in encounter order. Reject any repeated ID with a different amount, including missing versus zero, with ValueError.

Expected: Chunks[(1,10),(2, NA)] then[(1,10),(3,20)] return IDs 1,2,3. Repeating ID 2 with amount 0 raises ValueError; missing is not normalized to zero.

def unique_records(chunks: Iterable[pd.DataFrame]) -> pd.DataFrame:
    seen: dict[int, int | None] = {}
    rows = []
    for chunk in chunks:
        if (
            not {"event_id", "amount_cents"}.issubset(chunk.columns)
            or chunk["event_id"].isna().any()
            or not pd.api.types.is_integer_dtype(chunk["event_id"].dtype)
            or not pd.api.types.is_integer_dtype(chunk["amount_cents"].dtype)
        ):
            raise ValueError("Expected integer event IDs and integer-cent amounts")
        for event, amount in chunk[["event_id", "amount_cents"]].itertuples(index=False, name=None):
            event = int(event)
            value = None if pd.isna(amount) else int(amount)
            if event in seen:
                if seen[event] != value:
                    raise ValueError("One event identity has conflicting amounts")
            else:
                seen[event] = value
                rows.append((event, value))
    result = pd.DataFrame(rows, columns=["event_id", "amount_cents"])
    result["amount_cents"] = pd.array(result["amount_cents"], dtype="Int64")
    return result

Identity state persists across batches, so a duplicate arriving later is still recognized. None is an internal sentinel for missing amount, distinct from the integer zero. Conflicting payloads fail rather than letting encounter order decide truth. This implementation retains all unique identities and result rows, so it is not constant-memory; a larger pipeline may need an external key store or partitioning while preserving the same conflict policy.

a = pd.DataFrame(
    {
        "event_id": pd.Series([1, 2], dtype="Int64"),
        "amount_cents": pd.Series([10, pd.NA], dtype="Int64"),
    }
)
b = pd.DataFrame(
    {
        "event_id": pd.Series([1, 3], dtype="Int64"),
        "amount_cents": pd.Series([10, 20], dtype="Int64"),
    }
)
r = unique_records([a, b])
assert r.event_id.tolist() == [1, 2, 3] and pd.isna(r.loc[1, "amount_cents"])
conflict = pd.DataFrame(
    {"event_id": pd.Series([2], dtype="Int64"), "amount_cents": pd.Series([0], dtype="Int64")}
)
expect_value_error(lambda: unique_records([a, conflict]))
Exercise 5: Carry rolling history across batches#

Yield full-window row-count rolling means across an iterable of finite numeric one-dimensional chunks. Require a positive non-Boolean integer window. Do not reset history at a chunk boundary, and yield nothing before a full window exists.

Expected: Chunks[1,2] then[3,4] with window 3 yield [2,3], the same as one chunk[1,2,3,4]. Empty input yields no values; window 0 and NaN input fail on iteration.

def rolling_means(chunks: Iterable[Iterable[float]], window: int) -> Iterator[float]:
    if isinstance(window, bool) or not isinstance(window, (int, np.integer)) or window <= 0:
        raise ValueError("Expected a positive integer window")
    history: deque[float] = deque(maxlen=window)
    for chunk in chunks:
        values = np.asarray(chunk, dtype=float)
        if values.ndim != 1 or not np.isfinite(values).all():
            raise ValueError("Expected finite one-dimensional chunks")
        for value in values:
            history.append(float(value))
            if len(history) == window:
                yield math.fsum(history) / window

A deque with maxlen retains only the most recent window observations and evicts older ones as new values arrive. The generator yields outputs incrementally, so a consumer need not collect every result. Validation occurs when the generator is iterated, which is why error tests call list. This is a row-count window over one sequence; entity-specific or elapsed-time windows require additional keys and timestamp-aware state.

assert list(rolling_means([[1, 2], [3, 4]], 3)) == [2.0, 3.0]
assert list(rolling_means([[1, 2, 3, 4]], 3)) == [2.0, 3.0]
assert list(rolling_means([], 3)) == []

"""Reference implementation and exact boundary checks for python-pandas-04."""

import math
from collections import deque
from collections.abc import Callable, Iterable, Iterator
from io import StringIO

import numpy as np
import pandas as pd  # type: ignore[import-untyped]


def mean_state(values: pd.Series) -> tuple[float, int]:
    if not pd.api.types.is_numeric_dtype(values.dtype):
        raise ValueError("Expected numeric measurements")
    known = values.dropna().to_numpy(dtype=float)
    if not np.isfinite(known).all():
        raise ValueError("Known measurements must be finite")
    return math.fsum(float(value) for value in known), len(known)


def merge_means(states: list[tuple[float, int]]) -> float | None:
    for total, count in states:
        if (
            not math.isfinite(total)
            or isinstance(count, bool)
            or not isinstance(count, (int, np.integer))
            or count < 0
            or (count == 0 and total != 0)
        ):
            raise ValueError("Expected valid sum/count states")
    count = sum(count for _, count in states)
    return math.fsum(total for total, _ in states) / count if count else None


def customer_totals(chunks: Iterable[pd.DataFrame]) -> pd.DataFrame:
    state: dict[str, tuple[int, int, int]] = {}
    for chunk in chunks:
        if (
            not {"customer_id", "amount_cents"}.issubset(chunk.columns)
            or chunk["customer_id"].isna().any()
            or not chunk["customer_id"].map(lambda value: isinstance(value, str)).all()
            or not pd.api.types.is_integer_dtype(chunk["amount_cents"].dtype)
        ):
            raise ValueError("Expected known string customer IDs and integer-cent measurements")
        for customer, amount in chunk[["customer_id", "amount_cents"]].itertuples(
            index=False, name=None
        ):
            rows, known, total = state.get(customer, (0, 0, 0))
            if not pd.isna(amount):
                known += 1
                total += int(amount)
            state[customer] = (rows + 1, known, total)
    output_rows = []
    for customer, (count, known, total) in sorted(state.items()):
        if not -(2**63) <= total < 2**63:
            raise ValueError("Customer total exceeds the declared Int64 representation")
        output_rows.append((customer, count, known, total if known else pd.NA))
    result = pd.DataFrame(
        output_rows, columns=["customer_id", "row_count", "known_count", "total_cents"]
    )
    result["total_cents"] = pd.array(result["total_cents"], dtype="Int64")
    return result


def unique_records(chunks: Iterable[pd.DataFrame]) -> pd.DataFrame:
    seen: dict[int, int | None] = {}
    rows = []
    for chunk in chunks:
        if (
            not {"event_id", "amount_cents"}.issubset(chunk.columns)
            or chunk["event_id"].isna().any()
            or not pd.api.types.is_integer_dtype(chunk["event_id"].dtype)
            or not pd.api.types.is_integer_dtype(chunk["amount_cents"].dtype)
        ):
            raise ValueError("Expected integer event IDs and integer-cent amounts")
        for event, amount in chunk[["event_id", "amount_cents"]].itertuples(index=False, name=None):
            event = int(event)
            value = None if pd.isna(amount) else int(amount)
            if event in seen:
                if seen[event] != value:
                    raise ValueError("One event identity has conflicting amounts")
            else:
                seen[event] = value
                rows.append((event, value))
    result = pd.DataFrame(rows, columns=["event_id", "amount_cents"])
    result["amount_cents"] = pd.array(result["amount_cents"], dtype="Int64")
    return result


def rolling_means(chunks: Iterable[Iterable[float]], window: int) -> Iterator[float]:
    if isinstance(window, bool) or not isinstance(window, (int, np.integer)) or window <= 0:
        raise ValueError("Expected a positive integer window")
    history: deque[float] = deque(maxlen=window)
    for chunk in chunks:
        values = np.asarray(chunk, dtype=float)
        if values.ndim != 1 or not np.isfinite(values).all():
            raise ValueError("Expected finite one-dimensional chunks")
        for value in values:
            history.append(float(value))
            if len(history) == window:
                yield math.fsum(history) / window


def csv_chunks(text: str, chunksize: int) -> Iterator[pd.DataFrame]:
    if isinstance(chunksize, bool) or not isinstance(chunksize, int) or chunksize <= 0:
        raise ValueError("Expected a positive integer chunk size")
    for chunk in pd.read_csv(
        StringIO(text),
        chunksize=chunksize,
        dtype={"event_id": "Int64", "customer_id": "string", "amount_cents": "Int64"},
    ):
        if (
            chunk.columns.tolist() != ["event_id", "customer_id", "amount_cents"]
            or chunk["event_id"].isna().any()
            or chunk["customer_id"].isna().any()
        ):
            raise ValueError("CSV schema and record identities must be valid")
        yield chunk


def expect_value_error(call: Callable[[], object]) -> None:
    try:
        call()
    except ValueError:
        return
    raise AssertionError("Expected ValueError")


def main() -> None:
    # Exercise 1: Retain the correct mean denominator
    assert mean_state(pd.Series([1, pd.NA, 3], dtype="Float64")) == (4.0, 2)
    assert mean_state(pd.Series([], dtype="Float64")) == (0.0, 0)
    assert mean_state(pd.Series([pd.NA], dtype="Float64")) == (0.0, 0)
    expect_value_error(lambda: mean_state(pd.Series([np.inf])))
    # Exercise 2: Combine uneven chunks correctly
    mean = merge_means([(4.0, 2), (100.0, 1)])
    assert mean is not None and math.isclose(mean, 104 / 3)
    with_empty = merge_means([(0.0, 0), (4.0, 2), (100.0, 1)])
    assert with_empty is not None and math.isclose(with_empty, 104 / 3)
    assert merge_means([]) is None
    expect_value_error(lambda: merge_means([(5.0, 0)]))
    expect_value_error(lambda: merge_means([(1.0, True)]))
    # Exercise 3: Reduce typed amounts across batches
    a = pd.DataFrame(
        {"customer_id": ["a", "b"], "amount_cents": pd.Series([10, pd.NA], dtype="Int64")}
    )
    b = pd.DataFrame(
        {"customer_id": ["a", "b"], "amount_cents": pd.Series([20, pd.NA], dtype="Int64")}
    )
    r = customer_totals(iter([a, b]))
    assert (
        r.customer_id.tolist() == ["a", "b"]
        and r.row_count.tolist() == [2, 2]
        and r.known_count.tolist() == [2, 0]
    )
    assert r.loc[0, "total_cents"] == 30 and pd.isna(r.loc[1, "total_cents"])
    pd.testing.assert_frame_equal(r, customer_totals([pd.concat([a, b])]))
    mixed_ids = pd.DataFrame(
        {"customer_id": ["a", 1], "amount_cents": pd.Series([1, 2], dtype="Int64")}
    )
    expect_value_error(lambda: customer_totals([mixed_ids]))
    # Exercise 4: Detect conflicts across chunk boundaries
    a = pd.DataFrame(
        {
            "event_id": pd.Series([1, 2], dtype="Int64"),
            "amount_cents": pd.Series([10, pd.NA], dtype="Int64"),

    conflict = pd.DataFrame(

    expect_value_error(lambda: unique_records([a, conflict]))
    # Exercise 5: Carry rolling history across batches
    assert list(rolling_means([[1, 2], [3, 4]], 3)) == [2.0, 3.0]
    assert list(rolling_means([[1, 2, 3, 4]], 3)) == [2.0, 3.0]
    assert list(rolling_means([], 3)) == []
    expect_value_error(lambda: list(rolling_means([[1]], 0)))
    expect_value_error(lambda: list(rolling_means([[np.nan]], 1)))
    # Exercise 6: Make parsing a typed batch boundary
    text = "event_id,customer_id,amount_cents\n1,a,10\n2,b,\n3,a,20\n"

        and str(chunks[0].amount_cents.dtype) == "Int64"
        and pd.isna(chunks[0].loc[1, "amount_cents"])
    )
    expect_value_error(lambda: list(csv_chunks("event_id,customer_id,amount_cents\n1,a,bad\n", 2)))
    expect_value_error(lambda: list(csv_chunks("event_id,customer_id,amount_cents\n,a,10\n", 2)))
