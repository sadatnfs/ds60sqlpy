Purpose and mental model#

A network is a composition of small operations. The chain rule connects their local derivatives: a change in a weight changes an intermediate value, which changes an activation, which changes the loss. Multiplying the local sensitivities gives the derivative along that path. Missing one factor can leave every forward value correct while producing the wrong update.

Trace z=2·wz=2\cdot w, a=z·za=z\cdot z and L=(a−1)2L={\left(a-1\right)}^{2} at w=1w=1. The intermediate values are z=2z=2, a=4a=4 and L=9L=9. Their local sensitivities are ∂z∂w=2\frac{\partial z}{\partial w}=2, ∂a∂z=2·z=4\frac{\partial a}{\partial z}=2\cdot z=4 and ∂L∂a=2·(a−1)=6\frac{\partial L}{\partial a}=2\cdot (a-1)=6. The product is 48. Writing these values separately makes a factor-of-two mistake diagnosable before using a tape.

A path can also become constant. If the activation a=4a=4 is computed once and then held fixed while w varies, the displayed loss at w=1w=1 is still 9, but the new computation no longer depends on w. Its derivative is zero. The next lesson turns that distinction into recording-scope behavior; here you can see it directly with functions and finite probes.

Vocabulary and concepts#

Composition: a computation that feeds the output of one operation into another.

Local derivative: the sensitivity of one operation output to its immediate input at the current value.

Chain rule: multiplication of local sensitivities along a connected dependency path.

ReLU: the rectified linear function max(0,z), whose negative-side slope is zero and positive-side slope is one.

Convention at zero: an explicitly chosen derivative-like value at a kink; it is not a unique ordinary derivative.

Syntax or reasoning anatomy#

Use separate names for the forward values and derivative factors. In dL_da da_dz dz_dw, each adjacent intermediate symbol cancels conceptually, leaving loss change per weight change. Evaluate all factors at the same original state before multiplying. A direct expansion of the complete scalar polynomial provides another check, but the local trace generalizes to larger computations.

A finite central probe must recompute the whole path for each perturbed weight. Reusing a previously computed activation probes a different constant function. ReLU also requires a piecewise explanation: negative inputs give zero, positive inputs pass through, and zero is a kink. Record the framework's chosen convention later instead of treating a symmetric probe as a differentiability proof.

A graph can add sensitivities as well as multiply them#

The worked chain has one route from w to loss, so multiplying its local factors gives the complete derivative. If an input feeds two branches that later add, the derivative adds their contributions. For q(w) = w squared + 3w, the derivative is 2w + 3. At w = 1 the two branches contribute 2 and 3, for a total of 5. Forgetting the second route can produce a plausible number while omitting part of the computation.

This addition of paths explains a residual connection later in the course. For an output x + f(x), the input sensitivity includes an identity contribution as well as the derivative through f. It does not make every gradient nonzero: branch contributions can cancel. Inspect the actual derivatives at the current state instead of assuming a named architecture guarantees a particular value.

At a ReLU kink, the left slope is zero and the right slope is one. A symmetric probe at zero returns one-half, but an automatic-differentiation implementation uses its declared convention for that nonsmooth point. Agreement away from the kink and a separately understood convention at the kink are more useful than demanding that every numerical probe match every framework value.

Worked example / walkthrough#

Run Examples A and B in order in one scratch file, then run that complete file in a fresh process. Example B may reuse the imports, helpers and fixture state established in Example A. Do not treat an isolated later block as a standalone program.

Example A: Recover every chain factor#

Do the forward pass and then calculate each local derivative.

w = 1.0
z = 2 * w
a = z * z
loss = (a - 1) ** 2
gradient = (2 * (a - 1)) * (2 * z) * 2
assert (z, a, loss, gradient) == (2.0, 4.0, 9.0, 48.0)
print(z, a, loss, gradient)

Expected: The three factors are 6, 4 and 2. A correct loss of 9 does not guarantee all factors were retained.

Example B: Freeze one intermediate value#

Compare functions with the same value at the original point but different dependencies.

full = lambda value: ((2 * value) ** 2 - 1) ** 2
frozen_a = 4.0
frozen = lambda value: (frozen_a - 1) ** 2
h = 1e-5
full_slope = (full(1 + h) - full(1 - h)) / (2 * h)
frozen_slope = (frozen(1 + h) - frozen(1 - h)) / (2 * h)
assert abs(full_slope - 48) < 1e-7
assert frozen_slope == 0.0
print(full_slope, frozen_slope)

Expected: Both functions equal 9 at w=1w=1. Their slopes differ because only the first recomputes a from the changed weight.

Progressive hints#

  • Hint 1: Write each intermediate value before any derivative factor.
  • Hint 2: Multiply the immediate sensitivities in reverse dependency order, retaining the inner scale.
  • Hint 3: Ensure finite probes call the whole forward expression again rather than reuse a captured intermediate.

Common pitfalls#

If a backward answer is off by a small integer factor, inspect the local derivative table before changing a learning rate. A tuned rate can hide a wrong gradient for one fixture and fail on another. If a finite probe reports zero while a hand derivative is nonzero, check that the perturbed function recomputes every dependent value instead of closing over a frozen activation.

At ReLU zero, a symmetric slope of one half does not contradict a framework convention of zero. They describe different objects at a nondifferentiable point. Keep forward correctness, dependency connectivity and derivative policy as separate checks. A constant path and a connected path can also share the same value at one input, so a scalar loss comparison alone is insufficient.
