## Outcome and mechanism

Fit a small rpart classifier and distinguish its partition, probability output, complexity policy and generalization limits.

A decision tree partitions predictor space through a sequence of rules. A terminal leaf stores an outcome summary for the observations reaching that region. The resulting prediction is piecewise constant, which gives trees useful nonlinear behavior but also limits how they extrapolate beyond the observed range.

The rpart interface supports several response types, so specify the method rather than relying on a response's accidental storage type. A factor response with method="class" defines a classification problem. Splitting criteria, class priors, loss policies and complexity controls affect the fitted tree and should be retained with the result.

The authored fixture places four low-class observations before four high-class observations along one predictor. A depth-one tree can separate them with an exact threshold. This makes the split and class probabilities inspectable. Perfect training predictions on this constructed pattern are a software/mechanism check, not evidence of broad predictive quality.

Complexity controls change the model family. A larger depth or smaller penalty can fit more detailed training patterns. Pruning returns a simpler tree according to a defined complexity criterion. Selecting that criterion using held-out performance requires a development protocol; repeatedly choosing it on the final assessment set invalidates a clean final comparison.

Missing predictors have package-specific handling, including surrogate behavior. If an application instead requires complete predictors, enforce that policy in an explicit admission wrapper rather than attributing it to the package. New factor levels, unexpected types and observation ownership also need a declared prediction contract.

Finally, a leaf probability is a fitted frequency-like model output, not a calibrated guarantee. Evaluate probability quality, decisions and subgroup behavior independently on appropriate held-out units. A prediction at x=1000 can be confidently assigned to the same terminal region as x=8 without establishing that the real-world outcome rule remains valid there.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Leaf | A terminal region of the predictor partition with its fitted outcome summary. |
| Complexity parameter | A control used to restrict or prune splits under the tree-fitting criterion. |
| Surrogate split | An alternative predictor rule used by the tree implementation when the primary splitting value is unavailable. |
| Piecewise constant prediction | A prediction that stays fixed within a terminal region rather than extending a linear slope. |

## Read the syntax

Fit rpart::rpart with method="class" and explicit rpart.control settings. Inspect frame$var, predict(type="class") and predict(type="prob"). A pruned tree is another model object. ## Worked examples

### Example 1: An inspectable two-leaf classifier

```r
d <- data.frame(x = 1:8, label = factor(rep(c("low", "high"), each = 4), levels = c("low", "high")))
fit <- rpart::rpart(label ~ x, data = d, method = "class", control = rpart::rpart.control(minsplit = 2, minbucket = 1, maxdepth = 1, cp = 0, xval = 0))
classes <- predict(fit, data.frame(x = c(2, 7)), type = "class")
prob <- predict(fit, data.frame(x = c(2, 7)), type = "prob")
stopifnot(identical(as.character(classes), c("low", "high")))
stopifnot(sum(fit$frame$var == "<leaf>") == 2, max(abs(rowSums(prob) - 1)) < 1e-12)
print(prob)
```

**Expected observation:** Two leaves; classes low/high; probability rows sum to 1.

The one-dimensional fixture is deliberately separable. It validates class identity and normalized probability output without claiming calibrated performance on unseen populations.

### Example 2: Pruning changes the model

```r
d <- data.frame(x = 1:8, label = factor(rep(c("low", "high"), each = 4)))
fit <- rpart::rpart(label ~ x, data = d, method = "class", control = rpart::rpart.control(minsplit = 2, minbucket = 1, maxdepth = 1, cp = 0, xval = 0))
small <- rpart::prune(fit, cp = 1)
stopifnot(nrow(small$frame) == 1, sum(small$frame$var == "<leaf>") == 1)
print(small)
```

**Expected observation:** One terminal root after pruning.

The strong complexity threshold collapses this tree to one leaf. This demonstrates a model change, not a claim that the pruned or unpruned candidate is universally preferable.
