## Purpose and mental model

A defensible language-system decision compares candidate systems under one frozen task definition. The tiny transformer, count baseline and local retrieval variant have different capabilities, so use common questions and explicit correctness, support, abstention and resource criteria. Preserve tokenizer, data and model identities, verify causal and cache behavior, and report failure examples. A small local benchmark can justify a teaching conclusion or a no-go, but cannot establish broad deployment reliability. The capstone intentionally uses deterministic question records and a tiny decoder probe rather than pretending that fluent generated text is an automatic correctness test.

## Vocabulary and concepts

**Common evaluation contract:** The same questions,units and scoring rules used for every candidate.

**Go/no-go:** A decision applying declared acceptance gates to observed evidence.

**Unknown gate:** A required check lacking an execution or review receipt.

Keep result tables keyed by question ID and grouped by family. Compare paired errors, not unaligned averages. A release dictionary records each required gate asTrue,False orNone for unexecuted. ## Worked example / walkthrough

### Example A: Freeze common questions

The task contract is frozen before comparing systems. The unanswerable case tests abstention rather than rewarding a fabricated response.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
class TinyDecoder(nn.Module):
    def __init__(self,vocab=16,width=32,heads=2,context=32):
        super().__init__()
        self.vocab,self.width,self.heads,self.context=vocab,width,heads,context
        self.token=nn.Embedding(vocab,width); self.position=nn.Embedding(context,width)
        self.norm1=nn.LayerNorm(width); self.qkv=nn.Linear(width,3*width,bias=False)
        self.projection=nn.Linear(width,width,bias=False); self.norm2=nn.LayerNorm(width)
        self.feed=nn.Sequential(nn.Linear(width,2*width),nn.ReLU(),nn.Linear(2*width,width))
        self.output=nn.Linear(width,vocab,bias=False)
    def forward(self,ids,cache=None):
        if ids.ndim!=2 or ids.dtype!=torch.long or ids.shape[1]==0: raise ValueError('nonempty long batch,time IDs')
        offset=0 if cache is None else cache['k'].shape[2]
        batch,time=ids.shape
        if offset+time>self.context or torch.any(ids<0) or torch.any(ids>=self.vocab): raise ValueError('context or vocabulary limit')
        x=self.token(ids)+self.position(torch.arange(offset,offset+time))
        q,k,v=self.qkv(self.norm1(x)).chunk(3,dim=-1)
        def split(t): return t.reshape(batch,time,self.heads,self.width//self.heads).transpose(1,2)
        q,k,v=map(split,(q,k,v))
        if cache is not None:
            if cache['k'].shape[0]!=batch: raise ValueError('cache batch mismatch')
            k=torch.cat([cache['k'],k],dim=2); v=torch.cat([cache['v'],v],dim=2)
        allowed=torch.arange(k.shape[2])[None,:]<=torch.arange(offset,offset+time)[:,None]
        scores=q@k.transpose(-2,-1)/(self.width//self.heads)**.5
        weights=torch.softmax(scores.masked_fill(~allowed,float('-inf')),dim=-1)
        mixed=(weights@v).transpose(1,2).contiguous().reshape(batch,time,self.width)
        x=x+self.projection(mixed); x=x+self.feed(self.norm2(x))
        return self.output(x),{'k':k.detach(),'v':v.detach()}
import hashlib,json,time
questions=[{'id':'q1','family':'shape','answerable':True},{'id':'q2','family':'color','answerable':True},{'id':'q3','family':'astronomy','answerable':False}]
fixture_hash=hashlib.sha256(json.dumps(questions,sort_keys=True).encode()).hexdigest()
assert len({q['id'] for q in questions})==3 and questions[2]['answerable'] is False
```

**Expected:** 3 distinct questions and a missing-evidence case.
