## Outcome and mechanism

Convert S3, S4, R6 and S7 values through validated adapters and inspect ggplot2 through public build interfaces.

Interoperability begins with a data contract, not a choice of class system. A consumer needs to know the type and shape of its inputs, their units and missingness policy, and whether reading them can mutate shared state. This lesson defines one ordinary record with a finite numeric vector and a unit string. Every adapter returns that contract, so the numerical summary does not need to know which object system produced it.

An adapter is an explicit translation at a boundary. For an S3 value it reads the documented fields, for an S4 value the declared slots, for an R6 object public read methods, and for an S7 object declared properties. It validates the extracted values again. This is useful when a domain object is supplied by a different package or when an older representation remains in circulation. Silent unclass calls are insufficient because removing a label does not preserve or verify units, scale, missingness or reference ownership.

The common record uses ordinary numeric values and a character scalar. The adapter converts integer input to double deliberately but does not convert physical units. Empty vectors have a missing mean and count zero. Two records with the same mean but different units are not interchangeable measurements. A conversion between seconds and milliseconds must be an explicitly tested transformation outside this adapter.

R6 requires extra attention to ownership. The example exposes a numeric snapshot through a public method, then constructs a record from it. Mutating that returned numeric record does not change the source object's private vector. This narrow observation does not imply that every R6 getter returns a deep copy; a getter returning an environment could expose shared mutable state. The adapter contract must exclude or handle such references.

Package internals evolve. ggplot2 4.0.0 changed central objects to S7, and this environment prepares ggplot2 4.0.3. Existing examples that assume every plot is a simple S3 list, mutate internal attributes or apply S4 slot introspection can therefore be brittle. Build a plot with exported ggplot2 functions, then inspect documented ggplot_build or layer_data results. Do not make an internal class spelling the core assertion of an analytical test.

The worked build checks one point layer against the input coordinates without rendering a figure. A successful build verifies layer data for this fixture. It does not verify a browser display, visual accessibility or a causal interpretation of plotted values. Subsequent plotting lessons add explicit print calls and output checks. Keep the representation, numerical data and rendered figure as separate evidence.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Adapter | A function translating a public source interface into a validated target contract. |
| Snapshot | A value representing state at a point in time, with an explicit ownership policy. |
| Public API | Documented operations intended for callers to depend on. |
| Representation detail | An internal storage choice that may change without preserving direct access patterns. |

## Read the syntax

Use named adapter functions such as from_s4 rather than guessing from identical-looking syntax. The result list(values=...,unit=...) is revalidated before calculation. ggplot2::ggplot_build(plot)$data[[1]] exposes built layer data; packageVersion("ggplot2") records the prepared API version without implying compatibility with every future version.

## Worked examples

### Example 1: Two representations produce the same checked record

```r
measurement_record <- function(values, unit) {
  if (!is.numeric(values) || is.complex(values) || !is.null(dim(values)) ||
    any(!is.finite(values))) stop("values must be a finite numeric vector")
  if (!is.character(unit) || length(unit) != 1L || is.na(unit) || !nzchar(unit)) {
    stop("unit must be one nonempty string")
  }
  list(values = as.double(values), unit = unit)
}
record_mean <- function(record) {
  checked <- measurement_record(record$values, record$unit)
  list(
    mean = if (length(checked$values)) mean(checked$values) else NA_real_,
    count = length(checked$values), unit = checked$unit
  )
}

s3_value <- structure(list(values = c(2, 4), unit = "ms"), class = "measure_s3")
methods::setClass("MeasureS4", slots = c(values = "numeric", unit = "character"))
s4_value <- methods::new("MeasureS4", values = c(2, 4), unit = "ms")
from_s3 <- function(x) {
  stopifnot(inherits(x, "measure_s3"))
  measurement_record(x$values, x$unit)
}
from_s4 <- function(x) {
  stopifnot(methods::is(x, "MeasureS4"))
  measurement_record(x@values, x@unit)
}
a <- from_s3(s3_value)
b <- from_s4(s4_value)
stopifnot(identical(a, b), identical(record_mean(a), list(mean = 3, count = 2L, unit = "ms")))
print(record_mean(a))
```

**Expected observation:** Mean 3, count 2, unit ms for both representations.

Both adapters read their declared representation and validate the common boundary. Equality of resulting records, rather than similar class labels, makes the summary interchangeable for this contract.

### Example 2: Inspect built ggplot2 data through an exported operation

```r
data <- data.frame(time = c(1, 2, 3), latency = c(8, 5, 6))
plot <- ggplot2::ggplot(data, ggplot2::aes(x = time, y = latency)) +
  ggplot2::geom_point()
built <- ggplot2::ggplot_build(plot)
layer <- built$data[[1]]
stopifnot(identical(layer$x, data$time), identical(layer$y, data$latency))
cat("ggplot2", as.character(utils::packageVersion("ggplot2")), "\n")
print(layer[c("x", "y")])
```

**Expected observation:** Coordinates(1,8),(2,5),(3,6) and the prepared package version.

The public builder produces the point coordinates. The assertions test those data, not undocumented internal plot slots. No print(plot) call is made, so this example intentionally checks construction without claiming that a figure was displayed.

## Reference review

All four adapters converge on one ordinary record. The equal-record assertion compares values, type normalization and units, rather than merely comparing a final mean. The R6 copy test is intentionally limited to a returned numeric vector.

The ggplot2 test exercises a public builder and checks actual layer coordinates. It remains valid without relying on the central plot object's internal S3 or S7 layout. Empty values and nonfinite values take different paths under the declared contract: one yields a missing summary, the other is rejected.
