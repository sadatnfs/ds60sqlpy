## Purpose and mental model

A count-based model is a useful baseline because every probability can be traced to a small table. A bigram model predicts the next token using only the immediately preceding token as its context. This restricted context is an explicit modeling assumption, not the complete probability chain rule for arbitrary text.

Use vocabulary [A,B,C] and two training sequences [A,B,A] and [A,A]. Count only transitions within each sequence. The resulting count rows are A:[1,1,0], B:[1,0,0] and C:[0,0,0]. The end of one sequence must not create a transition into the start of the next. Add one to every candidate count, then normalize the row; the declared vocabulary determines how much smoothing mass is added.

Fit these counts on training sequences only. Encoding or scoring validation text must not update the table or expand its vocabulary. A zero-count context then has a clear fallback under this smoothing policy: equal probability among the three known candidates. This small inspectable baseline will later make a neural model's held-out score meaningful without requiring any pretrained asset or online model.

## Vocabulary and concepts

**Bigram:** an ordered pair of neighboring tokens inside one sequence.

**Context row:** the counts or probabilities for next-token candidates after one preceding token.

**Vocabulary:** the fixed candidate set and its order; it is frozen before evaluation.

**Add-one smoothing:** adding one pseudo-count to every vocabulary candidate before normalization.

**Fallback:** the declared behavior for a context without training observations, rather than an undocumented default.

## Syntax or reasoning anatomy

A count matrix has one context row and one next-token column, both ordered by the vocabulary. For A, counts [1,1,0] become smoothed masses [2,2,1], whose denominator is five. For B, [1,0,0] becomes [2,1,1], denominator four. A context with no observations receives [1,1,1], denominator three.

Count transitions by zipping each sequence with its one-position suffix. This creates no pair after the final token and no pair across documents. A dictionary maps token strings to fixed row/column indices. Reject unknown training tokens instead of silently changing the declared vocabulary. For an unseen scoring context, the reference explicitly chooses a uniform known-vocabulary fallback; it does not pretend that this estimates a rich semantic relationship.

## Worked example / walkthrough

### Example A: Recover smoothed rows

Read the three raw rows before adding pseudo-counts.

```python
import numpy as np

counts = np.array([[1, 1, 0], [1, 0, 0], [0, 0, 0]], dtype=np.int64)
mass = counts + 1
probabilities = mass / mass.sum(axis=1, keepdims=True)
np.testing.assert_allclose(probabilities[0], [2 / 5, 2 / 5, 1 / 5], rtol=0, atol=1e-12)
np.testing.assert_allclose(probabilities.sum(axis=1), 1.0, rtol=0, atol=1e-12)
print(probabilities)
```

**Expected:** Each row sums to one under the same three-candidate vocabulary. Smoothing changes the model; disclose it rather than labeling it raw frequency.

### Example B: Do not invent a document-boundary transition

Count two single-token documents independently and contrast concatenation.

```python
documents = [["A"], ["B"]]
pairs = [pair for document in documents for pair in zip(document, document[1:])]
concatenated = ["A", "B"]
wrong_pairs = list(zip(concatenated, concatenated[1:]))
assert pairs == []
assert wrong_pairs == [("A", "B")]
print(pairs, wrong_pairs)
```

**Expected:** Joining documents creates a transition that the independent-document fixture never observed. Reset context at boundaries unless another explicit boundary-token policy is chosen.

## Progressive hints

- **Hint 1:** List pairs inside each sequence before adding them to a shared matrix.
- **Hint 2:** Add one to every known candidate, including zero-count candidates, before summing the denominator.
- **Hint 3:** Treat validation as a lookup-only path and compare the original table afterward.

## Common pitfalls

If validation text changes a probability, inspect whether the scoring path increments counts or adds vocabulary entries. If a boundary pair appears unexpectedly, print the per-document transition list before aggregating. If a row sums above or below one, inspect its smoothed denominator and candidate order.

Smoothing is not evidence that an unseen word or context is well modeled; it is a declared nonzero fallback over known candidates. A bigram model's limited context can be useful as a baseline while still missing long dependencies. A later transformer should be compared on the same frozen split and scoring units, not against a baseline accidentally deprived of preprocessing information that the neural model received.
