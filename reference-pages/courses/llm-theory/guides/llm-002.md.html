llm-002: Scores, stable softmax and probability mass#

Learning objectives#

Purpose and mental model#

A model score is not automatically a probability. Softmax converts a finite vector of scores into nonnegative weights that sum to one. The normalization axis and the set of allowed choices are part of the operation. A mathematically familiar formula can still fail numerically when exponentials overflow, or semantically when several query rows share one global denominator.

The small fixture [0,0] gives two equal choices, so each receives one half. Adding 1000 to both scores should change neither choice's relative preference nor its probability. Direct exponentiation overflows for the shifted numbers in ordinary float64, but subtracting their maximum first yields exactly the same stable computation as before.

This lesson treats a row as one categorical choice among candidates. It does not claim that the resulting weights represent confidence in truth. A wrong answer can receive the highest probability under a model. Later attention and next-token losses will reuse these normalization contracts, so we will also test forbidden choices, empty inputs and the distinction between normalizing one row and an entire matrix.

Vocabulary and concepts#

Score: an unnormalized numeric preference; its magnitude alone is not a probability.

Softmax: exponentiation followed by normalization over a declared candidate axis.

Normalizer: the sum of allowed exponential weights that becomes the denominator.

Allowed mask: a boolean array specifying which choices may participate; True means included in this lesson.

Temperature: a positive score divisor that changes the concentration of softmax without changing the ranking of unequal finite scores.

Syntax or reasoning anatomy#

For one row, subtract the maximum allowed score, exponentiate the shifted values and divide by their sum. The subtraction changes every score by the same amount. That shared factor would cancel between numerator and denominator, but computing after subtraction avoids forming enormous exponentials. A forbidden choice receives zero exponential mass before normalization.

np.asarray converts input into a numeric array, while ndim and shape check the declared one-row interface. A boolean mask is distinct from integers whose truthiness happens to be nonzero. Reject an all-false row because no allowed categorical distribution exists. Keep axis-specific reasoning explicit: stacking two valid row distributions is different from normalizing all entries in a matrix as one choice.

Worked example / walkthrough#

Example A: A stable shift of equal scores#

Implement the basic formula on two finite fixtures. No random draw is necessary.

import numpy as np

for scores in ([0.0, 0.0], [1000.0, 1000.0]):
    values = np.asarray(scores, dtype=np.float64)
    mass = np.exp(values - values.max())
    probabilities = mass / mass.sum()
    np.testing.assert_allclose(probabilities, [0.5, 0.5], rtol=0, atol=1e-12)
    print(probabilities)

Expected: Both rows print the same two halves. The large offset has no effect on relative probabilities, and the shifted exponentials never require exp(1000).

Example B: Forbidden mass must not reach the denominator#

Keep a huge score in a forbidden middle choice; remove it before normalization.

scores = np.array([0.0, 100.0, 0.0])
allowed = np.array([True, False, True])
masked = np.where(allowed, scores, -np.inf)
mass = np.exp(masked - masked.max())
probabilities = mass / mass.sum()
np.testing.assert_allclose(probabilities, [0.5, 0.0, 0.5], rtol=0, atol=1e-12)
print(probabilities)

Expected: The forbidden high score has no effect on the two legal alternatives. An all-false mask would make the row invalid and must be rejected before this formula.

Exercises#

  1. Explain the shift. Run both equal-score fixtures and derive why subtracting a shared offset preserves the ratio. Expected: Both outputs are [0.5,0.5] and every row sum is 1. Verify: Assert the output vectors with rtol=0, atol=1e-12 and record the two exponentials actually formed after shifting.
  1. Construct a stable helper. Implement softmax(scores,allowed=None) for a finite nonempty vector. Compare [0,log(3)] with the same vector plus 1000. Expected: Both yield [0.25,0.75] within 1e-12. Verify: Assert each vector and their difference separately; no direct exp(1000) is needed.
  1. Preserve the legal candidate set. Use [0,100,0] with mask [True,False,True], then explain why normalizing first and setting the middle result to zero is wrong. Expected: Legal distribution [0.5,0,0.5]; the post-normalization deletion loses probability mass. Verify: Assert the legal row sum is 1 and compare it with the tiny remaining mass from the broken order.
  1. Find a wrong reduction axis. Take a 2x2 matrix of zero scores. Compare one global softmax with two independently normalized rows. Expected: A global normalizer gives every entry 0.25 and row sums 0.5; row-wise normalization gives entries 0.5 and row sums 1. Verify: Inspect the two row-sum arrays, not just whether all four values are nonnegative.
  1. Reject invalid distributions. Test an empty vector, a NaN score, an integer mask and an all-false boolean mask. Expected: Empty, NaN and all-false cases raise ValueError; integer mask raises TypeError. Verify: Capture all four exceptions independently and verify the original equal-score case still returns [0.5,0.5].
  1. Transfer to temperature. For scores [0,log(3)], divide by positive temperature 2 before softmax and compare the ranking with temperature 1. Expected: At temperature 2, probabilities are [1/(1+sqrt(3)),sqrt(3)/(1+sqrt(3))]; index 1 remains the largest. Verify: Assert the new values within 1e-12, the sum 1 and the unchanged argmax; do not interpret the winner as guaranteed truth.

Progressive hints#

  • Hint 1: Start with equal legal scores so their normalized weights must be equal.
  • Hint 2: Subtract the maximum over allowed scores before exponentiation.
  • Hint 3: Check the row sum after masking, and reject a row whose legal set is empty.

Common pitfalls#

If a probability is NaN, inspect empty or fully forbidden choices before adding small constants to a denominator. If scores are large, inspect whether exponentiation happened before maximum subtraction. If every value looks plausible but row sums are one half, inspect the normalization axis. Nonnegativity alone does not define a valid categorical row.

A boolean mask can have opposite meanings in different libraries. Translate the inclusion rule instead of trusting the variable name. Temperature zero is not passed into this division formula; a future decoder can implement a separate greedy branch. A normalized weight is a model-dependent preference, not independent evidence that its corresponding answer is factually correct.
