## Outcome and mechanism

Fit and inspect PCA while preserving its preprocessing, orientation and interpretation contracts.

Principal component analysis finds orthogonal directions of variation in a numerical representation. The representation includes centering and scaling choices. Measuring one feature in much larger units can make it dominate an unscaled covariance analysis even when it contains the same underlying pattern as another feature.

R's prcomp uses a singular-value decomposition of the centered and optionally scaled data. Its rotation matrix contains loading directions, while its x component contains observation scores. Their shapes and orientation matter when reconstructing the original data. A plot of scores without the preprocessing and feature definitions is incomplete evidence.

A loading vector's sign is not uniquely determined. Reversing one loading direction and the corresponding score coordinate leaves the reconstruction unchanged. Tests should therefore compare explained variance, subspaces or reconstructed values rather than demand a particular arbitrary sign across implementations.

Scaling to unit variance changes the question from variation in original units to variation relative to each feature's spread. Neither choice is universally correct. A feature with zero variance cannot be standardized by dividing by its standard deviation, so it needs an explicit removal or modeling policy before scaling.

PCA used inside a predictive procedure must be fitted on training data only. New observations are transformed using the retained training center, scale and loadings. Recomputing those quantities on held-out data changes the fitted representation and can leak assessment information. Finally, high explained variance is not proof that a component is scientifically meaningful, causal or useful for a downstream target.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Loading | A coordinate direction in feature space. |
| Score | An observation coordinate after projection into the component basis. |
| Explained variance | The variation assigned to a retained component under the declared preprocessing. |
| Sign indeterminacy | The equivalent reversal of a loading and its corresponding score coordinate. |

## Read the syntax

Use prcomp(x, center=TRUE, scale.=...) and inspect center, scale, rotation, sdev and x. For an unscaled full-rank representation, scores %*% t(rotation) reconstructs centered data. With scaling, multiply reconstructed columns by the stored scale and add the stored center. predict(pc, newdata=...) applies the fitted transformation to new observations.

## Worked examples

### Example 1: Units change an unscaled direction

```r
x <- cbind(short = c(-2, -1, 1, 2), long = c(-20, -10, 10, 20))
raw <- prcomp(x, center = TRUE, scale. = FALSE)
standardized <- prcomp(x, center = TRUE, scale. = TRUE)
stopifnot(abs(abs(raw$rotation["long", 1]) - 10 / sqrt(101)) < 1e-10)
stopifnot(max(abs(abs(standardized$rotation[, 1]) - rep(1 / sqrt(2), 2))) < 1e-10)
stopifnot(raw$sdev[2] < 1e-10)
print(abs(raw$rotation[, 1]))
print(abs(standardized$rotation[, 1]))
```

**Expected observation:** Raw large-unit loading magnitude10/sqrt101; standardized magnitudes1/sqrt2.

The two features are exactly proportional. Their scale difference dominates the unscaled loading, while standardization gives equal-magnitude coordinates. Absolute values avoid testing an arbitrary sign.

### Example 2: Reconstruct with retained preprocessing

```r
x <- cbind(a = c(1, 2, 4, 5), b = c(2, 1, 5, 4))
pc <- prcomp(x, center = TRUE, scale. = TRUE)
scaled_reconstruction <- pc$x %*% t(pc$rotation)
reconstructed <- sweep(sweep(scaled_reconstruction, 2, pc$scale, "*"), 2, pc$center, "+")
stopifnot(max(abs(reconstructed - x)) < 1e-10)
stopifnot(max(abs(crossprod(pc$rotation) - diag(2))) < 1e-10)
print(pc$sdev^2 / sum(pc$sdev^2))
```

**Expected observation:** Near-exact reconstruction and orthonormal loading columns.

Using every component recovers the admitted data up to rounding. The calculation explicitly reverses scaling and centering rather than treating scores as original-unit measurements.

## Reference review

The reference compares sign-invariant quantities and reconstructs the original data using saved preprocessing. It does not assume one implementation's arbitrary loading signs are authoritative. The constant-feature failure and new-row transformation exercise the admission and application boundaries separately.

Explained variance is computed from squared component standard deviations under the selected scaling. It describes this feature representation. A predictive or scientific interpretation must connect it to an independent question and evaluation design.
