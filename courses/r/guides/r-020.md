## Outcome and mechanism

Reduce a defect to a small case and build behavioral checks that cover ordinary, boundary and rejected inputs.

Debugging begins by making the failure reproducible. Preserve the exact input, observed result and intended behavior before changing several things at once. A minimal example removes unrelated data and dependencies while retaining the failing mechanism. In a classroom pad, a self-contained script also avoids hidden session state from an earlier run.

Inspect structure as well as printed values. str, typeof, length and dim can reveal a dropped dimension or unintended coercion that rounded console output hides. Add assertions near the boundary where an invariant first becomes necessary. A later nonsensical model result may originate in an earlier ID join, missingness mask or vector-length mismatch.

A regression test should exercise behavior, not simply repeat the implementation's formula. For a weighted mean, check a deliberately unequal group-size example whose expected result is derived independently. Include an empty population, a missing or invalid weight and a zero-total-weight case under the declared policy. Catching every error and returning success would invalidate the test.

Reproducibility also includes random-number configuration and package versions. set.seed establishes a repeatable stream for a chosen generator configuration; it does not make different algorithms or arbitrary future package versions identical. sessionInfo records useful environment context. Avoid asserting that one fixed numerical sequence must match across every R version, platform and package change without a supported compatibility contract.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Minimal reproduction | A small self-contained input and program that retains a defect. |
| Invariant | A property expected to hold throughout an operation. |
| Regression check | A check that prevents a known defect from returning. |
| Reproducibility record | Inputs, configuration and version evidence needed to interpret a result. |

## Read the syntax

Use stopifnot for compact behavioral assertions and isTRUE(all.equal(...)) for a justified numeric tolerance. Test an expected error with a narrow handler. Reset the seed immediately before a reproducibility comparison and retain source plus session metadata.

## Worked examples

### Example 1: A behaviorally specified weighted mean

```r
weighted_average <- function(x, w) {
  stopifnot(is.numeric(x), is.numeric(w), length(x) == length(w), length(x) > 0L)
  stopifnot(all(is.finite(x)), all(is.finite(w)), all(w >= 0), sum(w) > 0)
  sum(x * w) / sum(w)
}
stopifnot(weighted_average(c(10, 20), c(1, 3)) == 17.5)
stopifnot(weighted_average(c(10, 20), c(2, 6)) == 17.5)
print(weighted_average(c(10, 20), c(1, 3)))
```

**Expected observation:** 17.5 under both weight scales.

The independent expected amount is \((10+60)/4=17.5\). Scaling every weight by the same positive constant is a useful invariant that tests meaning rather than source text.

### Example 2: Repeat a seeded stream deliberately

```r
set.seed(17)
first <- runif(4)
set.seed(17)
second <- runif(4)
stopifnot(identical(first, second))
stopifnot(all(first >= 0 & first <= 1))
print(list(same_stream = identical(first, second), r_version = getRversion()))
```

**Expected observation:** The two vectors match exactly in this run.

Resetting the same seed before each draw reproduces this generator stream in the same environment. The range assertion checks a separate distribution-support property.
