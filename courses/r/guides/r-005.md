## Outcome and mechanism

Select and replace vector elements without confusing positions, exclusions and unknown masks.

R's ordinary vector positions start at one. A positive integer index selects positions, and repeating an index repeats an output value. Zero selects nothing. A negative index excludes positions. Do not mix positive and negative positions in the same ordinary index, except zeros, because retaining and excluding would conflict.

Names provide labels, but they are not a relational key enforced by R. Names can be duplicated, absent or out of date. Character indexing selects a named value and can return NA for a missing name on an atomic vector. Validate the name set when missing or duplicated identifiers would make a calculation ambiguous.

A logical index is another vector. TRUE retains an entry, FALSE excludes it and NA can produce an unknown output entry. If a predicate contains NA, x[predicate] may contain a placeholder whose originating value is not established by the predicate. A deliberate known-only mask avoids that ambiguity. which returns positions of true entries and drops unknown predicates, so it expresses a different missingness policy.

Replacement uses the same selection mechanism on the left side of <-. x[2] <- 99 replaces an existing position, while an out-of-range assignment can extend a vector and introduce missing gaps. A boundary check should reject extension if the operation means update an existing observation. Syntax convenience does not establish a safe update contract.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Positive index | One-based positions to retain, possibly repeated. |
| Negative index | Positions to exclude. |
| Named index | Selection by an exact name on an object. |
| Logical mask | A vector describing which positions to retain. |

## Read the syntax

Use x[c(1,3)] to retain positions, x[-2] to exclude the second, and x[c("A","C")] for names. Keep the mask length equal to the data length when it describes one decision per record. Validate any requested key before updating.

## Worked examples

### Example 1: Order and duplicates are part of selection

```r
x <- c(A = 10, B = 20, C = 30)
selected <- x[c(3, 1, 1)]
stopifnot(identical(unname(selected), c(30, 10, 10)))
stopifnot(identical(names(selected), c("C", "A", "A")))
print(selected)
```

**Expected observation:** C 30, A 10, A 10.

The requested output order is C, A, A, and duplication is preserved. This is positional extraction, not a unique-key set operation.

### Example 2: Unknown mask versus known-only selection

```r
x <- c(10, 20, 30)
mask <- c(TRUE, NA, FALSE)
raw <- x[mask]
known <- x[!is.na(mask) & mask]
stopifnot(identical(raw, c(10, NA_real_)), identical(known, 10))
print(list(raw = raw, known = known))
```

**Expected observation:** raw contains 10 and NA; known contains 10.

The first output preserves an unknown selected position. The second explicitly restricts selection to known TRUE predicates.
