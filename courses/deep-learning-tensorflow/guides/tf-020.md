## Purpose and mental model

Pooling summarizes a local region without fitting a separate coefficient at each position. Max pooling retains the largest response; average pooling retains the mean. These summaries discard information and therefore have different invariances. Augmentation changes training inputs under an assumption that the desired label remains the same. A horizontal flip may preserve the label of a symmetric shape but can change a left-pointing arrow into a right-pointing arrow. The validity of an augmentation comes from task semantics, not from the availability of a library transform. Evaluation must use a fixed policy so score changes are not concealed by random transformations.

## Vocabulary and concepts

**Pooling:** A local reduction that discards spatial detail.

**Augmentation:** A training transformation justified by label semantics.

**Label invariance:** The target remains valid after a transformation.

## Syntax anatomy and reasoning sequence

max_pool2d and avg_pool2d reduce spatial patches in a four-dimensional image tensor. flip_left_right reverses the width axis while preserving batch, height and channels. Use literal arrays to inspect these axes. Training augmentation and evaluation transformation should be separate functions, with evaluation returning a known deterministic input representation.

## Ask what information a transformation discards

For the patch with values 1,3,2 and 4, max pooling returns 4 while average pooling
returns 2.5. Changing the smallest value from 1 to 0 leaves the maximum unchanged
but changes the average to 2.25. This is a direct demonstration of two different
summaries. Neither retains the full spatial arrangement or every input value.

The gradient consequences differ too. Away from ties, a maximum routes local
sensitivity through its maximizing input; an average distributes sensitivity
across the averaged positions. Tie behavior belongs to the particular
operation's definition and implementation. Pooling is therefore a modeling
choice about retained information, not a universal improvement over an
unpooled representation.

Augmentation introduces another assumption: the transformed example must
retain a valid target or receive the corresponding target transformation.
A horizontal flip can preserve an object category while changing a left/right
label. A segmentation mask or bounding box must be transformed consistently
with the image. Applying the same-looking transform to only the pixels can
create mislabeled supervision.

Keep the default evaluation representation fixed so repeated measurements
refer to the same task. Test-time augmentation is a separate inference policy
that needs its own aggregation rule and evaluation. An involution check,
such as flipping twice and recovering the original image, proves the transform's
mechanics; it does not prove that one flip preserves the label's meaning.

## Worked example / walkthrough

### Example A: Compare two reductions

The max ignores the three smaller values, while the average uses every value equally. Equal output shapes do not mean equal retained information.

```python
import numpy as np
import tensorflow as tf

x = tf.constant([[[[1.0], [3.0]], [[2.0], [4.0]]]])
assert float(tf.nn.max_pool2d(x, 2, 2, "VALID")[0, 0, 0, 0]) == 4
assert float(tf.nn.avg_pool2d(x, 2, 2, "VALID")[0, 0, 0, 0]) == 2.5
```

**Expected:** max4; average2.5.

### Example B: Inspect a flip

The operation reverses columns, not rows. Naming the width axis prevents a mistaken vertical transformation from silently changing a directional task.

```python
import numpy as np
import tensorflow as tf

x = tf.constant([[[[1.0], [3.0]], [[2.0], [4.0]]]])
assert float(tf.nn.max_pool2d(x, 2, 2, "VALID")[0, 0, 0, 0]) == 4
assert float(tf.nn.avg_pool2d(x, 2, 2, "VALID")[0, 0, 0, 0]) == 2.5
flipped = tf.image.flip_left_right(x)
np.testing.assert_array_equal(flipped.numpy().reshape(2, 2), [[3, 1], [4, 2]])
```

**Expected:** rows[3,1] and[4,2].

## Common pitfalls and diagnosis

When an augmented model degrades, inspect a transformed input and
its target together. Distinguish information discarded by pooling from
incorrect labels introduced by augmentation. If a transform passes a
round-trip pixel check, still ask whether its intermediate image has the
same semantic target. Keep evaluation randomness explicit.
