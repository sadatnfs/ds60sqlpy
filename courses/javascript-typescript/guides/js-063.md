# js-063: Choropleths, rate denominators and missing geographic joins

## Level and prerequisites

Advanced; about 110 minutes plus independent practice. Direct prerequisites: `js-062`.

## Learning objectives

Build a choropleth of rates joined by stable IDs, keeping zero, missing and invalid denominators distinct. The central exercise is: Build a stable-ID choropleth join.

## Purpose, vocabulary and mental model

A choropleth colors geographic regions according to a value. The map’s geometry and the statistical table usually come from different sources, so they must be joined by a stable identifier. A display name is often a weak key because spelling, language and boundary definitions can change.

Raw counts often track population or exposure rather than the phenomenon of interest. A rate divides an event count by a relevant denominator, such as eligible people or observation time. The denominator must match the numerator’s geography, period and population. A beautiful map cannot repair a mismatched denominator.

Missing data needs its own visual state. A region with no measurement is not equivalent to a measured zero. Keep an explicit missing color or pattern, a legend and a table. Be cautious about ecological inference: a region-level association does not necessarily describe individuals within that region.

### Key terms

- **Choropleth:** A map that fills each region with a color representing a value for that region.
- **Rate:** An event count divided by a matching denominator, such as eligible people, for the same geography, period and population.
- **Geographic join:** Matching map features to statistical rows through a stable region ID and reporting unmatched features and rows.
- **Missing data:** A region without a measurement, drawn with its own color or pattern and legend entry so it is not confused with a measured zero.
- **Ecological inference:** Drawing conclusions about individuals from associations measured only at the region level, which aggregated data cannot support.

## Syntax anatomy and mechanism

Create a Map from stable region ID to validated data, then look up each feature’s ID. Validate duplicate statistical IDs and report unmatched features and rows. Compute rates only for positive valid denominators. Choose a sequential scale for nonnegative ordered rates and explain its domain.

The reference uses synthetic planar regions with `geoIdentity`, so the lesson isolates join and rate logic without introducing a global projection. It includes one missing region deliberately. This is a map-like teaching fixture, not a real-world geographic claim.

## Worked example / walkthrough

### Worked example 1: Compute an explicit rate

Numerator and denominator have the same scope.

```javascript
const rate = (events, population) => (population > 0 ? events / population : null);
console.log(rate(10, 100), rate(10, 0));
```

**Expected observation:** 0.1 and null; zero denominator is not a valid rate.

### Worked example 2: Distinguish missing and zero

Map membership is separate from a numeric value, and the drawing keeps the two cases visibly different.

```javascript
// js-063 worked example 2: a complete program for the classroom preview.
const host = document.querySelector("#chart");
const output = document.querySelector("#output");
host.replaceChildren();
const check = (condition, message) => {
  if (!condition) throw new Error(message);
};
const svg = d3
  .select(host)
  .append("svg")
  .attr("viewBox", "0 0 640 360")
  .attr("role", "img")
  .attr("aria-label", "Choropleths, rate denominators and missing geographic joins")
  .style("width", "100%")
  .style("max-width", "640px");
const regions = ["A", "B", "C"];
const values = new Map([
  ["A", 0],
  ["C", 0.3],
]);
const color = d3.scaleSequential(d3.interpolateBlues).domain([0, 0.5]);
svg
  .selectAll("rect")
  .data(regions)
  .join("rect")
  .attr("x", (d, i) => 60 + i * 180)
  .attr("y", 100)
  .attr("width", 150)
  .attr("height", 120)
  .attr("fill", (d) => (values.has(d) ? color(values.get(d)) : "white"))
  .attr("stroke", "#111827")
  .attr("stroke-dasharray", (d) => (values.has(d) ? null : "6 4"));
svg
  .selectAll("text")
  .data(regions)
  .join("text")
  .attr("x", (d, i) => 70 + i * 180)
  .attr("y", 250)
  .text((d) => (values.has(d) ? `${d}: ${values.get(d)}` : `${d}: no data`));
check(values.has("A") && values.get("A") === 0, "A is a measured zero");
check(!values.has("B"), "B has no supplied record");
output.textContent = "js-063 worked example 2 complete";
```

**Expected observation:** Three regions: A filled as a measured zero, C shaded for 0.3, and B drawn white with a dashed outline and labeled no data.

## Six progressive exercises

### Exercise 1: Predict rates for 10/100 and 20/100.

**Expected evidence:** 0.1 and 0.2 with an explicit common denominator meaning.

**Progressive hint:** A rate is a derived quantity.

### Exercise 2: Add a region with no statistical row.

**Expected evidence:** It receives the documented missing-data appearance.

**Progressive hint:** Do not default a failed join to zero.

### Exercise 3: Build a stable-ID choropleth join.

**Expected evidence:** Every feature is matched or explicitly listed as missing.

**Progressive hint:** A join audit prevents silent region loss and name-based mismatches.

### Exercise 4: Diagnose a map of raw events interpreted as risk.

**Expected evidence:** Population or exposure may explain the count pattern.

**Progressive hint:** Choose a denominator appropriate to the question and verify its geographic and temporal alignment.

### Exercise 5: Handle a zero denominator.

**Expected evidence:** Reject or mark the rate undefined rather than divide to infinity.

**Progressive hint:** An invalid denominator cannot support a meaningful color.

### Exercise 6: Explain ecological inference limits.

**Expected evidence:** Regional summaries do not automatically describe individuals.

**Progressive hint:** Aggregation can create or reverse relationships.

## Debugging and common mistakes

If a region shows no color, check the join first: list feature IDs without a statistics row and rows without a feature. Compute rates in a separate step and return `null` for a zero denominator instead of dividing into `Infinity`. Then check that measured zero, missing and invalid rates each get their own documented fill. ([checkpoints](../STUDY-GUIDE.md#d3-debugging-checkpoints))

Exercise 4 is the controlled failure: Diagnose a map of raw events interpreted as risk. Distinguishing evidence: Population or exposure may explain the count pattern.

## Accessibility and interpretation

Color alone cannot carry the value, so label regions or provide a table of region, numerator, denominator and rate. Use a sequential palette that stays distinguishable in grayscale, and mark missing data with an outline or pattern plus the words "no data" rather than a color that resembles zero. ([accessibility review](../STUDY-GUIDE.md#d3-accessibility-review))

A map of raw counts mostly shows where people are; divide by an exposure such as population to show a rate. Regional rates describe regions, and inferring individual risk from them is the ecological fallacy. Small denominators produce unstable rates, so report each denominator beside its rate. ([statistical meaning](../STUDY-GUIDE.md#d3-statistical-meaning))
