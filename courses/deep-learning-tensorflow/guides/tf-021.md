## Purpose and mental model

A padded sequence contains both real observations and artificial storage positions. An embedding lookup turns token IDs into vectors, but padding does not become a real token merely because it has a vector. Carry a valid-token mask alongside the sequence. When averaging token losses, divide by the number of valid targets rather than the padded length. Appending more padding should leave the score unchanged. Some layers propagate Keras masks, while custom arithmetic must apply them explicitly. This lesson treats token zero as padding under a declared vocabulary policy; another vocabulary may assign zero a real meaning.

## Vocabulary and concepts

**Padding:** Artificial positions added to equalize storage shapes.

**Embedding:** A learned or fixed vector table indexed by token ID.

**Mask:** A boolean description of which positions participate.

## Syntax anatomy and reasoning sequence

The boolean comparison ids!=0 identifies valid tokens. tf.gather selects embedding rows in token order. tf.where(mask,loss,0) suppresses padding contributions, then reduce_sum(mask) supplies the denominator. Reject a completely padded sequence because it has no observed target loss. Avoid assuming that a numerical zero vector is an adequate replacement for an explicit mask.

## Padding is storage, not an observed target

Padding allows examples of different lengths to share one rectangular tensor.
It creates positions for storage and computation, not new observations.
If two valid token losses equal \(\log(2)\) and a padded position has arbitrary
loss 100, the masked mean is still \(\log(2)\). The numerator excludes the padding
loss and the denominator counts two active positions.

An embedding lookup maps token IDs to feature vectors. Reserving zero as a
padding ID is a vocabulary convention. Keras's mask-zero behavior propagates
mask information; it does not mean that every custom downstream operation
automatically ignores those positions or that row zero must be a zero vector.
Inspect mask handling at each custom layer or loss boundary.

Selecting a sequence summary also needs a length contract. The element at
length-1 is the last valid position only when valid tokens form a contiguous
prefix followed by right padding. If the mask can contain holes, count-minus-one
can select a padded position. Use the actual valid indices or reject layouts
outside the declared contract.

An entirely padded example has no active-token mean. Returning zero would
quietly change the objective and could make an empty batch look perfect.
Reject it or define an explicit exclusion policy with its own contributing
count. The same principle applies when instruction tuning excludes prompt
tokens from the loss while retaining them as visible context.

## Worked example / walkthrough

### Example A: Mark valid positions

The mask derives from vocabulary semantics, not from the magnitude of an embedding vector. A real token could legitimately have a zero vector.

```python
import numpy as np
import tensorflow as tf

ids = tf.constant([2, 3, 0])
mask = ids != 0
assert mask.numpy().tolist() == [True, True, False]
assert int(tf.reduce_sum(tf.cast(mask, tf.int32))) == 2
```

**Expected:** mask[True,True,False], count2.

### Example B: Normalize masked losses

The numerator and denominator must use the same participation policy. Zeroing the padding loss but dividing by three would understate the mean valid-token loss.

```python
import numpy as np
import tensorflow as tf

ids = tf.constant([2, 3, 0])
mask = ids != 0
assert mask.numpy().tolist() == [True, True, False]
assert int(tf.reduce_sum(tf.cast(mask, tf.int32))) == 2
losses = tf.constant([np.log(2), np.log(2), 100.0], dtype=tf.float64)
mean = tf.reduce_sum(tf.where(mask, losses, 0.0)) / tf.reduce_sum(tf.cast(mask, tf.float64))
np.testing.assert_allclose(float(mean), np.log(2), atol=1e-12, rtol=0)
```

**Expected:** masked meanlog2; padding loss100 has no effect.

## Common pitfalls and diagnosis

If appending padding changes a metric, inspect both masking and
the denominator. If summaries select a padding state, verify the right-padding
assumption. If a custom layer ignores a Keras mask, pass or apply the mask
deliberately instead of assuming embedding metadata changes arbitrary tensor
operations. Empty participation requires an explicit decision.
