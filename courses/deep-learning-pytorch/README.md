# Deep Learning with PyTorch

This36lesson journey is being authored with depth comparable to the complete
[TensorFlow journey](../deep-learning-tensorflow/README.md). It starts with
inspectable tensors and gradients and progresses through data pipelines,
training loops, CNNs, sequences, transformers, checkpointing, diagnosis and
model releases. The [track plan](track.json) pairs each topic with its TensorFlow
counterpart. The [authored manifest](lessons.json) lists completed lesson sets;
a planned title is not a finished tutorial.

Use the Docker classroom's `llm-torch-cpu` profile. This is the shared prepared
PyTorch CPU worker, also used by the LLM courses; no host Python, GPU, model
weights or external dataset download is required for the default examples.
See [classroom setup](../../docs/docker-classroom.md) for visible build logs,
startup and persistent progress. The [comparison guide](COMPARISON.md) explains
how to study the two frameworks together without assuming identical defaults.
