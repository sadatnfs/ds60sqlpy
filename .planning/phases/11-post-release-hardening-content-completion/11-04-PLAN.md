# Plan 11-04: shrink the security exception surface and add code scanning

## Objective

Fewer image findings need owner exceptions, and the repository has code
scanning and dependency alerts (HARD-01).

## Tasks

1. Tracer: stop shipping repository Dockerfiles inside the App image
   (`.dockerignore`), after confirming no runtime path reads them, and drop
   the 27 DS-0002 policy entries the scan no longer reports.
2. Add a CodeQL workflow (Python, JavaScript, Actions) with pinned actions and
   fix its real findings.
3. Enable Dependabot vulnerability alerts and security updates through the
   GitHub API; document it if the token cannot.
4. Reduce OS package findings where a fix exists: newer bases, removing
   unneeded packages, kernel-header CVEs handled honestly. Never approve
   pending-owner exceptions on the owner's behalf.

## Verification

- App scan shows no DS-0002 findings; CodeQL workflow green; Dependabot alert
  status recorded; `docker/cve-policy.json` entry count reduced.
