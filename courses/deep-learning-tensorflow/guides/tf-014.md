# tf-014: Multiclass and multilabel are different tasks

## Level and prerequisites

Intermediate; approximately 105 minutes. Direct prerequisites: `tf-013`.

## Learning objectives

The central investigation is concrete: Contrast one-of-three integer targets with three independent binary labels; compute cross entropy for uniform three-class logits. The finish condition is Uniform three-class \(\mathrm{CE}=\log(3)\); sparse targets are class indices. Multilabel targets have one binary value per class and need independent decisions.

## Purpose and mental model

Multiclass and multilabel prediction answer different questions. In a multiclass task exactly one class is chosen, so a softmax distributes one unit of probability across mutually exclusive outcomes. In a multilabel task several labels may hold at once, so each label gets its own binary decision. A tensor with three outputs does not by itself tell you which task is intended. The target contract determines the activation, loss and denominator. Integer sparse targets name one class index; a vector such as [1, 0, 1] names two independently present labels. Converting one task into the other changes the meaning of the data.

## Vocabulary and concepts

**Multiclass:** One outcome among mutually exclusive categories.

**Multilabel:** Independent binary outcomes that may coexist.

**Sparse target:** An integer index of the observed class.

## Syntax anatomy and reasoning sequence

Sparse categorical cross entropy takes class indices with shape (batch,), alongside logits shaped (batch, classes). Sigmoid cross entropy instead takes a binary matrix matching logits. Softmax reduces across the class axis. Explicitly check which axes a loss function reduces before comparing mean losses, particularly when multilabel losses are averaged across both labels and examples.

## Let the target's meaning determine the output geometry

Multiclass classification assumes one selected class among C alternatives.
The model produces C competing logits and softmax normalizes their probability
mass to one. With three equal logits, each class has probability \(\frac{1}{3}\) and the
negative log probability of the selected class is \(\log(3)\).

Multilabel classification permits several labels to be true at once. Three
zero logits passed through independent sigmoids produce three probabilities
of 0.5 whose sum is 1.5. That sum is valid because the labels are not mutually
exclusive outcomes of one categorical draw. Replacing those sigmoids with
softmax would force labels to compete and change the modeling assumptions.

Target shapes encode part of this distinction. Sparse categorical targets
use one class index per example, often shape (B,). A multilabel target uses
one indicator for each example-label pair, shape (B, C). A categorical one-hot
target also has shape (B, C), so shape alone cannot identify the task: its row
constraints and intended probability distribution must agree too.

Reduction defines the reported unit. For two examples and three independent
binary labels with zero logits, six binary losses each equal \(\log(2)\). Their
sum is 6 \(\log(2)\), and their mean is \(\log(2)\). If some labels are unobserved, count
only the intended active targets; treating an unknown label as a negative
creates supervision that the data did not supply.

## Worked example / walkthrough

### Example A: Uniform class uncertainty

Three equal scores create a uniform distribution. The target probability is one third, so the negative log likelihood is log 3, independent of which class index is chosen.

```python
import numpy as np
import tensorflow as tf

logits = tf.zeros((1, 3))
loss = tf.nn.sparse_softmax_cross_entropy_with_logits(labels=[1], logits=logits)
np.testing.assert_allclose(loss.numpy(), [np.log(3)], atol=1e-6, rtol=0)
```

**Expected:** loss \(\log(3)\).

### Example B: Independent labels

Independent binary probabilities do not need to sum to one. Forcing a softmax here would make the two present labels compete for probability mass.

```python
import numpy as np
import tensorflow as tf

logits = tf.zeros((1, 3))
loss = tf.nn.sparse_softmax_cross_entropy_with_logits(labels=[1], logits=logits)
np.testing.assert_allclose(loss.numpy(), [np.log(3)], atol=1e-6, rtol=0)
probs = tf.math.sigmoid(logits).numpy()
np.testing.assert_array_equal(probs, [[0.5, 0.5, 0.5]])
assert probs.sum() == 1.5
```

**Expected:** three probabilities 0.5 with total 1.5.

## Common pitfalls and diagnosis

If softmax probabilities look plausible but several labels should
coexist, revisit the target definition before tuning the model. Reject class
indices outside 0 through C-1. Check whether unknown multilabel entries were
converted to zeros and whether the loss denominator counts examples, labels
or active example-label pairs.
