llm-016: A tiny causal transformer from explicit parts#

Status: authored beta content. The manifest inventories complete teaching files; runtime readiness remains a separate, measured property.

Level and prerequisites#

Intermediate; approximately 135 minutes. Direct prerequisites: llm-015. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

Learning objectives#

Assemble one decoder block and verify its shape and information boundary before training. The central investigation is concrete: Build a decoder with width 32, two heads, one block and vocabulary<=128; retain the NumPy mask test as a reference. The finish condition is Parameter count<50000, logits shape=(batch,time,vocabulary), and prefix outputs agree in eval mode within 1e-6. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

Purpose and mental model#

A small causal decoder makes the transformer data path visible. Token IDs index a learned table, position IDs add order, and a tokenwise normalization feeds query/key/value projections. Two heads attend only to current and earlier positions. Their outputs are rejoined, projected and added through a residual connection. A second tokenwise normalization and feed-forward block produce another residual. The output projection creates one vocabulary score per token position. No pretrained model or downloaded corpus is needed. A parameter count and a context limit bound this teaching model; they do not make it a general-purpose language system.

Vocabulary and concepts#

Decoder block: Causal attention and tokenwise transformations with residual connections.

Logits: Unnormalized vocabulary scores for each prediction position.

Context limit: Maximum number of token positions represented by the model.

Syntax anatomy and reasoning sequence#

The TinyDecoder helper uses width32,heads2,context32,vocabulary16. Its tensor path is(batch,time,width) to(batch,heads,time,head_width), then back. The boolean allowed matrix uses key_position<=query_position, so the diagonal is allowed for shifted targets. LayerNorm reduces features only. forward returns logits plus detached K/V state for later inference lessons; training in this lesson always passes cache=None.

Worked example / walkthrough#

Example A: Build a bounded decoder#

The exact count follows the embedding, projection and feed-forward shapes. A small parameter count bounds the fixture but says little about capability on unseen tasks.

import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
class TinyDecoder(nn.Module):
    def __init__(self,vocab=16,width=32,heads=2,context=32):
        super().__init__()
        self.vocab,self.width,self.heads,self.context=vocab,width,heads,context
        self.token=nn.Embedding(vocab,width); self.position=nn.Embedding(context,width)
        self.norm1=nn.LayerNorm(width); self.qkv=nn.Linear(width,3*width,bias=False)
        self.projection=nn.Linear(width,width,bias=False); self.norm2=nn.LayerNorm(width)
        self.feed=nn.Sequential(nn.Linear(width,2*width),nn.ReLU(),nn.Linear(2*width,width))
        self.output=nn.Linear(width,vocab,bias=False)
    def forward(self,ids,cache=None):
        if ids.ndim!=2 or ids.dtype!=torch.long or ids.shape[1]==0: raise ValueError('nonempty long batch,time IDs')
        offset=0 if cache is None else cache['k'].shape[2]
        batch,time=ids.shape
        if offset+time>self.context or torch.any(ids<0) or torch.any(ids>=self.vocab): raise ValueError('context or vocabulary limit')
        x=self.token(ids)+self.position(torch.arange(offset,offset+time))
        q,k,v=self.qkv(self.norm1(x)).chunk(3,dim=-1)
        def split(t): return t.reshape(batch,time,self.heads,self.width//self.heads).transpose(1,2)
        q,k,v=map(split,(q,k,v))
        if cache is not None:
            if cache['k'].shape[0]!=batch: raise ValueError('cache batch mismatch')
            k=torch.cat([cache['k'],k],dim=2); v=torch.cat([cache['v'],v],dim=2)
        allowed=torch.arange(k.shape[2])[None,:]<=torch.arange(offset,offset+time)[:,None]
        scores=q@k.transpose(-2,-1)/(self.width//self.heads)**.5
        weights=torch.softmax(scores.masked_fill(~allowed,float('-inf')),dim=-1)
        mixed=(weights@v).transpose(1,2).contiguous().reshape(batch,time,self.width)
        x=x+self.projection(mixed); x=x+self.feed(self.norm2(x))
        return self.output(x),{'k':k.detach(),'v':v.detach()}
torch.manual_seed(7); model=TinyDecoder(); model.eval(); count=sum(p.numel() for p in model.parameters())
assert 0<count<50000

Expected: parameter count below50000.

Example B: Trace output axes#

Every input position produces a distribution over the same sixteen-token vocabulary. The time axis is not a class axis and must not be reduced accidentally.
