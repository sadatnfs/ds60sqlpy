# Plan 11-06: execute guide code samples

## Objective

Complete guide code blocks are executed in CI and fragments are explicitly
marked (HARD-03).

## Tasks

1. Tracer: `scripts/check_guide_examples.py` extracts fenced blocks from
   companion guides, classifies complete blocks versus annotated fragments,
   and runs complete Python blocks locally first.
2. Extend to SQL (against the course Postgres) and to the other languages in
   their worker images inside the ordinary CI groups.
3. Fix every failing sample; mark true fragments with a fence annotation.
4. Update the `guide_examples` ledger in `docs/track-qualification.md` and
   the matrix fields.

## Verification

- The harness passes locally for Python and in CI for the worker groups; the
  ledger names the executed scope.
