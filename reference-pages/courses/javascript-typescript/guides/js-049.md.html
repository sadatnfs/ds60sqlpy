js-049: Time series: dates, sorted lines and visible gaps#

Level and prerequisites#

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: js-048. This is the D3.js specialization within the JavaScript path. Use the original language and browser lessons whenever syntax or DOM behavior is unfamiliar.

Learning objectives#

Build a UTC line chart with a gap. Explain interpolation limits for irregular observations. Produce a chart whose data transformation, visual encoding and interaction can be explained and checked independently.

Purpose, vocabulary and mental model#

A time series associates measurements with times. A JavaScript Date represents an instant, while formatting can use local time or UTC. If the lesson uses UTC dates, use UTC parsing, scales and formatting consistently so a chart does not shift a day in another time zone.

A line connects observations in the supplied order. D3 does not automatically sort your records by time. Connecting unsorted points can produce a zigzag that implies a path the data never took. Sorting a copy preserves the source order when other code owns the original data.

Missing intervals deserve visible treatment. A line generator’s defined predicate can break a path at missing observations. Connecting across a long outage can imply continuous measurement when none exists. Explain whether a gap means missing data, no activity or a deliberate sampling interval.

Syntax anatomy and mechanism#

d3.scaleUtc maps instants to x positions. A line generator uses x and y accessors to produce an SVG path string. .defined(d => Number.isFinite(d.value)) controls which records form continuous segments. Set fill: none for an ordinary line so the path is not treated as a filled polygon.

A null value must be rejected explicitly because Number(null) becomes zero. Sorting and missingness policies are data decisions, not merely chart styling. The reference checks ordering and the number of separate path segments in a small fixture.

Worked example / walkthrough#

Worked example 1: Use explicit UTC instants#

The Z suffix makes the time zone unambiguous.

const a=new Date("2024-01-01T00:00:00Z");
const b=new Date("2024-01-02T00:00:00Z");
console.log((b-a)/86400000);

Expected observation: 1 day for these two instants.

Worked example 2: Break a line at missing data#

This fragment uses already defined x and y scales.

const line=d3.line().defined(d=>d.value!==null).x(d=>x(d.date)).y(d=>y(d.value));

Expected observation: A null observation splits the line instead of drawing a false zero or connecting through it.

Debugging and common mistakes#

Keep three checkpoints separate: the records after parsing, the domain and geometry after transformation, and the visible marks after rendering. A chart can look plausible while silently dropping records or assigning the wrong scale. Inspect counts, IDs, finite coordinates and meaningful expected values before adjusting colors. A missing mark may come from invalid input, a missing selection, an undefined scale result or clipping outside the viewBox.

The controlled failure for this lesson is: Diagnose a line that doubles back in time. Its distinguishing evidence is Input order is unsorted or dates were parsed incorrectly. Preserve that failing case when repairing your program. Do not remove an assertion or broaden a scale merely to hide a wrong input. Explain whether a changed value should affect the data, an encoding, a layout or only presentation.

Accessibility and interpretation#

Give the visualization a descriptive title and a short textual summary of the main result. Keep a table or list when exact values matter. Do not encode a critical category only through color; use labels, shapes or position as appropriate. Interactive controls need keyboard operation and clear focus, and motion should respect the user's reduced-motion preference. Automated DOM checks support, but do not replace, a real keyboard and assistive-technology review.

A data scientist must also defend the statistical meaning. State the population, units, aggregation, missing-value policy and uncertainty where relevant. Synthetic points illustrate a mechanism and do not establish a real-world finding. A beautiful visualization should make a valid claim easier to inspect, not make a weak claim appear certain.
