# tf-035: Comparing models with uncertainty

## Level and prerequisites

Advanced; approximately 135 minutes. Direct prerequisites: `tf-034`.

## Learning objectives

Use paired evidence and keep model selection separate from final assessment. The central investigation is concrete: Compare two saved prediction vectors on the same held-out IDs; use a seeded paired resampling calculation and trace which decisions consumed validation data. The finish condition is Paired differences are keyed by the same IDs, bootstrap samples preserve pairs, and no test result is used to choose a new configuration.

## Purpose and mental model

A model comparison should preserve pairing: both models predict the same held-out identities. Subtract each record loss before summarizing so shared difficulty remains represented. Resampling the pairs approximates variability under a stated sampling assumption; resampling each model separately discards their dependence. A fixed seed makes the teaching calculation reproducible, but it does not make a small sample representative. If related observations share a group, resample groups rather than pretending every row is independent. Model selection belongs on validation data. Opening the final test and then changing configuration consumes it as a selection source, even if the resulting number is still called test error.

## Vocabulary and concepts

**Paired difference:** Loss A minus loss B for the same observation.

**Bootstrap:** Resampling observed units with replacement.

**Selection leakage:** Using assessment outcomes to choose the evaluated configuration.

## Syntax anatomy and reasoning sequence

Align dictionaries by stable IDs and verify equal key sets. Compute per-ID squared errors for each model and their difference. np.random.default_rng provides a local seeded generator. Sample integer indices with replacement and apply the same indices to the paired difference vector. A percentile interval describes this resampling calculation under its assumptions, not a universal confidence guarantee.

## Compare predictions on the same observational units

The fixture aligns both models to the same three IDs before comparing their
errors. Its paired error differences are [-1, 0, -1], with mean \(\frac{-2}{3}\) under
the declared subtraction convention. A negative difference favors the
candidate in that convention. Write the sign rule beside the statistic so a
better score cannot be mistaken for a worse one.

Resampling this vector keeps the comparison paired: each selected unit brings
both models' outcomes together. Independently resampling the two error lists
would break their covariance and answer a different uncertainty question.
If units are clustered by customer or document family, resample at the
appropriate independent-unit level rather than automatically treating every
row as an independent draw.

The fixed random seed makes the resampling calculation repeatable. It does
not make three observations representative, create additional independent
data or remove uncertainty about deployment conditions. Repeated bootstrap
draws reuse the same three pieces of observed information. Report that small
sample size and the attainable distribution alongside any interval.

Require the full expected ID set before comparing scores. An inner join that
silently drops missing candidate predictions can make a failing model look
better. Decide how missing predictions count and report them. Use validation
comparisons for selection, then assess the selected configuration on a
preserved final test. If the final test drives another choice, it has become
part of selection and cannot remain an untouched final assessment.

## Worked example / walkthrough

### Example A: Align by identity

Dictionary insertion order is not an alignment contract. Joining by IDs keeps each difference attached to the same target record.

```python
import numpy as np

truth = {"a": 0.0, "b": 1.0, "c": 2.0}
a = {"a": 0.0, "b": 2.0, "c": 2.0}
b = {"c": 3.0, "a": 1.0, "b": 2.0}
ids = sorted(truth)
diff = np.array([(a[i] - truth[i]) ** 2 - (b[i] - truth[i]) ** 2 for i in ids])
np.testing.assert_array_equal(diff, [-1, 0, -1])
```

**Expected:** paired differences [-1, 0, -1].

### Example B: Calculate the mean difference

The sign depends on the declared subtraction order. A negative A-minus-B loss difference favors A for this metric and sample only.

```python
import numpy as np

truth = {"a": 0.0, "b": 1.0, "c": 2.0}
a = {"a": 0.0, "b": 2.0, "c": 2.0}
b = {"c": 3.0, "a": 1.0, "b": 2.0}
ids = sorted(truth)
diff = np.array([(a[i] - truth[i]) ** 2 - (b[i] - truth[i]) ** 2 for i in ids])
np.testing.assert_array_equal(diff, [-1, 0, -1])
np.testing.assert_allclose(diff.mean(), -2 / 3, atol=1e-12, rtol=0)
```

**Expected:** mean \(\frac{-2}{3}\); model A has lower MSE on this fixture.

## Common pitfalls and diagnosis

For a suspicious improvement, verify the ID sets and subtraction
direction first. For an implausibly narrow interval, inspect the independent
unit and whether paired errors were separated. Reproducing a seeded vector
checks computation, not sampling validity. Record missing predictions rather
than dropping them through an inner join.
