# Profile interval roots and boundary cases

Start with: tmb-029.

Outcome: Find confidence endpoints by a stated likelihood-rise equation.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A profile interval endpoint solves \(f_p(t)-f_p(\hat t)=c\), where \(c\) is a chosen NLL rise. `tmbroot` targets those roots directly. In contrast, `tmbprofile` computes a curve useful for inspection and its confidence method interpolates crossings. Root finding and curve construction serve related but distinct purposes.

The default target is half a 95% chi-square-one quantile. That calibration assumes a regular interior scalar parameter and an appropriate large-sample likelihood-ratio approximation. It is not a universal 95% guarantee for variance boundaries, unidentified mixture components or sparse event data.

### Worked case A: a known-variance normal mean

For observations with known standard deviation \(\sigma\), the NLL rise is \(n(\mu-\bar y)^2/(2\sigma^2)\). Solving for the cutoff yields endpoints \(\bar y\pm\sigma\sqrt{2c/n}\). The companion compares this formula to `uniroot` results. This is an independent oracle for a small native `tmbroot` test.

A root solver needs an interval that brackets the target. If both ends of the requested parameter range stay below the cutoff, the data and requested range have not supplied a finite endpoint. Increasing an arbitrary range until a number appears is not a substitute for understanding a flat or unbounded likelihood.

### Worked case B: constrained domain

A positive parameter may have a lower boundary at zero. The companion shows a quadratic profile centered near that boundary and identifies when an unconstrained lower endpoint would be negative. Simply truncating that endpoint changes the coverage behavior. The appropriate likelihood-ratio reference distribution can differ at a boundary; explain the inferential method instead of labeling every clipped interval 95%.

`tmbroot` accepts named or linear-combination targets, parameter ranges and continuation controls. Record the target, domain and whether both endpoints converged. Root-finding numerical tolerance is distinct from statistical interval accuracy.

### Answered discussion

**Why inspect a profile if roots are faster?** The profile can expose asymmetry, multiple regions and optimizer failures that two endpoints hide. **Can a root interval cross a different likelihood basin?** It can if the profiling path switches modes. Multiple starts and curve inspection may be necessary. **Does a finite endpoint imply an identified parameter?** No. Check the underlying profile, optimizer and sensitivity to the domain.

See [tmbroot in the TMB manual](https://cran.r-project.org/web/packages/TMB/TMB.pdf). Keep the numerical equation and statistical cutoff visible in every reported interval.

### Complete R companion

```r
y <- c(1, 2, 4, 7);sigma <- 2;n <- length(y);center <- mean(y);cutoff <- .5 * qchisq(.95, 1)
rise <- function(mu) n * (mu - center)^2 / (2 * sigma^2) - cutoff
roots <- c(uniroot(rise, c(center - 10, center))$root, uniroot(rise, c(center, center + 10))$root)
exact <- center + c(-1, 1) * sigma * sqrt(2 * cutoff / n)
print(rbind(roots = roots, exact = exact));stopifnot(max(abs(roots - exact)) < 1e-4)
print(c(unconstrained_lower = .1 - 1.96 * .2, positive_domain_boundary = 0))
```
