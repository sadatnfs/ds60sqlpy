# dbt-013: Selectors, graph expansion and state comparison

## Level and prerequisites

Advanced. Direct prerequisites: `dbt-003`, `dbt-004`

**Outcome:** Construct and inspect a reproducible selection against an explicit baseline.

## Question and mechanism

Selection controls which resources a command considers. A tag-based selection expresses a group chosen by project metadata; graph operators expand to related resources. State selection compares current project metadata with a saved manifest. These mechanisms can reduce work, but they are not themselves tests of scientific correctness or deployment safety.

The first case tags a base model and selects it with its downstream dependent. The unrelated model is excluded. The second saves a manifest, changes one source file and uses state:modified+ to include the changed model and its downstream consumer. The selected set is inspected explicitly before any claim about reduced validation is made.

A state comparison depends on the baseline manifest. Keeping that baseline inside the directory that the next command overwrites can destroy the comparison. Save it separately with its source revision and environment identity. Also distinguish a changed definition from changed underlying data: a source can receive new records while the model file remains unchanged.

## Syntax and data contract

ls returns the selected resource list without running model transformations. tag:feature+ adds downstream graph expansion. state:modified+ compares definitions against --state and includes downstream resources. The program uses --resource-type model and --output name so its expected set is explicit. Keep state artifacts outside the active target output directory.

## Worked case 1: Select a tagged subgraph

The first project has a tagged base model, its child and an unrelated model. The actual list result must contain exactly base and child. This validates selection semantics without treating the selection as an executed data test.

**Expected evidence:** The selected model names are base and child.

```python
import os
import tempfile
from pathlib import Path

import yaml


def project(directory, models=None, seeds=None, schema=None, snapshots=None, macros=None):
    os.environ["DBT_SEND_ANONYMOUS_USAGE_STATS"] = "false"
    os.environ["DBT_USE_COLORS"] = "false"
    os.environ["DO_NOT_TRACK"] = "true"
    root = Path(directory) / "project"
    root.mkdir(parents=True)
    for folder in ("models", "seeds", "snapshots", "macros"):
        (root / folder).mkdir()
    config = {
        "name": "classroom",
        "version": "1.0",
        "config-version": 2,
        "profile": "classroom",
        "model-paths": ["models"],
        "seed-paths": ["seeds"],
        "snapshot-paths": ["snapshots"],
        "macro-paths": ["macros"],
    }
    (root / "dbt_project.yml").write_text(yaml.safe_dump(config))
    output = {
        "type": "duckdb",
        "path": str(root / "warehouse.duckdb"),
        "schema": "main",
        "threads": 1,
        "settings": {"threads": 2, "memory_limit": "256MB"},
    }
    (root / "profiles.yml").write_text(
        yaml.safe_dump({"classroom": {"target": "dev", "outputs": {"dev": output}}})
    )
    for name, sql in (models or {"answer": "select 42::integer as answer"}).items():
        (root / "models" / (name + ".sql")).write_text(sql)
    for name, csv in (seeds or {}).items():
        (root / "seeds" / (name + ".csv")).write_text(csv)
    if schema:
        (root / "models/schema.yml").write_text(yaml.safe_dump({"version": 2, **schema}))
    if snapshots:
        (root / "snapshots/snapshots.yml").write_text(
            yaml.safe_dump({"version": 2, "snapshots": snapshots})
        )
    for name, sql in (macros or {}).items():
        (root / "macros" / (name + ".sql")).write_text(sql)
    return root


def invoke(root, *arguments, succeeds=True):
    from dbt.cli.main import dbtRunner

    result = dbtRunner().invoke(
        [
            "--quiet",
            "--no-use-colors",
            "--no-send-anonymous-usage-stats",
            *arguments,
            "--project-dir",
            str(root),
            "--profiles-dir",
            str(root),
            "--no-partial-parse",
        ]
    )
    if succeeds:
        assert result.success, str(result.exception)
    else:
        assert not result.success, "The deliberately invalid fixture was accepted."
    return result


def names(result):
    return [str(value) for value in result.result]


def example_one():
    with tempfile.TemporaryDirectory() as d:
        p = project(
            d,
            models={
                "base": "{{ config(tags=['feature']) }} select 1 as x",
                "child": "select x+1 as x from {{ ref('base') }}",
                "unrelated": "select 9 as x",
            },
        )
        invoke(p, "parse")
        selected = names(
            invoke(
                p, "ls", "--select", "tag:feature+", "--resource-type", "model", "--output", "name"
            )
        )
        assert set(selected) == {"base", "child"}, selected
        return {"selected_models": sorted(selected)}


if __name__ == "__main__":
    print(example_one())
```


## Worked case 2: Compare against a saved manifest

The second case saves a prior manifest before editing base.sql. The state selector includes the modified base and its dependent child. The baseline remains separate from the command's new target artifacts.

**Expected evidence:** Changed and downstream selection contains both models.

```python

import shutil
import tempfile
from pathlib import Path

import yaml


def project(directory, models=None, seeds=None, schema=None, snapshots=None, macros=None):
    os.environ["DBT_SEND_ANONYMOUS_USAGE_STATS"] = "false"
    os.environ["DBT_USE_COLORS"] = "false"
    os.environ["DO_NOT_TRACK"] = "true"
    root = Path(directory) / "project"
    root.mkdir(parents=True)
    for folder in ("models", "seeds", "snapshots", "macros"):
        (root / folder).mkdir()
    config = {
        "name": "classroom",
        "version": "1.0",
        "config-version": 2,
        "profile": "classroom",
        "model-paths": ["models"],
        "seed-paths": ["seeds"],
        "snapshot-paths": ["snapshots"],
        "macro-paths": ["macros"],
    }
    (root / "dbt_project.yml").write_text(yaml.safe_dump(config))
    output = {
        "type": "duckdb",
        "path": str(root / "warehouse.duckdb"),

    for name, csv in (seeds or {}).items():

            yaml.safe_dump({"version": 2, "snapshots": snapshots})
        )
    for name, sql in (macros or {}).items():
        (root / "macros" / (name + ".sql")).write_text(sql)
    return root


def invoke(root, *arguments, succeeds=True):
    from dbt.cli.main import dbtRunner

    result = dbtRunner().invoke(
        [
            "--quiet",
            "--no-use-colors",
            "--no-send-anonymous-usage-stats",
            *arguments,
            "--project-dir",
            str(root),
            "--profiles-dir",
            str(root),
            "--no-partial-parse",
        ]
    )
    if succeeds:
        assert result.success, str(result.exception)
    else:
        assert not result.success, "The deliberately invalid fixture was accepted."
    return result


def names(result):
    return [str(value) for value in result.result]


def example_two():
    with tempfile.TemporaryDirectory() as d:
        p = project(
            d, models={"base": "select 1 as x", "child": "select x+1 as x from {{ ref('base') }}"}
        )
        invoke(p, "parse")
        state = p / "previous_state"
        state.mkdir()
        shutil.copyfile(p / "target/manifest.json", state / "manifest.json")
        (p / "models/base.sql").write_text("select 2 as x")
        selected = names(
            invoke(
                p,
                "ls",
                "--state",
                str(state),
                "--select",
                "state:modified+",
                "--resource-type",
                "model",
                "--output",
                "name",
            )
        )
        assert set(selected) == {"base", "child"}, selected
        return {
            "changed_and_downstream": sorted(selected),
            "state_is_not_a_quality_certificate": True,
        }


if __name__ == "__main__":
    print(example_two())
```


## Practice

Make each requested change in a saved copy. Compare both the expected result and the deliberately changed assumption. The separate reference explains the answers.


### 1. Remove graph expansion

Select tag:feature without the plus suffix.

**Check:** Only the explicitly tagged model is selected.

**Hint:** Tags and dependency traversal are different operations.


### 2. Add an unrelated change

Edit the unrelated model and inspect state selection.

**Check:** The changed node appears under the matching state selector.

**Hint:** Compare with the saved manifest.


### 3. Protect the baseline

Store prior manifest data outside target/.

**Check:** The next invocation does not overwrite it.

**Hint:** The active output directory is mutable.


### 4. Change only data

Explain why new source rows can matter without a model-file edit.

**Check:** The answer distinguishes definitions from data state.

**Hint:** state:modified is not a data freshness check.


### 5. Inspect selected tests

Include tests and examine the resource types returned.

**Check:** The intended tests are visible in the selection.

**Hint:** Selecting models is not proof of test inclusion.


### 6. Record a CI decision

List the evidence needed to justify a reduced build.

**Check:** It includes baseline, selection, dependencies and executed results.

**Hint:** A selection plan is only one stage.


## Diagnose errors and misleading results

Unexpectedly small selections can result from tags, graph direction, indirect-test rules or an overwritten baseline. Inspect ls output before executing a destructive or expensive command. A successful selector command with zero intended resources is not a completed validation.
