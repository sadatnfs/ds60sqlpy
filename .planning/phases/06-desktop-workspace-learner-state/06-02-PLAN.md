<objective>
Close the one real draft-loss path found by research (S1, classroom.js:1313-1342):
a stale localStorage backup silently overwriting a newer server draft, which
for single-slot module drafts (D-02, modules.py:360-437) is unrecoverable
(STATE-01, ROADMAP Phase 6 success criterion 3).

Purpose: restore stays automatic when it is provably safe and becomes a learner
choice when it is not. Nothing is ever deleted without an explicit confirm.

Output: fingerprinted backups, a non-destructive conflict panel, pure helper
tests and 5 harness checks. Plus the missing harness proof that a module
history click never executes (research gap T1).

Decisions honored: D-02 (single module slot stays; this plan is the fix),
D-05 (no dashes in copy), D-07 (the existing silent-recovery test is updated
deliberately to the new non-destructive behavior, not deleted or loosened),
D-08.

Deviation from research Pattern 2, recorded on purpose: the fingerprint is a
synchronous 53-bit string hash (cyrb53) instead of `crypto.subtle.digest`.
Restore runs inside the synchronous part of `openLesson` and the
`beforeunload` stash must be synchronous; an async digest would reorder
existing harness timing (settle() only drains microtasks) and could miss a
stash at unload. The fingerprint is a change detector, not a security control;
a collision only falls back to the old silent-restore behavior. The server
exposes no draft `updated_at` (grep of modules.py finds none), so the stash's
own `saved_at` is the recorded time.
</objective>
