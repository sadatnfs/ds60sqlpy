## Purpose and mental model

Inference is a function with a data contract, not just a call to model.predict. The model expects a nonempty batch of two finite float32 features per record and accepts at most four records. Inputs outside that boundary should receive named failures rather than silent coercion. Batching should preserve record identity: predicting one record alone or alongside others should give the same result for this stateless model. This local contract does not start a server or claim security isolation. It establishes a small, reviewable boundary that an eventual service would need to enforce consistently.

## Vocabulary and concepts

**Inference contract:** Accepted inputs and guaranteed output structure for prediction.

**Batch limit:** Maximum number of observations accepted in one call.

**Finite value:** A numeric value that is neither NaN nor infinity.

## Syntax anatomy and reasoning sequence

np.asarray inspects the incoming data without automatically changing its dtype. Check rank, feature width, batch limit and finiteness before converting to a tensor. A fixed coefficient vector[2,-1] gives an independent expected output. Returning a new array prevents a caller from mutating stored input through a shared view. Validation order should make errors predictable enough to diagnose.

## Turn a tensor function into an explicit prediction contract

An inference boundary defines what callers may submit before the model
executes. The lesson checks rank, feature width, dtype, finite values and a
bounded batch size. Each condition prevents a different ambiguity: a flat
vector lacks an explicit batch axis, a different width changes the feature
schema, and NaNs can propagate through otherwise valid matrix operations.
Validate the whole request before publishing a partial result.

Shape alone does not encode meaning. Two columns representing age in years
and income in dollars cannot be swapped merely because both are float32.
Changing dollars to thousands of dollars also preserves shape while changing
the numerical problem. Store feature names, order, units and preprocessing
version with the model's input contract.

The fixture's fixed stateless model predicts each row independently. Its
result for a batch should match concatenated results for the same rows split
into smaller batches, within the declared tolerance. This is a useful
metamorphic check because it changes execution grouping without changing
the intended examples. It is not a universal property of every network:
training-mode batch normalization, stochastic layers or cross-example
operations can make a row depend on its neighbors.

The input array should remain unchanged after prediction. Mutating a caller's
buffer during normalization can make repeated requests behave differently
or contaminate another consumer. Compare a before/after copy in this bounded
fixture. Request validation and deterministic batching establish this local
function contract; a deployed service additionally needs measured capacity,
concurrency, lifecycle and operational behavior.

## Worked example / walkthrough

### Example A: Predict a valid batch

The reference coefficient vector makes output arithmetic transparent. Shape validation ensures the result is one scalar per input record.

```python
import numpy as np
import tensorflow as tf
def predict(values):
    x=np.asarray(values)
    if x.dtype!=np.float32: raise TypeError('float32 dtype required')
    if x.ndim!=2 or x.shape[1]!=2: raise ValueError('shape must be (batch,2)')
    if not 1<=len(x)<=4: raise ValueError('batch must contain 1..4 records')
    if not np.isfinite(x).all(): raise ValueError('finite values required')
    return (tf.constant(x)@tf.constant([[2.],[-1.]])).numpy()[:,0].copy()
x=np.array([[1,2],[3,4]],dtype='float32'); result=predict(x)
np.testing.assert_array_equal(result,[0,2]); assert result.shape==(2,)
```

**Expected:** outputs 0,2 with shape(2,).

### Example B: Compare batch independence

A stateless affine model should not depend on neighboring records. A training-mode normalization layer could violate this behavior, so the test is valuable when the implementation grows.

```python
import numpy as np
import tensorflow as tf
def predict(values):
    x=np.asarray(values)
    if x.dtype!=np.float32: raise TypeError('float32 dtype required')
    if x.ndim!=2 or x.shape[1]!=2: raise ValueError('shape must be (batch,2)')
    if not 1<=len(x)<=4: raise ValueError('batch must contain 1..4 records')
    if not np.isfinite(x).all(): raise ValueError('finite values required')
    return (tf.constant(x)@tf.constant([[2.],[-1.]])).numpy()[:,0].copy()
x=np.array([[1,2],[3,4]],dtype='float32'); result=predict(x)
np.testing.assert_array_equal(result,[0,2]); assert result.shape==(2,)
single=np.concatenate([predict(x[i:i+1]) for i in range(2)])
np.testing.assert_array_equal(single,result)
```

**Expected:** exact equality for this fixed linear fixture.

## Common pitfalls and diagnosis

A batch-versus-singleton mismatch first calls for checking model
mode and cross-example operations. A repeated-call mismatch calls for checking
input mutation and hidden state. Reject invalid rank, width or nonfinite
values at the named boundary so the learner sees the violated contract,
not a later opaque matrix-multiplication exception.
