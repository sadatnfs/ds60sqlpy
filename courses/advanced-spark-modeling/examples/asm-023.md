# Worked reference: Idempotent clamp proof

This is an editable reading/project reference. It has no ordinary pad Run action.

For BIGINT x, define c(x)=max(x,0), preserving null. If x<0, both c(c(x)) and c(x) are zero. If x>=0, both are x. If x is null, both are null. No arithmetic overflows because comparison and selection do not add or multiply.

The probe uses a range-backed column so local-table constant folding does not erase the expression before the custom rule is inspected. It expects two typed nodes in the analyzed plan and one in the optimized plan, plus identical boundary outputs. This structural observation supplements the proof; it does not replace it.
