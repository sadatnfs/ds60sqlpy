# Worked reference: Stable expression value table

This is an editable reading/project reference. It has no ordinary pad Run action.

| Input | Expected finite-domain result |
| --- | --- |
| -1000.0 | 0.0 to double precision |
| 0.0 | log(2), approximately 0.6931471805599453 |
| 1000.0 | 1000.0 |
| null | null |

The project evaluates this table with whole-stage code generation enabled and disabled. Both paths must agree. The table does not qualify NaN/infinity extensions or another Spark binary version. Preserve generated-source output when investigating a mismatch.

See `courses/advanced-spark-modeling/projects/catalyst/README.md` for the bounded offline Docker command. The project compiles its two Scala sources before running the exact-version probe.
