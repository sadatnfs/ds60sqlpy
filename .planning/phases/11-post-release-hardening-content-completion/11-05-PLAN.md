# Plan 11-05: publish the scientific project images from GitHub Actions

## Objective

The qualified scientific images (spark-torch, spark-tmb, tmb-public-api,
tmb-cpp-api) are pushed to Docker Hub with multi-arch manifests only by
`publish-images.yml`, gated by the same scan policy as the course images
(HARD-05).

## Tasks

1. Tracer: extend `scripts/ci_scientific_projects.py` and the
   `scientific-projects` job with a scan-gated push of each per-arch image and
   a manifest step that joins AMD64 and ARM64 under the release version.
2. Keep release metadata within its size bound and record the pushed digests
   in the scientific receipts.
3. Document the published names in `docs/dockerhub.md` and the README.
4. Tests cover the new push and manifest commands without a registry.

## Verification

- Publish run pushes the four scientific images; `docker buildx imagetools
  inspect` shows both architectures; nothing is pushed from a local machine.
