Maintain prose, practice and direct prerequisites in units.json. Complete bounded
programs are maintained in ../references/. The local service project in
../projects/local-system/ is separate maintained source with its own Docker
lifecycle and persistent owned state. Ordinary classroom pads remain fresh,
short-lived and offline after dependency preparation.

Run `python courses/ml-engineering/authoring/build.py`, then --check from the
repository root. This directory also owns publish.py, the shared publisher for
Polars, dbt and this route. Format references before generating. Root's shared
reader/TeX generation is separate. Do not reintroduce task-local construction
scripts as product generators or maintain duplicate sources.

Execute actual Feast historical and online operations, MLflow tracking/registry
readback, model inference and ASGI checks. Preserve the authoritative request
population when a feature backend drops unmatched rows. Track event, availability,
prediction and label-availability clocks separately. The synthetic sequence uses
hours. Never describe a fixture score as validation for a real deployment.

Use the worker figure wrapper for plotted references. Never launch host browser
windows from Plotly.show during verification. Two plot/report outputs share the
classroom budget. The service checker verifies actual Docker and loopback HTTP
separately; mocks or TestClient cannot qualify container routing and restart.

Preserve no-network ordinary examples, local tracking and registry URIs, disabled
usage telemetry, bounded artifacts, finite/schema validation, read-only serving
state and CLI-only administration. All test cleanup is ownership-scoped.
