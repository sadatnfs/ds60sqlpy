llm-010: Position, order and tokenwise normalization#

Level and prerequisites#

Beginner; approximately 105 minutes. Direct prerequisites: llm-009. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

Learning objectives#

Explain why content attention alone does not identify position and preserve causal normalization. The central investigation is concrete: Jointly permute Q, K and V for unmasked content-only attention, then add a fixed position table. Separately compare tokenwise LayerNorm with sequence-wide normalization under causal-prefix checks. The finish condition is Without positions or a causal mask, jointly permuting inputs permutes outputs. A causal mask itself imposes an order boundary. Sequence-wide normalization can change earlier prefix values and is rejected for this decoder. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

Purpose and mental model#

Keep content, location and visibility as separate ideas#

A useful way to reason about sequence models is to ask three questions about each token occurrence. What features describe its current content? Where does it occur relative to other tokens? Which other positions is it permitted to read? An embedding addresses the first question, positional information contributes to the second, and an attention mask controls the third. All three can influence an output, but they do so through different mathematical operations. Treating them as one vague notion of "sequence awareness" makes implementation mistakes difficult to diagnose.

Consider moving tokens between rows of an unmasked attention input. If their queries, keys and values move together, the same content comparisons still occur, just under different row and column labels. The output vectors follow the moved token identities. This is equivariance: the output changes in the same structured way as the input. It is different from invariance, where the output would remain unchanged. A classifier that averages all token outputs might later be invariant to some rearrangements even though its attention layer itself is equivariant.

A fixed causal triangle changes that thought experiment. The first row has one permitted source, the second has two and later rows have larger prefixes. Moving content between those locations changes which information is available. The mask therefore imposes an order on visibility, yet does not directly tell the layer that two accessible tokens are three positions apart. A position vector or relative-position rule can supply that extra distinction. In a learned absolute table, position zero and position one have different parameter rows; in later relative methods, the relationship between positions enters the attention calculation more directly.

Normalization addresses another problem: the scale and offset of a token's numeric features can vary as transformations are composed. For a two-feature token [1,3], the mean is 2, the deviations are [-1,1], and the population variance across its features is 1. Dividing by 1+ϵ\sqrt{1+\epsilon}1+ϵ​ produces a centered representation with controlled scale. These are statistics of one token's feature vector, not estimates from two independent people or documents. That is why the reduction axis and denominator follow a layer definition rather than a statistical sample-variance convention.

The causal consequence becomes visible when comparing that operation with a reduction across time. If a future token changes from [10,20] to [1000,2000], tokenwise normalization leaves the first token's mean and variance unchanged. A time-wide mean does not: the future values enter the statistic applied to the first token. The subsequent causal attention mask cannot remove information already embedded in its input. The first row's single allowed attention weight is one, so it simply passes along that contaminated value representation.

This chapter's permutation and normalization experiments are useful whenever an implementation has plausible shapes but uncertain semantics. Shapes tell us which operations are possible; labels on the axes tell us what those operations mean. A reduction over the wrong axis can return exactly the expected shape and still violate the prediction task. The detailed calculations below make that difference visible before we assemble a deeper decoder.

Vocabulary and concepts#

Permutation equivariance: Reordering inputs produces the corresponding reorder of outputs, rather than necessarily leaving outputs unchanged.

Positional representation: Information attached to positions or position relationships, distinct from token content.

Causal visibility: A rule forbidding a query from reading future key positions.

Reduction axis: The array dimension over which a statistic combines values.

Prefix invariance: Earlier outputs are unchanged when future tokens are appended or changed under the stated causal computation.

Epsilon: A positive denominator stabilizer that also slightly changes normalized variance.

Syntax anatomy and reasoning sequence#

Use the shape convention Q:[Tq,Dk], K:[Tk,Dk], V:[Tk,Dv]. Scores have shape [Tq,Tk], one comparison for each query/key pair. Row-wise softmax reduces the key axis, so every query receives a distribution over allowed keys. Multiplying weights [Tq,Tk] by V [Tk,Dv] gives output [Tq,Dv]. The key and value row counts must match because each attention weight selects a corresponding value row. Query count need not equal key count in cross-attention, although this lesson's main self-attention fixture uses both equal to three.

The score rule is S=QKTDkS=\frac{QK^{\mathsf T}}{\sqrt{D_k}}S=Dk​​QKT​. Stable softmax subtracts each row maximum before exponentiation. Subtracting a common row constant preserves the normalized probabilities, while reducing the risk of overflow. A Boolean allowed matrix has the score shape. Forbidden scores become negative infinity, giving zero exponential mass. Each query needs at least one allowed key: an all-forbidden row has no normalized distribution and is rejected instead of silently producing NaN.

For feature normalization of X:[B,T,D], the mean and variance have shape [B,T,1]. They reduce only D, leaving batch and token dimensions distinct. keepdims=True retains the singleton axis so subtraction broadcasts over the intended features. The variance here divides by D, not D-1, because the operation normalizes the features of this token rather than estimating a population variance from independent sampled cases. The output has the same shape as X. Its mean is zero up to floating-point error; its variance is σ2σ2+ϵ\frac{\sigma^2}{\sigma^2+\epsilon}σ2+ϵσ2​, not exactly one when epsilon is positive.

Deriving the permutation identity#

Let P be a permutation matrix reordering token rows. Replacing Q,K,V by P Q,P K,P V gives scores P S PT{P}^{T}PT. This reorders both the query rows and the key columns. A row-wise softmax commutes with those reorders: softmax⁡(PSPT)=Psoftmax⁡(S)PT\operatorname{softmax}(PSP^{\mathsf T})=P\operatorname{softmax}(S)P^{\mathsf T}softmax(PSPT)=Psoftmax(S)PT. The output is therefore Psoftmax⁡(S)PTPV=Psoftmax⁡(S)VP\operatorname{softmax}(S)P^{\mathsf T}PV=P\operatorname{softmax}(S)VPsoftmax(S)PTPV=Psoftmax(S)V, because PT{P}^{T}PT P is the identity. Reordering only Q, or forgetting to reorder V with K, is a different experiment and does not test this identity.

If a mask M is present, the corresponding relabelling identity requires reordering the mask too, as P M PT{P}^{T}PT. Keeping a causal triangle fixed is intentionally different: it keeps the visibility graph attached to row positions while moving content. Similarly, adding a fixed position table E gives input P X + E after a content reorder, while a pure reorder of the original positioned input would be P(X+E)=PX+PEP(X+E)=PX+PEP(X+E)=PX+PE. Unless E happens to remain unchanged under P, those expressions differ.

Worked values and a full-path failure diagnosis#

For the three-token attention fixture, the weight rows are approximately [0.40111209,0.19777581,0.40111209], [0.19777581,0.40111209,0.40111209] and [0.24825508,0.24825508,0.50348984]. Multiplication by V gives [3,4], [3.40667256,4.40667256] and [3.51046953,4.51046953]. These rounded values are for inspection; the assertions use the underlying arithmetic with a stated float64 tolerance. A row permutation changes the array order of these outputs, not the relationships attached to token identities.

The first normalization fixture deliberately uses only two features, making every statistic calculable by hand. Row [10,20] has mean 15 and variance 25, so its result is [−5,5]25+1×10−5\frac{[-5,5]}{\sqrt{25+1\times10^{-5}}}25+1×10−5​[−5,5]​. Replacing that row with [1000,2000] changes its own mean to 1500 and variance to 250000. The first row's mean remains 2 and variance remains 1. In contrast, reducing axis=0 replaces per-token statistics with one statistic per feature across time. The output shape can still be [T,D], so a shape-only test does not catch this semantic mistake.

A causal-prefix test must rerun the whole path on the prefix. Slicing the already computed full result merely reuses any leaked statistics and cannot detect their source. Example C below first normalizes each token and proves prefix equality through masked attention. It then centers across the full time axis before attention and shows the first output disagrees with a separately recomputed one-token prefix. For the first causal row, the only allowed attention weight is one, so its output equals its preprocessed value row. This makes upstream leakage impossible for the attention mask to hide.

This reasoning is local to the specified computation. It does not claim that any normalization named LayerNorm is configured correctly, that a framework's default axis matches your layout, or that a long model has no other leakage path. Residual branches, preprocessing, pooling and cache offsets all deserve their own data-dependency checks. The connected Transformer walkthrough shows how these components fit into a full small decoder. The position chapter develops RoPE and relative biases, while normalization and gated feed-forward blocks derives their gradients and parameter choices.

When to use each mechanism#

Use a causal boundary when a prediction must depend only on its prefix. Use positional information when the model needs location or distance distinctions beyond content and visibility. Learned absolute tables need a defined maximum range; sinusoidal or rotary formulas can be evaluated at new positions but do not by themselves establish reliable long-context behavior. Choose tokenwise feature normalization when independent per-position statistics are intended. A sequence-wide reduction can be valid for a deliberately noncausal encoder or a summary statistic, but it changes the causal contract and should not enter this decoder accidentally.

LayerNorm's learned affine gain and bias are omitted here so the centering arithmetic is visible. If gain differs across features or bias is nonzero, the final affine output need not have zero mean even though the internal normalized values did. Epsilon prevents division by zero; it also weakens exact scale invariance near constant inputs. For x scaled by a positive factor a, the denominator contains a_squared times variance plus epsilon, so the result is not exactly unchanged unless epsilon is negligible or transformed consistently. These details matter when a unit test expects exact invariances that the implemented formula does not promise.

For the original normalization definition and learned gain/bias, read Layer Normalization. The examples and permutation derivation here are original small-array demonstrations.

Worked example / walkthrough#

Example A: Permute content-only attention#

The first query has scores [12,0,12][\frac{1}{\sqrt{2}},0,\frac{1}{\sqrt{2}}][2​1​,0,2​1​], so keys one and three receive equal weight. Their values are symmetric around [3,4], and the middle value is [3,4] itself, making the first weighted result exactly [3,4] in real arithmetic. The row permutation preserves these relationships. This is an unmasked calculation; a fixed causal triangle would change the experiment.

import numpy as np

def attention_parts(query, key, value, allowed=None):
    query = np.asarray(query, dtype=np.float64)
    key = np.asarray(key, dtype=np.float64)
    value = np.asarray(value, dtype=np.float64)
    if any(array.ndim != 2 for array in (query, key, value)):
        raise ValueError('query, key and value must be rank-two matrices')
    if query.shape[1] == 0 or query.shape[1] != key.shape[1]:
        raise ValueError('query and key feature widths must match and be positive')
    if key.shape[0] == 0 or key.shape[0] != value.shape[0]:
        raise ValueError('every key must have one value row')
    if not all(np.isfinite(array).all() for array in (query, key, value)):
        raise ValueError('finite inputs required')
    if allowed is None:
        allowed = np.ones((query.shape[0], key.shape[0]), dtype=bool)
    else:
        allowed = np.asarray(allowed)
        if allowed.dtype != np.bool_ or allowed.shape != (query.shape[0], key.shape[0]):
            raise ValueError('allowed must be a Boolean query-by-key matrix')
    if not allowed.any(axis=-1).all():
        raise ValueError('each query needs at least one allowed key')
    scores = query @ key.T / np.sqrt(query.shape[-1])
    masked_scores = np.where(allowed, scores, -np.inf)
    shifted_scores = masked_scores - masked_scores.max(axis=-1, keepdims=True)
    mass = np.exp(shifted_scores)
    weights = mass / mass.sum(axis=-1, keepdims=True)
    output = weights @ value
    return scores, weights, output


def attention(query, key, value, allowed=None):
    return attention_parts(query, key, value, allowed)[2]

query = np.array([[1., 0.], [0., 1.], [1., 1.]])
value = np.array([[1., 2.], [3., 4.], [5., 6.]])
order = np.array([2, 0, 1])
scores, weights, original = attention_parts(query, query, value)
changed = attention(query[order], query[order], value[order])
np.testing.assert_allclose(changed, original[order], atol=1e-12, rtol=0)
scale = np.exp(1 / np.sqrt(2))
expected_first_weights = np.array([scale, 1, scale]) / (2 * scale + 1)
np.testing.assert_allclose(weights[0], expected_first_weights, atol=1e-12, rtol=0)
np.testing.assert_allclose(original[0], [3, 4], atol=1e-12, rtol=0)
assert scores.shape == weights.shape == (3, 3)
assert original.shape == (3, 2)

Expected: attention weights move with key identities; output follows the same row reorder; the first original output is [3,4].

Example B: Normalize each token#

For [1,3], the mean is 2, centered features are [-1,1], and the mean squared centered value is 1. The second token uses a different mean and variance, but neither statistic appears in the first token calculation. Altering the future row cannot change the first normalized row. Positive epsilon makes the magnitude slightly below one.

import numpy as np

def layer_norm(values, epsilon=1e-5):
    values = np.asarray(values, dtype=np.float64)
    if values.ndim < 1 or values.shape[-1] == 0:
        raise ValueError('a nonempty feature axis is required')
    if not np.isfinite(values).all() or not np.isfinite(epsilon) or epsilon <= 0:
        raise ValueError('finite inputs and positive finite epsilon are required')
    mean = values.mean(axis=-1, keepdims=True)
    variance = ((values - mean) ** 2).mean(axis=-1, keepdims=True)
    return (values - mean) / np.sqrt(variance + epsilon)

values = np.array([[1., 3.], [10., 20.]])
changed = values.copy()
changed[1] = [1000., 2000.]
normalized = layer_norm(values)
expected_first = np.array([-1., 1.]) / np.sqrt(1 + 1e-5)
np.testing.assert_allclose(normalized[0], expected_first, atol=1e-12, rtol=0)
np.testing.assert_allclose(layer_norm(changed)[0], normalized[0], atol=1e-12, rtol=0)
assert normalized.shape == values.shape

Expected: the first normalized row remains [−1,1]1+1×10−5\frac{[-1,1]}{\sqrt{1+1\times10^{-5}}}1+1×10−5​[−1,1]​, approximately [-0.999995,0.999995].

Example C: Recompute the entire causal prefix#

The one-token prefix has zero time-centered values, while the first row centered using future rows is nonzero. The first causal attention row reads only itself, so it exposes exactly that contaminated value. This is a test of the full preprocessing-plus-attention path, not only of the mask matrix.

Common pitfalls and diagnosis#

If the permutation test fails, first check whether Q, K and V were reordered consistently. Next inspect whether a position table, a mask or another row-dependent operation was held fixed. A test that changes only one of those ingredients cannot be interpreted as the unmasked content-only theorem. Inspect weights as well as outputs: a symmetric value fixture can hide a wrong weight permutation by accidentally producing the same mixture. Very large query/key norms can also make attention nearly one-hot on each self-match, reducing a mask-order difference below a loose comparison tolerance. Use moderate score magnitudes and non-identical value rows when designing the negative control.

If a prefix test fails, recompute preprocessing and normalization on the prefix rather than slicing their full-sequence results. Print the reduction axis and statistic shapes. For X:[B,T,D], a feature mean should be [B,T,1]; [B,1,D] mixes time. A causal triangle applied afterward cannot remove information already included in a value row. Use non-identical token rows and change a future row by a large controlled amount to make the dependency obvious.

If NaN appears, check finite inputs, positive epsilon and at least one allowed key per query. An all-masked softmax row is undefined under this contract. Do not replace its NaNs with zeros and call that normalization: that invents a new output policy. Constant feature rows are a different case and legitimately normalize to zero with positive epsilon. Finally, compare float64 arithmetic with the declared tolerance and keep exact identity/shape checks separate from approximate numerical checks.
