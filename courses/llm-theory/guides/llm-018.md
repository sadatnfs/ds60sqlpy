# llm-018: A bounded training loop with visible state

Status: authored beta content. The manifest inventories complete teaching files; runtime readiness remains a separate, measured property.

## Learning objectives

Implement forward, loss, zero_grad, backward and optimizer.step in the correct order. The central investigation is concrete: Train on at most 128 local sequences for at most 200 steps; log an initial loss and a gradient norm on a fixed diagnostic batch. The finish condition is Weights change after a real step; gradients do not accumulate accidentally. All loss/gradient values remain finite, and stopped budgets are reported without a convergence claim. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

## Purpose and mental model

A training loop changes model state through a controlled sequence: clear gradients, calculate logits, reduce loss over active targets, backpropagate, inspect gradients and apply one update. Without zeroing, gradients accumulate. Without optimizer.step, losses may be repeatedly computed while weights never change. A bounded loop records an exact update count and stops even if the model has not converged. This lesson trains a small literal transition task for twelve steps, well below the two-hundred-step ceiling. Finite losses and a changed parameter demonstrate a functioning update path; they do not demonstrate held-out language quality.

## Vocabulary and concepts

**Training step:** One gradient calculation followed by one optimizer update.

**Gradient norm:** A magnitude summary used to diagnose update scale.

**Step budget:** A hard upper bound on optimization work.

## Syntax anatomy and reasoning sequence

model.train() declares training behavior. Adam operates on model.parameters(). zero_grad(set_to_none=True) removes previous leaf gradients. Flatten logits and shifted labels for cross entropy. Compute a gradient norm after backward and before step. Snapshot parameters with detach().clone(), because a reference to the same tensor would change with the model and hide updates.

## Worked example / walkthrough

### Example A: Prepare a tiny training batch

The fixture is small enough to enumerate every target. The context length and vocabulary remain below the decoder limits.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
class TinyDecoder(nn.Module):
    def __init__(self,vocab=16,width=32,heads=2,context=32):
        super().__init__()
        self.vocab,self.width,self.heads,self.context=vocab,width,heads,context
        self.token=nn.Embedding(vocab,width); self.position=nn.Embedding(context,width)
        self.norm1=nn.LayerNorm(width); self.qkv=nn.Linear(width,3*width,bias=False)
        self.projection=nn.Linear(width,width,bias=False); self.norm2=nn.LayerNorm(width)
        self.feed=nn.Sequential(nn.Linear(width,2*width),nn.ReLU(),nn.Linear(2*width,width))
        self.output=nn.Linear(width,vocab,bias=False)
    def forward(self,ids,cache=None):
        if ids.ndim!=2 or ids.dtype!=torch.long or ids.shape[1]==0: raise ValueError('nonempty long batch,time IDs')
        offset=0 if cache is None else cache['k'].shape[2]
        batch,time=ids.shape
        if offset+time>self.context or torch.any(ids<0) or torch.any(ids>=self.vocab): raise ValueError('context or vocabulary limit')
        x=self.token(ids)+self.position(torch.arange(offset,offset+time))
        q,k,v=self.qkv(self.norm1(x)).chunk(3,dim=-1)
        def split(t): return t.reshape(batch,time,self.heads,self.width//self.heads).transpose(1,2)
        q,k,v=map(split,(q,k,v))
        if cache is not None:
            if cache['k'].shape[0]!=batch: raise ValueError('cache batch mismatch')
            k=torch.cat([cache['k'],k],dim=2); v=torch.cat([cache['v'],v],dim=2)
        allowed=torch.arange(k.shape[2])[None,:]<=torch.arange(offset,offset+time)[:,None]
        scores=q@k.transpose(-2,-1)/(self.width//self.heads)**.5
        weights=torch.softmax(scores.masked_fill(~allowed,float('-inf')),dim=-1)
        mixed=(weights@v).transpose(1,2).contiguous().reshape(batch,time,self.width)
        x=x+self.projection(mixed); x=x+self.feed(self.norm2(x))
        return self.output(x),{'k':k.detach(),'v':v.detach()}
torch.manual_seed(7); model=TinyDecoder(); ids=torch.tensor([[1,2,3,4],[2,3,4,5]]); inputs=ids[:,:-1]; targets=ids[:,1:]
assert tuple(inputs.shape)==(2,3) and targets.numel()==6
```

**Expected:** inputs shape(2,3);6 active targets.
