# c-022: Stacks, queues and ring-buffer invariants

## Level and prerequisites

## Purpose and mental model

A stack removes the most recently inserted value; a queue removes the earliest. The same array storage can support different behavioral contracts. A bounded ring buffer reuses positions by wrapping indices modulo capacity. Keep occupancy separate from index values so full and empty are not confused when head equals tail. Every enqueue must prove spare capacity before writing, and every dequeue must prove nonempty state before reading. Fixed capacity makes resource use predictable and overflow behavior explicit. A concurrent queue requires additional synchronization; the sequential ring here is not automatically safe to share across threads.

## Vocabulary and concepts

- **FIFO:** First in, first out removal order.
- **LIFO:** Last in, first out removal order.
- **Ring buffer:** Fixed storage reused through wrapped indices.

## Syntax anatomy and execution trace

The queue stores head and count. The next insertion index is (head+count)%capacity, and removal advances head modulo capacity. count ranges from zero through capacity. Returning bool plus an output pointer preserves the distinction between an empty queue and a legitimate zero-valued item. Rejected operations leave both structure and output unchanged.

## Worked example / walkthrough

### Worked example 1: Preserve FIFO order

Enqueue 2 then 5 and dequeue twice.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

enum { QUEUE_CAPACITY = 4 };
struct Queue {
  int data[QUEUE_CAPACITY];
  size_t head, count;
};
bool enqueue(struct Queue *q, int value) {
  if (q->count == QUEUE_CAPACITY)
    return false;
  size_t index = (q->head + q->count) % QUEUE_CAPACITY;
  q->data[index] = value;
  q->count++;
  return true;
}
bool dequeue(struct Queue *q, int *out) {
  if (q->count == 0 || out == NULL)
    return false;
  *out = q->data[q->head];
  q->head = (q->head + 1) % QUEUE_CAPACITY;
  q->count--;
  return true;
}

int main(void) {
  /* Preserve FIFO order */
  {
    struct Queue q = {0};
    int out = 0;
    CHECK(enqueue(&q, 2) && enqueue(&q, 5));
    CHECK(dequeue(&q, &out) && out == 2);
    CHECK(dequeue(&q, &out) && out == 5);
  }
  puts("Worked example checks passed.");
  return 0;
}

```

**Observe:** The values arrive as 2 then 5.

The queue contract differs from a stack, which would return 5 first.

### Worked example 2: Reject an empty read

Dequeue from a new queue with output 9.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

enum { QUEUE_CAPACITY = 4 };
struct Queue {
  int data[QUEUE_CAPACITY];
  size_t head, count;
};
bool enqueue(struct Queue *q, int value) {
  if (q->count == QUEUE_CAPACITY)
    return false;
  size_t index = (q->head + q->count) % QUEUE_CAPACITY;
  q->data[index] = value;
  q->count++;
  return true;
}
bool dequeue(struct Queue *q, int *out) {
  if (q->count == 0 || out == NULL)
    return false;
  *out = q->data[q->head];
  q->head = (q->head + 1) % QUEUE_CAPACITY;
  q->count--;
  return true;
}

int main(void) {
  /* Preserve FIFO order */
  {
    struct Queue q = {0};
    int out = 0;
    CHECK(enqueue(&q, 2) && enqueue(&q, 5));
    CHECK(dequeue(&q, &out) && out == 2);
    CHECK(dequeue(&q, &out) && out == 5);
  }

  /* Reject an empty read */
  {
    struct Queue q = {0};
    int out = 9;
    CHECK(!dequeue(&q, &out) && out == 9 && q.count == 0);
  }
  puts("Worked example checks passed.");
  return 0;
}

```

**Observe:** The operation fails and output stays 9.

No element is read before the occupancy check. Zero cannot be used as an empty sentinel because zero may be a real item.

## Common pitfalls and diagnosis

Begin with the first relevant compiler warning or error. A declaration mismatch can cause many later diagnostics, so fix one cause at a time. If a check fails, compare actual and expected values and identify the earliest state transition that differs from the intended invariant. A program that compiles can still contain undefined behavior. A program that ran once without crashing can still access invalid memory.

For every pointer, identify its target object, bounds, alignment, lifetime and whether mutation is permitted. For every library call, inspect its return value before using output. For every owned resource, identify one release on each completed path. The worked examples and solutions explain the lesson-specific counterexamples; keep those distinctions rather than replacing a rejected input with a plausible default.
