# Stable parameter constraints

Start with: tmb-003, bayes-004.

Outcome: Use unconstrained coordinates without changing the inferential target.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

An optimizer is easier to use when it moves on an unconstrained Euclidean space. Many scientific parameters are constrained: standard deviations are positive, correlations lie between -1 and 1, and probabilities lie between zero and one. Transform unconstrained coordinates into valid parameters, then evaluate the intended likelihood.

For a scale, use \(\sigma=e^s\). For an AR(1) correlation, use \(\phi=\tanh(z)\). The chain rule gives \(\partial f/\partial s=\sigma\,\partial f/\partial\sigma\) and \(\partial f/\partial z=(1-\phi^2)\partial f/\partial\phi\). TMB differentiates these operations. It cannot rescue an overflowing exponential or identify a flat likelihood near a boundary.

### Worked case A: positivity without clipping

The companion evaluates a normal objective as a function of log scale. The optimizer never proposes a negative scale. Compare this with `max(sigma, 1e-6)`: all values below the threshold map to the same number, producing a flat region and a nondifferentiable corner. A clipped function can have a small numerical gradient far from a meaningful statistical optimum.

A transformation can also badly condition an otherwise simple problem. If predictor units are huge, a reasonable coefficient can be close to zero on one scale and enormous on another. Center and scale explanatory variables, record that transformation, and convert reported coefficients back consistently.

### Worked case B: correlation near one

At \(z=0\), the derivative of `tanh` is one. At \(z=8\), it is tiny. A small gradient in transformed coordinates can therefore hide a substantial gradient with respect to correlation. The companion prints both the correlation and transformation derivative. Check likelihood profiles and distance to the stationarity boundary instead of declaring success from one gradient norm.

### When a Jacobian belongs

If you maximize the same likelihood \(p(y\mid\sigma)\) using \(s\) as coordinates, evaluate \(p(y\mid e^s)\). Do not add a Jacobian merely because the optimizer uses transformed coordinates. If instead you transform a probability density over the parameter itself, its measure changes: \(p_s(s)=p_\sigma(e^s)e^s\). Bayesian prior densities and integration over transformed latent variables need this distinction. For TMB random effects, integration coordinates matter because TMB approximates an integral, not just a point optimum.

### Diagnostics and answered discussion

**Does a log scale eliminate zero-variance solutions?** No. It moves the boundary to negative infinity. **Can I impose bounds in `nlminb`?** Yes, but bounds must reflect the scientific model and sensitivity to them should be reported. Our default interface keeps transforms simple and treats non-finite evaluation as failure. **What if a probability is exactly zero?** Decide whether the model genuinely permits a boundary distribution. A numerical epsilon is not a substitute for a documented model.

The [TMB manual](https://cran.r-project.org/web/packages/TMB/TMB.pdf) describes `map` for fixed or tied parameter components. Map a known scale to a fixed value when that is the scientific assumption; do not optimize it and then disguise the estimate as known.

### Fixing and tying parameters with a map

In a direct TMB project, `map=list(log_sigma=factor(NA))` fixes the declared log scale at its supplied starting value rather than estimating it. Equal factor levels can tie elements of a parameter vector. A map changes the free-coordinate dimension; always read `obj$par` and its names after construction. Our small JSON API deliberately does not accept arbitrary maps. To study one, create a reviewed R project variant and add a matching dimension test.

Fixing a parameter from external calibration can be justified, but treating a previously estimated value as known discards its uncertainty. Likewise, tying coefficients asserts equality in the model; it is not merely a computational optimization. Compare predictions and likelihood targets before deciding whether a reduced parameterization is appropriate.

### Complete R companion

```r
y <- c(1, 2, 4, 7)
objective <- function(s) -sum(dnorm(y, mean(y), exp(s), log = TRUE))
fit <- optimize(objective, interval = c(-3, 3))
print(c(log_sd = fit$minimum, sd = exp(fit$minimum)))
z <- c(0, 2, 8)
print(data.frame(z = z, phi = tanh(z), derivative = 1 - tanh(z)^2))
stopifnot(all(exp(c(-10, 0, 10)) > 0), 1 - tanh(8)^2 < 1e-5)
```
