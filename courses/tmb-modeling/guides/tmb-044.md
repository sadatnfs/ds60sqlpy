# Separable arrays and scalar or vector scales

Start with: tmb-043, tmb-041.

Outcome: Compose normalized densities while preserving axis order and scale Jacobians.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

Density composition lets a model express structure without manually expanding every covariance entry. `SCALE` applies a common scale to a base density. `VECSCALE` applies coordinate-specific scales. `SEPARABLE` combines compatible density structures across array dimensions, often yielding a Kronecker covariance. The transformations must include their normalizing Jacobians, not only divide residuals by a scale.

If \(u=Dz\), with positive diagonal entries \(s_i\), the NLL becomes \(f_z(D^{-1}u)+\sum_i\log s_i\). For a common scale \(s\), the correction is \(q\log s\). These terms affect scale estimation.

### Worked case A: vector scaling

The companion starts from a correlated two-dimensional standard-scale covariance and applies distinct scales. It checks the direct covariance \(D\Sigma D\) against the transformed-state NLL plus log-Jacobian. Swapping the scales changes which variable has which uncertainty, even if the determinant stays the same.

```cpp
Type nll = density::VECSCALE(density::MVNORM(correlation), scales)(state);
```

The correlation matrix must have the intended interpretation and scales must be valid. An arbitrary covariance supplied as “correlation” can double-count scaling.

### Worked case B: two array axes

For an array with rows indexing space and columns indexing time, a separable covariance can be \(\Sigma_{time}\otimes\Sigma_{space}\) under column-major vectorization. The companion constructs a two-by-three example and checks selected covariance entries. `SEPARABLE(f,g)` applies its first component to the outer dimensions in the reviewed implementation, so axis ordering must be verified against a tiny dense oracle.

```cpp
Type nll = density::SCALE(
    density::SEPARABLE(density::AR1(phi_time), density::AR1(phi_space)),
    tau)(state_array);
```

This pattern states a separability assumption: cross-axis covariance factors into products. Real systems can violate it. More computationally convenient structure is not automatically a better scientific model.

### Answered discussion

**Can I transpose an array without changing the density composition?** Not unless the corresponding components and dimension interpretation are transposed consistently. **Does SCALE change correlation?** A single common scale changes variance, while the base correlation structure remains. **Can VECSCALE replace an arbitrary cross-covariance model?** It changes marginal scales but does not create every possible correlation pattern.

The [density composition source and documentation](https://github.com/kaskr/adcomp/blob/master/TMB/inst/include/tmbutils/density.hpp) is the primary reference. Array-order and normalizer tests are essential before publishing a new composed template.

### Complete R companion

```r
R <- matrix(c(1, .4, .4, 1), 2, 2);scales <- c(2, .5);D <- diag(scales);u <- c(.3, -.4)
nll <- function(x, S) length(x) * log(2 * pi) / 2 + as.numeric(determinant(S, logarithm = TRUE)$modulus) / 2 + sum(x * solve(S, x)) / 2
print(c(direct = nll(u, D %*% R %*% D), transformed = nll(u / scales, R) + sum(log(scales))))
stopifnot(abs(nll(u, D %*% R %*% D) - nll(u / scales, R) - sum(log(scales))) < 1e-12)
space <- .3^abs(outer(1:2, 1:2, "-"));time <- .7^abs(outer(1:3, 1:3, "-"));S <- kronecker(time, space)
print(S);stopifnot(S[1, 2] == .3, S[1, 3] == .7, abs(S[1, 4] - .21) < 1e-12)
```
