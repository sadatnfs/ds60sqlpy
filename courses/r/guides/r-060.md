## Outcome and mechanism

Build a linked numerical, static and interactive analysis whose denominators, identities, uncertainty and delivery limits can be reviewed.

An analytical visualization should connect its displayed marks to an explicit calculation. This capstone begins with identified synthetic records, a declared missing-value policy and two groups. The raw data, summary table and figures remain separate artifacts so a reviewer can reconstruct every value rather than trusting the appearance of a polished chart.

The observed-value policy retains eight measured values and records two missing measurements. Each group has four observed values. Means, standard errors and Student t intervals are calculated from those admitted observations. The intervals target group means under their stated assumptions; they are not predictions for future individuals and do not establish a causal treatment effect.

The static graphic shows observations and the mean intervals together. The interactive figure retains observation IDs and a separate summary trace with error bars. The summary trace does not add new observations to the underlying dataset. Counting all rendered points as sample size would therefore be a denominator error.

A printed table provides an alternative to hover and makes the eligibility counts inspectable. The report should name the metric, missingness rule, interval construction, package environment and limitations. A difference between group means is descriptive here because no randomized or otherwise identified causal design is supplied.

Acceptance proceeds through several evidence layers: numeric assertions, layer/trace parity, explicit plot printing, captured figure structure and actual browser inspection. This reference performs the first stages and can be executed through the prepared worker capture path. It does not infer readable labels, working hover controls or accessibility from a successful Rscript exit.

For independent work, change the group sizes or missingness pattern and derive the new expected summaries before modifying the figures. Explain how the report would change if the target were an overall observation mean, an equal-group mean or a causal contrast. A defensible analysis keeps those questions distinct.

## Worked examples

### Example 1: Compute the eligibility and uncertainty ledger

```r
d <- data.frame(id = c(paste0("A", 1:5), paste0("B", 1:5)), group = rep(c("A", "B"), each = 5), value = c(1, 2, 3, 4, NA_real_, 2, 3, 6, 7, NA_real_))
summary <- do.call(rbind, lapply(split(d$value, d$group), function(values) {
  observed <- values[!is.na(values)]
  n <- length(observed); se <- sd(observed) / sqrt(n); half <- qt(0.975, n - 1) * se
  data.frame(n = n, missing = sum(is.na(values)), mean = mean(observed), se = se, half = half)
}))
summary$group <- rownames(summary)
stopifnot(sum(summary$n) == 8, sum(summary$missing) == 2, max(abs(summary$mean - c(2.5, 4.5))) < 1e-12)
stopifnot(max(abs(summary$se^2 - c(5 / 12, 17 / 12))) < 1e-12)
print(summary)
```

**Expected observation:** Eight observed values, two missing values, group means 2.5/4.5 and squared SEs 5/12 and 17/12.

The table retains both observed and missing counts and labels the mean-interval construction. These are the exact values later supplied to both rendering systems.

### Example 2: Represent summaries without double-counting observations

```r
summary <- data.frame(group = c("A", "B"), n = c(4L, 4L), mean = c(2.5, 4.5), se = sqrt(c(5 / 12, 17 / 12)))
summary$half <- qt(0.975, 3) * summary$se
p <- plotly::plot_ly(summary, x = ~group, y = ~mean, type = "scatter", mode = "markers", name = "Group mean", error_y = list(type = "data", array = summary$half, visible = TRUE))
p <- plotly::layout(p, xaxis = list(title = "Group"), yaxis = list(title = "Mean and 95% t interval"))
trace <- plotly::plotly_build(p)$x$data[[1]]
stopifnot(length(trace$x) == 2, max(abs(as.numeric(trace$y) - summary$mean)) < 1e-12)
stopifnot(max(abs(as.numeric(trace$error_y$array) - summary$half)) < 1e-12)
print(summary)
print(p)
```

**Expected observation:** Two mean marks with exact supplied t-interval half-widths.

Two summary marks represent eight observations. The error bars reuse the declared half-widths; their visual presence does not change the observation denominator.
