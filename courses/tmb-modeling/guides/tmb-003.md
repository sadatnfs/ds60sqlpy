# The full Gaussian negative log likelihood

Start with: tmb-002, r-043.

Outcome: Derive and check the normalized Gaussian objective and its scale estimate.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A normal density is \(p(y\mid\mu,\sigma)=(2\pi\sigma^2)^{-1/2}\exp[-(y-\mu)^2/(2\sigma^2)]\). Independent observations multiply their densities. Taking the negative logarithm turns the product into a sum:

\[
f(\mu,s)=\frac n2\log(2\pi)+ns+\frac12e^{-2s}\sum_i(y_i-\mu)^2,\qquad s=\log\sigma.
\]

Every term matters when estimating the scale. Omitting \(ns\) lets the objective approach zero by sending the scale to infinity. Omitting only a parameter-independent constant preserves the optimizer but changes absolute likelihood comparisons and integration checks. Our models retain normalizers so independent numerical oracles can compare actual density values.

### Worked case A: ML scale versus sample SD

For 1, 2, 4 and 7, the mean is 3.5 and the residual sum of squares is 21. The maximum-likelihood variance is \(21/4=5.25\). R's `sd` instead computes \(\sqrt{21/3}\), the square root of the unbiased sample-variance estimator. They answer different questions. The ML estimate comes from differentiating the likelihood jointly in mean and scale. It is not a numerical optimizer error when it differs from `sd`.

```cpp
Type sigma = exp(log_sigma);
nll -= dnorm(y(i), mu, sigma, true);
```

The final `true` requests a log density. Subtraction converts log likelihood to negative log likelihood. Summing tiny ordinary densities or taking their product would cause avoidable floating-point underflow. The companion evaluates the expanded formula and `-sum(dnorm(..., log=TRUE))` independently.

### Worked case B: duplicated observations

Repeat every observation three times. The fitted mean and ML scale stay the same, while the total NLL and information triple. The data are only genuinely more informative if the new observations are independent. Copying rows does not create scientific replication. This distinction matters in Spark: a repeated partition or retry counted twice changes the statistical experiment even when fitted point estimates happen to remain unchanged.

A constant dataset has residual sum of squares zero. The unconstrained Gaussian scale MLE is then on the boundary \(\sigma\to0\), and the likelihood is unbounded. A log transform guarantees positivity but cannot create a finite interior optimum. Treat this as a model/data issue. If measurement precision supplies a defensible lower bound, state it; do not silently clamp the estimate to make a test pass.

### Diagnostics and answered discussion

**May I minimize mean NLL?** For an unpenalized fixed-size problem it has the same optimizer, but gradients, Hessians and regularization scaling change. Inverse curvature from a mean loss must be converted back to total-information scale. **Does normality of residuals guarantee independence?** No. Temporal correlation and group effects require explicit modeling or suitable robust inference. **Why include the constant if it does not affect the mean?** It supports normalized-density checks and consistent marginal likelihood calculations.

The original `normal_mean.cpp` and `tests/acceptance.R` compare the compiled objective to this closed form. A companion R calculation alone is mathematical evidence, not proof that a DLL compiled or ran.

### Complete R companion

```r
y <- c(1, 2, 4, 7)
mu <- mean(y)
sigma <- sqrt(mean((y - mu)^2))
nll <- function(y, mu, sigma) length(y) * log(sigma * sqrt(2 * pi)) + sum((y - mu)^2) / (2 * sigma^2)
print(c(mean = mu, ml_sd = sigma, sample_sd = sd(y)))
stopifnot(abs(nll(y, mu, sigma) + sum(dnorm(y, mu, sigma, log = TRUE))) < 1e-12)
y3 <- rep(y, 3)
stopifnot(mean(y3) == mu, abs(nll(y3, mu, sigma) - 3 * nll(y, mu, sigma)) < 1e-10)
print(c(original_nll = nll(y, mu, sigma), duplicated_nll = nll(y3, mu, sigma)))
```
