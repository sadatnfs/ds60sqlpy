# asm-017: A custom Estimator and fitted Model lifecycle

Tutorial mode. Stage: intermediate. Direct prerequisites: `asm-016`, `spark-027`.

## Starting point and result

An Estimator consumes training data and returns a fitted Model. A Model is a Transformer whose behavior includes learned state. This distinction prevents a common leakage error: recomputing preprocessing statistics from evaluation data. We implement centering because its correct training state is easy to inspect independently.

## Mechanism: fit once, transform with frozen state

For training values \(x_1,\ldots,x_n\), the fitted center is \(\hat\mu=n^{-1}\sum_i x_i\). The model transforms any future value with \(x-\hat\mu\). The Estimator performs one aggregate action for row count, present-value count and mean. It rejects empty training input, missing training values and a nonfinite fitted mean.

The learned scalar is a `DoubleParam` on `CenterModel`, so the default parameter persistence mechanism can store it. `setParent(this)` records the fitting relationship. The model's `transform` constructs native expressions with the stored scalar; it does not run another mean calculation. `copy` and schema checks follow the public ML stage contract.

This compact example is not a full scaling library. A multi-column standardizer requires feature ordering, scale estimates, zero-variance policy and often vector or table artifacts. Larger learned objects should not be squeezed into ad hoc strings merely to reuse default Params serialization. Design the artifact format and validation alongside the estimator.

## Worked case: training and test distributions differ

Training values one, two and three yield mean two. Test values ten and twelve therefore transform to eight and ten. Those results are intentionally far from zero: a distribution shift should remain visible. The program asserts them, saves the fitted model and reloads it, then asserts the same results through the public load path.

The round trip proves that the mean needed for prediction was persisted. Saving only the Estimator would preserve configuration but not the fitted mean. A deployment should identify both the fitted artifact and the training-data/model version that produced it.

## Worked case: refitting on test data hides the shift

A deliberately incorrect comparison fits a new center on the test values. Their mean is eleven, so the resulting centered values are minus one and one. This is numerically valid centering of that dataset, but it is not the trained transformation. It changes the pipeline at evaluation time and can leak information across a train/test boundary.

Cross-validation has the same issue. Put learned preprocessing inside the pipeline being fitted on each training fold, rather than precomputing a global center before splitting. If the feature depends on future information, correct parameter persistence alone cannot repair the temporal leakage.

## Failure diagnosis

A loaded model that predicts differently may be missing learned state, using a different input schema or silently refitting. A mean of NaN suggests invalid training data; an empty dataset must not be treated as a valid zero-mean training set. If the output name collides with an existing column, stop rather than replace it.

## Interview discussion

**Why not implement centering as a UDF with a captured variable?** A captured mean can compute correct values, but the stage contract makes parameter ownership, pipeline composition, validation and persistence explicit. The goal is reproducible behavior, not merely syntax convenience.

**Does saving a model make it portable across all Spark versions?** No. Public persistence has documented compatibility considerations, and custom classes add their own code and dependency requirements. Pin and test the environment used for restoration.

## Next step

## Complete reproducible program

Run this complete source in its declared prepared Spark profile. The fixture is tiny, deterministic and offline. Scala sources are compiled before execution; Python sources use the prepared PySpark environment. These are worked tutorials with no hidden solutions or exams. Runtime: `spark-local-scala`.

```scala
import org.apache.spark.sql.{SparkSession, DataFrame, Dataset, Encoder, Encoders}
import org.apache.spark.sql.functions._

import org.apache.spark.ml.{Estimator, Model, Transformer}
import org.apache.spark.ml.param.{ParamMap, DoubleParam}
import org.apache.spark.ml.param.shared.{HasInputCol, HasOutputCol}
import org.apache.spark.ml.util.{DefaultParamsWritable, DefaultParamsReadable, Identifiable}
import org.apache.spark.sql.types.{StructType, StructField, DoubleType}

class CenterModel(override val uid: String)
    extends Model[CenterModel]
    with HasInputCol
    with HasOutputCol
    with DefaultParamsWritable {
  def this() = this(Identifiable.randomUID("centerModel"))
  val center =
    new DoubleParam(this, "center", "fitted finite training mean", (x: Double) => x.isFinite)
  def configure(in: String, out: String, value: Double): this.type = {
    set(inputCol, in); set(outputCol, out); set(center, value)
  }
  override def transformSchema(schema: StructType): StructType = {
    require(schema($(inputCol)).dataType == DoubleType);
    require(!schema.fieldNames.contains($(outputCol)));
    schema.add(StructField($(outputCol), DoubleType, schema($(inputCol)).nullable))
  }
  override def transform(data: Dataset[_]): DataFrame = {
    transformSchema(data.schema); data.withColumn($(outputCol), col($(inputCol)) - lit($(center)))
  }
  override def copy(extra: ParamMap): CenterModel = defaultCopy(extra)
}
object CenterModel extends DefaultParamsReadable[CenterModel]
class CenterEstimator(override val uid: String)
    extends Estimator[CenterModel]
    with HasInputCol
    with HasOutputCol
    with DefaultParamsWritable {
  def this() = this(Identifiable.randomUID("centerEstimator"))
  def configure(in: String, out: String): this.type = { set(inputCol, in); set(outputCol, out) }
  override def transformSchema(schema: StructType): StructType = {
    require(schema($(inputCol)).dataType == DoubleType);
    require(!schema.fieldNames.contains($(outputCol)));
    schema.add(StructField($(outputCol), DoubleType, schema($(inputCol)).nullable))
  }
  override def fit(data: Dataset[_]): CenterModel = {
    transformSchema(data.schema)
    val row = data
      .agg(
        count(lit(1)).as("rows"),
        count(col($(inputCol))).as("present"),
        avg(col($(inputCol))).as("mean")
      )
      .head()
    require(
      row.getLong(0) > 0 && row.getLong(0) == row.getLong(1),
      "training input must be nonempty without nulls"
    )
    val value = row.getDouble(2); require(value.isFinite, "training mean must be finite")
    new CenterModel(uid + "_model").configure($(inputCol), $(outputCol), value).setParent(this)
  }
  override def copy(extra: ParamMap): CenterEstimator = defaultCopy(extra)
}
object CenterEstimator extends DefaultParamsReadable[CenterEstimator]
object Main {
  def main(args: Array[String]): Unit = {
    val spark = SparkSession.builder
      .master("local[2]")
      .appName("advanced-spark-modeling")
      .config("spark.ui.enabled", "false")
      .config("spark.driver.host", "127.0.0.1")
      .config("spark.driver.bindAddress", "127.0.0.1")
      .config("spark.sql.shuffle.partitions", "2")
      .config("spark.sql.adaptive.enabled", "false")
      .config("spark.sql.ansi.enabled", "true")
      .getOrCreate()
    require(spark.version == "4.0.1", "This example targets Spark 4.0.1")
    spark.sparkContext.setLogLevel("ERROR")
    import spark.implicits._
    try {
      val training = Seq(1.0, 2.0, 3.0).toDF("x")
      val test = Seq(10.0, 12.0).toDF("x")
      val model = new CenterEstimator().configure("x", "centered").fit(training)
      val result = model.transform(test).select("centered").as[Double].collect().toSeq
      require(result == Seq(8.0, 10.0))
      val directory =
        java.nio.file.Files.createTempDirectory("asm-center-").resolve("model").toString
      model.write.save(directory)
      require(
        CenterModel
          .load(directory)
          .transform(test)
          .select("centered")
          .as[Double]
          .collect()
          .toSeq == result
      )
      val leaked = new CenterEstimator()
        .configure("x", "centered")
        .fit(test)
        .transform(test)
        .select("centered")
        .as[Double]
        .collect()
        .toSeq
      require(leaked == Seq(-1.0, 1.0) && leaked != result)
      println("Training-only fit, fitted-model persistence and leakage counterexample passed")
    } finally { spark.stop() }
  }
}
```
