## Outcome and mechanism

Calculate and interpret distinct uncertainty quantities while keeping the resampling population and assumptions explicit.

An estimate is a statistic calculated from observed data. A standard error describes variation of an estimator under a sampling or resampling model. It is not the spread of the raw observations, and a small standard error does not repair a biased collection process.

For independent observations with a suitable finite variance, the usual estimated standard error of a sample mean is the sample standard deviation divided by the square root of the sample count. R's sd uses the sample-variance convention with divisor n-1. Retain the count and explain the independence assumption before using this formula for clustered or serially dependent observations.

The nonparametric bootstrap samples from the empirical distribution of the observed values. Its conditional target is not identical to the unknown population sampling distribution. The tiny fixture here enumerates all possible bootstrap samples, so there is no Monte Carlo approximation error in that conditional calculation. There is still uncertainty about how well the empirical distribution represents the population.

For four observations 2,4,6,8, the empirical distribution has variance five using divisor four. A four-draw mean from that distribution therefore has conditional variance 5/4. The usual estimated sampling variance from the unbiased sample variance is 5/3. Both calculations are internally coherent, but they answer different finite-sample questions. Treating their numerical difference as an automatic coding defect would lose that distinction.

A confidence interval additionally depends on a coverage argument. A Student t interval for a mean relies on its specified sampling/model assumptions; a percentile bootstrap interval has different approximation behavior. Neither is a prediction interval for a new observation. A narrow interval also says nothing by itself about whether the measured outcome matches the scientific question.

## Read the syntax

Calculate mean(x), sd(x), length(x) and sd(x)/sqrt(length(x)) separately. expand.grid enumerates the index choices for a small exact bootstrap; apply computes one mean per resample. Compare the population variance of those enumerated means with the analytic conditional target. qt supplies a Student t critical value, while quantile requires a declared probability and interpolation convention.

## Worked examples

### Example 1: Sample spread versus uncertainty of a mean

```r
x <- c(2, 4, 6, 8)
se <- sd(x) / sqrt(length(x))
stopifnot(mean(x) == 5, isTRUE(all.equal(var(x), 20 / 3)))
stopifnot(isTRUE(all.equal(se^2, 5 / 3)))
interval <- mean(x) + c(-1, 1) * qt(0.975, df = length(x) - 1) * se
stopifnot(interval[1] < 5, interval[2] > 5)
print(c(mean = mean(x), sample_sd = sd(x), mean_se = se))
print(interval)
```

**Expected observation:** Mean 5; sample variance 20/3; squared SE 5/3.

The observation standard deviation and the mean standard error differ by the square root of four. The interval is a model-dependent procedure, not a guarantee about this one realized dataset.

### Example 2: Enumerate the conditional bootstrap

```r
x <- c(2, 4, 6, 8)
indices <- expand.grid(rep(list(seq_along(x)), length(x)))
means <- apply(indices, 1, function(i) mean(x[as.integer(i)]))
conditional_variance <- mean((means - mean(means))^2)
stopifnot(length(means) == 256, mean(means) == 5)
stopifnot(isTRUE(all.equal(conditional_variance, 5 / 4)))
print(c(bootstrap_mean = mean(means), conditional_variance = conditional_variance))
```

**Expected observation:** 256 resamples; mean 5; conditional variance 1.25.

All 256 ordered resamples are equally weighted. Using mean squared deviations gives the exact variance of that finite conditional distribution; sd(means) would apply a sample divisor to a different object.

## Reference review

The reference uses different variance conventions for different objects. sd(x) estimates population spread from a sample, whereas the enumeration treats all bootstrap means as the complete conditional distribution. Neither result should be silently substituted for the other.

The shift test checks an invariant of centered spread. The count guard prevents an undefined sample-variance calculation from being interpreted as a usable estimate.
