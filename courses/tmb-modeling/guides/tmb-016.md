# Independent panels and parameter ownership

Start with: tmb-015, spark-016.

Outcome: Choose between separate panel fits and one shared likelihood.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A panel is a complete ordered set of measurements for one entity. Parallelization begins with ownership: which observations, parameters and latent states belong to each computation? If panels have independent parameters and no shared latent effects, they can be fitted separately. If they share a coefficient, each panel contributes to one common optimization problem.

For independent observations with a shared normal mean and known equal variance, the global MLE is \(\hat\mu=\sum_g n_g\bar y_g/\sum_g n_g\). Averaging the panel means equally gives a different result unless panel sizes are equal. For nonlinear likelihoods, even a sample-size-weighted average of separately fitted parameters generally does not solve the pooled score equation.

### Worked case A: different-sized groups

The companion uses a small group near zero and a larger group near ten. It prints the equal-panel average and the actual pooled mean. The difference is intentional: one estimator gives every panel equal weight, the other gives every observation equal weight. Neither should be smuggled into a lesson as a universal notion of “average performance.” Define the scientific target first.

With a shared parameter vector \(\theta\), evaluate every group's objective and gradient at the same current \(\theta\), sum the contributions, then let the driver update the parameter. Reusing gradients evaluated at each group's own fitted optimum does not provide a global gradient; those gradients are nearly zero by construction.

### Worked case B: within-panel dependence

Suppose each panel has its own AR(1) latent trajectory. Complete independent trajectories may contribute separate marginal likelihood terms. Splitting one trajectory by row count loses temporal edges. The companion shows an independent two-panel covariance with zero cross-panel entries and then adds a shared random intercept, making cross-panel covariance nonzero.

For Spark, preserve group identity and chronological order before an R/TMB fit. A pandas group can be too large for a worker even if the total dataset is distributed. Bound group sizes, report skew, and define a failure policy. Parallel group fitting increases throughput across independent problems; it does not make a single huge coupled model fit in memory.

### Diagnostics and answered discussion

**What can a worker return?** For independent fits, estimates, diagnostics and bounded predictions keyed by group. For global optimization, a value, gradient and exact row/group counts at the supplied common parameters. **Can task retries duplicate statistical contributions?** Yes if outputs are appended externally without idempotency. Use Spark's normal reduction semantics and source-bound results, not side-effectful counters. **Should compilation happen once per row?** No. Compile during preparation; load per process and construct objectives at appropriate group boundaries.

The Spark/TMB bridge is a separate project with its own acceptance. This chapter defines the statistical decomposition; it does not claim that an R-only example proves distributed execution or cluster speed.

```r
a <- c(-1, 1); b <- c(8, 9, 10, 11, 12, 10, 10, 10)
print(c(equal_panel_average = mean(c(mean(a), mean(b))), pooled_mean = mean(c(a, b))))
stopifnot(abs(mean(c(a, b)) - weighted.mean(c(mean(a), mean(b)), c(length(a), length(b)))) < 1e-12)
block <- matrix(0, 4, 4); block[1:2, 1:2] <- matrix(c(1, .5, .5, 1), 2); block[3:4, 3:4] <- matrix(c(1, .5, .5, 1), 2)
shared <- block + .2 * matrix(1, 4, 4)
print(list(independent = block, shared_intercept = shared))
stopifnot(block[1, 3] == 0, shared[1, 3] > .1)
```
