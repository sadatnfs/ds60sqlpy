## Calibration tests an inference procedure under a model

Simulation-based calibration repeatedly draws parameters from a prior, generates data from the model and applies the inference procedure. When posterior samples are correct and suitable exchangeability conditions hold, the simulated true parameter has a uniform rank among those posterior draws. The procedure checks computational calibration relative to a specified generative model.

For a scalar parameter and S posterior draws, ranks range from zero through S. Under an exact continuous posterior sampler, the true parameter and the posterior draws are exchangeable conditional on the simulated data. A nonuniform rank pattern can reveal biases or dispersion errors, but finite replicates, dependent MCMC samples and the chosen test quantities affect what can be detected.

The example uses a normal prior and one normal observation with unit variances. Its exact posterior is normal with mean \(y/2\) and variance .5, allowing independent iid posterior samples and an analytic conditional oracle.

## Worked case 1: compare correct and shifted inference

Across 500 simulated datasets, the program draws 64 posterior samples per dataset and records the rank of the simulated parameter. It compares the correct posterior with an algorithm whose posterior location is shifted upward by one. The shifted algorithm produces much smaller ranks on average because the true parameter tends to lie below its posterior draws.

The code checks a deliberately strong contrast rather than claiming that one histogram or average proves correctness. The exact posterior makes the intended conditional distribution known. A more subtle error could require more replicates, different summaries or a targeted test quantity.

Real MCMC draws are correlated. Treating heavily dependent samples as if they were iid can distort a rank diagnostic. Appropriate handling of effective draws, thinning or other calibration procedures should follow the method's assumptions. A large number of stored samples does not automatically supply the exchangeability used by the simple iid argument.

## Worked case 2: an algorithm ignores the data

A third algorithm returns independent samples from the prior regardless of the simulated observation. Its parameter ranks can look marginally uniform because both the true parameter and those returned samples are marginally drawn from the prior. This is a particularly important counterexample: a reassuring marginal rank calculation can miss an inference algorithm that performs no update.

The program compares the returned sample means with the analytic conditional posterior mean \(y/2\). The prior-only algorithm has much larger conditional error. This independent oracle reveals the failure that a simple marginal parameter-rank summary can miss.

The example motivates using several scientifically relevant test quantities, including quantities that depend on the data or likelihood, and additional reference checks. It does not claim that the mean-error test used here is available for every complex model. When no analytic posterior is known, calibration design and targeted simplified cases become even more important.

## What SBC does not establish

SBC tests the computational procedure under data generated by the assumed model. If the observation model is unrealistic, a calibrated inference algorithm can still provide misleading conclusions for real data. Prior predictive checks, posterior predictive checks and substantive model criticism address related but different questions.

The generative simulation should include the relevant observation process. If the real analysis handles censoring, missingness, selection or delayed measurements, omitting those mechanisms from the calibration simulation can leave the difficult part of the implementation untested. Likewise, changing the prior or data preprocessing after calibration changes the qualified procedure.

Inspect calibration across important parameter regions and data conditions. An aggregate result can conceal failures in a rare but consequential regime. The number of replicates limits sensitivity, especially for tail behavior and high-dimensional quantities. Preserve the simulated parameters, data seeds, algorithm configuration and diagnostic results so failures can be reproduced.

## Answered scientific discussion

**Does a uniform-looking rank histogram prove that the posterior is correct?** No. It is evidence about specified test quantities under a specified simulation design. The prior-only counterexample demonstrates why additional quantities and independent checks matter.

**How should calibration be used in practice?** Combine it with tractable reference models, density/gradient checks, sampler diagnostics and scientific model criticism. Each answers a different question. The purpose is to locate and understand failures, not to obtain a single badge that certifies an entire Bayesian workflow.
