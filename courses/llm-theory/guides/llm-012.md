## Purpose and mental model

<!-- textbook-foundations-start -->

### A model distribution does not yet specify one output

Suppose the next-token logits are [2,1,0]. The model has supplied a preference ordering and, after softmax, a probability distribution. It has not yet specified whether the application should always take the largest entry or draw randomly according to the mass. Those are decoding policies. Keeping the model fixed while changing the policy can change generated text, so a reproducible experiment must record both.

Greedy decoding ignores the sizes of probability gaps and chooses an argmax. Here it selects token zero. If the logits were [1,1,0], a tie rule would also be needed; the NumPy rule used here chooses the first maximum. Greedy is useful when a deterministic local choice is desired, but it is not a search for the globally most probable sequence. An initially less likely branch can lead to more likely later continuations, as the sequence chapter showed. Nor does a deterministic output make an answer factually justified.

Sampling uses the full distribution instead. For the literal mass [0.5,0.3,0.2], imagine laying three adjacent intervals across a ruler of length one. Token zero owns [0,0.5), token one owns [0.5,0.8), and token two owns [0.8,1). A uniform random draw selects the interval containing it. The supplied draws 0.1, 0.6 and 0.9 therefore choose tokens zero, one and two. The randomness is in the draw; once both draw and cumulative table are fixed, the selection is an ordinary deterministic calculation.

Temperature adjusts the ruler before drawing by scaling logits. Dividing [2,1,0] by 0.5 doubles the differences, putting about 0.8668 probability on token zero instead of about 0.6652. Dividing by two flattens the distribution, reducing that probability to about 0.5065. Positive scaling preserves ranking, so these changes leave the greedy choice unchanged while changing sampling frequencies. It is useful to distinguish a model becoming more confident through a policy transformation from a model becoming more accurate through new evidence or better learned parameters.

Top-k changes which candidates receive any interval at all. Keeping only tokens zero and one removes token two, then recomputes the denominator over the retained scores. Their probabilities become approximately [0.7311,0.2689]. This deliberately samples from a truncated distribution rather than the original model distribution. The truncation can suppress low-probability alternatives, but it may also remove a desirable continuation. The appropriate policy depends on the task and must be evaluated as part of the system.

For reproducibility, distinguish a mathematical distribution from a particular random sequence. Two implementations can sample the same distribution yet produce different draws or consume their RNG state in a different order. The fixed-draw fixture isolates selection arithmetic from that issue. Later generation loops add stopping rules, context limits and caches; none should silently change the declared candidate mapping or turn a draw of exactly one into a legal interval index.

## Vocabulary and concepts

**Greedy decoding:** Selecting a highest-scoring token under a tie policy.

**Temperature:** Positive divisor controlling score concentration before softmax.

**Top-k:** A filter retaining the k highest-scoring candidates.

## Syntax anatomy and reasoning sequence

Subtract the maximum before exponentiation. Require positive temperature for stochastic sampling; handle zero-temperature greedy mode separately. np.argmax returns the first maximum, which implements the declared smallest-index tie rule. np.searchsorted(cumulative,draw,side='right') selects the interval containing a draw in[0,1). Filter candidates before the final normalization.

## Derive the actual selection probabilities

For logits [2, 1, 0], stable softmax can subtract 2 and normalize [1, \(\exp(-1)\), \(e^{-2}\)]. The probabilities are approximately [0.665241, 0.244728, 0.090031]. Temperature 0.5 first divides the logits by 0.5, giving probabilities [0.866813, 0.117310, 0.015876]. Temperature 2 gives approximately [0.506480, 0.307196, 0.186324]. The order remains unchanged for every positive temperature, so greedy selection still chooses token zero. Sampling frequencies change because the mass assigned to each interval changes.

Temperature modifies the selection distribution, not the learned weights or the factual evidence available to the model. A sharper distribution can confidently select an incorrect token. It should not be described as improving calibration merely because its highest probability increases. Zero temperature is implemented as a separate greedy policy here; dividing scores by zero is not a numerical implementation of that policy. When several logits tie for the maximum, a positive-temperature limit distributes mass among them, while this lesson's greedy rule selects the smallest index.

## Filtering and drawing are separate operations

Keeping only the first two logits produces probabilities [\(\frac{e^2}{e^2+e}\), \(\frac{\exp(1)}{\exp(2)+\exp(1)}\), 0], approximately [0.731059, 0.268941, 0]. Removing the third probability after the original normalization would leave a total near 0.909969, which is not a complete categorical distribution. Filtering must be followed by normalization over the retained support.

For probabilities [0.5, 0.3, 0.2], cumulative boundaries are [0.5, 0.8, 1]. Draws in [0, 0.5) select token zero, [0.5, 0.8) select token one, and [0.8, 1) select token two. The right-sided search puts a draw exactly equal to 0.5 in the second interval. A draw of one belongs to none of these half-open intervals and must be rejected. Zero-probability tokens have empty intervals and should not be selected.

The fixture supplies explicit draws so the decision can be reconstructed without a hidden RNG state. Real generation must preserve both the random-source state and the decoding policy if it is to be replayed. Changing top-k, temperature, tie ordering or the number of earlier draws can change output despite reusing a seed. The later nucleus-sampling chapter adds a probability-mass cutoff, termination rules and output caps; these are policy choices with their own failure cases.


## Worked example / walkthrough

### Example A: Calculate greedy choice

Only ranking matters to greedy selection. A common shift or positive temperature preserves this particular decision.

```python
import numpy as np


def softmax(x):
    x = np.asarray(x, dtype=float)
    mass = np.exp(x - x.max())
    return mass / mass.sum()


scores = np.array([2.0, 1.0, 0.0])
assert int(np.argmax(scores)) == 0
```

**Expected:** token0.

### Example B: Change temperature

Sharper probabilities make high-scoring tokens more likely without changing their order. They do not create new evidence that the selected token is correct.

```python
import numpy as np


def softmax(x):
    x = np.asarray(x, dtype=float)
    mass = np.exp(x - x.max())
    return mass / mass.sum()


scores = np.array([2.0, 1.0, 0.0])
assert int(np.argmax(scores)) == 0
p = softmax(scores)
cool = softmax(scores / 0.5)
assert cool[0] > p[0] and p.argmax() == cool.argmax() == 0
```

**Expected:** token0 probability increases; argmax stays0.

## Common pitfalls and diagnosis

If sampling selects an impossible or out-of-range token, inspect normalization after filtering and the half-open draw boundary before changing the RNG. If temperature changes the greedy answer for unequal finite logits, inspect sign, zero handling and numerical overflow. If a replay differs despite the same seed, compare policy, draw order and vocabulary indexing as well as generator state.
