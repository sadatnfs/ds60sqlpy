# Applied science: identification, prediction and decisions

Connected worked tutorials in causal inference, forecasting, survival, ranking, optimization, synthesis, spatial analysis and survey/high-dimensional reasoning.

The entry route assumes basic Python and the linked statistics foundations. Beginner here means first contact with the applied mechanism, not first contact with programming. Each unit defines its target and supplies two contrasting cases, a complete bounded computation, diagnostic interpretation and an answered scientific discussion. Read specialist branches independently using their direct prerequisites. The final dossier connects evidence and resource decisions without pretending that one model resolves every scientific question.

Start with the [classroom installation guide](../../README.md). These are complete worked tutorials. Sources and notes are saved; reading markers do not certify mastery.
