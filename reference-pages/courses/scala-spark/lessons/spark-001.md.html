spark-001 learner worksheet#

Authored beta teaching content. Publication and runtime qualification are separate gates. Read the current capability notice before running. No opening or saving this lesson installs tools, starts a cluster or proves mastery.

Read the guide, predict first, and keep an independent response for each task. These are reasoning fixtures, not commands to execute.

Worked example 1: Trace a Scala program#

The arrows are different phases. A source edit does not retroactively modify a process that already ran.
