# c-032: Generic byte APIs, alignment and element-size discipline

## Purpose and mental model

C can write generic storage algorithms using void pointers and explicit element sizes. That flexibility moves type information into the API contract. A wrong element size can copy partial objects, overrun storage or produce misaligned access. void pointer arithmetic is not standard C, so byte traversal uses unsigned char pointers. A generic operation should state overlap, alignment, lifetime and ownership rules rather than claiming that void means any operation is safe. Keep type-specific interpretation at a reviewed boundary and prefer typed wrappers for common callers.

## Vocabulary and concepts

- **Type erasure:** Removing concrete type information from an interface.
- **Element size:** The storage width the generic algorithm uses per element.
- **Typed wrapper:** A type-specific API around a more general implementation.

## Syntax anatomy and execution trace

void * can hold object pointers and convert back to an appropriate object pointer. unsigned char * supports bytewise stepping. A swap helper can exchange representations one byte at a time without allocating, provided its two regions are valid, equally sized and nonoverlapping. qsort receives element size explicitly; the comparator must cast each supplied pointer to the actual element type. Generic code still needs bounded size arithmetic.

## Worked example / walkthrough

### Worked example 1: Swap integer objects

Exchange two ints using their exact object size.

```c
#include <assert.h>
#include <limits.h>
#include <stdbool.h>
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static void lesson_check(bool condition, const char *file, int line) {
  if (!condition) {
    fprintf(stderr, "Check failed at %s:%d\n", file, line);
    abort();
  }
}
#define CHECK(condition) lesson_check((condition), __FILE__, __LINE__)

struct Pair {
  int x, y;
};
void swap_bytes(void *left, void *right, size_t size) {
  unsigned char *a = left, *b = right;
  for (size_t i = 0; i < size; i++) {
    unsigned char saved = a[i];
    a[i] = b[i];
    b[i] = saved;
  }
}
size_t count_nonzero(const void *data, size_t size) {
  const unsigned char *bytes = data;
  size_t count = 0;
  for (size_t i = 0; i < size; i++)
    if (bytes[i] != 0)
      count++;
  return count;
}

int main(void) {
  /* Swap integer objects */
  {
    int a = 2, b = 7;
    swap_bytes(&a, &b, sizeof a);
    CHECK(a == 7 && b == 2);
  }
  puts("Worked example checks passed.");
  return 0;
}
```

**Observe:** The values become 7 and 2.

The size comes from the actual object rather than a guessed platform width.

```c
  for (size_t i = 0; i < size; i++) {
    unsigned char saved = a[i];
    a[i] = b[i];
    b[i] = saved;

size_t count_nonzero(const void *data, size_t size) {

  size_t count = 0;

int main(void) {
  /* Swap integer objects */
  {
    int a = 2, b = 7;
    swap_bytes(&a, &b, sizeof a);
    CHECK(a == 7 && b == 2);
  }

  /* Swap fixed byte arrays */
  {
    unsigned char a[] = {1, 2, 3}, b[] = {4, 5, 6};
    swap_bytes(a, b, sizeof a);

```

**Observe:** Their byte contents exchange exactly.

The operation changes representation bytes without interpreting them as another type.

## Common pitfalls and diagnosis

Begin with the first relevant compiler warning or error. A declaration mismatch can cause many later diagnostics, so fix one cause at a time. If a check fails, compare actual and expected values and identify the earliest state transition that differs from the intended invariant. A program that compiles can still contain undefined behavior. A program that ran once without crashing can still access invalid memory.

For every pointer, identify its target object, bounds, alignment, lifetime and whether mutation is permitted. For every library call, inspect its return value before using output. For every owned resource, identify one release on each completed path. The worked examples and solutions explain the lesson-specific counterexamples; keep those distinctions rather than replacing a rejected input with a plausible default.
