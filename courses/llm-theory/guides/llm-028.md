## Learning objectives

The central investigation is concrete: Train a decoder with fewer than 50000 parameters, context at most 32 and at most 200 updates; compare held-out loss with the count baseline and submit failure analysis. The finish condition is Tokenizer/split/model hashes, masks, loss denominator, seed/profile and exact step count are recorded. Any quality conclusion names the held-out unit and uncertainty. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

## Purpose and mental model

A tiny-transformer capstone combines model mechanics, fitting and evaluation into one inspectable experiment. The training corpus is local and authored, the vocabulary is fixed, and document families define the split. The decoder has fewer than fifty thousand parameters and uses at most thirty-two context positions. A fixed small update budget prevents unbounded experimentation. Compare held-out token loss with a train-only count baseline using the same vocabulary and target events. Model hashes and split hashes record identity, while causal tests and denominator checks establish different properties. A poor score or an inconclusive comparison is a valid result when its limitations are reported honestly.

## Vocabulary and concepts

**Capstone evidence:** A combined record of mechanics, data lineage and held-out observations.

**Count baseline:** A smoothed transition model fitted on the same training data.

**Frozen test:** Assessment data excluded from model and prompt selection.

## Worked example / walkthrough

### Example A: Freeze corpus identity

The literal corpus prevents hidden downloads and makes every target visible. Document identity is separate from token identity because repeated tokens are expected across splits.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
class TinyDecoder(nn.Module):
    def __init__(self,vocab=16,width=32,heads=2,context=32):
        super().__init__()
        self.vocab,self.width,self.heads,self.context=vocab,width,heads,context
        self.token=nn.Embedding(vocab,width); self.position=nn.Embedding(context,width)
        self.norm1=nn.LayerNorm(width); self.qkv=nn.Linear(width,3*width,bias=False)
        self.projection=nn.Linear(width,width,bias=False); self.norm2=nn.LayerNorm(width)
        self.feed=nn.Sequential(nn.Linear(width,2*width),nn.ReLU(),nn.Linear(2*width,width))
        self.output=nn.Linear(width,vocab,bias=False)
    def forward(self,ids,cache=None):
        if ids.ndim!=2 or ids.dtype!=torch.long or ids.shape[1]==0: raise ValueError('nonempty long batch,time IDs')
        offset=0 if cache is None else cache['k'].shape[2]
        batch,time=ids.shape
        if offset+time>self.context or torch.any(ids<0) or torch.any(ids>=self.vocab): raise ValueError('context or vocabulary limit')
        x=self.token(ids)+self.position(torch.arange(offset,offset+time))
        q,k,v=self.qkv(self.norm1(x)).chunk(3,dim=-1)
        def split(t): return t.reshape(batch,time,self.heads,self.width//self.heads).transpose(1,2)
        q,k,v=map(split,(q,k,v))
        if cache is not None:
            if cache['k'].shape[0]!=batch: raise ValueError('cache batch mismatch')
            k=torch.cat([cache['k'],k],dim=2); v=torch.cat([cache['v'],v],dim=2)
        allowed=torch.arange(k.shape[2])[None,:]<=torch.arange(offset,offset+time)[:,None]
        scores=q@k.transpose(-2,-1)/(self.width//self.heads)**.5
        weights=torch.softmax(scores.masked_fill(~allowed,float('-inf')),dim=-1)
        mixed=(weights@v).transpose(1,2).contiguous().reshape(batch,time,self.width)
        x=x+self.projection(mixed); x=x+self.feed(self.norm2(x))
        return self.output(x),{'k':k.detach(),'v':v.detach()}
import hashlib,json
docs=[[1,2,3,4],[1,2,4,3]]; held=[1,3,2,4]; split={'train':['a','b'],'test':['c']}; digest=hashlib.sha256(json.dumps(split,sort_keys=True).encode()).hexdigest()
assert len(docs)==2 and len(held)-1==3 and len(digest)==64
```

**Expected:** train2 documents;holdout1;context3.

### Example B: Train a bounded decoder

The budget and architecture are fixed before held-out evaluation. Training loss is retained as diagnostic evidence rather than a substitute for a test score.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F
class TinyDecoder(nn.Module):
    def __init__(self,vocab=16,width=32,heads=2,context=32):
        super().__init__()

        self.norm1=nn.LayerNorm(width); self.qkv=nn.Linear(width,3*width,bias=False)
        self.projection=nn.Linear(width,width,bias=False); self.norm2=nn.LayerNorm(width)
        self.feed=nn.Sequential(nn.Linear(width,2*width),nn.ReLU(),nn.Linear(2*width,width))
        self.output=nn.Linear(width,vocab,bias=False)

        q,k,v=self.qkv(self.norm1(x)).chunk(3,dim=-1)
        def split(t): return t.reshape(batch,time,self.heads,self.width//self.heads).transpose(1,2)
        q,k,v=map(split,(q,k,v))
        if cache is not None:
            if cache['k'].shape[0]!=batch: raise ValueError('cache batch mismatch')
            k=torch.cat([cache['k'],k],dim=2); v=torch.cat([cache['v'],v],dim=2)
        allowed=torch.arange(k.shape[2])[None,:]<=torch.arange(offset,offset+time)[:,None]

torch.manual_seed(11); model=TinyDecoder(); opt=torch.optim.Adam(model.parameters(),lr=.01); batch=torch.tensor(docs); curve=[]
for _ in range(20):
    opt.zero_grad(set_to_none=True); logits,_=model(batch[:,:-1]); loss=F.cross_entropy(logits.reshape(-1,16),batch[:,1:].reshape(-1)); loss.backward(); opt.step(); curve.append(loss.item())
assert len(curve)==20 and np.isfinite(curve).all() and sum(p.numel() for p in model.parameters())<50000
```
