# Advanced Spark source ownership

The units file owns the 38 stable IDs, direct prerequisites and declared runtime surfaces. Original chapter prose is in chapters/ and complete programs or worked project notebooks are in programs/. Edit those inputs, then run the subject builder. It emits this subject's guides, examples, track, lesson admission and coverage files only; shared HTML, TeX inventories and registry integration belong to the root integration owner.

Every chapter has an explanation, two materially different worked cases, failure diagnosis, answered interview discussion and a concrete next step. Reading/project chapters do not invent a pad execution channel. The public Spark programs use the prepared Spark 4.0.1, Scala 2.13 and JDK 17 contract. The root-owned spark-torch and spark-tmb projects require separate qualification. The Catalyst project is exact-version experimental code, not a stable extension library.

Do not change IDs or other subjects, copy external source without license review, assume pandas/Torch/TMB in the ordinary Spark image, or weaken numerical tests. Preserve learner volumes and project state. No network work happens when a learner opens a chapter.
