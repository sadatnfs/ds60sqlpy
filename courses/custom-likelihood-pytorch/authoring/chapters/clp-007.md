## Binary likelihoods without unstable probabilities

A binary response needs a probability between zero and one. Logistic regression maps an unrestricted linear predictor \(\eta_i=x_i^\top\beta\) through \(p_i=1/(1+e^{-\eta_i})\). Coefficients describe changes in log odds conditional on the included predictors. They do not directly describe changes in probability, and observational associations are not automatically causal effects.

Expanding the Bernoulli log-likelihood gives a stable NLL expression:

\[
\mathcal L(\beta)=\sum_i\{\operatorname{softplus}(\eta_i)-y_i\eta_i\},
\quad \operatorname{softplus}(z)=\log(1+e^z).
\]

A numerically stable implementation evaluates softplus without explicitly exponentiating an enormous positive value. Computing probabilities first and then taking `log(p)` or `log(1-p)` can lose information when the probability rounds to zero or one. Clipping probabilities may conceal that numerical failure while introducing a different objective near the clipping boundaries.

The score and observed Hessian are

\[
\nabla\mathcal L=X^\top(p-y),\qquad
H=X^\top\operatorname{diag}\{p_i(1-p_i)\}X.
\]

The Hessian is positive semidefinite, but that fact does not guarantee a finite minimizer. Separation is the key counterexample.

## Worked case 1: overlapping binary outcomes

The fixture uses predictor values \((-2,-1,0,1,2,3)\), an intercept column and outcomes \((0,1,0,1,1,0)\). Both labels appear across the predictor range, so no single threshold perfectly separates this tiny sample. The code evaluates the analytic score at a specified nonzero coefficient vector and compares it with AD before performing any optimization.

L-BFGS then gives an intercept near -0.05746 and slope near 0.11492. The fitted probabilities range roughly from 0.429 to 0.571. These probabilities are deliberately modest: the sample contains little linear evidence about class membership. The final gradient is small, but the example makes no claim about classification usefulness or probability calibration on unseen records. Assess those with held-out data and appropriate sample sizes.

Changing a probability threshold does not change the fitted likelihood. Threshold selection answers a decision problem involving costs and prevalence; coefficient estimation answers a probability-modeling problem. Keeping these separate prevents an accuracy score from being mistaken for evidence about the likelihood's numerical correctness.

## Worked case 2: perfectly separated data

Take predictor values \((-2,-1,1,2)\), labels \((0,0,1,1)\), no intercept and positive slopes 1, 2, 4 and 8. Every larger slope moves the correct class probabilities closer to one, so the NLL decreases along this path. There is no finite unpenalized MLE. The code prints the decreasing sequence rather than reporting the last coefficient as a successful estimate.

A tiny gradient can occur when fitted probabilities saturate, even as the coefficient diverges. Consequently, a small gradient alone is not evidence of a well-identified finite optimum. A penalty or prior can yield a finite solution, but that is a changed estimation problem and must be declared. Bias-reduction approaches also have their own objective and inferential interpretation; they are not equivalent to silently capping coefficients.

The program additionally evaluates correctly classified logits of magnitude 1000. The stable expression remains finite. This numerical check is distinct from separation: an expression can be stable while the statistical MLE does not exist.

## Debugging and modeling assumptions

Require a design with the expected coefficient dimension and binary outcomes of the correct shape. A binary indicator encoded as strings or as values one and two must be explicitly transformed. Check finite inputs before fitting. If observations belong to repeated subjects, the independent-row Bernoulli model may have inappropriate uncertainty even if it gives acceptable mean probabilities.

Case-control sampling changes how an intercept relates to population prevalence unless the sampling design is accounted for. Class weights also change the objective. Weighted classification training is not automatically population-probability estimation. State whether probabilities are intended for the sample or a target population and validate accordingly.

## Answered review questions

**Why not fit squared error to binary outcomes?** It can be a useful estimating procedure, but it uses a different loss and can yield predictions outside the unit interval for unconstrained linear means. Bernoulli likelihood directly encodes the binary observation support.

**Does a positive logistic coefficient always increase probability by the same amount?** No. Its effect on log odds is constant conditional on the model; the probability derivative also depends on the current probability through \(p(1-p)\).

**What should an interview answer about separation include?** Explain the unbounded coefficient path, distinguish numerical saturation from model existence, and state how a chosen penalty, prior or bias-reduction method changes the fitting problem and uncertainty interpretation.
