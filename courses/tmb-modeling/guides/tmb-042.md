# Stable distribution helpers and mixtures

Start with: tmb-041, tmb-011.

Outcome: Evaluate probability terms stably without changing their statistical meaning.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

TMB supplies distribution and special-function helpers for typed arithmetic. Common likelihood code uses normal, Poisson, binomial, gamma and related densities, with their exact argument conventions checked against the pinned headers. A familiar name does not guarantee that every parameterization matches another package. For example, a variance-based negative-binomial helper must not receive a dispersion parameter as though it were a variance.

Request log densities whenever available and sum them. Multiplying many ordinary probabilities can underflow. A mixture requires a sum of component probabilities before taking a log, so simply adding component log likelihoods is mathematically wrong.

### Worked case A: a two-component normal mixture

For \(p(y)=\pi p_1(y)+(1-\pi)p_2(y)\), compute \(\log p(y)\) using a stable log-sum operation on \(\log\pi+\log p_1\) and \(\log(1-\pi)+\log p_2\). TMB's `logspace_add` supports this operation in the typed graph. The companion compares a stable implementation with ordinary densities in a moderate case and demonstrates underflow in an extreme case.

```cpp
Type log_p = -logspace_add(Type(0), -eta);
Type log_one_minus_p = -logspace_add(Type(0), eta);
Type contribution =
    -logspace_add(log_p + component_one, log_one_minus_p + component_two);
```

Here `eta` is the unconstrained mixture logit and both components are log densities. This avoids separately forming a probability that rounds to exactly zero or one at extreme logits.

### Worked case B: subtracting probabilities

Interval censoring can require \(\log(F(R)-F(L))\). `logspace_sub(log_FR, log_FL)` expresses a log-space subtraction, but the domain still requires the first probability to be at least the second. A stable numerical helper cannot repair reversed interval endpoints or an incorrectly chosen tail probability. The companion checks a known difference using a stable `log1p` formula.

Stable evaluation and statistical identifiability are separate. A two-component mixture can have label switching, weakly determined weights or an unbounded likelihood when a component scale collapses. Reparameterization and stable logs do not automatically solve those issues.

### Answered discussion

**Can I add an epsilon to every probability?** That changes the likelihood. Use stable identities and explicit model assumptions first. **Does a finite loss imply a finite derivative?** No. Test both over the intended parameter range. **Should I clip a logit?** Clipping changes the objective and derivative; if a scientific bound is intended, make it explicit and analyze its consequences.

The [TMB convenience helpers](https://github.com/kaskr/adcomp/blob/master/TMB/inst/include/convenience.hpp) and [distribution implementation](https://github.com/kaskr/adcomp/tree/master/TMB/inst/include) define the pinned numerical interfaces. New distribution families require their own known-value and gradient tests.

### Complete R companion

```r
log_add <- function(a, b) {
  m <- max(a, b);m + log(exp(a - m) + exp(b - m))
}
a <- log(.3) + dnorm(.5, -1, 1, log = TRUE);b <- log(.7) + dnorm(.5, 1, 1, log = TRUE)
print(c(stable = log_add(a, b), direct = log(.3 * dnorm(.5, -1, 1) + .7 * dnorm(.5, 1, 1))))
print(c(extreme_stable = log_add(-1000, -1001), extreme_direct = log(exp(-1000) + exp(-1001))))
log_difference <- function(a, b) {
  stopifnot(a > b);a + log1p(-exp(b - a))
}
stopifnot(abs(log_difference(log(.9), log(.4)) - log(.5)) < 1e-12)
```
