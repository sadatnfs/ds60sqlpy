# jax-002: Array axes, broadcasting and functional updates

## Starting point and outcome

Beginner. Direct prerequisites: `jax-001`

Control the shape and meaning of every reduction and update in a small array calculation.


## Mechanism and purpose

An axis has both a length and a meaning. In a two-row table of three features, axis zero identifies observations and axis one identifies features. A sum over axis one returns one total per observation. A sum over axis zero returns one total per feature. Both operations are valid, so neither a successful call nor a finite result tells you which question was intended.

Broadcasting aligns trailing dimensions. A vector of three feature offsets can be added to a (2,3) table. A vector of two observation offsets needs an explicit column axis to express a separate offset for each row. Adding the wrong shape may fail loudly; adding a coincidentally compatible shape can silently express a different computation. Deliberately use unequal axis lengths when testing an axis contract.

JAX arrays present immutable values to ordinary Python code. A functional update such as x.at[index].set(value) returns an updated array; it does not make assigning into the old array a supported operation. The compiler may optimize storage internally, but the programming contract remains that the old value is unchanged. Later buffer-donation lessons discuss a separate explicit permission to reuse storage.

Index behavior also deserves a declared contract. Do not infer that an out-of-range gather or scatter must behave like a Python list or NumPy array. For this lesson, a small host-side validator accepts only integer indices within a fixed known array length before calling the numerical helper. This validator is intentionally outside JIT. A later transformed computation needs a compatible validation or masking policy instead of applying Python decisions to traced values.

## Key terms

- **Axis:** One dimension of an array with both a length and a meaning, such as observations on axis zero and features on axis one.
- **Broadcasting:** The rule that aligns trailing dimensions so a smaller array combines with a larger one, which can silently express an unintended pairing.
- **Reduction:** An operation such as a sum or mean that collapses a chosen axis, so the axis argument decides which question the result answers.
- **Functional update:** An expression such as x.at[index].set(value) that returns a new array and leaves the original value unchanged.
- **Index contract:** A declared rule for which positions are legal, checked before a gather or scatter instead of assuming list or NumPy behavior.

## Derivation and shape contract

For \(X\in\mathbb R^{2\times3}\), row sums satisfy \(r_i=\sum_{j=0}^{2}X_{ij}\) and column sums satisfy \(c_j=\sum_{i=0}^{1}X_{ij}\). Row centering is \(X_{ij}-\frac13\sum_kX_{ik}\). Keeping the reduced axis as a singleton makes the subtraction's intended broadcast visible. The centered row sums should be zero, which is a stronger oracle than checking only the output shape.

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)

### Worked example 2: Return a changed value

Replace index one of [10,20,30] with 99 and inspect both arrays.

The update is a function from old value and instruction to new value. Retaining both arrays makes the ownership contract observable.

**Expected:** New [10,99,30]; original [10,20,30].

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def replace_at(values, index, value):
    if type(index) is not int or not 0 <= index < values.shape[0]:
        raise ValueError("index outside the vector")
    return values.at[index].set(value)


def main():
    # Case 1: Return a changed value
    old = jnp.array([10.0, 20.0, 30.0])
    new = replace_at(old, 1, 99.0)
    close(new, [10.0, 99.0, 30.0])
    close(old, [10.0, 20.0, 30.0])

    print("jax-002: 1 asserted case passed")


if __name__ == "__main__":
    main()
```
