# Inner and outer convergence

Start with: tmb-013, tmb-007.

Outcome: Diagnose latent-mode failure separately from fixed-parameter convergence.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

A latent model has two numerical searches. At each proposed fixed parameter vector \(\theta\), an inner optimizer finds \(\hat u(\theta)\). The outer optimizer then uses the approximate marginal objective and its gradient to update \(\theta\). If the inner search is inaccurate, the outer search is being shown a distorted objective surface.

In a purely quadratic latent problem, one exact Newton step from any start reaches the mode in exact arithmetic. Nonlinear latent models do not generally have this property. The TMB manual exposes `inner.control`, `inner.method` and `random.start`; use them to diagnose a particular model rather than applying a universal setting from an unrelated example.

### Worked case A: exact quadratic latent mode

The companion constructs a positive-definite two-state precision matrix. Its gradient is \(Hu-b\), so a Newton step is \(u-H^{-1}(Hu-b)=H^{-1}b\). Two widely different starts converge to the same answer. This is the reason a known quadratic inner problem can tolerate a one-step policy. It is not permission to use one inner iteration for every TMB model.

Warm starts reuse a previous latent solution and can reduce work as the outer parameters move. They can also hide sensitivity to initial modes in a nonconvex problem. Check a few fresh starts and inspect the inner gradient, especially when a finite-difference derivative comparison is unexpectedly noisy.

### Worked case B: truncating a nonlinear inner solve

For \(f(u)=(u^2-1)^2+0.1u\), multiple stationary points exist. The companion runs a limited optimizer and a fuller search from different starts. The resulting objective and gradient explain more than the exit code alone. This pedagogical objective is intentionally nonconvex; it is not advertised as a normalized density or a reliable random-effect model.

A useful failure receipt includes outer coordinates, latent start, final inner mode, inner gradient, inner/outer convergence status, and the objective being approximated. Never silently keep the previous successful objective when a new inner evaluation fails. That creates false smoothness and can make the outer optimizer appear more stable than it is.

### Diagnostics and answered discussion

**Can I tell `nlminb` to ignore failed inner evaluations?** Replacing them arbitrarily changes the optimization problem. A bounded invalid-domain policy must be deliberate, and failures should remain visible. **Will a tighter outer tolerance fix a loose inner solve?** No. Inner accuracy must support the precision demanded of the outer function and gradient. **How do I test gradients?** Compare several perturbation sizes, ensure the inner solve converges at every perturbation, and use an exact Gaussian oracle first.

The [MakeADFun documentation](https://cran.r-project.org/web/packages/TMB/TMB.pdf) describes its latent starting-value behavior. Our default project uses TMB's reviewed defaults for the small Gaussian latent cases and qualifies them against exact marginals. More difficult latent models need additional convergence evidence before promotion to ordinary runnable lessons.

### Complete R companion

```r
H <- matrix(c(3, .5, .5, 2), 2, 2); b <- c(1, -2)
newton <- function(u) u - solve(H, drop(H %*% u) - b)
print(rbind(from_zero = newton(c(0, 0)), from_far = newton(c(10, -7)), exact = solve(H, b)))
stopifnot(max(abs(newton(c(10, -7)) - solve(H, b))) < 1e-12)
fn <- function(u) (u^2 - 1)^2 + .1 * u
gr <- function(u) 4 * u * (u^2 - 1) + .1
for (start in c(-2, 2)) {
  short <- nlminb(start, fn, gr, control = list(iter.max = 1))
  full <- nlminb(start, fn, gr)
  print(c(start = start, limited_gradient = gr(short$par), full_value = full$objective, full_gradient = gr(full$par)))
}
```
