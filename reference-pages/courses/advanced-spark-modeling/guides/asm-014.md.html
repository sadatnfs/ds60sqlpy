asm-014: Registering a SQL aggregate with explicit nulls#

Tutorial mode. Stage: intermediate. Direct prerequisites: asm-013, spark-012.

Starting point and result#

SQL users should be able to invoke a custom aggregate without knowing its Scala implementation. Registering udaf(new WeightedMeanSummary) exposes the typed implementation through Spark's function registry. The mathematical and data-quality contracts still belong to the author. This example returns an auditable struct rather than silently dropping invalid observations and displaying a mean.

Mechanism: weights, nullability and accepted rows#

The buffer stores rows seen, rows accepted, total accepted weight and weighted sum. An observation is accepted only when its value and weight are both present, finite and the weight is nonnegative. The weighted mean is

where A is the explicitly accepted set. Scala Option[Double] represents nullable inputs. Matching (Some(v), Some(w)) handles present values; the alternative records the row as seen but not accepted. This is an illustrative rejection policy, not a universal rule for missingness. A likelihood fit may instead reject the whole evaluation when any required observation is invalid.

The merge operation adds all four fields. finish retains them, allowing a SQL caller to inspect exclusions before dividing. Zero-weight rows can be accepted while contributing neither numerator nor denominator. That is different from a missing row. Negative weights are excluded by this example because they do not define its intended weighted-average contract.

Worked case: valid and invalid rows together#

The fixture contains value two with weight one, value ten with weight three, a missing value with weight two and value nine with weight minus one. Four rows are seen, two are accepted, accepted weight is four and weighted sum is 32. Therefore the reported weighted mean is eight. The SQL call returns the same typed struct as the Dataset implementation.

The program registers the function, creates a temporary view and expands the returned struct into columns. A production caller should expose both the result and exclusion counts. If the number eight appeared without those counts, the reader could not know that half the input rows were rejected.

Worked case: no valid denominator#

A second fixture contains only missing inputs. The output records one seen row, zero accepted rows and zero total weight. The program does not divide. A caller can represent the undefined mean as null with a reason code, or fail a modeling contract that requires positive total weight.

Do not replace the denominator with one merely to avoid an exception. That would create a numeric result with no statistical meaning. Similarly, adding a tiny epsilon changes the result in a scale-dependent way and hides whether the original dataset contained usable information.

Failure diagnosis#

If typed Dataset behavior differs from SQL registration, inspect encoder field order, SQL argument order and nullable input handling. If the weighted result changes after excluding rows, reconcile the exclusion counts first. Overflow can occur even with finite individual values when a product or accumulated sum exceeds double range; real input contracts need magnitude bounds or explicit post-reduction finiteness checks.

Interview discussion#

Should null inputs always be ignored by an aggregate? No. Define the mathematical target and missing-data policy. Counting ignored rows is useful even when exclusion is intentional.

Is a frequency-weighted mean equivalent to repeated rows? For nonnegative integer frequency weights, yes for this arithmetic result. That equivalence does not automatically extend to survey-design uncertainty or arbitrary signed weights.

Next step#

Compare this structured aggregate with scalar UDFs and native expressions. Choose the least opaque mechanism that can express the required behavior.

Complete reproducible program#

import org.apache.spark.sql.{SparkSession, DataFrame, Dataset, Encoder, Encoders}
import org.apache.spark.sql.functions._

import org.apache.spark.sql.expressions.Aggregator
case class WeightedInput(value: Option[Double], weight: Option[Double])
case class WeightedSummary(seen: Long, accepted: Long, totalWeight: Double, weightedSum: Double)
class WeightedMeanSummary extends Aggregator[WeightedInput, WeightedSummary, WeightedSummary] {
  def zero = WeightedSummary(0L, 0L, 0.0, 0.0)
  def reduce(b: WeightedSummary, x: WeightedInput): WeightedSummary = (x.value, x.weight) match {
    case (Some(v), Some(w)) if v.isFinite && w.isFinite && w >= 0 =>
      WeightedSummary(b.seen + 1, b.accepted + 1, b.totalWeight + w, b.weightedSum + v * w)
    case _ => b.copy(seen = b.seen + 1)
  }
  def merge(a: WeightedSummary, b: WeightedSummary) = WeightedSummary(
    a.seen + b.seen,
    a.accepted + b.accepted,
    a.totalWeight + b.totalWeight,
    a.weightedSum + b.weightedSum
  )
  def finish(b: WeightedSummary) = b
  def bufferEncoder: Encoder[WeightedSummary] = Encoders.product[WeightedSummary]
  def outputEncoder: Encoder[WeightedSummary] = Encoders.product[WeightedSummary]
}
object Main {
  def main(args: Array[String]): Unit = {
    val spark = SparkSession.builder
      .master("local[2]")
      .appName("advanced-spark-modeling")
      .config("spark.ui.enabled", "false")
      .config("spark.driver.host", "127.0.0.1")
      .config("spark.driver.bindAddress", "127.0.0.1")
      .config("spark.sql.shuffle.partitions", "2")
      .config("spark.sql.adaptive.enabled", "false")
      .config("spark.sql.ansi.enabled", "true")
      .getOrCreate()
    require(spark.version == "4.0.1", "This example targets Spark 4.0.1")
    spark.sparkContext.setLogLevel("ERROR")
    import spark.implicits._
    try {
      val input = Seq(
        WeightedInput(Some(2), Some(1)),
        WeightedInput(Some(10), Some(3)),
        WeightedInput(None, Some(2)),
        WeightedInput(Some(9), Some(-1))
      ).toDS()
      spark.udf.register("weighted_summary", udaf(new WeightedMeanSummary))
      input.createOrReplaceTempView("measurements")
      val r = spark
        .sql("SELECT weighted_summary(value,weight) AS summary FROM measurements")
        .select("summary.*")
        .as[WeightedSummary]
        .head()
      require(r == WeightedSummary(4, 2, 4, 32))
      require(r.weightedSum / r.totalWeight == 8.0)
      val rejected =
        Seq(WeightedInput(None, None)).toDS().select(new WeightedMeanSummary().toColumn).head()
      require(rejected.accepted == 0 && rejected.totalWeight == 0)
      println(
        s"$r mean=8.0 rejected=${r.seen - r.accepted}; all-invalid denominator=${rejected.totalWeight}"
      )
    } finally { spark.stop() }
  }
}
