# jax-001: From a Python function to a numerical contract

## Starting point and outcome

Beginner. Direct prerequisites: No prior JAX knowledge.

Specify a small computation and distinguish its numerical result from a model-quality claim.


## Mechanism and purpose

A numerical program starts with a question about values. JAX adds transformations to Python functions, but those transformations cannot choose the intended question. Begin with a linear predictor: one input number represents one observation, one parameter multiplies it, and the output is one prediction for that observation. A function takes named inputs and returns a result. Returning a new value is different from changing an object that another part of the program owns.

Suppose the observed inputs are 1, 2 and 3 and the targets are twice those values. At weight zero every prediction is zero. We can calculate the errors without a library: -2, -4 and -6. Squaring produces 4, 16 and 36. Their mean is 56/3. This number describes an explicitly chosen error summary on three authored observations. It does not estimate performance on unseen data by itself.

Arrays organize these observations. Shape (3,) means a vector with three entries. Shape (3,1) means three rows and one column. These representations can interact differently with a target vector even when printing makes them appear similar. A shape assertion is therefore part of the mathematical specification. Later JAX transformations preserve the computation we write, including an unintended broadcast if it is otherwise legal.

The classroom runs a complete source submission in a fresh process. An import makes a library available; a function definition creates a callable object; calling the function performs the described computation. An assertion asks whether the observed value satisfies a contract. A successful assertion is evidence for that case. Keep the source, predicted result and actual saved output together, and change one meaningful assumption at a time when investigating a failure.

This first unit intentionally uses tiny data and no fitted neural network. The purpose is to learn the evidence discipline that makes a larger calculation interpretable: identify the input unit, state the operation, calculate an independent expected answer, and explain which claim remains outside the experiment.

## Key terms

- **Numerical contract:** The stated inputs, operation, shapes and expected value that a computation must satisfy before its result is trusted.
- **Prediction unit:** The quantity one output describes, here one prediction for one observation, which sets the denominator of the mean loss.
- **Array shape:** The tuple of axis lengths, such as (3,) for a vector or (3,1) for a column, which decides how arrays pair and broadcast.
- **Independent oracle:** An expected value derived without the code under test, such as a hand-calculated loss of 56/3, used to check that code.

## Derivation and shape contract

For inputs \(x_i\), targets \(y_i\) and scalar weight \(w\), define \(\widehat y_i=wx_i\) and \(L(w)=N^{-1}\sum_i(\widehat y_i-y_i)^2\). The denominator counts observations because each observation has one output here. With several output coordinates, a mean over every array entry would answer a different weighting question. At \(w=0\), the three residual squares sum to 56 and the loss is \(56/3\). At \(w=2\), every residual is zero. Neither calculation uses a gradient or updates a parameter.

## Worked investigations

### Worked example 1: A hand-calculated loss

Evaluate the zero-weight predictor on the three observations.

The assertion compares JAX with a calculation made from the three squared residuals. It checks the mean denominator as well as the prediction rule.

**Expected:** Loss 56/3, predictions [0,0,0].

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def predict(weight, inputs):
    return weight * inputs


def mse(weight, inputs, targets):
    if inputs.ndim != 1 or inputs.shape != targets.shape or inputs.size == 0:
        raise ValueError("one nonempty target per input")
    return jnp.mean((predict(weight, inputs) - targets) ** 2)


x = jnp.array([1.0, 2.0, 3.0])
y = 2 * x


def main():
    # Case 1: A hand-calculated loss
    close(predict(0.0, x), [0.0, 0.0, 0.0])
    close(mse(0.0, x, y), 56 / 3)

    print("jax-001: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: A plausible shape mistake

Replace the target vector with a column and apply the contract before subtraction.

Broadcasting can be legal while the pairing is wrong. The guard rejects this representation before JAX has a chance to compute a misleading mean.

**Expected:** ValueError rather than an unintended 3-by-3 error matrix.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def predict(weight, inputs):
    return weight * inputs


def mse(weight, inputs, targets):
    if inputs.ndim != 1 or inputs.shape != targets.shape or inputs.size == 0:
        raise ValueError("one nonempty target per input")
    return jnp.mean((predict(weight, inputs) - targets) ** 2)


x = jnp.array([1.0, 2.0, 3.0])
y = 2 * x


def main():
    # Case 1: A plausible shape mistake
    try:
        mse(0.0, x, y[:, None])
    except ValueError:
        pass
    else:
        raise AssertionError("shape mismatch accepted")

    print("jax-001: 1 asserted case passed")


if __name__ == "__main__":
    main()
```
