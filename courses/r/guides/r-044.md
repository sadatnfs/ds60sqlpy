## Outcome and mechanism

Translate a logistic model between its link scale, probabilities and evaluation quantities without confusing their interpretations.

A generalized linear model combines a response distribution with a link between its mean and a linear predictor. For binomial logistic regression, the linear predictor is a log-odds quantity. Applying the inverse logit produces a probability between zero and one. The two scales support different interpretations and should be labeled in output.

R can represent binomial observations as individual zero/one responses or as a two-column matrix of successes and failures. Aggregated counts preserve their trial denominators when supplied correctly. A vector of proportions without the corresponding weights would describe a different likelihood. The small two-group fixture below has ten trials in each group and admits an exact probability oracle.

Exponentiating a coefficient gives an odds ratio conditional on the encoded model. It does not multiply probabilities by that factor. Changing probability from 0.2 to 0.6 multiplies odds from 0.25 to 1.5, an odds ratio of six; multiplying the original probability by six would be meaningless here.

Prediction quality has several dimensions. A threshold turns probabilities into decisions under an explicit tie and cost policy. Brier score evaluates squared probability error. Log loss penalizes small assigned probability for observed outcomes. Calibration compares predicted probabilities with observed frequencies under a stated grouping and sampling design. These quantities should not be substituted for one another.

Convergence also does not guarantee a scientifically adequate model. Complete separation can drive unpenalized logistic coefficients toward extreme values, while confounding, selection and misspecification remain outside the optimizer's numerical diagnosis. A preferred threshold or calibrated appearance on reused training data is not independent evidence of population performance.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Link scale | The transformed mean scale modeled by a linear predictor, here log odds. |
| Odds ratio | A multiplicative comparison of odds, not of probabilities. |
| Calibration | Agreement between predicted probabilities and observed event frequencies under a defined evaluation design. |
| Separation | A pattern in which predictors perfectly divide outcomes and can prevent finite unpenalized logistic coefficient estimates. |

## Read the syntax

Fit glm(cbind(successes, failures) ~ x, family=binomial(), data=d). predict(type="link") returns log odds; type="response" returns probabilities. plogis and qlogis translate the two scales. Calculate scores from the same trial counts, and retain the evaluation denominator. Use held-out outcomes for a calibration assessment rather than treating fitted training frequencies as independent validation.

## Worked examples

### Example 1: Recover probabilities and odds

```r
d <- data.frame(x = c(0, 1), successes = c(2, 6), failures = c(8, 4))
fit <- glm(cbind(successes, failures) ~ x, family = binomial(), data = d)
p <- predict(fit, type = "response")
eta <- predict(fit, type = "link")
stopifnot(max(abs(p - c(0.2, 0.6))) < 1e-8)
stopifnot(max(abs(plogis(eta) - p)) < 1e-10)
stopifnot(abs(exp(coef(fit)[["x"]]) - 6) < 1e-7)
print(data.frame(x = d$x, log_odds = eta, probability = p))
```

**Expected observation:** Probabilities 0.2/0.6; odds ratio 6.

The saturated two-group fixture recovers the two observed trial proportions. Its coefficient expresses an odds ratio of six, not a sixfold probability change.

### Example 2: Score probabilities before thresholding

```r
successes <- c(2, 6)
failures <- c(8, 4)
p <- c(0.2, 0.6)
n <- sum(successes + failures)
brier <- sum(successes * (1 - p)^2 + failures * p^2) / n
log_loss <- -sum(successes * log(p) + failures * log1p(-p)) / n
accuracy <- (failures[1] + successes[2]) / n
stopifnot(abs(brier - 0.2) < 1e-12, abs(accuracy - 0.7) < 1e-12, is.finite(log_loss))
print(c(brier = brier, log_loss = log_loss, threshold_accuracy = accuracy))
```

**Expected observation:** Brier 0.2, threshold accuracy 0.7, finite log loss.

The same probabilities produce a continuous score and a threshold decision score. The threshold rule is explicitly p>=0.5; another cost policy could choose another threshold.

## Reference review

The two-column response retains successes and failures as trial counts. The exact fixture probabilities make link-scale and odds calculations independently checkable. Brier score and classification accuracy evaluate different properties of those same predictions.

The separation example is diagnosed from the geometry of its inputs rather than forcing an unstable fit and presenting a huge coefficient as a valid estimate. The held-out frequency comparison uses new outcomes and remains a descriptive calibration check with its count visible. It does not infer population calibration from two bins.
