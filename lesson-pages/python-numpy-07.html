Vocabulary and concepts: directions, strengths and reduced shape#

Reduced SVD: A factorization of a real mmm-by-nnn matrix AAA as

U has shape (m, k), s has shape (k,), and NumPy's Vh has shape (k, n). The columns of U and rows of Vh are orthonormal: UTU=IkU^{\mathsf T}U=I_kUTU=Ik​ and VTV=IkV^{\mathsf T}V=I_kVTV=Ik​. The singular values are nonnegative and ordered from largest to smallest. They describe how strongly the matrix acts along special input directions.

Reduced does not mean approximate. All kkk components still reconstruct the complete matrix up to floating-point error. Approximation begins when components are deliberately discarded. For a tall matrix, U @ U.T projects into a column subspace and need not equal the identity on the whole observation space. Confusing these two orthogonality expressions causes false test failures.

Numerical rank: A threshold decision about small singular values. Exact algebraic rank and useful numerical rank can differ when measurements or computations contain error.

Frobenius norm: The square root of the sum of squared matrix entries; it measures total reconstruction error, rather than the largest error in a single direction.

Syntax anatomy and invariant checks#

np.linalg.svd(a, full_matrices=False) requests reduced factors. The expression (u * s) @ vh scales columns of u by the singular values before multiplication. Broadcasting aligns s with the final dimension of u; u * s[:, None] would express a different operation and may fail only for certain shapes. Use a rectangular fixture to expose that mistake.

Paired singular vectors may flip signs without changing their outer product. If singular values repeat, valid bases within their associated subspace can also rotate. Do not assert a particular sign or copy exact vector entries from one machine. Compare the reconstructed matrix, singular values, orthonormality and appropriate subspace projections with justified tolerances.

Worked example: discarded strength predicts approximation error#

Predict which diagonal entry disappears in the rank-two reconstruction. This complete program uses a diagonal matrix so the approximation can be checked independently of the factorization implementation.

import numpy as np

matrix = np.diag([6.0, 2.0, 0.5])
u, singular, vh = np.linalg.svd(matrix, full_matrices=False)
rank_two = (u[:, :2] * singular[:2]) @ vh[:2]
assert np.allclose(rank_two, np.diag([6, 2, 0]))
assert np.isclose(np.linalg.norm(matrix - rank_two, ord="fro"), 0.5)
assert np.allclose(u.T @ u, np.eye(3))
print("singular values:", singular.tolist(), "tail error:", np.linalg.norm(matrix - rank_two))

The omitted component has strength 0.5, so the Frobenius reconstruction error is 0.5 in exact arithmetic. With several discarded components, the error is the square root of their squared strengths, not their simple sum. Changing the retained rank to zero yields a zero matrix and the full matrix norm as the error.

Worked example: a weight changes the fitted objective#

A row weight determines the cost of its squared residual. Predict which observation contributes nothing to this fit, then run the full example.

import numpy as np

x = np.array([0.0, 1.0, 2.0])
design = np.column_stack((np.ones(3), x))
target = np.array([1.0, 3.0, 20.0])
weights = np.array([1.0, 1.0, 0.0])
root = np.sqrt(weights)
beta = np.linalg.lstsq(design * root[:, None], target * root, rcond=None)[0]
assert np.allclose(beta, [1, 2])
assert np.allclose(design[:2] @ beta, target[:2])
assert not np.isclose(design[2] @ beta, target[2])
print("coefficients:", beta.tolist(), "ignored-row prediction:", float(design[2] @ beta))

The zero-weight third observation contributes zero cost, so the line through the first two points is the minimizer. It predicts 5 at the third input and does not attempt to match the observed 20. That disagreement is intentional evidence that weights affect the objective; it is not a solver bug.

Replace the zero weight with a positive value and the fit changes. Replacing every weight by ten times itself should preserve the minimizing coefficients within numerical tolerance while multiplying the weighted objective by ten. Multiplying rows by weights instead of square roots would instead square the intended weights, changing relative emphasis.

Prewhitening and the meaning of weights#

Weighted least squares minimizes

Constructing D explicitly is unnecessary: a * root[:, None] scales rows, while y * root scales the target. This operation is often called prewhitening for independent errors with known relative variances. Inverse-variance weights correspond to a specific statistical model. Arbitrary importance weights define a different objective and should not be described as verified measurement precision.

Nonnegative weights permit ignoring a row; all-zero weights provide no fitting information and are rejected here. Rank-deficient designs remain valid because least squares can choose a minimum-norm coefficient vector. Different coefficient vectors may predict the same observations. Identifiability, residual size and conditioning therefore need separate interpretation.

Ridge without squaring the conditioning problem#

Ridge adds a coefficient penalty:

Solve that augmented system with lstsq. Forming A.T @ A can square the condition number, and explicitly inverting it adds unnecessary numerical work. The augmented route expresses the intended objective directly. Positive regularization shrinks unstable directions, but it also introduces bias and changes the estimation problem.

This unit penalizes every coefficient, including an intercept column if present. Many applications exempt the intercept, which requires a different penalty matrix. Feature units also matter: rescaling one column changes the meaning of an equal penalty on its coefficient. Do not interpret alpha without specifying the design and preprocessing.

Common pitfalls and diagnosis#

If reconstruction passes but orthogonality fails, inspect which product you asserted and whether the matrix is rectangular. If rank changes after merely rescaling all data, check whether you used an absolute threshold instead of the declared relative threshold. If coefficients become very large despite tiny residuals, examine singular values and whether the data constrain each direction.

If lstsq returns an empty residuals array, recompute the residual explicitly instead of concluding that the residual is zero. That metadata can be empty for rank-deficient or certain shape cases. If changing all weights by a common factor changes the fit materially, inspect prewhitening, numerical scale and the solver's threshold.

Applications include heteroscedastic calibration, compressed matrix storage and regularized linear prediction. None of these tiny examples qualifies a production model. Exercise 1: Verify a reduced factorization#

Contract: reduced_svd. For a nonempty finite real two-dimensional matrix, return U, s, Vh from np.linalg.svd with full_matrices=False. Reject empty axes, nonmatrices, bool/complex/object/string and nonfinite values with ValueError. Preserve the source. For shape (m, n), k=min(m, n), require shapes (m, k), (k,), (k, n). Validate reconstruction and orthonormality without asserting singular-vector signs.

Expected: For [[3, 0], [0, 2], [0, 0]], s is [3, 2], reconstruction matches input, U.T @ U and Vh @ Vh.T match identity. U @ U.T is not generally the full identity.

def reduced_svd(matrix: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    return np.linalg.svd(_matrix(matrix), full_matrices=False)

Reduced SVD omits unused null-space columns while retaining all singular values. Multiplying U by the vector s scales its columns by broadcasting, then multiplication by Vh reconstructs the matrix. Signs can flip in paired vectors without changing that product. Repeated singular values allow basis rotation, so compare reconstructed operators and subspaces rather than exact individual vectors.

Exercise 2: State a rank decision policy#

Contract: rank_at_tolerance. Return the number of singular values strictly greater than rtol times the largest singular value. Require a nonempty finite real matrix and a finite nonnegative scalar rtol, excluding bool. A zero matrix has rank zero. Invalid input raises ValueError. This explicit relative rule intentionally differs from selecting a hidden library default.

Expected: diag([1, 1e-9]) has rank 1 with rtol=1e-8 and rank 2 with rtol=1e-10. Equality at the cutoff is excluded. Multiplying all entries by a moderate positive constant preserves the decision.

def rank_at_tolerance(matrix: np.ndarray, rtol: float) -> int:
    a = _matrix(matrix)
    relative = _nonnegative(rtol)
    singular = np.linalg.svd(a, compute_uv=False)
    # Division avoids overflow in rtol * largest_singular_value.
    if singular[0] == 0:
        return 0
    return int(np.count_nonzero(singular / singular[0] > relative))

Numerical rank depends on a tolerance and a scale. The ratio comparison is equivalent to the stated rule for a positive largest value and avoids overflowing the product of a large tolerance and singular value. Handle the all-zero matrix before division. A tolerance should reflect precision and application uncertainty; this function exposes the decision rather than claiming one threshold is universally correct.

Exercise 3: Fit a prewhitened system#

Contract: weighted_lstsq. Fit the minimum-norm least-squares coefficient vector after multiplying each design row and matching target by sqrt(weight). Require nonempty finite real design, matching target vector and finite nonnegative row weights with at least one positive entry. Use np.linalg.lstsq(..., rcond=None). Reject invalid shapes, all-zero weights or nonfinite prewhitened arrays/results with ValueError. Preserve inputs.

Expected: A one-column design of ones, target [0, 4, 100] and weights [1, 3, 0] fits coefficient [3]. A zero weight removes that row from the objective. A rank-deficient design remains valid.

def weighted_lstsq(design: np.ndarray, target: np.ndarray, weights: np.ndarray) -> np.ndarray:
    a, b = _system(design, target)
    root = np.sqrt(_weights(weights, a.shape[0]))
    with np.errstate(over="ignore", invalid="ignore"):
        whitened, observed = a * root[:, None], b * root
    if not np.isfinite(whitened).all() or not np.isfinite(observed).all():
        raise ValueError("Prewhitening exceeds finite floating range")
    coefficients = np.linalg.lstsq(whitened, observed, rcond=None)[0]
    if not np.isfinite(coefficients).all():
        raise ValueError("Nonfinite fitted coefficients")
    return coefficients

Squaring a sqrt(weight)-scaled residual reproduces weight times residual squared. Scaling by weight itself would optimize a different objective with squared weights. Lstsq handles rank deficiency with a minimum-norm solution at its numerical threshold. There is no inverse of the normal equations here. Multiplying all positive weights by the same moderate factor preserves the minimizer, though objective values rescale.

Exercise 4: Measure a low-rank approximation#

Contract: truncated_svd. Return (reconstructed, tail_frobenius_error) for the first rank components of reduced SVD. rank must be an integer from 0 through min(shape), excluding bool. The error value is the Euclidean norm of discarded singular values. Rank zero returns a zero matrix. Reject invalid inputs or nonfinite outputs with ValueError. Preserve the source and return the original matrix shape.

Expected: diag([5, 3, 1]) at rank 1 reconstructs diag([5, 0, 0]) with error 10\sqrt{10}10​. Full rank has zero tail error; observed reconstruction error may remain at roundoff scale.

def truncated_svd(matrix: np.ndarray, rank: int) -> tuple[np.ndarray, float]:
    a = _matrix(matrix)
    if (
        isinstance(rank, (bool, np.bool_))
        or not isinstance(rank, (int, np.integer))
        or not 0 <= rank <= min(a.shape)
    ):
        raise ValueError("Rank must be an integer from zero through min(shape)")
    u, singular, vh = reduced_svd(a)
    with np.errstate(over="ignore", invalid="ignore"):
        reconstructed = (u[:, :rank] * singular[:rank]) @ vh[:rank, :]
    # hypot.reduce evaluates a Euclidean length without squaring huge values first.
    error = float(np.hypot.reduce(singular[rank:], initial=0.0))
    if not np.isfinite(reconstructed).all() or not np.isfinite(error):
        raise ValueError("Approximation or error exceeds finite floating range")
    return reconstructed, error

For the optimal truncated SVD, the tail norm is the exact Frobenius approximation error in exact arithmetic. This reports the ideal truncation error, not a certified bound on floating-point reconstruction error or data-model error. np.hypot.reduce avoids squaring huge singular values before summation. The theorem concerns matrix approximation, not whether the retained components preserve a downstream classifier or causal interpretation.

Exercise 5: Regularize through an augmented system#

Contract: ridge_fit. Return coefficients minimizing ||A beta - y|| squared plus alpha times ||beta|| squared. Require a nonempty finite real design, matching target and finite nonnegative alpha excluding bool. Solve the least-squares system formed by stacking A with sqrt(alpha) times the identity, and y with zeros. Penalize every column, including any intercept. Alpha zero follows minimum-norm least squares. Reject invalid inputs or nonfinite results with ValueError.

Expected: With A=identity, y=[2, 4] and alpha=1, return [1, 2]. For duplicate columns and positive alpha, coefficients remain finite. Negative alpha must fail.

def ridge_fit(design: np.ndarray, target: np.ndarray, alpha: float) -> np.ndarray:
    a, b = _system(design, target)
    penalty = np.sqrt(_nonnegative(alpha)) * np.eye(a.shape[1])
    augmented = np.vstack((a, penalty))
    observed = np.concatenate((b, np.zeros(a.shape[1])))
    coefficients = np.linalg.lstsq(augmented, observed, rcond=None)[0]
    if not np.isfinite(coefficients).all():
        raise ValueError("Nonfinite fitted coefficients")
    return coefficients

The lower block adds alpha times the squared coefficient norm to the residual objective. This solves the intended regularization problem without explicitly constructing A.T @ A or an inverse. The intercept policy is important: applications often exempt it, but this contract penalizes all columns. Feature scaling changes what an equal coefficient penalty means, so preprocessing is part of model design.

Exercise 6: Audit the fitted objective independently#

Contract: weighted_sse. Return sum(weight * (A beta - y)**2) as a finite float for the same real finite design, target and nonnegative-weight policy as weighted_lstsq, with one finite coefficient per column. Reject malformed inputs or an unrepresentable result with ValueError. Do not refit, mutate inputs or rely on the residuals array returned by lstsq.

Expected: The weighted intercept example at beta=[3] has SSE 12; beta=[2] has SSE 16. lstsq may return an empty residuals array for a rank-deficient system, yet this explicit objective remains meaningful.

def weighted_sse(
    design: np.ndarray, target: np.ndarray, weights: np.ndarray, coefficients: np.ndarray
) -> float:
    a, b = _system(design, target)
    w = _weights(weights, a.shape[0])
    beta = _real(coefficients)
    if beta.shape != (a.shape[1],):
        raise ValueError("Expected one coefficient per design column")
    with np.errstate(over="ignore", invalid="ignore"):
        positive = w > 0
        residual = np.sqrt(w[positive]) * (a[positive] @ beta - b[positive])
        result = float(residual @ residual)
    if not np.isfinite(result):
        raise ValueError("Weighted residual sum exceeds finite floating range")
    return result

Recompute the residual from the original system and the proposed coefficients. This checks a directly observable prediction rather than trusting a solver metadata convention. Its value alone does not prove good conditioning or an appropriate weighting model. Examine perturbations, singular values and domain assumptions as separate evidence. Overflow is rejected rather than returning infinity as if it were a usable score.

from collections.abc import Callable

import numpy as np


def _real(values: np.ndarray) -> np.ndarray:
    source = np.asarray(values)
    if source.dtype.kind not in "iuf":
        raise ValueError("Expected real numeric values, excluding bool")
    result = source.astype(np.float64)
    if not np.isfinite(result).all():
        raise ValueError("Expected finite values")
    return result


def _matrix(values: np.ndarray) -> np.ndarray:
    matrix = _real(values)
    if matrix.ndim != 2 or min(matrix.shape) == 0:
        raise ValueError("Expected a nonempty matrix")
    return matrix


def _system(design: np.ndarray, target: np.ndarray) -> tuple[np.ndarray, np.ndarray]:
    a, b = _matrix(design), _real(target)
    if b.shape != (a.shape[0],):
        raise ValueError("Target must be a vector with one value per row")
    return a, b


def _weights(weights: np.ndarray, rows: int) -> np.ndarray:
    w = _real(weights)
    if w.shape != (rows,) or np.any(w < 0) or not np.any(w > 0):
        raise ValueError("Expected nonnegative row weights with at least one positive value")
    return w


def _nonnegative(value: float) -> float:
    if isinstance(value, (bool, np.bool_)) or not isinstance(
        value, (int, float, np.integer, np.floating)
    ):
        raise ValueError("Expected a finite nonnegative scalar")
    try:
        result = float(value)
    except (TypeError, ValueError) as error:
        raise ValueError("Expected a finite nonnegative scalar") from error
    if not np.isfinite(result) or result < 0:
        raise ValueError("Expected a finite nonnegative scalar")
    return result


def reduced_svd(matrix: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    return np.linalg.svd(_matrix(matrix), full_matrices=False)


def rank_at_tolerance(matrix: np.ndarray, rtol: float) -> int:
    a = _matrix(matrix)
    relative = _nonnegative(rtol)
    singular = np.linalg.svd(a, compute_uv=False)
    # Division avoids overflow in rtol * largest_singular_value.
    if singular[0] == 0:
        return 0
    return int(np.count_nonzero(singular / singular[0] > relative))


def weighted_lstsq(design: np.ndarray, target: np.ndarray, weights: np.ndarray) -> np.ndarray:
    a, b = _system(design, target)
    root = np.sqrt(_weights(weights, a.shape[0]))
    with np.errstate(over="ignore", invalid="ignore"):
        whitened, observed = a * root[:, None], b * root
    if not np.isfinite(whitened).all() or not np.isfinite(observed).all():
        raise ValueError("Prewhitening exceeds finite floating range")
    coefficients: np.ndarray = np.linalg.lstsq(whitened, observed, rcond=None)[0]
    if not np.isfinite(coefficients).all():
        raise ValueError("Nonfinite fitted coefficients")
    return coefficients


def truncated_svd(matrix: np.ndarray, rank: int) -> tuple[np.ndarray, float]:
    a = _matrix(matrix)
    if (
        isinstance(rank, (bool, np.bool_))
        or not isinstance(rank, (int, np.integer))
        or not 0 <= rank <= min(a.shape)
    ):
        raise ValueError("Rank must be an integer from zero through min(shape)")
    u, singular, vh = reduced_svd(a)
    with np.errstate(over="ignore", invalid="ignore"):
        reconstructed = (u[:, :rank] * singular[:rank]) @ vh[:rank, :]
    # hypot.reduce evaluates a Euclidean length without squaring huge values first.
    error = float(np.hypot.reduce(singular[rank:], initial=0.0))
    if not np.isfinite(reconstructed).all() or not np.isfinite(error):
        raise ValueError("Approximation or error exceeds finite floating range")
    return reconstructed, error


def ridge_fit(design: np.ndarray, target: np.ndarray, alpha: float) -> np.ndarray:
    a, b = _system(design, target)
    penalty = np.sqrt(_nonnegative(alpha)) * np.eye(a.shape[1])
    augmented = np.vstack((a, penalty))
    observed = np.concatenate((b, np.zeros(a.shape[1])))
    coefficients: np.ndarray = np.linalg.lstsq(augmented, observed, rcond=None)[0]
    if not np.isfinite(coefficients).all():
        raise ValueError("Nonfinite fitted coefficients")
    return coefficients


def weighted_sse(
    design: np.ndarray, target: np.ndarray, weights: np.ndarray, coefficients: np.ndarray
) -> float:
    a, b = _system(design, target)
    w = _weights(weights, a.shape[0])
    beta = _real(coefficients)
    if beta.shape != (a.shape[1],):
        raise ValueError("Expected one coefficient per design column")
    with np.errstate(over="ignore", invalid="ignore"):
        positive = w > 0
        residual = np.sqrt(w[positive]) * (a[positive] @ beta - b[positive])
        result = float(residual @ residual)
    if not np.isfinite(result):
        raise ValueError("Weighted residual sum exceeds finite floating range")
    return result


def expect_value_error(call: Callable[[], object]) -> None:
    try:
        call()
    except ValueError:
        return
    raise AssertionError("Expected ValueError")


def main() -> None:
    a = np.array([[3.0, 0.0], [0.0, 2.0], [0.0, 0.0]])
    u, singular, vh = reduced_svd(a)
    assert u.shape == (3, 2) and singular.shape == (2,) and vh.shape == (2, 2)
    np.testing.assert_allclose((u * singular) @ vh, a, atol=1e-12)
    np.testing.assert_allclose(u.T @ u, np.eye(2), atol=1e-12)
    np.testing.assert_allclose(vh @ vh.T, np.eye(2), atol=1e-12)
    assert rank_at_tolerance(np.diag([1.0, 1e-9]), 1e-8) == 1
    assert rank_at_tolerance(np.zeros((2, 3)), 0) == 0
    expect_value_error(lambda: rank_at_tolerance(a, -1))
    design, target, weights = (
        np.ones((3, 1)),
        np.array([0.0, 4.0, 100.0]),
        np.array([1.0, 3.0, 0.0]),
    )
    beta = weighted_lstsq(design, target, weights)
    np.testing.assert_allclose(beta, [3.0], atol=1e-12)
    expect_value_error(lambda: weighted_lstsq(design, target, np.zeros(3)))
    low, error = truncated_svd(a, 1)
    np.testing.assert_allclose(low, [[3, 0], [0, 0], [0, 0]], atol=1e-12)
    assert np.isclose(error, 2) and np.isclose(np.linalg.norm(a - low), error)
    assert truncated_svd(a, 0)[0].shape == a.shape
    expect_value_error(lambda: truncated_svd(a, True))
    np.testing.assert_allclose(ridge_fit(np.eye(2), np.array([2.0, 4.0]), 1), [1, 2], atol=1e-12)
    expect_value_error(lambda: ridge_fit(a, np.ones(3), -1))
    assert np.isclose(weighted_sse(design, target, weights, beta), 12)
    assert weighted_sse(design, target, weights, np.array([2.0])) > 12
    expect_value_error(lambda: weighted_sse(design, target, weights, np.array([1.0, 2.0])))
    print("python-numpy-07: six SVD, weighted fit, and ridge contracts passed")


if __name__ == "__main__":
    main()
