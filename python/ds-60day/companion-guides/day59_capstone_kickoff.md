# Day 59 — Capstone Kickoff (Companion Guide)

## Goal
Define scope, success metrics, and a realistic plan for your capstone.

## Deliverables
- Problem statement and hypotheses
- Data sources, contracts, and access plan
- Baseline metric, risks, and milestones with timeline

## Suggested workflow
1) Stakeholders and use cases — who benefits and how?
2) Data audit — quality, freshness, volume, gaps
3) Baseline — heuristics or simplest model
4) Plan — milestones for data prep, modeling, eval, delivery
5) Risks — assumptions, failure modes, mitigations

## Stretch goals
- Create a project board; define acceptance criteria
- Draft a communication cadence and demo checkpoints
