Vocabulary and mental model#

  • Axis: A numbered dimension of an array; reducing an axis combines the positions along that dimension.
  • Broadcasting: A rule matching dimensions from the right, allowing equal sizes or a size of one without explicitly repeating the smaller input.
  • Contraction: An operation that multiplies values and sums over a shared dimension, as in a dot product.
  • Batch dimension: A leading dimension indexing independent examples or matrices while trailing dimensions describe each example.

Shape is part of a function's meaning. An array with shape(n, d) can represent n observations and d features, but NumPy does not know those names. Reducing axis zero averages observations and returns one value per feature. Reducing axis one averages features and returns one value per observation. Both computations can run successfully while one answers the wrong question.

Broadcasting compares dimensions from the right. A matrix(n, d) plus a vector(d,) applies one offset per feature. A vector(n,) does not mean one value per row unless its shape is made(n,1). When n happens to equal d, the wrong operation may run and silently act on columns. Tests should use unequal sizes so a shape mistake cannot hide in a square example.

keepdims=True retains reduced dimensions with size one. A row mean then has shape(n,1), preserving the axis role needed for subtraction. It is clearer than deleting an axis and later guessing how to restore it. Inserting None or using np.newaxis adds a size-one dimension without duplicating all values; the resulting arithmetic may still allocate a much larger result.

Pairwise distances illustrate both power and cost. If a has shape(n, d) and b has shape(m, d), then a[:, None,:]-b[None,:,:] has shape(n, m, d). Summing squared differences over the last axis yields (n, m) distances. This is readable for tiny fixtures but uses memory proportional to nmd. A formula or blocked implementation can reduce temporary storage for large inputs, with different numerical tradeoffs.

Matrix multiplication contracts the last dimension of the left array with the next-to-last dimension of the right. For an input batch(b, n, d) and weights(d, k), the result is(b, n, k). einsum names axes explicitly, making a contraction such as 'bnd, dk->bnk' visible. It is a notation for a mathematical operation, not a guarantee of speed. Compare the result with a hand-derived small case before optimizing.

The exercises make shape validation explicit, preserve inputs, reject undefined denominators and test nonsquare examples. Empty outer batches can remain valid, while a mean over an empty feature axis is usually undefined. Decide these cases before relying on a library warning or accidental broadcasting behavior.

Worked examples and syntax anatomy#

Example 1#
x = np.array([[1.0, 3.0, 5.0], [2.0, 4.0, 9.0]])
centered = x - x.mean(axis=1, keepdims=True)
assert centered.shape == (2, 3) and np.allclose(centered.mean(axis=1), 0)
print("Row centered:", centered.tolist())

axis=1 combines the three feature positions inside each row. keepdims retains a two-by-one mean so subtraction repeats each row's own mean across its three columns. The zero row means are a mathematical invariant, not merely an expected printout.

Example 2#
a = np.array([[0.0, 0.0], [3.0, 4.0]])
b = np.array([[0.0, 4.0], [3.0, 0.0], [0.0, 0.0]])
difference = a[:, None, :] - b[None, :, :]
distance = np.sqrt(np.sum(difference**2, axis=-1))
assert distance.shape == (2, 3)
assert np.allclose(distance, [[4, 3, 0], [3, 4, 5]])
print("Pairwise distances:", distance.tolist())

The inserted singleton axes form every a-row/b-row pair. The final axis still represents coordinate differences and is the only axis summed. The resulting two-by-three table preserves the identities of both sets of points; accidentally summing axis zero would answer a different question.

Common mistakes and diagnosis#

A broadcasting error names incompatible dimensions, but a successful broadcast can still be wrong. Write the semantic axis names and use nonsquare fixtures before changing shapes. If normalization produces NaN only for zero rows, inspect whether division happened before masking. If a pairwise operation exhausts memory, calculate the temporary shape(n, m, d) and estimate its bytes before increasing hardware. If einsum gives an unexpected axis order, read the labels to the right of the arrow as the exact output order and compare one small result with an explicit loop.

Exercises and reasoning#

Exercise 1: Reduce the observation axis#

Return a new floating matrix whose columns have zero means. Require a finite two-dimensional array with at least one row. Test two rows and three columns so row/column mistakes cannot pass accidentally.

Expected: [[1,10,100],[3,14,108]] becomes[[-1,-2,-4],[1,2,4]]. The source is unchanged; shape(0,3) and a vector raise ValueError.

def column_center(values: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    if x.ndim != 2 or x.shape[0] == 0 or not np.isfinite(x).all():
        raise ValueError("Expected a finite matrix with observations")
    mean = (x / x.shape[0]).sum(axis=0, keepdims=True)
    with np.errstate(over="ignore", invalid="ignore"):
        result = x - mean
    if not np.isfinite(result).all():
        raise ValueError("Centered result exceeds finite floating range")
    return np.asarray(result)

Each output column subtracts the average across observations, so axis zero is reduced. Keeping the dimension documents that the result has one row of feature means. Conversion makes fractional means representable. The nonsquare fixture prevents a row-centered result from having a misleadingly compatible interpretation, and the empty-observation rejection prevents an undefined mean from quietly producing NaNs.

x = np.array([[1, 10, 100], [3, 14, 108]])
assert np.allclose(column_center(x), [[-1, -2, -4], [1, 2, 4]])
assert x[0, 0] == 1
assert np.allclose(column_center(np.array([[1e308], [1e308]])), [[0], [0]])
expect_value_error(lambda: column_center(np.empty((0, 3))))
expect_value_error(lambda: column_center(np.array([1, 2])))
Exercise 2: Broadcast one factor per row#

Multiply each matrix row by its corresponding finite factor without mutating either input. Require factors to be a one-dimensional vector whose length equals the number of rows. Permit an empty row batch.

Expected: [[1,2,3],[4,5,6]] with [10,100] gives [[10,20,30],[400,500,600]]. Three factors raise ValueError; shape(0,3) with an empty vector returns (0,3).

def scale_rows(values: np.ndarray, factors: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    f = np.asarray(factors, dtype=float)
    if (
        x.ndim != 2
        or f.ndim != 1
        or len(f) != x.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(f).all()
    ):
        raise ValueError("Expected one finite factor per row")
    return np.asarray(x * f[:, None])

The new axis changes factors from shape(n,) to(n,1), so the factor is repeated across columns of its own row. Without it, a vector is matched to the last dimension and means column factors. The length check is deliberately stronger than asking whether NumPy can broadcast the inputs, because a numerically valid broadcast could violate the function's row-level meaning.

x = np.array([[1, 2, 3], [4, 5, 6]])
assert np.allclose(scale_rows(x, np.array([10, 100])), [[10, 20, 30], [400, 500, 600]])
assert scale_rows(np.empty((0, 3)), np.array([])).shape == (0, 3)
expect_value_error(lambda: scale_rows(x, np.array([1, 2, 3])))
Exercise 3: Create all pairs with a declared contraction#

Return squared Euclidean distances between rows of two finite matrices with equal feature counts. Support empty row sets. Reject mismatched feature dimensions or unrepresentable squared distances with ValueError. Use the tiny broadcasted difference, not Python nested loops.

Expected: [[0,0],[3,4]] against [[0,0]] yields [[0],[25]]. Empty left shape(0,2) returns shape(0,1); two versus three features raises ValueError.

def pairwise_squared(left: np.ndarray, right: np.ndarray) -> np.ndarray:
    a = np.asarray(left, dtype=float)
    b = np.asarray(right, dtype=float)
    if (
        a.ndim != 2
        or b.ndim != 2
        or a.shape[1] != b.shape[1]
        or not np.isfinite(a).all()
        or not np.isfinite(b).all()
    ):
        raise ValueError("Expected finite matrices with equal feature dimensions")
    with np.errstate(over="ignore", invalid="ignore"):
        difference = a[:, None, :] - b[None, :, :]
        result = np.sum(difference * difference, axis=-1)
    if not np.isfinite(result).all():
        raise ValueError("Squared distances exceed finite floating range")
    return np.asarray(result)

The temporary has an axis for left rows, an axis for right rows and an axis for features. Squaring and summing only the feature axis preserves the pair table. The explicit feature-count check prevents unrelated coordinate spaces from being compared. For large row counts this temporary can be expensive; the exercise teaches shape correctness, while a later optimization should use blocking and numerical checks rather than assume broadcasting is always cheap.

a = np.array([[0, 0], [3, 4]])
b = np.array([[0, 0]])
assert np.allclose(pairwise_squared(a, b), [[0], [25]])
assert pairwise_squared(np.empty((0, 2)), b).shape == (0, 1)
expect_value_error(lambda: pairwise_squared(a, np.ones((1, 3))))
Exercise 4: Contract observations using valid weights#

Return weighted column means for a finite matrix using one nonnegative finite weight per row. Require positive total weight. Reject negative weights, zero total or wrong length, rather than dividing and returning NaNs.

Expected: [[1,10],[3,30]] with [1,3] gives [2.5,25]. Weights[0,0],[-1,2] and [1] raise ValueError; weights scaled by ten give the same means.

def weighted_columns(values: np.ndarray, weights: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    w = np.asarray(weights, dtype=float)
    if (
        x.ndim != 2
        or w.ndim != 1
        or len(w) != x.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(w).all()
        or np.any(w < 0)
        or not np.any(w > 0)
    ):
        raise ValueError("Expected finite nonnegative weights with positive sum")
    scaled = w / w.max()
    normalized = scaled / scaled.sum()
    result = np.einsum("n,nd->d", normalized, x)
    if not np.isfinite(result).all():
        raise ValueError("Weighted result exceeds finite floating range")
    return np.asarray(result)

The repeated n label in the einsum input is summed and the remaining d label names the output feature axis. Scaling weights by their maximum before normalization prevents overflow in the total weight. Contracting normalized weights with values then forms a convex mean without multiplying two huge unnormalized operands. Scaling all weights equally must not change the result, giving an independent invariant. The nonnegative contract makes these weights interpretable as averaging weights; allowing signed weights would define a different operation with different denominator behavior.

x = np.array([[1, 10], [3, 30]])
assert np.allclose(weighted_columns(x, np.array([1, 3])), [2.5, 25])
assert np.allclose(weighted_columns(x, np.array([10, 30])), [2.5, 25])
assert np.isclose(
    weighted_columns(np.array([[1e308], [1e308]]), np.array([1e308, 1e308]))[0], 1e308
)
expect_value_error(lambda: weighted_columns(x, np.array([0, 0])))
expect_value_error(lambda: weighted_columns(x, np.array([-1, 2])))
expect_value_error(lambda: weighted_columns(x, np.array([1])))
Exercise 5: Preserve leading batch axes#

Apply a finite two-dimensional weight matrix(d, k) to values with at least two dimensions and final dimension d. Return all leading dimensions followed by k. Reject an incompatible final dimension.

Expected: A(2,3,4) input times a(4,2) weight matrix returns (2,3,2), matching an explicit per-batch matrix multiply. A(3,4) input also works; weights(3,2) are rejected.

def batched_projection(values: np.ndarray, weights: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    w = np.asarray(weights, dtype=float)
    if (
        x.ndim < 2
        or w.ndim != 2
        or x.shape[-1] != w.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(w).all()
    ):
        raise ValueError("Expected a compatible final feature dimension")
    return np.asarray(np.einsum("...d,dk->...k", x, w))

The ellipsis preserves every leading axis instead of hardcoding one batch dimension. Only the feature dimension d contracts with the weight matrix, and k becomes the last output dimension. Comparing with explicit per-batch multiplication validates the contraction independently of its compact notation. A reshape that flattens batches can produce equal numbers but lose entity boundaries, so shape is checked alongside values.

x = np.arange(24).reshape(2, 3, 4)
w = np.arange(8).reshape(4, 2)
r = batched_projection(x, w)
assert r.shape == (2, 3, 2) and np.allclose(r, np.stack([x[0] @ w, x[1] @ w]))
assert batched_projection(x[0], w).shape == (3, 2)
expect_value_error(lambda: batched_projection(x, np.ones((3, 2))))
Exercise 6: Normalize while preserving zero vectors#

Return a new finite matrix whose nonzero rows have Euclidean norm one and zero rows remain zero. Reject nonfinite or nonmatrix inputs. Avoid evaluating a zero division and then hiding its warning.

Expected: [[3,4],[0,0],[-2,0]] becomes[[.6,.8],[0,0],[-1,0]]. All results are finite, source stays unchanged and infinity raises ValueError.

def unit_rows(values: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    if x.ndim != 2 or not np.isfinite(x).all():
        raise ValueError("Expected a finite matrix")
    scale = np.max(np.abs(x), axis=1, keepdims=True, initial=0)
    scaled = np.zeros_like(x)
    np.divide(x, scale, out=scaled, where=scale != 0)
    norm = np.linalg.norm(scaled, axis=1, keepdims=True)
    result = np.zeros_like(x)
    np.divide(scaled, norm, out=result, where=norm != 0)
    return np.asarray(result)

Scaling each row by its largest absolute value first prevents squared-norm overflow for very large finite coordinates. The norm then reduces bounded features while retaining a one-column axis. A zero-initialized output gives zero rows their declared result, and where prevents invalid division. This differs from np.where(condition, x/norm,0), which evaluates x/norm before selection and may emit invalid values. Normalization changes scale but does not create meaningful direction for a zero vector.

x = np.array([[3.0, 4.0], [0.0, 0.0], [-2.0, 0.0]])
r = unit_rows(x)
assert np.allclose(r, [[0.6, 0.8], [0.0, 0.0], [-1.0, 0.0]]) and np.isfinite(r).all()
assert np.array_equal(x, [[3, 4], [0, 0], [-2, 0]])
assert np.allclose(unit_rows(np.array([[1e308, 1e308]])), [[np.sqrt(0.5), np.sqrt(0.5)]])
expect_value_error(lambda: unit_rows(np.array([[np.inf]])))

"""Reference implementation and exact boundary checks for python-numpy-02."""

from collections.abc import Callable

import numpy as np


def column_center(values: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    if x.ndim != 2 or x.shape[0] == 0 or not np.isfinite(x).all():
        raise ValueError("Expected a finite matrix with observations")
    mean = (x / x.shape[0]).sum(axis=0, keepdims=True)
    with np.errstate(over="ignore", invalid="ignore"):
        result = x - mean
    if not np.isfinite(result).all():
        raise ValueError("Centered result exceeds finite floating range")
    return np.asarray(result)


def scale_rows(values: np.ndarray, factors: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    f = np.asarray(factors, dtype=float)
    if (
        x.ndim != 2
        or f.ndim != 1
        or len(f) != x.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(f).all()
    ):
        raise ValueError("Expected one finite factor per row")
    return np.asarray(x * f[:, None])


def pairwise_squared(left: np.ndarray, right: np.ndarray) -> np.ndarray:
    a = np.asarray(left, dtype=float)
    b = np.asarray(right, dtype=float)
    if (
        a.ndim != 2
        or b.ndim != 2
        or a.shape[1] != b.shape[1]
        or not np.isfinite(a).all()
        or not np.isfinite(b).all()
    ):
        raise ValueError("Expected finite matrices with equal feature dimensions")
    with np.errstate(over="ignore", invalid="ignore"):
        difference = a[:, None, :] - b[None, :, :]
        result = np.sum(difference * difference, axis=-1)
    if not np.isfinite(result).all():
        raise ValueError("Squared distances exceed finite floating range")
    return np.asarray(result)


def weighted_columns(values: np.ndarray, weights: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    w = np.asarray(weights, dtype=float)
    if (
        x.ndim != 2
        or w.ndim != 1
        or len(w) != x.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(w).all()
        or np.any(w < 0)
        or not np.any(w > 0)
    ):
        raise ValueError("Expected finite nonnegative weights with positive sum")
    scaled = w / w.max()
    normalized = scaled / scaled.sum()
    result = np.einsum("n,nd->d", normalized, x)
    if not np.isfinite(result).all():
        raise ValueError("Weighted result exceeds finite floating range")
    return np.asarray(result)


def batched_projection(values: np.ndarray, weights: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    w = np.asarray(weights, dtype=float)
    if (
        x.ndim < 2
        or w.ndim != 2
        or x.shape[-1] != w.shape[0]
        or not np.isfinite(x).all()
        or not np.isfinite(w).all()
    ):
        raise ValueError("Expected a compatible final feature dimension")
    return np.asarray(np.einsum("...d,dk->...k", x, w))


def unit_rows(values: np.ndarray) -> np.ndarray:
    x = np.asarray(values, dtype=float)
    if x.ndim != 2 or not np.isfinite(x).all():
        raise ValueError("Expected a finite matrix")
    scale = np.max(np.abs(x), axis=1, keepdims=True, initial=0)
    scaled = np.zeros_like(x)
    np.divide(x, scale, out=scaled, where=scale != 0)
    norm = np.linalg.norm(scaled, axis=1, keepdims=True)
    result = np.zeros_like(x)
    np.divide(scaled, norm, out=result, where=norm != 0)
    return np.asarray(result)


def expect_value_error(call: Callable[[], object]) -> None:
    try:
        call()
    except ValueError:
        return
    raise AssertionError("Expected ValueError")


def main() -> None:
    # Exercise 1: Reduce the observation axis
    x = np.array([[1, 10, 100], [3, 14, 108]])
    assert np.allclose(column_center(x), [[-1, -2, -4], [1, 2, 4]])
    assert x[0, 0] == 1
    assert np.allclose(column_center(np.array([[1e308], [1e308]])), [[0], [0]])
    expect_value_error(lambda: column_center(np.empty((0, 3))))
    expect_value_error(lambda: column_center(np.array([1, 2])))
    # Exercise 2: Broadcast one factor per row
    x = np.array([[1, 2, 3], [4, 5, 6]])
    assert np.allclose(scale_rows(x, np.array([10, 100])), [[10, 20, 30], [400, 500, 600]])
    assert scale_rows(np.empty((0, 3)), np.array([])).shape == (0, 3)
    expect_value_error(lambda: scale_rows(x, np.array([1, 2, 3])))
    # Exercise 3: Create all pairs with a declared contraction
    a = np.array([[0, 0], [3, 4]])
    b = np.array([[0, 0]])
    assert np.allclose(pairwise_squared(a, b), [[0], [25]])
    assert pairwise_squared(np.empty((0, 2)), b).shape == (0, 1)
    expect_value_error(lambda: pairwise_squared(a, np.ones((1, 3))))
    # Exercise 4: Contract observations using valid weights
    x = np.array([[1, 10], [3, 30]])
    assert np.allclose(weighted_columns(x, np.array([1, 3])), [2.5, 25])
    assert np.allclose(weighted_columns(x, np.array([10, 30])), [2.5, 25])
    assert np.isclose(
        weighted_columns(np.array([[1e308], [1e308]]), np.array([1e308, 1e308]))[0], 1e308
    )
    expect_value_error(lambda: weighted_columns(x, np.array([0, 0])))
    expect_value_error(lambda: weighted_columns(x, np.array([-1, 2])))
    expect_value_error(lambda: weighted_columns(x, np.array([1])))
    # Exercise 5: Preserve leading batch axes
    x = np.arange(24).reshape(2, 3, 4)
    w = np.arange(8).reshape(4, 2)
    r = batched_projection(x, w)
    assert r.shape == (2, 3, 2) and np.allclose(r, np.stack([x[0] @ w, x[1] @ w]))
    assert batched_projection(x[0], w).shape == (3, 2)
    expect_value_error(lambda: batched_projection(x, np.ones((3, 2))))
    # Exercise 6: Normalize while preserving zero vectors
    x = np.array([[3.0, 4.0], [0.0, 0.0], [-2.0, 0.0]])
    r = unit_rows(x)
    assert np.allclose(r, [[0.6, 0.8], [0.0, 0.0], [-1.0, 0.0]]) and np.isfinite(r).all()
    assert np.array_equal(x, [[3, 4], [0, 0], [-2, 0]])
    assert np.allclose(unit_rows(np.array([[1e308, 1e308]])), [[np.sqrt(0.5), np.sqrt(0.5)]])
    expect_value_error(lambda: unit_rows(np.array([[np.inf]])))
    print("python-numpy-02: all six normal and boundary contracts passed")


if __name__ == "__main__":
    main()
