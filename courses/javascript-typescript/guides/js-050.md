# js-050: Scatterplots, size encodings and overplotting

## Level and prerequisites

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: `js-049`.

## Learning objectives

Build a scatterplot whose size encoding is proportional to area and handle overplotted points. The central exercise is: Build a three-variable scatterplot.

## Purpose, vocabulary and mental model

A scatterplot uses two quantitative positions to show the joint distribution of observations. Each point should have a defined row grain, such as one person or one experiment. A visible association does not by itself establish causality, and a few synthetic points cannot support a population conclusion.

When a third quantity controls circle size, decide whether the quantity maps to radius or area. Viewers perceive the filled area, so a square-root radius scale often makes area proportional to a nonnegative quantity. Doubling a radius quadruples area. A legend should explain the size meaning.

Overplotting occurs when points overlap. Opacity, smaller marks, aggregation or a density representation can help, but each changes what the reader can infer. Jitter can reveal repeated values while deliberately moving positions; explain and bound it rather than presenting moved points as exact measurements.

### Key terms

- **Scatterplot:** A chart that places each record as a point at two quantitative positions to show the joint distribution of two variables.
- **Area encoding:** Representing a third quantity by circle area. A `d3.scaleSqrt` radius keeps area proportional to the value, since doubling a radius quadruples the area.
- **Overplotting:** Points overlapping so that density and repeated values are hidden. Opacity, smaller marks, jitter or aggregation can reveal them, each changing what a reader can infer.
- **Jitter:** Small, bounded, disclosed offsets added to point positions to separate identical coordinates; jittered points are no longer exact measurements.
- **Correlation:** The degree to which two variables move together. A visible association in a scatterplot does not by itself establish causation.

## Syntax anatomy and mechanism

Use independent x and y scales for their units. A `scaleSqrt` radius range maps nonnegative magnitude to radius. A circle at `(x(d.x), y(d.y))` encodes one record. Colors can represent categories, but labels or shapes should support readers who cannot distinguish the colors.

The reference validates finite positions and the area relationship for magnitudes 1 and 4. It does not perform a statistical test. Use a tooltip or table for exact records and make missing or invalid coordinates an explicit data policy.

## Worked example / walkthrough

### Worked example 1: Compare radius and area

The ratio follows the square of radius.

```javascript
const r = d3.scaleSqrt().domain([0, 4]).range([0, 20]);
console.log(r(1), r(4));
```

**Expected observation:** 10 and 20; areas have ratio 1 to 4.

### Worked example 2: Detect duplicate coordinates

Repeated positions can hide observations, so this view counts records per position and sizes each circle by area.

```javascript
// js-050 worked example 2: a complete program for the classroom preview.
const host = document.querySelector("#chart");
const output = document.querySelector("#output");
host.replaceChildren();
const check = (condition, message) => {
  if (!condition) throw new Error(message);
};
const svg = d3
  .select(host)
  .append("svg")
  .attr("viewBox", "0 0 640 360")
  .attr("role", "img")
  .attr("aria-label", "Scatterplots, size encodings and overplotting")
  .style("width", "100%")
  .style("max-width", "640px");
const points = [
  { x: 1, y: 2 },
  { x: 1, y: 2 },
  { x: 2, y: 3 },
];
const x = d3.scaleLinear().domain([0, 3]).range([60, 600]);
const y = d3.scaleLinear().domain([0, 4]).range([320, 40]);
const counts = [
  ...d3.rollup(
    points,
    (rows) => rows.length,
    (d) => d.x,
    (d) => d.y,
  ),
].flatMap(([px, byY]) => [...byY].map(([py, n]) => ({ px, py, n })));
check(counts.length === 2, "Three records share two positions");
svg
  .selectAll("circle")
  .data(counts)
  .join("circle")
  .attr("cx", (d) => x(d.px))
  .attr("cy", (d) => y(d.py))
  .attr("r", (d) => 10 * Math.sqrt(d.n))
  .attr("fill", "#0f766e")
  .attr("fill-opacity", 0.7);
svg
  .selectAll("text")
  .data(counts)
  .join("text")
  .attr("x", (d) => x(d.px) + 20)
  .attr("y", (d) => y(d.py) + 5)
  .text((d) => `n = ${d.n}`);
output.textContent = "js-050 worked example 2 complete";
```

**Expected observation:** Two circles labeled n = 2 and n = 1; the repeated position is drawn once, with an area proportional to its two records.

## Debugging and common mistakes

When large values dominate, check whether the size scale maps magnitude to radius. A linear radius makes area grow with the square of the value; `d3.scaleSqrt` keeps area proportional, so sizes 1 and 4 give radii 10 and 20. Count records and unique coordinates separately to detect overplotting before trusting the visual density. ([checkpoints](../STUDY-GUIDE.md#d3-debugging-checkpoints))

Exercise 4 is the controlled failure: Diagnose mapping magnitude directly to radius. Distinguishing evidence: Area exaggerates large values quadratically.

## Accessibility and interpretation

Size and position are hard to read exactly, so give each point an accessible name with both coordinates and its size value, and add a summary of the overall pattern. Do not rely on transparency alone to show overlap; state the count at each repeated position in a label or table. ([accessibility review](../STUDY-GUIDE.md#d3-accessibility-review))

A scatterplot shows association between two measured variables at a stated row grain. An upward trend does not show that one variable causes the other; a third variable, selection or measurement design may explain it. Say how overplotted records are shown, because jitter, transparency and aggregation each change what the reader sees. ([statistical meaning](../STUDY-GUIDE.md#d3-statistical-meaning))
