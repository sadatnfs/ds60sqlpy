# Independent Spark likelihood package

This directory is the canonical implementation of distribution `ds60-spark-likelihood`, import `ds60_spark_likelihood`, version 0.1.0. It must not import the classroom/server package or require R. Root source paths under `src/ds60sqlpy/spark_likelihood` are compatibility aliases only; do not duplicate numerical implementations there.

Preserve the tested row kernel, finite float64 contracts, weighted reduction, one global penalty, empty-partition receipts, parameter digests and truthful optimizer status. Joint complete-unit losses use a distinct protocol and cannot be simulated by returning a scalar from the per-row callback. Cross-unit coupling must be refused or explicitly implemented with a different algorithm.

User-defined models require explicit dimensions, parameter/feature identities, deterministic behavior and prediction semantics. Prediction must be response-free. Persist JSON identities/configuration/parameters, not executable pickles or inferred generic prediction formulas. Runtime fitting never installs dependencies or collects raw observations to the driver.

Test independent mathematical oracles, invalid shapes/domains, changed weights/partitions, source/config identities, group integrity and actual native runtime behavior. Build a wheel, install it in an isolated environment and verify imports do not resolve through the classroom checkout. CPU/local Spark evidence is not GPU or remote-cluster performance evidence. Preserve failed and passed receipts. Coordinate heavy builds with the parent release owner. No em dashes.
