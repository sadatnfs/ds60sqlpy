## Mechanism and purpose

Python control flow and numerical control flow answer different questions during tracing. A Python branch can choose a static configuration before compilation. A runtime array value needs a representation whose decision remains part of the numerical computation. lax.cond supplies that representation for a scalar predicate, with branches that agree on output structure and shape.

A loop also has a state contract. lax.scan applies one transition repeatedly over a sequence and can return both the final carry and a history of outputs. The carry must retain its shape, dtype and tree structure at each step. A changing-length Python list is not a valid replacement for a fixed numerical carry. If the task needs variable-length records, padding, masks or a separate input-validation policy can provide a fixed storage representation without pretending padding is an observation.

Scan is especially useful for training and simulation because it makes the transition explicit. The mathematical recurrence should be derived before the code. A hidden dependency on a later input, an incorrect initial value or a different recurrence coefficient changes the function even if every output shape remains legal.

Dynamic while loops have a different differentiation contract from a fixed scan. A condition based on a runtime value can control how many iterations execute. Ordinary reverse-mode differentiation through such a dynamic loop is not generally supported by the standard primitive, whereas forward-mode can answer some local sensitivity questions. Do not replace a meaningful stopping rule with a fixed number of iterations merely to hide a differentiation error without explaining the changed computation.

A padded batch and a fixed-length scan are implementation tools, not permission to dilute an objective. Keep the count of participating events explicit. The next units will compose these control-flow choices with vectorization and masked objectives, retaining the same separation between storage and statistical meaning.

## Derivation and shape contract

The recurrence \(h_{t+1}=\frac12h_t+x_t\), starting at zero with inputs \([2,2,2]\), gives states \([2,3,3.5]\). The final sensitivity to the initial state is \((1/2)^3=1/8\). Sensitivities to the three inputs are \([1/4,1/2,1]\): earlier inputs pass through more attenuation steps. These independently derived coefficients test the transition and its differentiation together.

## Worked investigations

### Worked example 1: Trace a scan

Evaluate the recurrence on three values equal to two.

The returned carry and history have different roles. The final carry is the last updated state; the history makes every transition inspectable.

**Expected:** Final 3.5, history [2,3,3.5].

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def recurrence(initial, values):
    def step(carry, value):
        updated = 0.5 * carry + value
        return updated, updated

    return jax.lax.scan(step, initial, values)


def main():
    # Case 1: Trace a scan
    last, history = recurrence(jnp.float64(0.0), jnp.array([2.0, 2.0, 2.0]))
    close(last, 3.5)
    close(history, [2.0, 3.0, 3.5])

    print("jax-011: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

### Worked example 2: Branch on a runtime value

JIT branch and evaluate positive two and negative two.

Both branches return one scalar with the same dtype. The condition is represented inside the numerical program rather than converted to a Python Boolean during tracing.

**Expected:** 4 and 2.

```python
"""Small offline JAX mechanism investigation; CPU evidence only."""

from __future__ import annotations

import numpy as np
import jax
import jax.numpy as jnp


# Choose precision before creating arrays; the usual JAX default is 32 bit.
jax.config.update("jax_enable_x64", True)


def close(actual, expected, *, atol=1e-10, rtol=1e-10):
    np.testing.assert_allclose(np.asarray(actual), expected, atol=atol, rtol=rtol)


def branch(value):
    return jax.lax.cond(value >= 0.0, lambda x: x * x, lambda x: -x, value)


def main():
    # Case 1: Branch on a runtime value
    compiled = jax.jit(branch)
    close(compiled(jnp.float64(2.0)), 4.0)
    close(compiled(jnp.float64(-2.0)), 2.0)

    print("jax-011: 1 asserted case passed")


if __name__ == "__main__":
    main()
```

## Diagnosis and boundaries

For a carry error, compare shape, dtype and tree structure before and after one transition. For a gradient failure, identify the primitive and the differentiation mode. A branch that changes output shape needs a different representation or explicit static configuration.
