## Outcome and mechanism

Create a typed table, select records safely and verify its grain and key instead of relying on row positions.

A data frame stores columns that can have different types while presenting rows as aligned records. That alignment is positional within the table. The first row of every column describes the same observation, so a transformation must preserve the relationship among its fields. Sorting one column independently would destroy that record alignment.

Declare the row grain before interpreting a count or total. A table of order lines can contain repeated order IDs without being corrupt, while a customer dimension usually requires a unique customer key. R does not infer these business rules from the column names. Assertions should check uniqueness at the intended key and retain missing-key diagnostics.

Selection has several interfaces. df["amount"] returns a data frame, df[["amount"]] returns a vector, and df[rows, cols, drop=FALSE] explicitly preserves a rectangular result. Logical row masks should be complete when unknown rows are not intended. Subsetting with an NA mask can introduce rows of missing values, so the missingness policy belongs in the mask.

Modern R data.frame creation does not automatically convert strings to factors by default. Character labels and categorical factors are still distinct, and later lessons explain when each is appropriate. For now, inspect names, nrow and str, verify types and key constraints, and avoid treating row names as a durable business identifier.

## Read the syntax

Use data.frame to align columns, nrow/ncol for dimensions and df[order(df$id),, drop=FALSE] to sort complete records. anyDuplicated detects repeated keys; is.na detects missing ones. A valid key needs both checks.

## Worked examples

### Example 1: Sort records together

```r
orders <- data.frame(id = c("B", "A", "C"), amount = c(20, 10, 30))
stopifnot(!anyDuplicated(orders$id), !anyNA(orders$id))
ordered <- orders[order(orders$id), , drop = FALSE]
stopifnot(identical(ordered$id, c("A", "B", "C")))
stopifnot(identical(ordered$amount, c(10, 20, 30)))
print(ordered)
```

**Expected observation:** A10, B20, C30.

The row permutation is applied to the entire data frame. Each ID retains its original amount.

### Example 2: One selected column retains a declared shape

```r
measurements <- data.frame(id = c("A", "B", "C"), amount = c(10, NA_real_, 30))
keep <- !is.na(measurements$amount) & measurements$amount >= 20
selected <- measurements[keep, "amount", drop = FALSE]
stopifnot(is.data.frame(selected), nrow(selected) == 1L, ncol(selected) == 1L)
stopifnot(selected$amount == 30)
print(selected)
```

**Expected observation:** A one-row one-column data frame with amount 30.

The complete mask excludes the unknown amount. drop=FALSE preserves a table even though only one row and one column remain.
