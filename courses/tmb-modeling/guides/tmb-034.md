# Alternative integration and sequential reduction

Start with: tmb-033.

Outcome: Compare integration strategies without confusing a documented helper with a supported public export.

**Where this runs.** In the classroom, the base-R companion at the end of this chapter compares quadrature with the Laplace value and evaluates a discrete mixture marginal. In the separately prepared [owned project](../projects/tmb-local/README.md), `tests/public_api.R` only prints the `TMB::SR()` grid descriptor; no sequential-reduction fit runs there; a companion run is not a TMB compiler or rpy2 receipt, so its output is not evidence that a compiled model or the rpy2 bridge ran.

Laplace approximation is not the only possible way to integrate latent variables. Low-dimensional numerical quadrature can provide a useful oracle, and structured sequential reductions can exploit particular dependency patterns. The `integrate` argument of `MakeADFun` selects specialized integration paths whose requirements must be matched to the model.

`SR(x, discrete=FALSE)` is an exported helper for a sequential-reduction integration grid. Here `x` supplies interval breaks: the actual descriptor for breaks -3 through 3 has six midpoint locations and six unit widths. The continuous mode represents integration with respect to Lebesgue measure; the discrete mode uses counting measure. Constructing this descriptor is not the same as fitting an integrated model. The manual also documents `GK(...)`, a Gauss-Kronrod helper, but the pinned TMB 1.9.25 NAMESPACE does not export `GK`. That distinction matters: documentation presence does not guarantee that `TMB::GK` is a supported public call. This course records it as a documented non-exported helper and does not create a stable runtime promise around namespace-internal access.

## Key terms

- **Numerical quadrature:** Approximating an integral by a weighted sum over grid points, a useful oracle for small latent integrals.
- **SR:** The exported helper `SR(x, discrete=FALSE)` that builds a sequential-reduction integration grid from interval breaks, giving midpoints and widths.
- **Counting measure:** The measure used in discrete mode, where integration over a latent variable becomes a sum over its values.
- **Non-exported helper:** A function such as `GK` that the manual documents but the pinned NAMESPACE does not export, so it is not a supported public call.

### Worked case A: quadrature checks a small latent integral

The companion compares one-dimensional numerical integration of a non-quadratic density with its local Gaussian Laplace approximation. Increasing the tail penalty changes the true integral while leaving the local quadratic curvature unchanged. This creates a transparent test case for approximation quality.

A grid's domain and spacing determine accuracy. Too narrow a domain drops tail mass; too coarse a grid misses curvature. Numerical quadrature can also be expensive as dimension increases. A tensor grid with \(k\) points per axis has \(k^q\) combinations in \(q\) dimensions, making naive high-dimensional integration impractical.

### Worked case B: discrete integration is summation

For a finite latent state with known prior probabilities, marginalization is a weighted sum of conditional likelihoods. The companion computes a two-state mixture directly. Treating the state as a continuous parameter and applying a Gaussian Laplace approximation would change the problem. `discrete=TRUE` in a relevant grid helper expresses a distinct integration measure; it is not a universal switch for every latent categorical model.

### Answered discussion

**Should every large model use sequential reduction?** Only if its structure and the method's tested contract support it. **Can I claim exact inference because quadrature is deterministic?** Numerical truncation and integration error remain. **Why mention an unexported helper?** To prevent learners from mistaking an internal or incompletely exposed API for a promised stable interface. The inventory lists both callable public surface and explicitly separate documented helpers.

Use the [MakeADFun, SR and GK manual entries](https://cran.r-project.org/web/packages/TMB/TMB.pdf), pinned source and independent tiny examples before preparing an advanced integration variant.

### Worked case C: how far Laplace is from the quartic integral

For \(g(u)=u^2/2+\lambda u^4\), the mode is 0 and \(g''(0)=1\) for every \(\lambda\), so Laplace always returns \(\sqrt{2\pi}=2.506628\). The true integral shrinks as the tail penalty grows:

```text
lambda   quadrature   laplace    ratio     (numerical grid values, rounded)
0.1      2.1497       2.5066     0.858
0.8      1.6175       2.5066     0.645
```

These quadrature values come from a fine Riemann sum on \([-12,12]\), not from an R run; `integrate()` in the companion should agree to about four digits. With \(\lambda=0.1\), Laplace overstates the integral by about 17%, so the Laplace NLL is too small by \(-\log 0.858=0.153\). With \(\lambda=0.8\), the error grows to \(-\log 0.645=0.439\). If \(\lambda\) were an estimated parameter, these errors would vary with it and bias its estimate, because the approximation is blind to the quartic term that \(\lambda\) controls. A second-order curvature check at the mode cannot reveal the problem, since the curvature is identical in both rows.

### The two-state mixture and the grid explosion

The companion's mixture places prior mass 0.3 on a state with mean \(-1\) and 0.7 on a state with mean 1, both with standard deviation 0.8, and evaluates the observation 0.5. The conditional densities are 0.085983 and 0.410201, so the marginal is \(0.3(0.085983)+0.7(0.410201)=0.312936\) and the NLL is 1.161758 (closed-form values, rounded). The posterior probability of the first state is \(0.025795/0.312936=0.082\). That summation is exact; no curvature or mode is involved. A continuous Laplace treatment of a state label would instead look for a mode of a function defined only at two points.

The final frame prints \(20^q\) grid points: 20, 400, 8,000, 160,000 and 3,200,000 for \(q=1\) through 5. At five latent dimensions a tensor grid already needs over three million joint objective evaluations per outer step, which is why sequential reduction only helps when the model's dependency graph lets the sum or integral be taken one coordinate at a time. A chain where each state touches only its neighbors fits that pattern; a fully connected latent vector does not.

### Base-R companion (runs in the classroom)

```r
for (lambda in c(.1, .8)) {
  integral <- integrate(function(u) exp(-u^2 / 2 - lambda * u^4), -Inf, Inf)$value
  print(c(lambda = lambda, quadrature = integral, laplace = sqrt(2 * pi)))
}
prior <- c(.3, .7);conditional <- dnorm(.5, mean = c(-1, 1), sd = .8)
marginal <- sum(prior * conditional)
print(c(marginal_density = marginal, nll = -log(marginal)));stopifnot(marginal > 0)
print(data.frame(dimension = 1:5, grid_points = 20^(1:5)))
```
