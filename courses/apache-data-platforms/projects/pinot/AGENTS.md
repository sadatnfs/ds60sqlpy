# Owned Pinot workshop

Follow root and Apache course guidance. This project runs actual Pinot controller,
broker, server and ZooKeeper processes from the pinned official image. Each role
has distinct private-network addressing. Never replace it with QuickStart for
lifecycle qualification: the pinned QuickStart deletes its temporary data at
shutdown. Preserve the independently owned state volumes and use read-only checks
after resume or replacement. Kafka/hybrid/upsert and multistage extensions are
prepared routes until separately exercised. No global prune, TLS bypass, ambient
cluster access, emulation, publication or changes to learner volumes.
