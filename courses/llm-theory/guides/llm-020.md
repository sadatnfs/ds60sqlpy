## Purpose and mental model

<!-- textbook-foundations-start -->

### Numerical scale is part of the computation, not just a training setting

A model can have the right layers and target shapes while numerical values grow beyond a useful range. Large activations may produce very sharp softmax distributions, a squared objective may overflow even when its input is finite, and gradients may become too small or too large for a stable update. Initialization determines where this process begins. Understanding a simple scale transformation is more useful than treating every nonfinite loss as a mysterious property of deep learning.

The fixture uses \(x=[1,-1,2,-2]\). Its squared coordinates sum to ten, so its Euclidean norm is \(\sqrt{10}\). Multiplying by a diagonal matrix aI scales every coordinate by a. With \(a=0.01\) the output is [0.01,-0.01,0.02,-0.02]; with \(a=100\) it is [100,-100,200,-200]. The second norm is ten thousand times the first because 100/0.01=10,000. No randomness or nonlinear activation is involved, so this comparison isolates one cause.

Now score the output with the mean of its four squared coordinates. The loss is \(L=2.5a^2\). At \(a=0.01\) it is 0.00025; at \(a=100\) it is 25,000. Thus a ten-thousand-fold change in output scale produces a hundred-million-fold change in this objective. The derivative with respect to the full weight matrix scales linearly in a for this fixture, giving gradient norms about 0.05 and 500. Forward norms, loss magnitudes and parameter-gradient norms are related, but they do not share the same scale law.

This distinction explains why checking only the final loss is insufficient. At scale 1e38 in float32, the largest output coordinate is about 2e38, which can still be finite. Squaring it exceeds the representation's range, so the objective becomes nonfinite at that later operation. A log saying "the model output was finite" does not establish that the loss or backward path will remain finite. Inspect intermediate results in execution order and identify the first operation that violates the contract.

Residual addition creates another scale relationship. For the small diagonal branch, x+x*(0.01I)=1.01x, so it perturbs the representation only slightly. A branch with a very large output can dominate the residual stream, while a branch near -x can cancel it. Matching shape is necessary for addition but does not control magnitude or information retention. Normalization and initialization policies can help manage these relationships; their effects depend on the exact architecture and objective.

The lesson does not recommend 0.01 as a universal initialization constant. In a wider layer, the number of inputs and assumptions about their variance influence how sums scale. Learned representations can violate idealized independence assumptions, and a deep network combines many paths. Use this exact fixture to learn how to derive a scale effect, then inspect the actual layer statistics in a larger model. Replacing the failing input with an easier one would not demonstrate a repair; restoring finite behavior on the same fixture does.

## Vocabulary and concepts

**Activation norm:** Magnitude of an intermediate representation.

**Initialization scale:** Magnitude policy for initial parameter values.

**Residual scale:** Relative contribution of an added transformation branch.

## Syntax anatomy and reasoning sequence

Use torch.linalg.vector_norm to measure a tensor magnitude and torch.isfinite for elementwise checks. A matrix multiplied by a scalar scales linear outputs by that scalar. Autograd derivatives of a squared objective grow accordingly. Float32 multiplication by enormous values can overflow even when the input itself is finite. Keep the first nonfinite location in the diagnostic record.

## Calculate scale effects before a large model

For x=[1, -1, 2, -2], the Euclidean norm is \(\sqrt{10}\). A diagonal weight aI produces ax, so output norm is \(\left|a\right|\cdot \sqrt{10}\). Moving a from 0.01 to 100 multiplies the output norm by 10, 000. This is an exact property of the fixture, not an empirical recommendation for an initialization scale.

With loss equal to the mean of four squared outputs, \(L=\frac14\lVert xW\rVert_2^2\). At W=aI, the loss is \(2.5a^2\) and the weight gradient is (a/2)\({x}^{T}\) x. The Frobenius norm of \({x}^{T}\) x is ||x||^2=10, so the gradient norm is \(5\cdot \left|a\right|\). The small and large gradient norms are therefore about 0.05 and 500, again a factor of 10, 000, while the loss changes by a factor of 100, 000, 000. Forward magnitudes, gradient magnitudes and objective magnitudes scale differently.

## Locate the first nonfinite operation

At scale 1e38 in float32, the largest output magnitude in this fixture is about 2e38, still within the finite representation range. Squaring that output exceeds the range, so the objective can overflow even though the preceding matrix product is finite. Inspecting only the final loss cannot identify this first failing operation. Track intermediate tensors and their dtypes before widening tolerances or blaming the optimizer.

The repair uses the same input with a smaller scale, making the comparison controlled. It demonstrates numeric sensitivity; it does not prove that this diagonal initialization is suitable for a trained Transformer. Real initialization methods account for fan-in, fan-out, activation behavior and layer depth. Under simplified independent zero-mean assumptions, a sum of Din products has variance proportional to Din times input variance times weight variance, motivating inverse-fan-in scaling. Those assumptions should be named rather than treated as a universal distribution law.

Residual addition also needs a matching representation shape. A [1, 4] input can add a [1, 4] branch, while a [1, 3] branch violates the feature contract. Shape compatibility alone does not ensure good numerical conditioning: repeated residual branches can still amplify or cancel directions. The normalized decoder and later pre/post-norm chapter connect this scale diagnostic to actual model structure.


## Worked example / walkthrough

### Example A: Measure a small linear layer

The identity orientation preserves the input direction. Only scale changes, so the norm relation is independent of random projections.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F

x=torch.tensor([[1.,-1.,2.,-2.]]); small=.01*torch.eye(4); out=x@small
np.testing.assert_allclose(torch.linalg.vector_norm(out).item(),.01*np.sqrt(10),atol=1e-6,rtol=0)
```

**Expected:** output norm.01*sqrt10.

### Example B: Increase only the scale

Changing both scale and random orientation would confound the comparison. Here the factor follows directly from linearity.

```python
import numpy as np
import torch
from torch import nn
from torch.nn import functional as F

x=torch.tensor([[1.,-1.,2.,-2.]]); small=.01*torch.eye(4); out=x@small
np.testing.assert_allclose(torch.linalg.vector_norm(out).item(),.01*np.sqrt(10),atol=1e-6,rtol=0)
large=100*torch.eye(4); bigger=x@large
np.testing.assert_allclose((torch.linalg.vector_norm(bigger)/torch.linalg.vector_norm(out)).item(),10000,atol=.01,rtol=0)
```

**Expected:** activation norm increases by factor10000.

## Common pitfalls and diagnosis

Find the first nonfinite tensor rather than only the final failing scalar. Compare output, squared-output and gradient scales on the same input and dtype. A finite matrix product can still overflow in a later square or reduction. Validate residual feature shapes, then examine conditioning; a skip connection does not eliminate numeric scale problems.
