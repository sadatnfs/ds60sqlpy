# Plan 11-01: remove every em and en dash and gate the whole repository

## Objective

No tracked text file contains U+2014 or U+2013 except vendored third-party
code, and CI fails on any new one (HARD-07).

## Tasks

1. Tracer: add `scripts/check_no_dashes.py` that reads `git ls-files`, skips
   binary files and an explicit vendored allowlist
   (`src/ds60sqlpy/assets/vendor/textbook/katex.js` and other third-party
   vendor bundles), and reports `path:line:col` for each dash. Wire it into
   `.github/workflows/ci.yml` (core job, next to the public release scan) and
   cover it with a focused test.
2. Rewrite source prose in context: numeric and date ranges become a hyphen
   or "to"; parenthetical and clause dashes become commas, colons,
   parentheses or a sentence break. Never substitute " - " mechanically.
3. Scripts and tests that must name the characters use `\u2014` and `\u2013`
   escapes instead of literal characters.
4. Regenerate derived output with `make generate` (lesson pages, reference
   pages, `START_HERE.html`, compiled TeX, catalog, reports).

## Verification

- `python scripts/check_no_dashes.py` exits 0; the perl scan over
  `git ls-files` finds only allowlisted vendor files.
- Generators report no drift; targeted course tests pass.
