## Choose an information graph and then choose its objective

The preceding capstone asked which artifacts support a system-level claim. We now return to architecture and make its information boundaries explicit. An encoder, a causal decoder and an encoder-decoder differ in which positions may exchange information and how their representations are used. The words alone do not determine every training objective, output head or deployment task. Start with the available inputs and the event being predicted.

Imagine a complete source report x_1,...,x_S and a response y_1,...,y_T being generated one token at a time. The source report may be fully available before generation starts, while later response tokens do not yet exist. A source position with a larger index is therefore not the same kind of "future" as an unavailable target token. This distinction is the foundation of encoder-decoder attention.

### Follow the three attention paths

An encoder builds source representations. In ordinary bidirectional self-attention, source query i may read every nonpadding source key j. The score matrix has shape(S,S). A representation of the report's first word can incorporate a clarification near its end because the complete report is an allowed input.

A causal decoder builds target-prefix representations. Under the shifted-input convention, target query t may read target input positions up to t, but not later ones. Its self-attention score matrix has shape(T,T) with a causal access rule. This permits parallel teacher-forced computation over known training inputs while preserving the same next-token information boundary that incremental generation needs.

Cross-attention connects the two sequences. Queries come from target states, while keys and values come from encoded source states. Its score matrix has shape(T,S), which need not be square. The target row count determines the number of outputs; the source length determines how many evidence positions each target can compare. A source-padding mask can exclude missing source positions for every target without imposing a target-style triangular rule on source order.

### Trace the dependency graph through several layers

A causal mask in one attention operation is necessary but not sufficient to establish a whole model's information boundary. Suppose the initial representation at position i depends only on the input at i and its permitted positional information. If every layer computes position i only from previous-layer positions j<=i, then by induction every resulting state at i depends only on the prefix through i. Pointwise feed-forward layers and same-position residual additions preserve that property.

An operation that mixes statistics across all token positions can break the induction. So can preprocessing that places the current target answer into its own input position. The correct proof follows every path that reaches the prediction, not only the attention matrix displayed in a diagram. Prefix recomputation and controlled future perturbations provide practical tests of that graph, while mathematical inspection explains why the invariant should hold.

For an encoder-decoder, target causality can hold even though source representations are bidirectional, because the full source is assumed available. If the product changes to live transcription or streaming translation, later source text may no longer be available at the time of an emitted target. The source access rule must then change or the output timing claim must change. Reusing the same architecture name does not preserve the original availability assumption.

### Separate an objective from an architecture diagram

An autoregressive target objective scores the chain P(y|x)=product_t P(y_t|x,y_<t). Teacher forcing supplies the observed earlier target tokens during training. A masked-source objective instead corrupts selected input positions and asks a predictor to recover their original tokens using the permitted surrounding context. These are different supervised events, even when both use softmax and cross entropy.

For source[2,5,7], replacing the middle token with a mask ID produces input[2,0,7] while retaining target 5 at that selected position. The loss can include only that target while attention remains bidirectional over the corrupted source. The loss mask is a list of supervised positions; the attention mask is a query-key access relation. Substituting one for the other confuses what is learned with what is read.

A collection of masked conditional predictions is not automatically the same normalized joint sequence probability supplied by an autoregressive chain. To score a complete string under a masked model, one needs an additional declared procedure, such as a particular pseudo-likelihood construction. That score has its own conditioning and comparison rules. Do not compare it directly with an autoregressive sequence likelihood solely because both are called language-model loss.

### Diagnose the shifted-label boundary with a tiny example

The target sequence[5,7,3] becomes decoder inputs[1,5,7] when 1 is BOS. The three logits predict 5,7,3 respectively. At the second row, input 5 is a previous target and may be visible; the current label 7 must not already appear in that row's input through a faulty alignment. This is why an allowed diagonal can be causal under one construction and leak the answer under another.

The distinction is easy to miss when testing only tensor shapes. Both the correct and incorrect input arrays have length 3. A model can obtain a small loss by copying an unshifted label, and a triangular mask may still look familiar. Retain a table mapping each logit row to its input token, target token and allowed prefix. That table is often more diagnostic than another training run.

The zero-score attention fixture then isolates the access relation. All-allowed source attention averages[2,0],[0,2],[6,6] into[8/3,8/3] for each query. Causal target attention produces[2,0], then[1,1], then[8/3,8/3]. Nonuniform score tests are needed in addition to verify Q/K use and scaling. Equal scores make the mask visible but cannot test every component of attention arithmetic.

### Connect architecture to the task without turning tendencies into rules

An encoder representation can support classification, span labeling or retrieval embeddings when the complete input is available. A causal decoder naturally supports continuation and generation. An encoder-decoder makes the distinction between source evidence and generated target explicit. These are useful design patterns, not guarantees that only one family can solve a task or that one always performs best.

A decoder-only system can condition on a serialized source/prompt before generating a response. Its attention and loss policies must specify how those regions interact. A retrieval system can use an encoder for document/query representations and a decoder for answer generation. A subject-matter assistant may combine these pieces, but its citation support and access controls still require separate evaluation.

The important operational question is which inputs the model actually receives at the time of each prediction. A full report, a partially arrived stream, a retrieved excerpt and an untrusted tool result have different availability and authority contracts. Architecture supplies an information-processing graph; it does not establish the truth or permission status of every item placed in that graph.

### Move from information access to position

The access graph determines which positions can influence a query. Position encoding determines how the allowed positions are distinguished inside that computation. Two architectures can share an access graph while using different coordinate systems and therefore produce different scores. This gives the next chapter a precise starting question rather than treating position as another name for causality.
