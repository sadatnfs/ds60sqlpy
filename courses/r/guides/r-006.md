## Outcome and mechanism

Choose and test a missingness policy that preserves the distinction between absence, undefined arithmetic and zero.

NA represents a missing entry within a vector. Typed forms such as NA_real_, NA_integer_ and NA_character_ help retain a desired representation. NULL is different: it often denotes an absent component and has length zero. Combining NULL into a vector contributes no entry, while combining NA contributes one missing entry. Confusing these meanings changes counts and denominators.

NaN is a floating-point result for undefined operations such as 0/0. is.na reports TRUE for both NA and NaN, while is.nan distinguishes NaN specifically. Inf and -Inf represent infinities, such as the result of a nonzero number divided by zero. is.finite excludes all of these exceptional numeric values. Whether infinity is an admissible scientific result or a rejected input depends on the interface.

Dropping missing entries is an operation on the admitted population. sum(x, na.rm=TRUE) can return zero for an all-missing vector because the sum of an empty numeric set is zero in R. That arithmetic convention does not mean that the original observations measured zero. A summary function should retain a valid count and explicitly choose how an all-missing population is reported.

The same principle applies to averages. mean(numeric(0)) yields NaN, while a reporting function may deliberately return NA_real_ to indicate that no observed mean is available. State this policy at the boundary rather than letting an incidental implementation choice become the meaning of the metric. Later statistical chapters use those counts to make selection assumptions visible.

## Worked examples

### Example 1: Classify exceptional numbers

```r
x <- c(0, NA_real_, NaN, Inf, -Inf, 4)
stopifnot(identical(is.na(x), c(FALSE, TRUE, TRUE, FALSE, FALSE, FALSE)))
stopifnot(identical(is.finite(x), c(TRUE, FALSE, FALSE, FALSE, FALSE, TRUE)))
print(data.frame(value = x, missing = is.na(x), finite = is.finite(x)))
```

**Expected observation:** Only zero and four are finite.

A finite-value mask is stricter than a missing-value mask. It rejects infinities as well as missing and undefined results.

### Example 2: Absence and an all-missing summary

```r
stopifnot(length(c(1, NULL, 2)) == 2L, length(c(1, NA, 2)) == 3L)
x <- c(NA_real_, NA_real_)
observed <- sum(!is.na(x))
reported_sum <- if (observed == 0) NA_real_ else sum(x, na.rm = TRUE)
stopifnot(observed == 0, is.na(reported_sum), sum(x, na.rm = TRUE) == 0)
print(c(observed = observed, reported_sum = reported_sum))
```

**Expected observation:** Observed count zero; reported sum NA.

The reporting policy preserves no observed sum instead of interpreting the empty-sum arithmetic convention as a measurement.
