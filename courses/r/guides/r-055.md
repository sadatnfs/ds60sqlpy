## Outcome and mechanism

Choose scale, coordinate and facet policies while explaining how each affects calculations and visual comparisons.

A scale maps data values to visual properties and can transform or limit the data entering a layer. A coordinate system determines how those mapped positions are displayed. These stages are related but not interchangeable. In particular, setting a scale limit can remove observations before a statistic is calculated, while coordinate zoom can retain them in the calculation and change only the displayed window.

That distinction matters for a fitted line. If an extreme observation is outside a scale limit, a smoothing layer may fit without it. A coordinate zoom can hide the same point visually while retaining its influence on the fitted model. A plot that looks like a harmless zoom can therefore represent a different fitted analysis if the wrong mechanism is chosen.

Facets divide a dataset into panels. Shared scales support direct magnitude comparison across panels; free scales can reveal within-panel detail but make equal visual distances correspond to different values. State which comparison the reader should make, and label free-scale choices rather than allowing them to imply equality of magnitudes.

Transformations such as logarithmic scales change the mapping and often the interpretation of distance. Check the input domain before applying them. A nonpositive value cannot be silently treated as an ordinary positive observation on a log scale. A useful graphic preserves the admission decision and any excluded-count information.

Named palettes and factor levels are another scale contract. If category identity matters, specify the mapping by name and handle new categories deliberately. A polished legend cannot repair a chart that changed category meaning after a factor reorder. Validate the data-to-mark relationship before inspecting the final visual layout.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Scale limit | A restriction at the scale stage that can remove data before statistical transformation. |
| Coordinate zoom | A displayed-window restriction that can preserve the data used by layer statistics. |
| Facet | A panel subdivision determined by data variables. |
| Free scale | A panel-specific scale whose numerical mapping can differ from other panels. |

## Read the syntax

Use scale_y_continuous(limits=...) only when its data-removal behavior is intended. Use coord_cartesian(ylim=...) for a visual zoom that retains underlying statistic inputs. facet_wrap(...,scales="fixed" or "free_y") declares the comparison policy. Inspect built layer values and panel-scale assignments independently from the displayed image.

## Worked examples

### Example 1: A zoom can change a fitted line if implemented as a scale limit

```r
d <- data.frame(x = 1:4, y = c(1, 2, 3, 100))
base <- ggplot2::ggplot(d, ggplot2::aes(x, y)) +
  ggplot2::geom_point() +
  ggplot2::geom_smooth(method = "lm", formula = y ~ x, se = FALSE)
zoom <- base + ggplot2::coord_cartesian(ylim = c(0, 4)) + ggplot2::labs(title = "Coordinate zoom retains the fitted data")
limited <- base + ggplot2::scale_y_continuous(limits = c(0, 4)) + ggplot2::labs(title = "Scale limit removes a fitting observation")
a <- ggplot2::ggplot_build(zoom)$data[[2]]
b <- ggplot2::ggplot_build(limited)$data[[2]]
stopifnot(max(a$y, na.rm = TRUE) > 4, max(b$y, na.rm = TRUE) <= 4)
print(zoom)
print(limited)
```

**Expected observation:** The full-data fitted line differs from the line fitted after removing the extreme observation.

The warning about removed data is relevant evidence for the scale-limited fit. The two plots deliberately preserve different statistical inputs even though their visible y windows are similar.

### Example 2: Inspect a free facet scale

```r
d <- data.frame(x = rep(1:2, 2), y = c(1, 2, 100, 200), group = c("A", "A", "B", "B"))
fixed <- ggplot2::ggplot(d, ggplot2::aes(x, y)) +
  ggplot2::geom_point() +
  ggplot2::facet_wrap(~group, scales = "fixed")
free <- ggplot2::ggplot(d, ggplot2::aes(x, y)) +
  ggplot2::geom_point() +
  ggplot2::facet_wrap(~group, scales = "free_y")
stopifnot(length(unique(ggplot2::ggplot_build(fixed)$layout$layout$SCALE_Y)) == 1)
stopifnot(length(unique(ggplot2::ggplot_build(free)$layout$layout$SCALE_Y)) == 2)
print(free)
```

**Expected observation:** Two panels with two y-scale assignments under free_y.

The free-scale plot can show both within-group patterns clearly, but equal vertical distances no longer encode equal changes across groups.
