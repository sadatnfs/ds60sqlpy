# js-052: Statistical summaries, box plots and uncertainty intervals

## Level and prerequisites

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: `js-051`.

## Learning objectives

Compute quartiles, draw a box plot and present interval estimates without confusing spread with uncertainty. The central exercise is: Draw a labeled box and median.

## Purpose, vocabulary and mental model

A summary reduces a distribution to selected quantities. The median is a central order statistic; quartiles describe the middle part of the distribution. A box plot communicates chosen quantiles and whisker rules, which must be stated because conventions differ. It does not preserve every feature of the raw observations.

An uncertainty interval describes uncertainty about a parameter under a statistical procedure and assumptions. It is not the same as the spread of individual observations. A box showing sample quartiles and an interval around a mean answer different questions. Label both the statistic and the interval method when presenting estimates.

The lesson uses tiny synthetic samples to make quartiles and interval endpoints inspectable. It does not claim a confidence interval from an arbitrary pair of numbers. A visualization may render a supplied estimate and bounds correctly while the upstream statistical method is invalid; those checks remain separate.

### Key terms

- **Quantile:** The value below which a given fraction of sorted observations falls. `d3.quantileSorted` assumes its input is already sorted in ascending order.
- **Median:** The 0.5 quantile, the middle value of the sorted data; for `[1, 2, 3, 4, 5]` it is 3.
- **Box plot:** A summary that draws the first and third quartiles as a box, the median as a line and whiskers by a stated rule. It omits most features of the raw observations.
- **Sampling uncertainty:** Uncertainty about a parameter estimate that comes from observing only a sample. An interval from a stated procedure describes it, which differs from the spread of individual observations.

## Syntax anatomy and mechanism

Sort numerical values before using a function that assumes sorted input. `d3.quantileSorted` computes a quantile of an ordered array. For `[1, 2, 3, 4, 5]`, median is 3 and the first and third quartiles are 2 and 4. A simple box can map those values to x positions, with a median line inside.

For a supplied interval, check lower <= estimate <= upper before drawing a segment and point. If the interval spans zero, that visual fact should not be hidden by a truncated axis. The statistical interpretation still depends on the stated estimator and procedure.

## Worked example / walkthrough

### Worked example 1: Compute transparent quartiles

The input is explicitly sorted.

```javascript
const v = [1, 2, 3, 4, 5];
console.log(d3.quantileSorted(v, 0.25), d3.quantileSorted(v, 0.5), d3.quantileSorted(v, 0.75));
```

**Expected observation:** 2, 3 and 4.

### Worked example 2: Validate an interval before rendering

This does not calculate the interval statistically; it checks the supplied one and then draws it.

```javascript
// js-052 worked example 2: a complete program for the classroom preview.
const host = document.querySelector("#chart");
const output = document.querySelector("#output");
host.replaceChildren();
const check = (condition, message) => {
  if (!condition) throw new Error(message);
};
const svg = d3
  .select(host)
  .append("svg")
  .attr("viewBox", "0 0 640 360")
  .attr("role", "img")
  .attr("aria-label", "Statistical summaries, box plots and uncertainty intervals")
  .style("width", "100%")
  .style("max-width", "640px");
const estimate = { value: 0.2, lower: -0.1, upper: 0.5 };
check(
  estimate.lower <= estimate.value && estimate.value <= estimate.upper,
  "The estimate must lie inside its interval",
);
const x = d3.scaleLinear().domain([-0.5, 1]).range([60, 600]);
svg
  .append("line")
  .attr("x1", x(0))
  .attr("x2", x(0))
  .attr("y1", 60)
  .attr("y2", 300)
  .attr("stroke", "#9ca3af");
svg
  .append("line")
  .attr("x1", x(estimate.lower))
  .attr("x2", x(estimate.upper))
  .attr("y1", 180)
  .attr("y2", 180)
  .attr("stroke", "#111827")
  .attr("stroke-width", 3);
svg
  .append("circle")
  .attr("cx", x(estimate.value))
  .attr("cy", 180)
  .attr("r", 7)
  .attr("fill", "#dc2626");
svg.append("text").attr("x", 60).attr("y", 330).text("Estimate 0.2, interval -0.1 to 0.5");
check(x(estimate.lower) < x(0) && x(0) < x(estimate.upper), "The interval crosses the zero line");
output.textContent = "js-052 worked example 2 complete";
```

**Expected observation:** A horizontal interval from -0.1 to 0.5 with a point at 0.2 that crosses the grey zero line; the first check passes only because the supplied interval contains its estimate.

## Six progressive exercises

### Exercise 1: Predict the three quantiles.

**Expected evidence:** 2, 3, 4 for the stated five-value sample.

**Progressive hint:** The small ordered input makes the definition visible.

### Exercise 2: Add an extreme value and recompute.

**Expected evidence:** Quantiles and the visible range change according to the new sample.

**Progressive hint:** A summary is a function of data.

### Exercise 3: Draw a labeled box and median.

**Expected evidence:** The box endpoints map to Q1 and Q3 and the line maps to median.

**Progressive hint:** The geometry should encode actual statistics, not decorative percentages of chart width.

### Exercise 4: Diagnose calling an unsorted-only contract incorrectly.

**Expected evidence:** Sort a copy before quantileSorted.

**Progressive hint:** A function with a sorted-input precondition can return misleading values when that precondition is violated.

### Exercise 5: Distinguish individual spread from estimate uncertainty.

**Expected evidence:** Quartiles describe observations; a confidence interval concerns an estimator.

**Progressive hint:** They are not interchangeable error bars.

### Exercise 6: Design a comparison of two estimated effects.

**Expected evidence:** Show estimates, interval method, units and a meaningful zero reference.

**Progressive hint:** Visual overlap alone is not a complete hypothesis test.

## Debugging and common mistakes

When a quartile looks wrong, check whether the input was sorted: `d3.quantileSorted` trusts its input, so an unsorted array returns a wrong value without an error, while `d3.quantile` sorts internally. Compare Q1, median and Q3 with a hand calculation, and check that an interval's lower bound is at or below its estimate. ([checkpoints](../STUDY-GUIDE.md#d3-debugging-checkpoints))

Exercise 4 is the controlled failure: Diagnose calling an unsorted-only contract incorrectly. Distinguishing evidence: Sort a copy before quantileSorted.

## Accessibility and interpretation

A box plot is unfamiliar to many readers, so state the numbers it encodes in a caption or table and say whether whiskers show the range or a rule. For an interval, give the estimate and both bounds in the summary, including whether the interval crosses zero. ([accessibility review](../STUDY-GUIDE.md#d3-accessibility-review))

Quartiles describe the spread of observations; a confidence interval describes uncertainty about an estimate. Drawing both in the same style invites confusion. Name the interval method, its confidence level and the sample size, and read an interval that crosses zero as consistent with no effect, not as proof of none. ([statistical meaning](../STUDY-GUIDE.md#d3-statistical-meaning))
