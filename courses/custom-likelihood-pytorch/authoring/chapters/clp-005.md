## Recover a model whose answer we already know

Before fitting an unfamiliar nonlinear model, reproduce an ordinary Gaussian regression from its density. This supplies a transparent oracle for parameter layout, objective scaling, optimizer behavior and curvature. It also distinguishes the maximum-likelihood variance estimator from an unbiased variance estimator, which are often confused in handwritten likelihood code.

Let \(X\) be an \(n\times p\) full-column-rank design matrix and let independent observations satisfy \(Y\sim N(X\beta,\sigma^2 I)\). With \(s=\log\sigma\),

\[
\mathcal L(\beta,s)=ns+\frac n2\log(2\pi)
 +\frac12 e^{-2s}(y-X\beta)^\top(y-X\beta).
\]

The coefficient score is \(e^{-2s}X^\top(X\beta-y)\). Setting it to zero yields the least-squares solution. Setting the log-scale derivative to zero gives

\[
\widehat\sigma^2_{\mathrm{MLE}}=\frac{\mathrm{RSS}}{n},\qquad
\widehat\sigma^2_{\mathrm{unbiased}}=\frac{\mathrm{RSS}}{n-p}.
\]

The second formula has a finite-sample unbiasedness property under the stated model. It is not the maximizer of the ordinary likelihood. This difference is substantial for small samples, exactly where a teaching example should make it visible.

## Worked case 1: jointly fit coefficients and scale

Use \(x=(0,1,2,3,4)\), a design with intercept and slope, and \(y=(1.1,2.8,5.2,6.9,9.0)\). The least-squares coefficients are 1.02 and 1.99. RSS is 0.099, so the MLE scale is \(\sqrt{0.099/5}\), approximately 0.14071247. The square root of the unbiased variance estimate is approximately 0.18165902.

The code obtains the reference coefficients using `torch.linalg.lstsq`, computes the residual scale directly, and then independently fits the joint NLL with L-BFGS. It compares the optimized vector with this reference and checks the final gradient. This deliberately small, nonperfectly fitted fixture prevents a zero-scale boundary from making the likelihood unbounded. A negative final NLL is allowed: a continuous density can exceed one because probability is density integrated over a region.

The complete source uses a closure that zeroes gradients, recomputes NLL and calls backward for every evaluation requested by the optimizer. Chapter 15 examines why one optimizer step can invoke that closure repeatedly. Here the reference answer matters more than the number of iterations.

## Worked case 2: recenter the predictor

Replace \(x\) by \(x-\overline x\). The slope remains 1.99, the intercept becomes 5.0, and fitted values and scale remain unchanged. The two coefficient vectors represent the same mean function in different coordinates. This is a practical numerical improvement when a predictor's zero lies far outside its observed range: an intercept near the observed data can be easier to initialize and interpret.

A changed intercept is therefore not necessarily a regression. Compare predictions on the same original records and transform coefficient covariance when changing coordinates. Conversely, centering cannot repair exactly duplicate columns. The code checks design rank before fitting so that a nonunique coefficient vector is not reported as a unique estimate.

## Assumptions and failure diagnosis

Independent, constant-variance Normal residuals are the model assumptions, not consequences of using a linear mean. Residual dependence requires a joint likelihood or a carefully justified robust uncertainty calculation. Heteroskedasticity may warrant a scale model. A robust covariance can improve uncertainty under some misspecification while leaving a misspecified mean and its interpretation unchanged.

If RSS is exactly zero and the scale is free, NLL tends to negative infinity as \(\sigma\) approaches zero. The program rejects that fixture for ordinary joint MLE rather than returning a tiny arbitrary scale. If \(n\leq p\), saturated or underdetermined fits require particular care. If the design is nearly singular, a rank check alone is insufficient: inspect singular values and uncertainty, and consider scientifically motivated constraints or regularization.

## Answered review questions

**Why use a least-squares solver rather than explicitly invert \(X^\top X\)?** A dedicated least-squares solver avoids forming an inverse unnecessarily and can use more stable factorizations. The normal equations explain the solution, but they need not dictate the numerical implementation.

**Should every converged optimizer result be accepted?** No. Compare final gradient, objective, parameter domain, multiple initial values when needed and an independent oracle when available. Convergence describes the algorithm's stopping rule, not the truth of the model.

**Can the MLE scale be used directly for an exact small-sample coefficient interval?** Exact classical intervals use the residual degrees-of-freedom adjustment and a Student distribution under their assumptions. A large-sample inverse-Hessian approximation is a different inferential procedure. This chapter establishes point-estimation arithmetic and does not claim interval coverage.
