llm-043: Encoder, decoder and encoder-decoder architectures and objectives#

Level and prerequisites#

Advanced; approximately 210 minutes. Direct prerequisites: llm-042. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

Learning objectives#

Transformer architecture describes which positions exchange information and how those representations are used. The central investigation is concrete: Use zero queries/keys and values[[2, 0], [0, 2], [6, 6]] under all-allowed and causal masks. The finish condition is encoder rows all[8/3, 8/3]; decoder rows[2, 0], [1, 1], [8/3, 8/3]. both cross outputs[1, 1]; padded source weight 0. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

Purpose and mental model#

Choose an information graph and then choose its objective#

The preceding capstone asked which artifacts support a system-level claim. We now return to architecture and make its information boundaries explicit. An encoder, a causal decoder and an encoder-decoder differ in which positions may exchange information and how their representations are used. The words alone do not determine every training objective, output head or deployment task. Start with the available inputs and the event being predicted.

Imagine a complete source report x_1,...,x_S and a response y_1,...,y_T being generated one token at a time. The source report may be fully available before generation starts, while later response tokens do not yet exist. A source position with a larger index is therefore not the same kind of "future" as an unavailable target token. This distinction is the foundation of encoder-decoder attention.

Follow the three attention paths#

An encoder builds source representations. In ordinary bidirectional self-attention, source query i may read every nonpadding source key j. The score matrix has shape(S,S). A representation of the report's first word can incorporate a clarification near its end because the complete report is an allowed input.

A causal decoder builds target-prefix representations. Under the shifted-input convention, target query t may read target input positions up to t, but not later ones. Its self-attention score matrix has shape(T,T) with a causal access rule. This permits parallel teacher-forced computation over known training inputs while preserving the same next-token information boundary that incremental generation needs.

Cross-attention connects the two sequences. Queries come from target states, while keys and values come from encoded source states. Its score matrix has shape(T,S), which need not be square. The target row count determines the number of outputs; the source length determines how many evidence positions each target can compare. A source-padding mask can exclude missing source positions for every target without imposing a target-style triangular rule on source order.

Trace the dependency graph through several layers#

A causal mask in one attention operation is necessary but not sufficient to establish a whole model's information boundary. Suppose the initial representation at position i depends only on the input at i and its permitted positional information. If every layer computes position i only from previous-layer positions j<=i, then by induction every resulting state at i depends only on the prefix through i. Pointwise feed-forward layers and same-position residual additions preserve that property.

An operation that mixes statistics across all token positions can break the induction. So can preprocessing that places the current target answer into its own input position. The correct proof follows every path that reaches the prediction, not only the attention matrix displayed in a diagram. Prefix recomputation and controlled future perturbations provide practical tests of that graph, while mathematical inspection explains why the invariant should hold.

For an encoder-decoder, target causality can hold even though source representations are bidirectional, because the full source is assumed available. If the product changes to live transcription or streaming translation, later source text may no longer be available at the time of an emitted target. The source access rule must then change or the output timing claim must change. Reusing the same architecture name does not preserve the original availability assumption.

Separate an objective from an architecture diagram#

An autoregressive target objective scores the chain Pr(y∣x)=∏tPr(yt∣x,y<t)\Pr(y\mid x)=\prod_t\Pr(y_t\mid x,y_{<t}). Teacher forcing supplies the observed earlier target tokens during training. A masked-source objective instead corrupts selected input positions and asks a predictor to recover their original tokens using the permitted surrounding context. These are different supervised events, even when both use softmax and cross entropy.

For source[2,5,7], replacing the middle token with a mask ID produces input[2,0,7] while retaining target 5 at that selected position. The loss can include only that target while attention remains bidirectional over the corrupted source. The loss mask is a list of supervised positions; the attention mask is a query-key access relation. Substituting one for the other confuses what is learned with what is read.

A collection of masked conditional predictions is not automatically the same normalized joint sequence probability supplied by an autoregressive chain. To score a complete string under a masked model, one needs an additional declared procedure, such as a particular pseudo-likelihood construction. That score has its own conditioning and comparison rules. Do not compare it directly with an autoregressive sequence likelihood solely because both are called language-model loss.

Diagnose the shifted-label boundary with a tiny example#

The target sequence[5,7,3] becomes decoder inputs[1,5,7] when 1 is BOS. The three logits predict 5,7,3 respectively. At the second row, input 5 is a previous target and may be visible; the current label 7 must not already appear in that row's input through a faulty alignment. This is why an allowed diagonal can be causal under one construction and leak the answer under another.

The distinction is easy to miss when testing only tensor shapes. Both the correct and incorrect input arrays have length 3. A model can obtain a small loss by copying an unshifted label, and a triangular mask may still look familiar. Retain a table mapping each logit row to its input token, target token and allowed prefix. That table is often more diagnostic than another training run.

The zero-score attention fixture then isolates the access relation. All-allowed source attention averages[2,0],[0,2],[6,6] into[8/3,8/3] for each query. Causal target attention produces[2,0], then[1,1], then[8/3,8/3]. Nonuniform score tests are needed in addition to verify Q/K use and scaling. Equal scores make the mask visible but cannot test every component of attention arithmetic.

Connect architecture to the task without turning tendencies into rules#

An encoder representation can support classification, span labeling or retrieval embeddings when the complete input is available. A causal decoder naturally supports continuation and generation. An encoder-decoder makes the distinction between source evidence and generated target explicit. These are useful design patterns, not guarantees that only one family can solve a task or that one always performs best.

A decoder-only system can condition on a serialized source/prompt before generating a response. Its attention and loss policies must specify how those regions interact. A retrieval system can use an encoder for document/query representations and a decoder for answer generation. A subject-matter assistant may combine these pieces, but its citation support and access controls still require separate evaluation.

The important operational question is which inputs the model actually receives at the time of each prediction. A full report, a partially arrived stream, a retrieved excerpt and an untrusted tool result have different availability and authority contracts. Architecture supplies an information-processing graph; it does not establish the truth or permission status of every item placed in that graph.

Move from information access to position#

The access graph determines which positions can influence a query. Position encoding determines how the allowed positions are distinguished inside that computation. Two architectures can share an access graph while using different coordinate systems and therefore produce different scores. This gives the next chapter a precise starting question rather than treating position as another name for causality.

Design decisions and when to use this method#

Choose an encoder-style representation for tasks such as document classification or masked representation learning when the whole input is available. Choose a causal decoder for prefix-conditioned generation. Encoder-decoder designs make the source/target distinction explicit and can support translation, summarization and structured transformations. These are architectural tendencies, not guarantees that one family always wins.

Do not infer the training objective from a diagram alone. Check token shifting, corruption, loss masks, source availability and evaluation units. Prefix invariance proves one information boundary; it does not prove dataset independence, correct labels or factual reliability. Keep those checks separate when building a subject assistant.

Derivation and shape trace#

Let Q have shape(Tq,d), K shape(Tk,d), and V shape(Tk,dv), where d is the positive shared query/key feature width and dv is the value feature width. Scores are S=QKTdS=\frac{{QK}^{T}}{\sqrt{d}}, so the score matrix is Tq by Tk. For each query i, A_i is its nonempty allowed key set and m_i=max_(j in A_i) S_ij is the maximum allowed score. Normalize only that allowed set:

Aij=exp(Sij−mi)∑k∈Aiexp(Sik−mi),Oi=∑j∈AiAijVj.A_{ij}=\frac{\exp(S_{ij}-m_i)}{\sum_{k\in\mathcal A_i}\exp(S_{ik}-m_i)},\qquad O_i=\sum_{j\in\mathcal A_i}A_{ij}V_j.

Encoder self-attention can use every nonpadding source index. Decoder self-attention uses j<=i under the shifted-target convention. Cross-attention uses target queries and source keys, so its mask need not be square. Output row count follows Tq; output feature width follows V.

An autoregressive objective factors p(y|x) into the product over t of p(y_t|x,y_<t). A masked-source objective instead sums losses over a selected set of corrupted source positions. These objectives expose different conditioning information and supervise different events. Teacher forcing supplies previous target tokens, not the current answer, to the position predicting that answer. The loss mask identifies supervised events; the attention mask identifies accessible context. They must not be substituted for each other.

Architecture is a graph of permitted information#

Start with the data available at the moment of prediction. In document classification, the complete document may already exist. A representation of its first word can legitimately use later words. In next-token generation, the next answer token has not been observed and cannot be used as context. In translation with a complete source sentence, the decoder may use all source words while remaining causal over target words. The word "future" must therefore identify both a sequence and an availability policy. A later source position is not automatically forbidden merely because a later target position is.

The three attention sublayers expose different axes. Encoder self-attention compares source queries with source keys. Decoder self-attention compares target-prefix queries with target-prefix keys. Decoder cross-attention compares target queries with encoded source keys. If the source has length S and the target has length T, their score shapes are(S,S),(T,T) and(T,S), respectively. The value feature width determines each output width; it does not determine either position axis. For a batch and multiple heads, additional batch/head axes precede these dimensions, but the query/key distinction remains the same.

The zero-score fixture makes permitted information visible. With source values[2,0],[0,2],[6,6], an all-allowed query returns their mean[8/3,8/3]. A causal first target row sees only[2,0], and the second sees the mean[1,1]. A rectangular cross-attention operation with two target queries and three source keys has two output rows, each[8/3,8/3] under zero scores. Marking source position 2 as padding changes both cross outputs to[1,1]. Padding excludes an unavailable source value for every target query; it is not a rule forbidding target position 1 from seeing source position 2 merely because2>1.

Teacher forcing is a target construction rule. For desired target[5,7,3] and BOS 1, decoder inputs[1,5,7] are paired with labels[5,7,3]. At index1 the input token 5 is already observed context for predicting7. The diagonal is therefore legal. If inputs were[5,7,3] without the shift, the first position would contain the very label 5 it must predict. A triangular mask would not remove that same-position answer leak. A low training loss would then support neither useful prediction nor correct causality.

Loss masking answers another question: which predictions contribute to the objective? A padded target row may have attention edges but zero loss weight. A corrupted-source objective may supervise one selected source position while allowing bidirectional source attention. With original source[2,5,7], corruption[2,0,7] and an active loss only at the middle position, the target remains5 even though input0 is the mask token. Reusing the source-corruption mask as an attention mask would prohibit useful surrounding context or create the wrong matrix shape. Keep the arrays named by their roles rather than calling all of them "the mask."

The conditional sequence objective is L=−∑tlogPr(yt∣x,y<t)L=-\sum_t\log\Pr(y_t\mid x,y_{<t}). An encoder-decoder explicitly computes source representations from x and lets each target state read them. A causal decoder can also condition on a source/prompt by concatenating an appropriate representation and using a deliberate attention/loss policy. Architecture family alone therefore does not uniquely identify the task or training objective. A masked-source objective generally scores selected corruptions and is not simply the same autoregressive factorization with a different drawing.

Cross-attention has a useful backward interpretation. If O=AVO=AV and G=∂L∂OG=\frac{\partial L}{\partial O}, then ∂L∂V=AT\frac{\partial L}{\partial V}={A}^{T} G has source rows, while ∂L∂A=G\frac{\partial L}{\partial A}=G VT{V}^{T} has target-by-source shape. After differentiating row softmax into H=∂L∂SH=\frac{\partial L}{\partial S}, query gradients are H Kd\frac{K}{\sqrt{d}}, and key gradients are HT{H}^{T} Qd\frac{Q}{\sqrt{d}}. Target-side errors can thus train source-side keys/values through the cross-attention path. The transpose is not an arbitrary coding trick: it sums contributions from every target query that used a source position.

For an assistant that turns a complete report into structured findings, a source encoder can use the whole report. If the product later promises live partial results before the report is complete, the earlier availability assumption changes. A valid test inserts or changes source text that arrives only later and checks whether already published outputs depend on it. A successful mask arithmetic test does not settle whether a cited claim is entailed by the source. That requires an evidence and task-evaluation contract in addition to the architecture.

Interview reasoning: "Is an encoder allowed to see the answer?" It may see the complete source when the task permits it, but labels must not be smuggled into that source through data construction. Source availability, target shifting, label provenance and train/test separation are independent checks. The distinction follows the architecture in the Transformer paper and the bidirectional objective in BERT; the numerical examples here do not reproduce those trained systems.

Vocabulary and concepts#

Encoder: A representation network over source positions whose complete context may be available.

Causal decoder: A network preserving the target-prefix information boundary.

Cross-attention: Attention whose queries and keys/values come from different sequences.

Teacher forcing: Using observed prior target tokens as decoder input during supervised training.

Objective mask: The target positions included in the loss,distinct from the attention access mask.

Syntax anatomy and reasoning sequence#

The attention helper accepts Q shaped(Tq, d), K shaped(Tk, d), V shaped(Tk, dv) and a boolean allowed matrix(Tq, Tk). It validates nonempty legal rows, then uses a stable row-wise softmax of Q @ K.T / sqrt(d). Encoder self-attention has Tq=Tk=source length and an all-allowed source mask. Causal decoder self-attention has a lower triangle over target-prefix positions. Cross-attention can be rectangular, with target queries and source keys/values. Labels and loss masks are constructed independently from these attention masks.

Worked example / walkthrough#

Example A: Compare bidirectional and causal mixtures#

The score arithmetic is identical; the allowed information differs. A future source change may affect an encoder output when the whole source is available, while a future target change must not affect an earlier causal output.

import numpy as np
def attention(q,k,v,allowed):
    q,k,v=(np.asarray(value,dtype=np.float64) for value in (q,k,v)); allowed=np.asarray(allowed)
    if any(value.ndim!=2 for value in (q,k,v)) or not len(q) or not len(k) or q.shape[1]==0: raise ValueError('nonempty matrices required')
    if q.shape[1]!=k.shape[1] or k.shape[0]!=v.shape[0] or allowed.shape!=(len(q),len(k)): raise ValueError('attention shape mismatch')
    if allowed.dtype!=np.bool_: raise TypeError('boolean allowed mask required')
    if not allowed.any(1).all() or not all(np.isfinite(value).all() for value in (q,k,v)): raise ValueError('finite legal rows required')
    with np.errstate(over='ignore',invalid='ignore',divide='ignore'):
        scores=q@k.T/np.sqrt(q.shape[1])
    if not np.isfinite(scores[allowed]).all(): raise ValueError('finite computed attention scores required')
    masked=np.where(allowed,scores,-np.inf)
    with np.errstate(over='ignore',under='ignore'):
        mass=np.exp(masked-masked.max(1,keepdims=True))
    weights=mass/mass.sum(1,keepdims=True)
    return weights@v,weights
q=np.zeros((3,2)); values=np.array([[2.,0.],[0.,2.],[6.,6.]])
encoder,_=attention(q,q,values,np.ones((3,3),dtype=bool))
decoder,_=attention(q,q,values,np.tri(3,dtype=bool))
np.testing.assert_allclose(encoder,np.tile([8/3,8/3],(3,1)),atol=1e-12,rtol=0)
np.testing.assert_allclose(decoder,[[2,0],[1,1],[8/3,8/3]],atol=1e-12,rtol=0)

Expected: encoder rows all[8/3, 8/3]; decoder rows[2, 0], [1, 1], [8/3, 8/3].

Example B: Trace rectangular cross-attention#

The output count follows the query sequence, not the source length. A square-mask assumption would incorrectly reject or distort ordinary encoder-decoder attention.

target_queries=np.zeros((2,2)); source_keys=np.zeros((3,2))
cross,weights=attention(target_queries,source_keys,values,np.ones((2,3),dtype=bool))
assert weights.shape==(2,3) and cross.shape==(2,2)
np.testing.assert_allclose(cross,np.tile([8/3,8/3],(2,1)),atol=1e-12,rtol=0)

Expected: score/weight shape(2, 3); output shape(2, 2); both outputs[8/3, 8/3].

Example C: Build shifted decoder targets#

The current decoder input is the previous target under this shifted convention. Allowing the diagonal is compatible with causality; copying the current answer into the same input position would not be.

target=np.array([5,7,3]); inputs=np.concatenate([[1],target[:-1]]); labels=target.copy(); mask=np.tri(3,dtype=bool)
np.testing.assert_array_equal(inputs,[1,5,7]); np.testing.assert_array_equal(labels,[5,7,3])
assert mask[0,0] and not mask[0,1]

Expected: inputs[1, 5, 7]; labels[5, 7, 3]; diagonal allowed without seeing the target itself.

Controlled case study#

A study-summary assistant receives a complete report and generates a structured summary. An encoder-decoder may encode the entire report before target generation. If the product changes to live transcription, future source text is no longer available. Reusing unrestricted source attention would violate the streaming contract. The architecture name did not change; the input-availability assumption did. Perturb text that arrives later and test whether earlier published outputs depend on it under the intended serving policy.

Common pitfalls and diagnosis#

Start with a table naming every axis and which real-world information it represents. A square output may hide a swapped source/target axis when lengths happen to match, so retain the rectangular2-by-3 case. If loss is suspiciously small, inspect the target shift before changing the optimizer. If padding changes a result, inspect whether it was excluded before the normalizer.

Finite input elements do not guarantee a finite matrix product. Very large finite Q/K entries can overflow during their dot product. The helper controls NumPy's arithmetic warning behavior around that operation and explicitly rejects nonfinite computed allowed scores with ValueError. It does not silently propagate NaN weights. The reference remains a bounded pedagogical operation, not a trained encoder-decoder or a production backend.

Next step#

After choosing which positions may interact, the model still needs a way to represent their order or distance. A set of source vectors and an attention access matrix do not fully specify the positional computation. The next chapter examines learned absolute positions, rotary geometry and distance biases, then shows why a correct formula at a large index is weaker evidence than reliable use of long context by a trained model.
