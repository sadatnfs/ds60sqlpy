## Outcome and mechanism

Construct and inspect a ggplot whose data, mappings and layer-specific responsibilities are explicit.

A ggplot describes a graphic by combining data, aesthetic mappings and layers. The data supplies observations; aes maps columns or expressions to visual properties such as x position, y position, colour or shape. A geom chooses how those mapped values become marks. The plus operator adds components to the plot object rather than performing ordinary numerical addition.

A mapping inside aes differs from a constant setting outside it. Mapping colour to a group variable assigns values through a scale and can create a legend. Setting colour="blue" outside aes requests the same colour for the layer. Putting a literal string inside aes creates a mapped category with that label; it is not automatically the same as selecting that colour directly.

Layers can share the plot's default data and mappings or use their own. This is useful when raw observations and a derived summary appear together. A summary layer must contain the columns its mappings require. inherit.aes=FALSE makes a layer's separate contract explicit when it should not inherit all mappings from the raw data.

Constructing an object is not always the same as drawing it. Interactive sessions often print the final expression automatically, but scripts and functions should call print(p) explicitly. The classroom's R capture path relies on actual drawing or explicit widget printing. A variable containing a plot object alone is not evidence that a figure was emitted.

Inspecting ggplot_build can verify transformed layer data, group counts and mark coordinates. These are useful software checks, but they do not establish final readability, contrast or label placement. A complete graphical acceptance combines correct numerical/layer data with actual rendering and visual inspection at the delivered size.

## Vocabulary

| Term | Meaning |
| --- | --- |
| Aesthetic mapping | A relationship from data values to a visual property, specified through aes. |
| Constant setting | A fixed visual property supplied outside aes for a layer. |
| Layer | A data/statistic/geometry combination added to the plot. |
| Inherited mapping | A default mapping reused by a layer unless explicitly replaced or disabled. |

## Read the syntax

Start with ggplot2::ggplot(data, ggplot2::aes(x,y,...)), add geoms with +, then add labels and scales. Use a manual named palette when category-colour identity matters. Inspect ggplot_build(p)$data for layer values. Call print(p) explicitly in a script; do not rely on implicit interactive printing.

## Worked examples

### Example 1: Map group identity

```r
d <- data.frame(x = 1:4, y = c(1, 3, 2, 6), group = factor(c("A", "A", "B", "B"), levels = c("A", "B")))
p <- ggplot2::ggplot(d, ggplot2::aes(x, y, colour = group, shape = group)) +
  ggplot2::geom_point(size = 3) +
  ggplot2::scale_colour_manual(values = c(A = "#0072B2", B = "#D55E00")) +
  ggplot2::labs(x = "Input", y = "Response", colour = "Group", shape = "Group")
built <- ggplot2::ggplot_build(p)$data[[1]]
stopifnot(nrow(built) == 4, length(unique(built$colour)) == 2, length(unique(built$shape)) == 2)
print(p)
```

**Expected observation:** Four points, two group colours and shapes, one explicitly printed plot.

Group is mapped through two visual channels. The named palette preserves category identity, while the layer-data checks confirm four marks and two encoded groups.

### Example 2: Give a summary layer its own data

```r
d <- data.frame(x = 1:4, y = c(1, 3, 2, 6), group = c("A", "A", "B", "B"))
means <- aggregate(cbind(x, y) ~ group, d, mean)
p <- ggplot2::ggplot(d, ggplot2::aes(x, y, colour = group)) +
  ggplot2::geom_point(size = 2) +
  ggplot2::geom_point(data = means, mapping = ggplot2::aes(x, y), inherit.aes = FALSE, colour = "black", shape = 4, size = 5) +
  ggplot2::labs(x = "Input", y = "Response", title = "Raw points and group means")
built <- ggplot2::ggplot_build(p)$data
stopifnot(nrow(built[[1]]) == 4, nrow(built[[2]]) == 2)
stopifnot(max(abs(sort(built[[2]]$y) - c(2, 4))) < 1e-12)
print(p)
```

**Expected observation:** Raw layer four rows; summary layer two means at y2 and 4.

The second layer uses a derived table and only its own x/y mapping. It does not accidentally require the raw layer's complete aesthetic contract.
