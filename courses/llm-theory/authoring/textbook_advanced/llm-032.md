## Change a model through a restricted update space

Full fine-tuning allows a selected weight matrix to change entry by entry. Low-rank adaptation instead freezes a base matrix and learns an additive update represented by two smaller factors. The reduction concerns trainable state and the family of permitted updates. It does not mean that the base computation disappears, and it does not guarantee that every task can be solved as well as with unrestricted fine-tuning.

This lesson uses row-vector notation. Inputs X have shape(N,d_in), the frozen base W has shape(d_in,d_out), factor A has shape(d_in,r), and factor B has shape(r,d_out). The output is \(Y=X(W+AB)\). Rank r is the intermediate dimension of the update. Some libraries store transposed weight layouts or name the factors in the opposite order; the matrix equation is the reliable specification.

### Count the restriction before discussing quality

The full base matrix has \(d_{\mathrm{in}}\cdot d_{\mathrm{out}}\) entries. The two adapter factors have \(r\cdot (d_{\mathrm{in}}+d_{\mathrm{out}})\). For the fixture \(d_{\mathrm{in}}=d_{\mathrm{out}}=8\) and \(r=2\), the base has 64 entries and the adapter 32. This is a 50 percent trainable-parameter reduction for this one tiny matrix, not the many-orders-of-magnitude reduction possible for different dimensions and selected layers. The number must be calculated from the actual shapes being adapted.

The update A B has rank at most r. It can change many visible entries while remaining constrained to a lower-dimensional matrix family. A rank-one outer product can be dense, so counting nonzero entries does not measure rank. Conversely, a nominal rank-two parameterization may realize an update of rank zero or one because its factors are zero or linearly dependent. The rank bound is an upper bound, not a promise that every degree of freedom is being used.

Many practical LoRA formulations multiply the update by a scale \(\frac{\alpha}{r}\). The current fixture omits that extra factor, effectively using scale 1. When translating the derivation to another implementation, include the scale in both the forward equation and gradients. Rank, scale, target modules, dropout and bias policy are configuration choices that belong in the adapter artifact.

### Derive why zero initialization preserves the base function

The reference initializes W as the 8-by-8 identity, every entry of A as \(\frac{1}{8}\), and B as zero. Because A B is zero, the initial adapted output equals XW exactly. This gives a useful starting contract: adding the adapter has not already changed the base prediction before any optimization step.

Both factors should not be initialized to zero under an ordinary differentiable product update. If \(A=0\) and \(B=0\), the gradients through each factor contain the other zero factor and can remain zero at initialization. Initializing one factor nonzero and the other zero preserves the initial function while leaving a path for one factor's first gradient. The fixture chooses nonzero A and zero B to make that path easy to inspect.

For the all-ones input row X, X \(A=[1,1]\) because each adapter column sums eight copies of \(\frac{1}{8}\). The initial output has eight ones. The objective is the mean squared output, \(L=\frac18\sum_jY_j^2\), so its initial value is 1. This objective is a constructed mechanism test; it does not represent a real instruction-following task.

### Trace every matrix in the first backward pass

Let \(G=\frac{\partial L}{\partial Y}\) with shape(N,d_out). Differentiating \(Y=XW+(XA)B\) gives \(\frac{\partial L}{\partial B}=(XA)^{\mathsf T}G\) and \(\frac{\partial L}{\partial A}=X^{\mathsf T}GB^{\mathsf T}\). The frozen W is not included in the optimizer. These equations explain the first-step asymmetry without relying on a framework's printed tensor names.

At the fixture's initial state, each component of G is \(\frac{2}{8}=\frac{1}{4}\). Since X \(A=[1,1]\), every entry of dL/dB is \(\frac{1}{4}\). Since \(B=0\), dL/dA is zero. The zero A gradient is mathematically expected; it is not evidence that A is disconnected from the graph. After B changes, the next backward pass can give A a nonzero gradient.

With SGD learning rate .1, the first update sets every B entry to-.025 while A remains unchanged. Each entry of A B becomes 2*(\(\frac{1}{8}\))*(-.025)=-.00625. Multiplying by the all-ones X sums eight such entries, giving an adapter output of-.05 in every output coordinate. The new prediction is therefore .95 in all eight coordinates and the new objective is \({0.95}^{2}=0.9025\). This independently derived value explains why the reference's post-step loss must be lower than the initial loss.

Because both columns of the initialized A are identical and both rows of B receive the same first update, this particular update is actually rank one despite the allowed rank-two parameterization. The reference correctly checks \(\mathrm{rank}\le 2\) rather than equality. A useful explanation should distinguish the architecture's maximum rank from the rank realized by this data and initialization.

### Freezing and optimizer membership are separate checks

A frozen base should not receive an update through the selected training path. In this fixture, W is an ordinary tensor and the optimizer is constructed only from A and B. The saved base copy remains equal after the step. In a larger model, inspect both `requires_grad` and optimizer parameter groups, and consider buffers or stochastic modes that can change behavior without a parameter update.

A stale gradient left on a parameter can also be misleading when changing which parts are trainable. Clearing or rebuilding the intended optimizer state is part of a deliberate transition. The small lesson avoids those complications by constructing a fresh adapter optimizer, but it supplies the conceptual check: identify the trainable parameter set, the gradient paths and the actual post-step state separately.

Reducing trainable parameters can reduce their gradients and optimizer states. It does not remove the need to store or read the frozen base, and it does not automatically remove all activations needed for backward through the adapted network. The memory savings depend on the chosen layers, optimizer, precision and implementation. Quantized-base adaptation introduces another approximation contract, which the following precision chapter will examine.

### Merge and reuse only under a bound artifact identity

For inference, one can form a merged matrix \(W_{\mathrm{merged}}=W+A\) B under the same layout and scale, then evaluate XW_merged. In exact arithmetic this equals the unmerged formula. Floating-point rounding can differ depending on dtype and operation order, so compare actual outputs under the intended tolerance before declaring a conversion correct. A merged adapter is not another independent update to add a second time.

An adapter must be paired with the base model and tokenizer it was trained against, along with target-module names, dimensions, rank, scale and any additional trainable components. Loading factors into a different base with compatible shapes can silently change the function in an unintended way. Cache identity must also change when adapted weights change, because cached K/V states were computed under previous parameters.

A useful task comparison evaluates the frozen base, the adapted model and, when relevant, another adaptation strategy on the same held-out families and scoring contract. It reports both task outcomes and resource changes. The [original LoRA study](https://arxiv.org/abs/2106.09685) supplies the broader method, while this lesson derives a tiny actual update. It does not establish pretrained-model quality or domain expertise from a matrix-rank check.
