# Connected statistical learning tutorials

These complete reading and coding units deepen the original book without
replacing its forty chapter IDs or its method anchors. The examples use small
offline fixtures and the existing scientific packages. Each source file is
self-contained in the classroom Python pad. All explanations and answers are
available; there are no exams, submissions or hidden reference gates.

The deliberately reused nonlinear tree fixture makes forest and boosting
comparisons easier to follow. Actual XGBoost, regularization, PCA and search/CV
practice already exists in Python Days 36 to 40; the guides link those sources
where their implementation detail complements the statistical explanation.
