# Original offline teaching data

These CSV files are original synthetic fixtures generated by the maintained
`python/authoring/build_teaching_fixtures.py` script. They contain no observed
restaurant customers or historical passengers and are distributed with this
repository's Apache-2.0 license. They are not copies of Seaborn's tips table or
Kaggle's Titanic data or Palmer Penguins measurements. Their familiar column shapes let existing exercises focus
on programming mechanisms without downloading data on first use.

- `restaurant-bills.csv`: 240 generated rows with bill, tip, group size and
  categorical context. Seed 20261028. Monetary values are constructed in cents
  and written as decimal text.
- `passenger-outcomes.csv`: 360 generated rows with explicit synthetic outcome
  rules and missing observations. Seed 20261029. The generated relationship
  between attributes and outcomes is an authoring choice, not evidence about
  historical survival, fairness or any real population.
- `bird-measurements.csv`: 180 generated rows with three labelled synthetic
  measurement groups. Seed 20261030. Species names are categorical labels; the
  generated measurements are not biological observations or validated ranges.
- `manifest.json`: exact SHA-256 content identities and row counts. The loader
  validates these before returning a new DataFrame.

In the Docker classroom or a prepared contributor checkout:

```python
from ds60sqlpy.teaching_data import load_teaching_frame

bills = load_teaching_frame("restaurant-bills")
passengers = load_teaching_frame("passenger-outcomes")
print(bills.attrs["dataset_kind"], bills.shape)
print(passengers.attrs["dataset_kind"], passengers.shape)
```

The adapter has a fixed dataset allowlist, does not accept arbitrary paths and
makes no network request. It resolves reviewed course assets, including when the
calling lesson was copied into a saved pad. A returned frame can be edited
without changing the source CSV or a later call's frame. Counts, coefficients,
plots and p-values produced from these examples describe a teaching fixture;
they cannot justify real-world statistical or business conclusions.

Regenerate deliberately from the repository root, then check exact bytes:

```sh
python python/authoring/build_teaching_fixtures.py
python python/authoring/build_teaching_fixtures.py --check
```

A source/data change requires renewed notebook/reference checks and publication
of its new manifest. Do not silently replace data while retaining old receipts.
