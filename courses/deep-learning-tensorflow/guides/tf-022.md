# tf-022: Attention with an explicit information boundary

## Level and prerequisites

Intermediate; approximately 120 minutes. Direct prerequisites: `tf-021`.

## Learning objectives

Verify causal masking independently of apparent model accuracy. The central investigation is concrete: Implement one fixed attention head in TensorFlow and compare its equal-logit result with a NumPy oracle; change only future values. The finish condition is Outputs for \(V=[[2,0],[0,2],[6,6]]\) are \([[2,0],[1,1],[\frac{8}{3},\frac{8}{3}]]\) within 1e-6; future changes leave earlier rows unchanged.

## Purpose and mental model

Attention mixes value vectors using weights derived from query-key scores. A causal mask restricts each query to its current and earlier positions. The mask must act before the key-axis softmax, otherwise forbidden positions can consume probability mass or influence normalization. Equal scores make the allowed distribution easy to calculate: each legal key receives equal weight. Prefix invariance is a direct information-boundary test: recomputing a shorter prefix should reproduce the full computation early outputs. This property must hold across every decoder component, not just attention. A passing mask test cannot detect a contaminated training corpus or incorrect target shifting.

## Vocabulary and concepts

**Query:** A vector used to request information from keys.

**Key:** A vector scored against a query.

**Causal mask:** A rule excluding future positions from a query.

## Syntax anatomy and reasoning sequence

Q@transpose(K) forms query-by-key scores, scaled by square root of key width. tf.linalg.band_part constructs the lower triangle. tf.where replaces forbidden scores with negative infinity before `tf.nn.softmax(axis=-1)`. Multiplying weights by V returns one output vector per query. The supplied helper accepts only square, nonempty self-attention with matching row counts and finite data.

## Normalize only over information the prediction may use

An attention row describes one query's distribution over permitted keys.
With zero scores and three keys, an unmasked softmax gives each key one-third.
If future weights are then zeroed without renormalization, the first causal
row has mass one-third and the second has mass two-thirds. The output has been
shrunk as well as restricted. Masking scores before normalization instead
produces a proper distribution over the remaining legal positions.

The score matrix has query positions on one axis and key positions on the
other. Its multiplication by values contracts the key axis. Confusing that
axis with feature width can still produce plausible-looking numbers when
small dimensions happen to coincide. Keep dimensions distinct in at least
one diagnostic fixture and check every output shape.

Prefix invariance is an end-to-end causality property. Recomputing a prefix
alone should agree with the corresponding early outputs of the full sequence
when weights, positions and evaluation behavior are unchanged. Perturbing a
future value is a useful negative control, but attention is not the only
possible leakage path: an upstream reduction across time can also change
an earlier query or key.

A row with no permitted keys has no normalized attention distribution under
this contract. Reject it instead of converting undefined arithmetic into a
uniform distribution. Check the mask convention of the exact API you call;
some boolean masks identify permitted positions while others identify
positions to block.

## Worked example / walkthrough

### Example A: Calculate uniform mixtures

Each row averages exactly its legal values. The first row copies one vector, the second averages two, and the third averages three. No learned weights are needed to inspect the boundary.

```python
import numpy as np
import tensorflow as tf


def attention(q, k, v):
    q, k, v = (np.asarray(a, dtype=np.float64) for a in (q, k, v))
    if any(a.ndim != 2 for a in (q, k, v)) or not len(q) or q.shape[1] == 0:
        raise ValueError("nonempty matrices required")
    if (
        k.shape != q.shape
        or v.shape[0] != len(q)
        or not all(np.isfinite(a).all() for a in (q, k, v))
    ):
        raise ValueError("shape or finite contract")
    q, k, v = (tf.constant(a, tf.float64) for a in (q, k, v))
    scores = q @ tf.transpose(k) / tf.sqrt(tf.cast(q.shape[1], tf.float64))
    allowed = tf.linalg.band_part(tf.ones((q.shape[0], q.shape[0]), dtype=tf.bool), -1, 0)
    return tf.nn.softmax(tf.where(allowed, scores, tf.constant(-np.inf, tf.float64)), axis=-1) @ v


q = np.zeros((3, 2))
v = np.array([[2.0, 0.0], [0.0, 2.0], [6.0, 6.0]])
out = attention(q, q, v).numpy()
np.testing.assert_allclose(out, [[2, 0], [1, 1], [8 / 3, 8 / 3]], atol=1e-6, rtol=0)
```

**Expected:** outputs \([[2,0],[1,1],[\frac{8}{3},\frac{8}{3}]]\).

### Example B: Perturb the future

A change to a future value must not influence earlier queries. This causal assertion is more informative than a visually triangular attention plot.

```python
import numpy as np
import tensorflow as tf


def attention(q, k, v):
    q, k, v = (np.asarray(a, dtype=np.float64) for a in (q, k, v))
    if any(a.ndim != 2 for a in (q, k, v)) or not len(q) or q.shape[1] == 0:
        raise ValueError("nonempty matrices required")
    if (
        k.shape != q.shape
        or v.shape[0] != len(q)
        or not all(np.isfinite(a).all() for a in (q, k, v))
    ):
        raise ValueError("shape or finite contract")
    q, k, v = (tf.constant(a, tf.float64) for a in (q, k, v))
    scores = q @ tf.transpose(k) / tf.sqrt(tf.cast(q.shape[1], tf.float64))
    allowed = tf.linalg.band_part(tf.ones((q.shape[0], q.shape[0]), dtype=tf.bool), -1, 0)
    return tf.nn.softmax(tf.where(allowed, scores, tf.constant(-np.inf, tf.float64)), axis=-1) @ v


q = np.zeros((3, 2))
v = np.array([[2.0, 0.0], [0.0, 2.0], [6.0, 6.0]])
out = attention(q, q, v).numpy()
np.testing.assert_allclose(out, [[2, 0], [1, 1], [8 / 3, 8 / 3]], atol=1e-6, rtol=0)
future = v.copy()
future[2] = [100, 200]
changed = attention(q, q, future).numpy()
np.testing.assert_allclose(changed[:2], out[:2], atol=1e-6, rtol=0)
np.testing.assert_allclose(changed[2], [34, 202 / 3], atol=1e-6, rtol=0)
```

**Expected:** first two rows unchanged; final row [34,202/3].

## Common pitfalls and diagnosis

Inspect row sums immediately after the mask operation. If early
outputs change with future data, test the attention layer and its upstream
normalization separately. Use nonuniform scores to expose ignored queries
or keys, and unequal axis lengths to expose transposition mistakes. Reject
all-masked rows before exponentiation can produce NaNs.
