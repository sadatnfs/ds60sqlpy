# js-051: Histograms, bin boundaries and distribution shape

## Level and prerequisites

Intermediate; about 110 minutes plus independent practice. Direct prerequisites: `js-050`.

## Learning objectives

Build histograms with explicit bin boundaries and explain how bin choices and densities change the shape. The central exercise is: Build the explicit-boundary count histogram.

## Purpose, vocabulary and mental model

A histogram groups quantitative observations into intervals and displays their counts or density. The bins are numerical intervals, not arbitrary categories. Their boundaries affect the apparent distribution, especially with small samples. A meaningful histogram states the sample, units, domain and binning policy.

A bin usually includes its lower boundary and excludes its upper boundary, except the final bin includes its upper endpoint. This convention prevents double-counting values exactly on a threshold. Values outside the declared domain require a policy and should not disappear without explanation.

Count and density are different vertical quantities. With unequal bin widths, equal counts do not imply equal density. A density histogram uses height proportional to count divided by sample size and bin width, so area represents probability mass. The reference uses equal-width bins and counts to keep the first reasoning explicit.

### Key terms

- **Histogram:** A chart of counts or densities for quantitative observations grouped into adjacent numeric intervals.
- **Bin:** One interval with lower edge `x0` and upper edge `x1`. `d3.bin` returns each bin as an array of its observations, so the count is the array length.
- **Threshold:** A boundary value between bins. A value equal to a threshold belongs to the bin that starts there, and only the last bin includes its upper edge.
- **Density:** Count divided by sample size and bin width, so bar area represents the share of observations; it is needed when bin widths differ.

## Syntax anatomy and mechanism

`d3.bin().domain([0, 10]).thresholds([2, 4, 6, 8])` creates intervals with known edges. Each returned bin is an array of observations with x0 and x1 properties. The count is its length. A rectangle’s width follows x(x1)-x(x0), and its height follows the count scale.

Test boundary values explicitly. The sample `[0, 2, 2, 4, 9, 10]` produces counts `[1, 2, 1, 0, 2]` for the chosen bins. The total count must equal the number of included finite observations. This simple conservation check catches many accidental exclusions.

## Worked example / walkthrough

### Worked example 1: Inspect a threshold boundary

The value 2 belongs to the interval starting at 2.

```javascript
const bins = d3.bin().domain([0, 10]).thresholds([2, 4, 6, 8])([0, 2, 2, 4, 9, 10]);
console.log(bins.map((b) => b.length));
```

**Expected observation:** 1, 2, 1, 0, 2.

### Worked example 2: Compute one density height

Each bar's height is its count divided by sample size times bin width, so bar areas add up to 1.

```javascript
// js-051 worked example 2: a complete program for the classroom preview.
const host = document.querySelector("#chart");
const output = document.querySelector("#output");
host.replaceChildren();
const check = (condition, message) => {
  if (!condition) throw new Error(message);
};
const svg = d3
  .select(host)
  .append("svg")
  .attr("viewBox", "0 0 640 360")
  .attr("role", "img")
  .attr("aria-label", "Histograms, bin boundaries and distribution shape")
  .style("width", "100%")
  .style("max-width", "640px");
const values = [0, 2, 2, 4, 9, 10];
const bins = d3.bin().domain([0, 10]).thresholds([2, 4, 6, 8])(values);
const density = (bin) => bin.length / (values.length * (bin.x1 - bin.x0));
const x = d3.scaleLinear().domain([0, 10]).range([60, 600]);
const y = d3.scaleLinear().domain([0, 0.2]).range([320, 40]);
svg
  .selectAll("rect")
  .data(bins)
  .join("rect")
  .attr("x", (d) => x(d.x0) + 1)
  .attr("width", (d) => x(d.x1) - x(d.x0) - 2)
  .attr("y", (d) => y(density(d)))
  .attr("height", (d) => y(0) - y(density(d)))
  .attr("fill", "#2563eb");
const area = d3.sum(bins, (d) => density(d) * (d.x1 - d.x0));
check(Math.abs(density(bins[1]) - 1 / 6) < 1e-12, "Bin [2, 4) has density 1/6");
check(Math.abs(area - 1) < 1e-12, "Density areas sum to 1");
output.textContent = "js-051 worked example 2 complete";
```

**Expected observation:** Five density bars; the [2, 4) bar has height 1/6 per unit and the bar areas sum to 1.

## Six progressive exercises

### Exercise 1: Predict membership of value 2.

**Expected evidence:** It enters the bin whose lower edge is 2.

**Progressive hint:** The interval convention avoids counting one observation twice at a shared boundary.

### Exercise 2: Change thresholds while retaining the data.

**Expected evidence:** The shape changes while included total count remains six.

**Progressive hint:** Binning is a view of the same observations.

### Exercise 3: Build the explicit-boundary count histogram.

**Expected evidence:** Five bins with counts 1, 2, 1, 0, 2.

**Progressive hint:** Use x0 and x1 for geometry rather than assuming all bin indices are data values.

### Exercise 4: Diagnose a missing maximum value.

**Expected evidence:** The final boundary convention or declared domain is wrong.

**Progressive hint:** A value equal to the final endpoint should be included under the stated D3 bin contract.

### Exercise 5: Explain unequal-width bin heights.

**Expected evidence:** Density is needed when area should represent probability mass.

**Progressive hint:** Raw counts with unequal widths can mislead visual comparisons.

### Exercise 6: Compare two groups with different sample sizes.

**Expected evidence:** Choose counts or normalized density according to the comparison question.

**Progressive hint:** Counts show workload magnitude; density compares shapes.

## Debugging and common mistakes

If a maximum value disappears, check the bin domain: `d3.bin` drops values outside it, while a value equal to the domain maximum lands in the last bin. Bins are half-open [x0, x1) except the last. Sum the bin lengths and compare with the input count; with explicit thresholds every one of the six values should be counted. ([checkpoints](../STUDY-GUIDE.md#d3-debugging-checkpoints))

Exercise 4 is the controlled failure: Diagnose a missing maximum value. Distinguishing evidence: The final boundary convention or declared domain is wrong.

## Accessibility and interpretation

Label each bar with its interval and count, such as "[2, 4): 2", because readers cannot recover boundaries from bar widths alone. Say in the summary whether heights show counts or density, and offer the bin table so a screen-reader user can compare intervals directly. ([accessibility review](../STUDY-GUIDE.md#d3-accessibility-review))

A histogram's shape depends on the bin edges as much as on the data, so state the boundaries and try another choice before describing peaks. With unequal widths, use density so that area, not height, represents the share of observations. Compare groups of different size with densities rather than raw counts. ([statistical meaning](../STUDY-GUIDE.md#d3-statistical-meaning))
