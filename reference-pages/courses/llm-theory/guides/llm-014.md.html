llm-014: Capstone: a small language-model evidence notebook#

Level and prerequisites#

Beginner; approximately 180 minutes. Direct prerequisites: llm-013. The prerequisite sequence introduces the notation used here; revisit its worked examples if an axis, probability or gradient is unfamiliar.

Learning objectives#

Present a count-based model and an independently tested attention mechanism with bounded claims. The central investigation is concrete: Fit a tiny bigram baseline from local text, freeze its tokenizer/split and produce causal-mask, loss and counterexample evidence. The finish condition is Conditional probabilities sum to 1, held-out units are declared, mask/prefix tests pass, and the report does not claim foundation-model competence. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

Purpose and mental model#

Assemble a small experiment whose result can be reconstructed#

This capstone is the point where the earlier ideas become one auditable chain. Begin with a declared vocabulary and training documents. Fit a probability table using only their internal transitions. Freeze that table. Score a separate held-out sequence, retaining both its total loss and the number of targets. Finally, write a conclusion whose scope matches those observations. None of these steps requires a large model, but each will remain necessary when the fitted state contains thousands or billions of parameters.

The training documents are ABAB and AC, encoded as [0,1,0,1] and [0,2] under vocabulary order [A,B,C]. The first contributes A to B twice and B to A once; the second contributes A to C once. The count total is four. Add-one smoothing yields A's row [1,3,2]6\frac{[1,3,2]}{6}6[1,3,2]​, B's row [2,1,1]4\frac{[2,1,1]}{4}4[2,1,1]​ and C's row [1,1,1]3\frac{[1,1,1]}{3}3[1,1,1]​. Writing the denominators explicitly makes it possible to detect both missing observations and incorrectly added smoothing mass.

The held-out sequence A,C,B supplies two conditional questions. The first, C after A, receives probability 13\frac{1}{3}31​ from A's fitted row. The second, B after C, also receives 13\frac{1}{3}31​ because C had no outgoing training observations and uses the predefined uniform smoothed row. The total loss is 2⋅log⁡(3)2\cdot \log(3)2⋅log(3), the mean is log⁡(3)\log(3)log(3), and perplexity is 3. This is a complete derivation of the reported scalar from the original documents. It also identifies the mechanism responsible for the second prediction: a smoothing fallback, not a learned observation of C followed by B.

Saving the count matrix before evaluation and comparing it afterward checks that scoring did not update it. That does not prove that the holdout was never examined during an earlier design choice. The experiment therefore needs a written policy as well as state checks: what data selected the vocabulary and smoothing, what records were reserved, and what was changed after seeing results? A reproducible computation and an independent assessment are complementary properties.

The causal-prefix exercise uses a different small mechanism, cumulative averaging of [2,4,8], producing [2,3,143][2,3,\frac{14}{3}][2,3,314​]. Recomputing each prefix should reproduce the corresponding early outputs. This validates the information boundary of that averaging operation. It does not establish that the count model uses attention or that the held-out loss proves causal correctness. The notebook deliberately keeps these observations separate instead of merging several passed checks into one vague success label.

A useful final report can therefore contain both a positive result and a limitation: the count table and scoring rule produced mean loss log⁡(3)\log(3)log(3) on two held-out transitions, and the tested cumulative computation preserved its prefixes. Those are exact local observations. Two targets from one authored sequence do not establish broad predictive quality, and a three-token vocabulary does not resemble the range of ordinary language. The experiment is valuable because a reviewer can see what happened and choose the next informative comparison.

Vocabulary and concepts#

Bigram model: A next-token distribution conditioned only on the preceding token.

Smoothing: A declared rule assigning mass to unobserved events.

Token-weighted loss: Total negative log likelihood divided by active target count.

Syntax anatomy and reasoning sequence#

Initialize a square count matrix with zeros. For each document, update only adjacent pairs inside it. Add one to every cell and divide each row by its row sum plus vocabulary size. Index the probability table with held-out current/next token IDs, sum negative logs and divide by the number of transitions. Save counts before evaluation to demonstrate that assessment did not refit the model.

Work through the fitted table#

The training documents ABAB and AC create four transitions: A to B twice, B to A once and A to C once. With vocabulary [A, B, C], the unsmoothed A row is [0, 2, 1], the B row [1, 0, 0], and the C row [0, 0, 0]. Add-one smoothing changes these to [1, 3, 2], [2, 1, 1] and [1, 1, 1], with denominators six, four and three. The resulting rows are [1/6, 12\frac{1}{2}21​, 13\frac{1}{3}31​], [12\frac{1}{2}21​, 14\frac{1}{4}41​, 14\frac{1}{4}41​] and [13\frac{1}{3}31​, 13\frac{1}{3}31​, 13\frac{1}{3}31​].

The held-out sequence A, C, B contains two scored transitions. A to C has probability 13\frac{1}{3}31​ and C to B has probability 13\frac{1}{3}31​, so total negative log likelihood is 2 log⁡(3)\log(3)log(3), mean loss is log⁡(3)\log(3)log(3), and perplexity is 3. The unseen C context is handled by the predeclared uniform smoothed row. It must not be fitted from its held-out successor merely to avoid an unknown event.

Smoothing is a modeling assumption that trades some probability mass from observed transitions to unobserved ones. Adding one to each numerator requires adding vocabulary size to the denominator. Changing vocabulary size or pseudocount strength changes the model and the score, even when observed counts stay fixed. Choose that policy before using the held-out result to judge the baseline.

What the evidence notebook should preserve#

Store the count matrix, vocabulary order, document-boundary policy, active target count and evaluation sequence identity. A probability matrix without its vocabulary ordering is ambiguous: row two and column one have meaning only through the token mapping. Preserve counts before evaluation and compare afterward to demonstrate that assessment did not update the fitted state.

The baseline's transparency makes it useful for diagnosing later neural-model experiments. If a complex decoder cannot beat a simple count model under the same tokenization, split and scoring rule, investigate the task and training loop before attributing the result to model capacity. Conversely, beating this tiny baseline on two held-out transitions does not establish broad language capability. The denominator is too small to support a stable deployment conclusion, and one document cannot represent every relevant family.

A successful capstone therefore includes a bounded claim and reproducible intermediate values, not only a final perplexity. The same structure will be reused when the model has learned weights: identify fitted state, freeze assessment conditions, count the actual prediction events, and show at least one controlled failure that would invalidate the conclusion.

Worked example / walkthrough#

Example A: Fit a tiny baseline#

The end of ABAB is not linked to the start of AC. Counts describe the specified training corpus, not all concatenations of its files.

import numpy as np

docs = [[0, 1, 0, 1], [0, 2]]
counts = np.zeros((3, 3), dtype=int)
for doc in docs:
    for a, b in zip(doc[:-1], doc[1:]):
        counts[a, b] += 1
assert counts[0, 1] == 2 and counts[1, 0] == 1 and counts[0, 2] == 1 and counts.sum() == 4

Expected: AtoB2,BtoA1,AtoC1; total4.

Example B: Normalize smoothed rows#

Smoothing adds three pseudocounts to each denominator because there are three possible next tokens. Adding one only to the numerator would create excess probability mass.

import numpy as np

docs = [[0, 1, 0, 1], [0, 2]]
counts = np.zeros((3, 3), dtype=int)
for doc in docs:
    for a, b in zip(doc[:-1], doc[1:]):
        counts[a, b] += 1
assert counts[0, 1] == 2 and counts[1, 0] == 1 and counts[0, 2] == 1 and counts.sum() == 4
prob = (counts + 1) / (counts.sum(1, keepdims=True) + 3)
np.testing.assert_allclose(prob.sum(1), 1, atol=1e-12, rtol=0)
np.testing.assert_allclose(prob[2], [1 / 3] * 3, atol=1e-12, rtol=0)

Expected: row sums1; unseen C context is uniform.

Common pitfalls and diagnosis#

Inspect the count numerator, vocabulary order and smoothing denominator before interpreting perplexity. An unseen context should follow the frozen smoothing policy. Confirm the number of held-out transitions and compare the count matrix before and after scoring. A lower score under changed tokenization or a changed target denominator is not automatically a model improvement.
