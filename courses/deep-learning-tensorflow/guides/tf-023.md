# tf-023: Debugging a custom training loop

The central investigation is concrete: Build a short custom loop with one intentionally disconnected forward value, then repair it and log weights before/after each step. The finish condition is The disconnected gradient is None, not zero. The repaired first two pilot updates end at \(w=\frac{448}{225}\) within 1e-12; loss is recomputed after every assignment. A useful explanation connects the calculation to the reason it is needed, rather than treating a function name as a definition.

## Purpose and mental model

An optimization loop can run without updating the intended parameter. A forward value calculated outside GradientTape may be disconnected even when its numeric value is correct. None means no recorded path, while a zero tensor means a recorded derivative evaluated to zero. Treating both as zero hides a model-construction failure. The loop must calculate loss inside the tape, request gradients for the intended variables, reject missing gradients, apply an update and recompute the post-update loss. A logged pre-update loss and post-update weight belong to different states. Tracing with tf.function changes how Python builds operations, so debug the eager state sequence first.

## Vocabulary and concepts

**Disconnected gradient:** No recorded differentiable path to the requested variable.

**Zero gradient:** A connected derivative whose current value is zero.

**State trace:** A record of values before and after each update.

## Syntax anatomy and reasoning sequence

Use a new tape for every step. w.assign_sub(rate*gradient) mutates the tracked variable. Keep before/after weights as Python floats only for logging; converting the forward result to a NumPy value inside the loss would sever differentiation. Recompute yhat after assignment. The scalar pilot has a closed-form recurrence \(w_{\mathrm{next}}=w-0.1\cdot \frac{28}{3}\cdot (w-2)\).

## Differentiate a missing path from a stationary point

Automatic differentiation follows recorded tensor operations. Converting an
intermediate to a NumPy value or constructing a new constant can disconnect
that recorded path even when the intended mathematical expression depends
on the parameter. A None gradient means the tape did not return that
connection. A tensor containing zero is a different result: the recorded
derivative can be zero at the evaluated point.

For the scalar squared-loss fixture, the update with learning rate 0.1
contracts the residual w-2 by a factor of \(\frac{1}{15}\) on each full-batch step.
Starting from zero gives w_1=28/15 and w_2=448/225. The squared residual, and
therefore this fixed-batch loss, contracts by \(\frac{1}{225}\) per step. These exact
relationships provide a way to locate the first incorrect update without
guessing from a final training curve.

The tape normally watches accessed trainable Variables. Differentiating with
respect to an ordinary input tensor may require explicitly watching it.
A nonpersistent tape is intended for one gradient extraction; retaining a
tape for repeated derivatives has a different lifetime and memory cost.
Treat those choices as part of the loop's state contract.

Check loss and gradient finiteness before assignment. Updating a weight with
an invalid gradient can contaminate later predictions and optimizer state,
making the first failure harder to locate. Recompute the post-update loss
after the assignment; printing an earlier tensor does not measure the new
parameter state.

## Worked example / walkthrough

### Example A: Expose a missing path

The tape cannot reconstruct operations it never recorded. The numerical loss4 alone does not reveal this missing dependency.

```python
import numpy as np
import tensorflow as tf

w=tf.Variable(0.,dtype=tf.float64); outside=(w-2)**2
with tf.GradientTape() as tape: loss=outside
assert tape.gradient(loss,w) is None
```

**Expected:** gradient is None.

### Example B: Distinguish an actual zero

The path exists and its slope is zero at the optimum. Replacing every None with zero would make these semantically different observations indistinguishable.

```python
import numpy as np
import tensorflow as tf

w=tf.Variable(0.,dtype=tf.float64); outside=(w-2)**2
with tf.GradientTape() as tape: loss=outside
assert tape.gradient(loss,w) is None
optimum=tf.Variable(2.,dtype=tf.float64)
with tf.GradientTape() as tape: loss=(optimum-2)**2
g=tape.gradient(loss,optimum); assert g is not None and float(g)==0
```

**Expected:** gradient is a tensor equal0.

## Common pitfalls and diagnosis

When a gradient is None, inspect tape scope, watched objects and
NumPy/constant conversions before replacing anything with zeros. When it is
zero, inspect the evaluated point and local derivative. For a wrong second
step, verify that the gradient used the updated weight and that the reported
loss was recomputed after assignment.
