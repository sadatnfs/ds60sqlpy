# Phase 08.1 unslop audit: classroom chrome

Skill: unslop by @heydamir (CC BY 4.0), `skills/unslop/SKILL.md` with
`references/signs.md`, `tokens.md`, `visuals.md`, `effects.md` and `refs.md`.

Scope: chrome in `src/ds60sqlpy/assets/classroom.html` and `classroom.css`,
with markup, copy and glyphs also scanned in `classroom.js`,
`classroom-shell.js`, `classroom-guide.js`, `classroom-editor.js`,
`browser-sandbox.html`, `plot-sandbox.html` and `browser-preview.js`. Lesson
content, walkthrough steps, readers, `courses/**` and `curriculum/**` were not
audited or edited.

## Look

Twelve desktop (1440x900) screenshots were taken before editing, in
`work/p081/before/`: home (light, dark), command palette, Python workspace
(light, dark), Python run result, SQL workspace (runtime unavailable state),
tour offer, tour first step, walkthrough, guide (light, dark).

## Classification

Light slop, polish mode. The layout, palette and information architecture
are already deliberate (spot-color thumb tabs, Latin Modern chapters, system
grotesque chrome, paired light and dark tokens with AA contrast). The slop is
in type weight noise, tracking, a few decorative gradients and loops, an
italic serif brand mark and one display flourish in the hero.

## Direction

- Product: a local desktop classroom where a new coder reads a lesson, runs
  code against a real runtime and steps through a solution.
- Character: a quiet lab notebook with a teacher's margin notes; calm, exact,
  legible for long sessions.
- World: printed textbooks, lab notebooks, terminal output and editor gutters.
- Moments: opening a lesson, the first run, a failing run, stepping a
  walkthrough, finding the guide.
- Signature: one restrained accent for "the thing you can act on now", with
  tabular, monospace-aligned status and result counts.

## Kept on purpose

| Item | Reason |
|------|--------|
| `.map-lesson` `repeating-linear-gradient` | Functional wireframe: neutral stripes stand for lines of lesson text in the course map. No accent or tint. Commented in the CSS and allowlisted by the guard. |
| `pulse` infinite animation on `#job-status` running, `.db-status` checking/working, `.step-panel[aria-busy]` step status | Functional busy indicators. The global `prefers-reduced-motion` block sets `animation: none !important`. |
| `.tok-comment` and `.tok-emphasis` italics | Code highlighting convention and markdown emphasis inside content, not chrome. |
| "✓" folio marker in classroom.js | Plain text glyph marking a completed lesson, not an emoji icon. |
| Arrows in "← All subjects", "← Previous", "Next →" and the "↗" fallback subject mark | Directional, functional glyphs. |
| `button.primary:hover` `filter: brightness(...)` | Pinned by the check "new subject primary buttons retain readable accent fills while hovered"; it keeps AA contrast on accent fills. |
| Dark theme shadows | They separate surfaces in dark mode; flattening them lost elevation. |
| Amber border on the dark appearance button after a click | It is the focus and subject accent cue; visible focus is required. |
| Copy | No hype words, no exclamation marks and no emoji in chrome copy. `print("Hello, classroom!")` is starter code, not chrome. |
| Layout, spacing scale, palette, iconography | Already deliberate; no changes needed for this pass. |
