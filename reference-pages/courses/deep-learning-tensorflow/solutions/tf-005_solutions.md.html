Exercise 3: Expose a one-sided bias#

Expanding f(h)-f(0) gives −4·h+h·h-4\cdot h+h\cdot h. Division by h produces -4+h, yielding the three stated forward differences. Their errors are exactly h in real arithmetic, which demonstrates finite-step bias without a framework. Smaller h reduces that bias until rounding and cancellation become relevant. The symmetric quadratic check avoids this term, but the lesson is about knowing the approximation contract, not declaring forward differences invalid for every use.

Inspectable reference functions#

The core functions below make the input and reduction policies explicit. The separate executable file adds all six exercise checks. Do not replace a failed assertion with a flattering default value or remove the invalid-input case.

from __future__ import annotations
import math


def central_difference(function, point, h):
    point, h = float(point), float(h)
    if not math.isfinite(point) or not math.isfinite(h) or h <= 0:
        raise ValueError("finite point and positive finite h required")
    high, low = float(function(point + h)), float(function(point - h))
    if not math.isfinite(high) or not math.isfinite(low):
        raise ValueError("finite probe values required")
    return (high - low) / (2 * h)
