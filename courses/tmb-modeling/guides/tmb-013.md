# Deriving the Laplace approximation

Start with: tmb-012, bayes-007.

Outcome: Derive the integrated objective and test its exact Gaussian special case.

The classroom companion runs in the prepared R statistics runtime. It uses base R to expose the mathematics or data contract. Compiling and executing TMB uses the separate [owned project](../projects/tmb-local/README.md); a companion run is not a TMB compiler or rpy2 receipt.

Let \(f(\theta,u)\) be the joint negative log density and define the marginal likelihood \(L(\theta)=\int\exp[-f(\theta,u)]\,du\). For fixed \(\theta\), find the conditional mode \(\hat u\) and the latent Hessian \(H_{uu}=\partial^2f/\partial u\partial u^T\) there. A second-order expansion gives a local Gaussian shape around the mode.

If \(H_{uu}\) is positive definite, the Gaussian integral yields
\[
-\log L(\theta)\approx f(\theta,\hat u)+\tfrac12\log|H_{uu}|-\tfrac q2\log(2\pi),
\]
where \(q\) is latent dimension. The determinant term measures local volume. A narrow high peak and a broad lower peak can have similar integrated probability. Optimizing only the peak value ignores this volume and generally changes the estimator.

### Worked case A: integrating a normal density

Take \(f(u)=\log\tau+\frac12\log(2\pi)+u^2/(2\tau^2)\). The mode is zero and Hessian is \(1/\tau^2\). Substituting these into the formula gives zero marginal NLL because the normalized density integrates to one. The companion checks two different scales. This tiny calculation detects missing normalizers or a sign error in the log determinant immediately.

The Gaussian random-intercept model has a quadratic latent objective too, so its Laplace integral is exact. Increasing latent dimension does not itself make a Gaussian approximation inaccurate; non-quadratic shape, weak curvature, skewness, boundaries and multiple important modes are the relevant concerns.

### Worked case B: a non-Gaussian shape

For \(f(u)=u^2/2+\lambda u^4\), the mode and local Hessian stay at zero and one as \(\lambda\) changes. The Laplace approximation based on this local quadratic therefore stays constant, while the actual integral shrinks as the tails become more strongly penalized. The companion uses base R's one-dimensional numerical integration to expose the approximation error.

This is why a successful inner optimizer and positive Hessian do not establish accurate integration. A multimodal latent distribution is more difficult: one local mode's approximation can miss substantial mass elsewhere. Small-dimensional quadrature, simulation checks and scientifically informed alternative parameterizations help assess such cases.

### Diagnostics and answered discussion

**Can I drop the determinant because it is expensive?** That produces a different objective, not the same marginal likelihood computed faster. **Must I differentiate the mode with respect to fixed parameters?** The marginal approximation depends on both the optimized mode and curvature. TMB constructs the needed derivatives; treating the mode as a fixed external constant generally loses terms. **Can a positive determinant certify the approximation?** No. Positive definiteness and local approximation adequacy are separate requirements.

The [TMB theory paper](https://arxiv.org/abs/1509.00660) explains the automatic differentiation and sparse linear algebra behind this calculation. Keep “Laplace approximate” in the result label unless the model has an exact special-case proof.

### How the moving mode enters derivatives

The conditional mode satisfies \(f_u(\theta,\hat u)=0\). Differentiating that stationarity equation gives

\[
\frac{d\hat u}{d\theta}=-H_{uu}^{-1}f_{u\theta}.
\]

At an exact inner mode, the direct derivative of the joint objective simplifies because \(f_u=0\). The curvature correction still changes with both the fixed parameters and the moving mode. For a differentiable positive-definite matrix, \(d\log|H|=\operatorname{tr}(H^{-1}dH)\). Thus the marginal gradient is not obtained by simply evaluating the fixed-coordinate gradient of the joint density while ignoring curvature.

Sparse factorization avoids forming a generic dense inverse when solving systems with \(H_{uu}\). It does not remove the need for the mixed and higher derivatives entering the calculation. A nearly singular latent Hessian makes both mode sensitivity and determinant derivatives unstable. This mathematical failure should be diagnosed before trying to distribute the calculation across more workers.

### Complete R companion

```r
for (tau in c(.5, 2)) {
  at_mode <- log(tau) + .5 * log(2 * pi)
  marginal_nll <- at_mode + .5 * log(1 / tau^2) - .5 * log(2 * pi)
  print(c(tau = tau, nll = marginal_nll))
  stopifnot(abs(marginal_nll) < 1e-12)
}
for (lambda in c(0, .2, 1)) {
  exact <- -log(integrate(function(u) exp(-u^2 / 2 - lambda * u^4), -Inf, Inf)$value)
  approximate <- -.5 * log(2 * pi)
  print(c(lambda = lambda, quadrature_nll = exact, laplace_nll = approximate, error = approximate - exact))
}
```
